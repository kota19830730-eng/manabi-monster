# 読解（dokkaiN.js）を しらべる 道具（v14.27／v14.28）

```bash
cd manabi-quest
node tools/dokkai/chkdok.js . 5      # 小5 の dokkai5.js を しらべる（1〜6）
```

出る もの
- お話の 数・形の NG（場面 12・たからばこ 3・ボス 6・choices 4つ ぜんぶ ちがう・英字の まざり）
- **その 学年を こえる かん字**（`MQ.kakusu.upTo(字, 学年)`）と どの 文に あるか
- 場面の 文の 長さ（へいきん・さいだい）

きまり
- 小1＝かん字 0・小2＝小1の 字まで・小3〜小6＝その 学年まで（smoke の「v14.27/28 読解」と 同じ 見方）
- 教育かん字に ない 字（距離・玄関・逃げる・誰・僕・涙 など）は 小6でも ひらがな
- 直しは Write で .js の 置換スクリプトを 書いて node で 流す（sed は 日本語で こわれる ことが ある）
- 小4〜小6は 説明文（kind: 'setsumei'）を 2本 いじょう（smoke が 見る）
