## 2. まだ 決めて いない（さいしょに 1回 聞く。聞けなければ おすすめで 進めて 一言 そえる）

1. **C（夕やけ）を どう 入れるか**：おすすめ＝**本当の 時計で 空が 変わる**（朝 6〜9・昼・夕 16〜19＝C の 空・夜＝紺＋星。タイトルと バトルの 山エリア）。ずっと 夕やけに すると 青空の 明るい 印象が 消える。

3. **エリアごとの 組み合わせ**：山＝A＋B の 松と 雪山／森＝B の 木を 多く・A の 山は 遠く 小さく／湖＝水面の 板＋あし／海＝すなはま＋ヤシ＋波／空＝雲の 床＋遠くの お城（A の 城）／町＝家なみ／塔＝石の 柱＋むらさきの クリスタル。**ふつうの エリアで 城が 見えるのは A の 遠景だけ**（塔の 中では 見えない）。

## 3. 作り方（見本の コードが そのまま 土台）

- 見本は **`tools/bgmock/bgmock.js`**（アプリを さわらず harness の `|js=` で かぶせる）。`range()`（山なみ＝点の ならびを 8px の 段に・同じ 高さは 1つに まとめる）／`tree()`／`castle()`／`bird()`／`floor()`（ゆか）が ある。**これを `js/ui/scenery.js`（新・`MQ.ui.scenery`）に うつして、タイトルは `start.js` の `.title__scene` の 先頭、バトルは `battle.js` の `d.bg`（`.arena__bg`）の `.arena__hills` の 前に 入れる。**
  - タイトル：`.bgfar`＝`.title__scene` の 中・bottom 0（＝地面の 上）・z-index 0（モンスター `.tmob` は z 1〜5）。
  - バトル：`.arena__bg .bgfar`＝bottom 74px（草の 上）・`.arena__hills` は 消す・`.arena__ground` は ゆか（`.afloorwrap > .afloor`）に。
  - **モンスターの うしろに 木や 城を 置かない**（見本では 城が てきの 真うしろに 来た）：バトルの 右 120px は 遠景だけ。
- 撮る：`tools/bgmock/shotjs.sh <mode> <A|B|C> <out.png> [WxH]`（`--allow-file-access-from-files` つき）。ページは `tools/bgmock/build-page.js`。
- **軽さ**（v12.5 の きまり）：層は 3枚まで・filter なし・部品 40〜60個・`#perf3d`／`#perf3d:title` の 上位5% 20ms いか（`tools/bgmock/cdp.js <url> 9 gpu`）。山なみは 同じ 高さの 段を 1つの 四角に まとめる。ゆっくり 流す なら transform だけ。
- **読みやすさ**：バトルの 上 30% だけ。ふきだし・てきの 数・タイムの 上に 濃い ものを 置かない（遠くは 色を うすく・きりを かける）。
- 画像ファイルは 使わない（CSS の 四角だけ）。STYLE_GUIDE に「背景（v12.6）」の 節を 足す。
- 順番の おすすめ：①バトルの ゆか ②タイトル（A＋B＋時計の 空）③バトルの 山・森・塔 ④のこりの エリア ⑤地図。sw は **132** から（v12.4＝claude-f7 129・v12.5＝130・v12.5.1＝131）。news.js に v12.6。
