## 新しい bgm.js の しくみ

- **曲は 文字で 書く**：`mel: 'e5 - - . g5 - a5 -'`（`-`＝前の 音を のばす・`.`＝おやすみ・1セクション 32こ＝2小節）、`chords: 'F G Em Am'`（4つ）。ベースは 書かなければ コードから 自動（8分の ルート・さいごに 5度）。`validate()` が 32こ・コード 4つ・読めない 音を 検査（smoke が 呼ぶ）。
- **楽器**：supersaw（のこぎり 5本・フィルター 3つ・左右・下に 四角）／pluck（アルペジオ・マップの メロディ）／pad（コード）／bass（のこぎり＋四角＋サイン）／chip／brass。
- **ドラム**：kick（ドン＋カッ）・snare・clap・hat・crash・riser（ため）。パターン `none / kick / half / full / hits / roll`。
- **サイドチェイン**：pad・arp・bass は `duckBus` を 通り、バスドラの たびに 0.42 まで しずむ。
- **曲の 組み立て**：セクションごとに `pad / arp / drums / crash / riser / stab`。イントロで ため → Bメロ ロール＋ライザー → サビ クラッシュ。
- **もりあがり**：level 1＝arp と ドラムが 1段 上／level 2＝メロディを 1オクターブ下でも 重ねる・テンポ ×1.05。おこり＝ドラム full＋バスドラ 2倍・テンポ ×1.06。
- ぜんたい：master 0.78 → lowshelf +3 → highshelf +5 → comp → limiter。リバーブ 0.8秒（wet 0.26）。

## 重さ（タブレットで とぎれない ために）＝もどさない

- **`retire()`＋`sweepTrash()`**：おわった 音の 出口を disconnect（tick の 頭で そうじ）。**これを 消すと 長く 鳴らす ほど 重く なる**（16秒で 47%）。楽器を 足したら 出口を かならず `retire(出口, 終わる時刻)`。
- ビブラートの LFO は **1音に 1つ**（重ねた 波に まとめて つなぐ）。ノイズの バッファは 長さごとに 使いまわし（`noiseCache`）。
- リバーブは **0.8秒**（1.6秒だと 重さの 半分）。
- 実測：この PC で 9〜18%（サビ 約14%）。前は 2〜6%。**実機（Android タブレット）で とぎれないかは 未確認** → だめなら supersaw を 3本に・pad を へらす。
