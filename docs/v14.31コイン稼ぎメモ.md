# v14.31 かんたんな 問題で コインを 稼げないように（B＋C）

ユーザー「おうちカプセルマシンは 簡単な問題ばかりして コインを 稼げないようにしたいんだけど、壁打ちしましょう」
→ 実測 → 4案 → ユーザー決定 **「B＋C」**・上限の はじめは **1日 2回**。

## 2. 4案と えらんだ 理由

| 案 | 中身 | 判断 |
|---|---|---|
| A 学年で 決める | 自分の 学年より 下は コインが へる | **採らない**。息子さんの「小2の 国語を 復習する」が 損に なる（ユーザーが 大事に している 使い方）。同じ 学年の中の かんたんステージにも 効かない |
| **B ★3 ずみは へる** | まだ ★3 でない／はじめて＝満額、★3 ずみの くり返し＝1まい | **採用**。復習を 罰しない・学年に 関係なく 効く |
| **C 1日 N回まで** | おうちマシンを 1日 N回に（親が 決める） | **採用**。稼ぎの 速さを ごほうびに 変えられなく する |
| D 専用の メダル | おうちの ごほうび だけ べつ通貨 | 採らない（通貨 2つは 小3に ややこしい・2〜3日） |

## 4. 効きめ（実測）

**小1 さんすう1 を 20回 くり返す（稼ぎ方）**

| | たたかいの コイン | レベルアップの コイン | 合計 |
|---|---|---|---|
| 直す 前 | 79.7 | 38.5 | 118.2 |
| 直した 後 | **23.0** | 38.5 | **62.3** |

**ふつうに 進めて いる 子**（はじめての ステージを 6つ 1回ずつ・30回 くり返して へいきん）

| | コイン |
|---|---|
| 直す 前 | 22.7 |
| 直した 後 | **22.7（まったく 同じ）** |

→ **ふつうに 遊ぶ 子には 1まいの 影響も ない。** 止まるのは くり返し稼ぎだけ。

**ごほうび 30まいに とどくまで**：新しい ステージを 進める 7.6回（いままで どおり）／
★3 ずみを くり返す 30回。**＋ 1日 2回の ふた。**

## 5. のこって いる こと（正直に）

**レベルアップの コインは ふたの 外**。EXP は へらして いない ので、
かんたんな ステージを くり返しても レベルは 上がり、コインが 出る。

**20回 くり返した ときの レベルアップの コイン**（EXP 約7600）

| スタート | 上がる レベル | コイン | むりょうけん |
|---|---|---|---|
| Lv.1 | → Lv.17（+16） | 40 | 3 |
| Lv.10 | → Lv.19（+9） | 27 | 1 |
| Lv.20 | → Lv.26（+6） | 24 | 1 |
| Lv.30 | → Lv.34（+4） | 20 | 0 |
| Lv.50 | → Lv.52（+2） | 10 | 0 |

**わざと のこして ある**：
- EXP を へらすのは 学びそのものを 罰する ことに なる（復習も 予習も 価値が ある）
- レベルは 上がるほど 高く なる＝**自然に 頭打ち**（Lv50 では 20回 くり返して 10まい）
- **1日 2回の ふた（C）が さいごの 守り**＝どれだけ ためても その日の ごほうびは 2つまで

ミッション（1日 5まい）・つづけた日（1〜3まい）も ふたの 外だが **1日 1回きり** なので 稼げない。

## 6. もどさない きまり

- **学年では 見ない**（A案を 採らなかった 理由＝復習を 罰しない）
- **へらすのは コインだけ。** けいけんち・そうび・図かん・たからもの・ぴかぴか・なかまは そのまま
- **0まいに しない**（`MASTERED_MAX = 1`）。ぜんぶ 取り上げると ばつに なる
- ごちゃまぜ・とっくん・さいごの塔には かけない
- `canPull` は **上限を コインより 先に** 見る（「30まい ためたのに まわせない」より
  「きょうは もう おしまい」を 先に 言う）
- 子どもの 画面に「にがて」「ずるい」と 書かない。けっか画面の 1行は **青**（赤い ばつに しない）

## 7. たしかめ方

```
node tools/smoke.js .        → 「コイン稼ぎの ふた（v14.31）」の 節
harness #result4             → ★3 ずみの けっか画面（1行・コインの ふえ方）
harness #prizemc             → 子どもの マシン（「きょうは あと N かい」）
harness #prizemc:limit       → 上限まで まわして「きょうは おしまい」
harness #prize:edit          → おうちの人の「1日にまわせる回数」
```

**わな（この 作業で 踏んだ）**
- smoke の IIFE の 中で `base` という 名前を 作らない（`const base` を かくして 落ちる）
- `node -e` の JS に `$$(...)` を 書かない（bash が 展開して 消える）→ Write で .js に
- **カプセルを 2回 つづけて まわす ときは `MQ.ui.capsuleFx.next()` を よぶ**。
  `skip()` は「出た ところ」まで しか 進めず、`rolling` が true の まま つぎが まわせない
- 既存の prize smoke は 10回 いじょう まわす ので `Z.setLimit(p, 0)` で 上限を 外す

数える 道具（scratchpad）：`coinfarm.js`（ステージ別）／`coinbreak.js`（内わけ）／
`effect1431.js`（前後の くらべ）／`lvcoins.js`（レベルアップの コイン）／`check1431.js`（ルール）
