# v14.51 かん字の 書き問題：線が たりない・多い を 見分ける（2026-10-11）

## きっかけ
ユーザー「間違った漢字を書いても正解判定がでます。線が1本少ないとかなら正解になる模様」。

## 数えた こと（直す 前）
- `#judgenear`（線が 1本 ちがう 字の 組み 36こ × 4＝144回：目←日・白←日・犬←大・本←木・玉←王・自←目 など）
- **ちがう 字なのに そのまま ○ 47%・見くらべ 53%・× 0%**。
- わけ：形の 点数（8×8 の 向き＋6×6 の こさ）は 字ぜんたいの にかたを 見るので、1本 ぬけても 0.9 ちかく 出る。
  画数の ルールも「半分 より 少ない」だけ だった。

## 直した こと（`js/core/handwrite.js` の `strokeDiff`）
1. 書いた 字を おてほんに かさねる。**かたむき・ななめ・たてよこの のび・ずれ を さがして いちばん かさなる 形に 合わせる**
   （かさね方を 合わせないと、7度 かたむいた だけで 正しい字が ずれて 見えた＝正しい字の 3わりが ×）。
2. かさねて、
   - miss＝おてほんの 線なのに 近く（3マス）に 書いた 線が ない ところ（線が たりない）
   - extra＝書いた 線なのに 近くに おてほんの 線が ない ところ（線が 多い）
   の **いちばん 大きい かたまりの 長さ（48 に 対する）と 量**を はかる。
3. はんてい（1字の ときだけ。「学校」の ような ことばは 線が つぶれる ので 見ない）：
   - **はっきり ちがう**（長さ 0.13・量 3.5% いじょう／多い は 長さ 0.12）→ **×**「おしい！ 線が たりないみたい」
   - **あやしい**（長さ 0.10・量 1.8% いじょう）→ ゆびの 画数も 合わなければ ×、合って いれば ○に せず 見くらべ
4. おうちの人ページの きびしさで 倍率（やさしい 1.25／ふつう 1／きびしい 0.85）。

## 結果（`#judgenear`・2回）
| | 直す 前 | 直した あと |
|---|---|---|
| 線が 1本 ちがう 字 → ○ | 47% | **7〜9%** |
| 線が 1本 ちがう 字 → × | 0% | **80〜81%** |
| 正しい字 → ○ | 98% | 91〜94% |
| 正しい字 → × | 0% | **2%**（見くらべ 5〜7%） |

のこる のは とても 小さな ちがい（休←体・本←木・申←中 など）。これは 見くらべ か ○ に なる ことが ある。
1回の はんていは PC で 約30ms（タブレットで 0.1〜0.2秒）。`#judge`（なぐりがき・べつの字）も くずれて いない。

## たしかめ方
- `#judgenear`（似た 字の 組み・正しい字の 当たり方・のこった 字の 名前・1回の 時間）
- `#judgeone:<字>`（フォントごとの 数字）
- `#write2` を 何回か（本物の バトルで 正しい字 → ○。右上に 書いた 字の 写し）

## もどさない
- かさねる 前の 合わせ（かたむき・ななめ・たてよこ・ずれ）を 外さない（外すと 正しい字が 3わり ×）。
- 試験は フォントの 字なので、**本物の 子どもの 字では 未確認**。正しく 書いたのに × が ふえたら、
  まず おうちの人ページで「やさしい」に し、こまかい 数字は `strokeDiff` の しきい値で。

## v14.53 きびしすぎた ので 直した（2026-10-12）
ユーザー「判定が 厳しすぎる。小学生が 正解できる 程度で。大人の 僕でも 正解判定 出なかった」。
- わけ：v14.51 は **フォントの 字（太くて 形が そろった 字）**で 校正した。手書きの 細い 線・ゆがみを
  「線が たりない」と 見まちがえて、正しく 書いても × に なった。
- 直し（`judge`）：**ゆびで 書いた とき（本物の 画面は いつも）は、画数が 合って いれば 線の ちがいでは × に しない。**
  画数が たりない うえに たりない 線が はっきり 見つかった とき（または 多い うえに 多い 線）だけ ×。
  あやしい だけなら 見くらべ。線の ならびが ない とき（テストの 字）は はっきり ちがう ときだけ ×。
- ○の しきい値も 下げた：ふつう 0.85 → **0.82**（やさしい 0.78・きびしい 0.88）。
- なぐりがきは「なぐりがき」の ことばを 先に（線が たりない より 先）。
- `#judgenear:hand`（細い フォント・ゆがみ 大・かたむき ±10・画数つき）：
  正しい字 ○ 94%・× 0%／線が 1本 ちがう 字 ○ 11%・× 67%。`#judgenear:hand:0.80` で しきい値を ためせる。
- **本物の 子どもの 字では まだ 見て いない**。きびしければ おうちの人ページの「やさしい」。
