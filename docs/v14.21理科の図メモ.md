# v14.21 理科の「ようすを 思いうかべる」単元に 図

2026-09-23。ユーザー「理科からお願い」（v14.20 で 理科・社会に 図を 入れた あと、
「あとは大丈夫？歴史とかさ」→ 数えて「歴史より 先に 理科」と 答えた その つづき）。

## 1. なぜ この 単元を えらんだか（数えた 結果）

v14.20 の あと、理科・社会の 全ステージで 図の わりあいを 数えた
（scratchpad の `hist.js`＝smoke の 読みこみ部分を vm で 借りて `st.make(12, {})` を 60回）。

**図が 0% の まま のこって いた ところ**のうち、**「ようすを 思いうかべる」問題が 多い**のは 理科だった。

| 学年 | 単元 | 問題の 種類 | 図に した 数 |
|---|---|---|---|
| 小6 | てこ | 12 | 7 |
| 小6 | 大地のつくり | 16 | 3 |
| 小6 | 月と太陽 | 16 | 2（いまの `moonQ` を 流用） |
| 小5 | ふりこ | 11 | 5 |
| 小5 | 電じしゃく | 12 | 5 |
| 小4 | もののあたたまり方 | 11 | 6 |
| 小4 | 空気と水 | 20 | 6 |
| 小4 | 水のすがた | 20 | 2 |

**合計 36問**（理科ぜんたいの 図つきは v14.20 の 16問と あわせて **52問**）。

### つけなかった ところと その わけ

- **水よう液（小6・10問）／もののとけ方（小5・16問）** … リトマス紙・ろ過・メスシリンダー など
  **道具の 絵が そのまま 答えに なる**（v4.9 の きまり）。とける量の グラフも 答えそのもの。
- **歴史（小6 社会・96問）** … 問い方の 87% が 人物・時代・名前の 暗記
  （だれ 19／いつ 26／ことば 16／その他 30／なぜ 4／どこ 1）。
  「縄文時代の 人々が 住んで いた 家を 何と いう？」に たて穴住居の 絵を つけると 答えが ばれる。
  **つけられるのは 年表だけ**（「いつ」26問・聞かれて いる 時代を「？」に して 位置だけ 見せる）＝ まだ やって いない。
- **てこの 道具（はさみ・くぎぬき・せんぬき）／ピンセット** … 支点の 場所を 描くと 答えに なる。
- **ふりこの「長さとは どこから どこまで？」** … 長さの 矢じるしを 描くと 答えに なる
  → **`pendulumQ(..., 'plain')`（矢じるしなし）**を つかう。smoke が 見て いる。

## 2. 足した 図（`js/content/zu.js`・24とおり）

| 呼び方 | すがた | つかった ところ |
|---|---|---|
| `leverQ(text, mark)` | てこ（おもり・台・おす 手）。`mark` が `'fulcrum'｜'effort'｜'load'` の ときは **その 点だけ 赤い ？**（名前は 書かない）、`'all'` の ときは 3つとも 名前つき | 小6 てこ 5問 |
| `balanceQ(text, l, r)` | 実験用てこ。うでに 1〜6の 目もり、わかって いる 重さと **「？g」** | 小6 てこ 2問 |
| `pendulumQ(text, kind)` | ふりこ。`'plain'`／`'parts'`（長さ・おもり・ふれはば に 名前）／`'two'`（25cm と 100cm） | 小5 ふりこ 5問 |
| `coilQ(text, kind)` | 電じしゃく。`'plain'`／`'coil'`（まいて ある ところに ？）／`'core'`（中の ぼうに ？）／`'series'`（かん電池 2こ） | 小5 電じしゃく 5問 |
| `strataQ(text)` | 地そう（6だんの しま模様・**字は 書かない**） | 小6 大地のつくり 2問 |
| `heatQ(text, kind)` | `'bar'` 金ぞくの ぼう／`'plate'` 金ぞくの 板（上から）／`'water'` ビーカー／`'boil'` ふっとう／`'cold'` 冷たい コップ／`'room'` へやと ストーブ／`'bath'` おふろ。**熱の つたわる 矢じるしは 描かない** | 小4 あたたまり方 6問・水のすがた 2問 |
| `airQ(text, kind)` | `'gun'` 空気でっぽう（前玉・後玉つき）／`'air'`／`'water'`／`'both'` ちゅうしゃき | 小4 空気と水 6問 |

＋ 前から ある `moonQ`（小6 月と太陽 2問）と `riverQ`（小6 大地のつくり 1問）を 流用。

### 共通の きまり

- **答えは 図に 出さない。** 名前を 聞く 問題では **場所だけ 赤い ？**で 教える
  （v14.19 の 二重数直線と 同じ 考え方）。
- **矢じるし（熱の 向き・力の 向き）は 描かない。** それが 答えに なる。
- 大きさは `box(inner, 140, 100)`（`.figbox` が 4:3 なので 回路の 図と 同じ）。
  100×100 の ものは `box(inner)`。
- **SVG の 字は かならず 書体を 書く**（`tx()` が `font-family="serif"` を 入れる）。
  ないと 見出し書体に なって 字が □ に なる（v14.19 の 実測）。
- 理科・社会は ぜんぶ `choice` の 問題なので **`scratch: false` は いらない**
  （メモ欄が 出るのは number / divrem / roma だけ＝`js/ui/battle.js` の `useMemo`）。

## 3. ついでに 直した ことばの バグ（前から あった）

学年ごとの ことば変換（`js/content/kotoba.js`）で、図を つけた 問題の 文が こわれて いた。

| もとの 文 | まえ | あと |
|---|---|---|
| しま模様に 重なった… | 小1〜小6 **「島模様」** | しま模様（そのまま） |
| 空気でっぽうの… | 小1 **「そら気でっぽう」** | くうきでっぽう |
| 川の 曲がった… | 小1・小2 **「きょくがった」** | まがった |

`kotoba.js` に `['しま模様', 'しま模様']`（さわらない ことば）・`['くうき', '空気']`・
`['ま', '曲', 3, 'がる|がった|がって|がり|…']` を 足した。
**`['ま', '曲', …]` を 足す ときは 「まが」「まげ」で grep して 全部が 本当に 曲か 見る**
（かまが・あまがさ・きまがわ などは 送りがなが ちがうので 当たらない ことを 確かめた）。
