## 見た目の きまり（この 画面だけ）

- **子どもの 画面とは 別の 画面**（`#screen-parent`・`js/ui/parent.js`）。HUD も タブも 出さない。
- 明るい 紙色（#f4f2ec）の 地・白い カード（#fffdf9・角丸 16）・線 #e7e2d7。**アクセントは 金 1色**（#c98c12／文字 #a8741a）。
  状態の 色：よくできる #2e8b3f／ふつう #d99a1e／苦手 #c8413b／まだ #a9a396。
- 文字：見出し・数字 **Zen Kaku Gothic New**（700／900）、本文 **BIZ UDPGothic**（Google Fonts・オフラインは 端末の ゴシック）。
- **文体は 大人向け**（漢字・です・ます）。小3向けの「ひらがな＋文節スペース」は この 画面だけ 外す。
- ボタン：黒（#26231f）の 主ボタン 1種類 ＋ 白い 副ボタン。ゲームの 3D ボタン・光沢は 使わない。
- アイコンは inline SVG（線・20px）。絵文字なし。
- 設定の 部品（学期・フィーバー・かん字の 採点・きろくの 保存・AI）は 図かんの ものを そのまま 借り、`.pp-legacy` の CSS で 明るい 見た目に そろえる。

## 画面

1. **ホーム**（`home`）：子どもの 画面へ／設定 → 学習レポート・名前・学年 → 今週／今月／すべて →
   3つの 数字（解いた 問題・正答率・学習した 日＋曜日の 点、先週との くらべ）→ 14日の 棒グラフ →
   **気になるところ**（さいきん 5問いじょう・70% 未満・3つ・タップで くわしく）→
   **成長のようす**（8週の 折れ線・はじめ→いま・±ポイント・身についた 単元 いま／先月・1問の 時間 今月／先月）→
   **伸びたところ**（今週と 先週で 上がった 単元 2つ）→ **単元ごとの 正答率**（教科ごと・6行＋「残り N単元を見る」）→
   先生に見せるレポートを作る／文字でコピー。
2. **単元の くわしい 画面**（`detail`）：教科・学期・単元名・％・これまで・最後に 学習 → どこで つまずいて いるか（こまかい 単元）→
   まちがえた 問題（多い 順・子どもの 答え／正しくは・「N回まちがい・M回正解」）→ **この単元を練習させる（6問）**（`MQ.ui.battle.startDrill`）。
3. **設定**（`settings`）：学校で ならった ところ／フィーバー教科／かん字の 採点／きろくの 保存／AI／この子の 記録（名前・学年 `MQ.save.setGrade`・消す）。
4. **先生に見せるレポート**（`report`）：画面で 見る プレビュー ＋ **印刷・PDFにする（A4）**（`reportHtml` を 新しい タブに 書いて `print()`）＋ 文字でコピー。
   A4 は 白黒でも 読める ように ◎○△ を 併記。「アプリからの見立て」は データから 自動で 文を 作る（`MQ.stats.report().notes`）。

## しくみ（v7.1 の stats に 足した もの）

- `core/battle.js`：`s.qAt`（問題を 出した とき）→ `results[].sec`（1問に かかった 秒）。
- `core/stats.js`：`p.stats.days['YYYY-MM-DD'] = { n, ok, t, u: { stageId: [ok, n] } }`（400日ぶん）。
  `period(p, 'week'|'month'|'all')`（今週＝日曜はじまり・先週との くらべ・曜日の 点）／`daily(p, 14)`／`weekly(p, 8)`／
  `growth(p, grade)`（first→last・delta・masteredNow／Prev（30日前 までの 記録で 85%〜）・secNow／Prev）／`improved(p, grade, 2)`／`report(p, grade)`。
  テスト用 `setNow`。
- `ui/dex.js`：おうちの人タブを 消し、`render('parent')` は `MQ.ui.parent` へ。設定の 部品は `MQ.ui.dex.sections`（terms / fever / judge / ai / records）。
- `ui/map.js`：「おうちの人」ボタン → `MQ.ui.parent.open('home')`。
- 古い「たんげんごとの できぐあい」「ぼうけんの きろく」の 一覧は 出さない（データは 残る）。
