# v14.15 ラスボスを 強く（2026-09-21）

ユーザー「**ラスボスが 弱すぎる。むすこが 30秒ぐらいで 終わるから もっと 歯ごたえが ほしい**」→ 壁打ち。

## 1. まず 数えた（ラスボス戦を 400回ずつ 自動で たたかわせた）

| | 問題数 | 勝率 |
|---|---|---|
| **ふつうの ステージ 1回**（ザコ12＋たからばこ＋ボス・正答90%） | **18.4問** | — |
| ラスボス戦（そうびなし・正答80%） | 8.3問 | 100% |
| ラスボス戦（相棒＋やみ一式・正答90%） | 6.9問 | 100% |
| ラスボス戦（＋ばくれつ・正答90%） | 6.5問（最短 5問） | 100% |
| **本気モード**（やみ一式・正答80%） | 8.0問 | **100%** |

**ラスボス戦は ふつうの たたかいの 3分の1の 長さだった。**
ラスボスには ザコが 出ないので、ボスの 6〜8問で ぜんぶ おわる。「30秒」は 正確な 体感。

### 弱い 原因（3つ＋1）
1. **短い** — HP 9・さいだい 14問。14問 使いきる 前に たおれる。
2. **1発が 大きすぎる** — カウンター 2／弱点 2／すきだらけ 2／セットわざ 2／相棒 +1 が かさなって
   **1回の 正解で へいきん 1.4ダメージ**。HP 9 は 実質 6〜7発。
3. **まちがえても 損が ない** — 2回めの 正解も 1ダメージ 入る。だから 正答 60% でも 勝率 100%。
4. **本気モードが ラスボスには 効いて いない** — 14問 も あるので 2回めが ガードされても 足りる（実測 100%）。

## 2. ユーザーの 決定（AskUserQuestion）

- **長さ**：20問前後（2〜3分）＝ふつうの たたかいと 同じくらい
- **しかけ**：**B 1回めの 正解だけ ダメージ**／**C 3つの 形態で たたかい方が 変わる**／**D 手下の ザコが 出る**
  （E 四天王の 前哨戦は 入れない）
- **本気**：えらびは のこす。**本気を もっと 強く**

## 3. 作る もの

### 3-1. 流れ（D・20問前後）
```
手下 4体（4問）→ 中ボス 1体（2問）→ ラスボス（約14問）＝ 合計 約20問
```
- 手下・中ボスの 問題は 塔の ステージの `make(n, { boss: false })`（教科が じゅんに まわる）。
- 手下の 絵は **その 問題の 教科の rank3 の ザコ**、中ボスは `MQ.enemies.midFor(教科)`。
- たからばこは 出さない（塔は ごほうびの 場所では ない）。

### 3-2. ラスボスの つよさ（BOSS_SET.tower）
| | いま | v14.15 |
|---|---|---|
| bossHp | 9 | **14** |
| bossMax | 14 | **20** |
| enrageAt | 6 | **9**（第2形態） |

### 3-3. B：1回めの 正解でしか ダメージが 入らない（ラスボスだけ）
- 2回めの 正解は **ダメージ 0**（`blocked`）。**けいけんちは 入る**＝ばつでは ない。
- いままで これは 本気モードだけの ルール（`s.bossHard && wasRetry`）。
  → **`s.lastStrict`（塔は いつも true）** に する。
- 相棒の 追い打ち・ばくれつは いままでどおり 通る／のこる。

### 3-4. C：3つの 形態で たたかい方が 変わる
| 形態 | いつ | ルール |
|---|---|---|
| 第1 | HP 14〜10 | ふつう |
| **第2（おこる）** | HP 9〜5 | **ガード**：1回めの 正解が **2問 れんぞく**しないと ダメージが 入らない（1問めは「ガードされた」・2問めで まとめて 2ダメージ） |
| **第3（さいごの 力）** | HP 4〜 | **毎問 ため**（カウンターの チャンス＝1回めの 正解で 2ダメージ）。そのかわり まちがえると 0 |

- 第2形態は「コンボ勝負」で **おそく なる**、第3形態は「一気に つめる」で **速く なる**＝おわりが もりあがる。
- 見た目の 変化（`enrage` / `final`）は もう ある ので それに のせる。

### 3-5. 本気モード（もっと 強く）
- ボスの **HP 1.5ばい**（14 → 21・さいだい 問題数は 同じ 20）
- 第2形態の ガードは **3問 れんぞく**
- ガードくだきが 本当に こわれる（いままでどおり）・けいけんち／コイン 2ばい（いままでどおり）
