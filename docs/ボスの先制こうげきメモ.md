## ボスの 大わざ（6しゅるい）

| わざ | ボス | 光 |
|---|---|---|
| fire ほのお | ナンバードラゴン（ほのおの ブレス）・まおう・かいぞく（たいほう） | 口に 火が たまる → 3D の ほのおが 主人公へ → 大ばくはつ・けむり |
| bolt かみなり | ビリビリナマズ・メカナイト・アルファグリフォン | 体に 電気 → 口から いなずま → 空から 2本 |
| ice こおり | アオミズチ（みずの ブレス）・ブリザードキング | こおりの つぶて・結晶 → 足もとから 氷の 柱 |
| slash 大ぎり | モジオニ・ハニワショーグン・カラステング・ダークロード | 赤い 気 → つっこんで X の 大ぎり・つめあと |
| quake じしん | イワサイドン・グランドタイタン・キングスライム・プリンススライム | 地ひびき → 体当たり → 足もとが われて 岩 |
| dark やみ／gold こばん | ナンバーマジン・フデダヌキ・おばけキング・メイオウハデス／コバンネズミ | 玉を ためて ぶつける → やみ（小判）の ばくはつ |

- どの ボスが どれかは `js/ui/battle.js` の **AMB_STYLE**（[わざ, 名前, 口の よこ, 口の たて]）。**ボスを 足したら ここにも 1行**（smoke が ボス ぜんぶを 見る）。
- 光は **`js/ui/bossfx.js`**（`MQ.ui.fxc.define('amb-<わざ>')`・fxcanvas.js の あとに 読む）。時間は ため 0 → はなつ／つっこむ 450 → 当たる 750（`IMP` と battle.js の `STRIKE`）。
- 空の 色は `.arena__spsky[data-sp="amb-<わざ>"]`・ため の 光は `.ambushaura--<わざ>`（css/style.css の さいご）。音は `MQ.sfx.amb_<わざ>`・`ambushWarn`・`ambushSmash`。

## しくみ

- core：`MQ.battle.bossAmbush()`（1回だけ・{ kind: 'broke'|'crack'|'none', type, need } か null）・`attacksOn()`。
- 画面：`ambush(then)`（bossIntro／towerIntro）→ `bigStrike()`、まちがい → `counterStrike()` → `mobStrike(hit, mid)`。
- 2D も 3D も `.enemy` ごと 動かす（`is-windup` → `is-rush`（つっこむ・--rush）／`is-cast`（はなつ））。主人公は `.hero.is-smashed`（ザコは `--lite`）。
  3D の 図に filter を かけない（ため の 光は べつの 要素）。keyframes は transform と opacity だけ。
