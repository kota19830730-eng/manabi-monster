# 実機チェックリスト（v11.1・約50分）

息子さんの Android タブレット（あれば iPad も）で 上から 順に。○×と 一言メモを 残す。
×の ときは「**何を したら・どう なった**」を 一言＋できれば スクリーンショット。
終わったら おうちの人ページ → せってい → いちばん 下「こまったとき・感想を送る」→
「文字でコピー」を LINE で 送る。

> **なぜ 今 やるか**：**v2.6（sw 38）を さいごに、85版ぶん 実機で 見て いない**。
> 見た目（HD・96マス）も カプセルマシンも 小4〜小6も、ぜんぶ PC の 中でしか 見て いない。
> 同級生に 配る 前に、ここを 1回 通す。
