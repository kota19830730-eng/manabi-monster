# 実機チェックリスト（v7.6・約40分）

息子さんの Android タブレット（あれば iPad も）で 上から 順に。○×と 一言メモを 残す。
×の ときは「何を したら・どう なった」を 一言＋できれば スクリーンショット。
○×を 押して 残せる ページ（アーティファクト）も ある。終わったら「結果を 文字で コピー」を Claude に 貼る。

- [ ] **学年チップ**：小1 → 小2 → 小4 → 小5（小6は 準備中）→ 4つとも 地図が 出る・見た目が ちがう・小5は 6エリア → 小3に もどす。
