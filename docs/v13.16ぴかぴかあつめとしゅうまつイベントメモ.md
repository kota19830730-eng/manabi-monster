## ③ ぴかぴか あつめ（`js/core/pika.js`・`MQ.pika`）

たからものは ★3（＝パーフェクト・にげた てき 0）で 金色（ぴかぴか）に なる（v1.2 から）。
でも 見えるのは メニューの たなの 中だけで、**地図から「どこが まだ ぴかぴかで ないか」が わからなかった**。
→ 見せて、もう一度 パーフェクトを めざす（＝ふくしゅう）きっかけに する。

| どこ | 何を 見せるか |
|---|---|
| 地図の ステージ | ボスから もらった たからものを ブロックの 左上に 小さく（`.node__tr`）。金色なら 金の わく＋✦ |
| 地図の ゾーン見出し | 「✦ 2/18」＝ぴかぴかの 数 / 開いて いる ステージ（`pikaChip`）。ぜんぶ 金なら **金の かんむり** |
| メニュー「もちもの」 | たなの 上に「ぴかぴか あつめ」の カード（`pikaCard`）：ぜんぶの 学年の 数・つぎの むりょうけんまでの バー・教科ごとの 点の ならび（金／白＝ふつう／かげ＝まだ） |
| けっか画面 | 1行だけ（`pikaRow`）：5こ たまった → 「ぴかぴか 10こ！（券）むりょうけん ×1」／ふえた → 「ぴかぴか 7こめ！ あと 3こで むりょうけん」／ボスは たおしたが ふつうの まま → 「パーフェクトで この たからものが ぴかぴかに！」（金の 絵つき） |

ごほうび：
- **ぴかぴかを 5こ あつめる たびに カプセルの むりょうけん 1まい**（`claim`）。カプセルを かくして いる 子は コイン 10（levelup.js と 同じ）。
- 数えるのは **ぜんぶの 学年の ぴかぴか**（たからものの id は 学年を またいで かぶらない）。
- 2回 もらわない：`p.pikaPaid`（はらった 数。5こで 1）。**もう あそんで いる 子は いまの 数まで はらった ことに する**（これまでの ぶんは なし。v13.15 で むりょうけんを もう わたして いる ので）。
- しょうごう「ぴかぴか マスター」（20こ）＝ **58種**。
- 金の かんむりは 見せる だけ（ごほうび なし）。学期で ステージが ふえると また 金で なく なる ことが ある（それで よい）。

## ④ しゅうまつ イベント（`js/core/weekend.js`・`MQ.weekend`）

**土よう日と 日よう日だけ**、週ごとに かわる 4つの まつりの どれか：

| まつり | 中身 | しくみ |
|---|---|---|
| ゴールデン まつり | ゴールデンスライムが かならず 1体 出る・たおすと コイン 3まい（ふだんは 1まい） | ui が `rareId` を ゴールデンに（3きょうだいより 先）・core の `goldenCoins` |
| たからばこ まつり | たからばこが 2こ・あけると コイン 2まいずつ（ふだんは 1こ・1まい） | core の `chests` / `chestCoins`（2こめは id に `:1`） |
| なかま まつり | なかまに なりたがる 見こみ 2ばい（上は 6わり）・相棒の けいけんち 2ばい | `pals.offerFrom(p, ids, rnd, mul)`・ui の applyRewards |
| コイン まつり | たたかいの おわりに コイン +3 | core の `summary().weekendCoins` |

- **どの まつりかは 日づけだけで 決まる**（月よう日はじまりの 週の 番号 % 4。**2026-09-14 の 週が 0＝ゴールデン**＝公開して はじめての しゅうまつ 9/19・20 が ゴールデン）。
  だから 平日の 予告「こんどの しゅうまつ ○○まつり」は **かならず あたる**（v8.3 の きまり「予告した ものは かならず 出す」・smoke が 400日ぶん 検査）。
- 出る ところ：ふつうの たたかいと ごちゃまぜ だけ（**とっくん・さいごの塔・タイムアタックは なし**）。
- **ばつは ない**・平日に へる ものも ない。効果は たたかった とき・正解した とき だけ（大原則）。
- 画面：
  - 土・日の はじめての 地図で **ポップ 1回**（`weekendPop`・`.bagcard`・しゅうまつごとに 1回＝`p.weekendSeen` に 週の かぎ）。はじめての 子（battles 2 みまん）には 出さない（「できる ことが ふえた」が 先）。お知らせ・塔の ポップが 出て いる ときは つぎに まわす（`goMap`）。
  - 地図の すみに むらさきの **ふだ**（`.wkchip`・てがみ／にげた敵と 同じ 場所）。押すと ポップ。
  - 上の 帯の パネルに 1まい（`weekendPanel`）。**平日は 予告**（「こんどの しゅうまつ（あと 5日）」・金よう日は「あしたから」）。
  - バトルの 1問めの 帯（`modebanner--wk`）・けっか画面の 1行（`.rs__wk`。ふえた ものが ある ときだけ）。
- おうちの人ページ（設定 → フィーバーの 節の いちばん 下）で **つける／なし**（`p.weekendOff`）。
- コインの 目安：1回 ＋2〜3まい（1日 3回で ＋6〜9。ふだんは 1日 約18まい）。
