### ② なかま分け（`GROUPS` / `KIND_GROUP`）

85しゅるいを そのまま ならべると さがせない ので、**いきもの／むし／おばけ・ひと／もの・のりもの／しぜん**の
5つに 分けた。「ほかの すがた」の 一覧は この 見出しつきで ならぶ（`MQ.monsterGen.groups` / `kindGroup(kind)`）。
一覧の 枠は 高さ 300px の スクロール。

### ③ はこの 中の 生きもの（v5.7）の 見わけを 安定させた

`photo.js` の `innerFigure`。**同じ 絵なのに 出たり 出なかったり**した（3回に 1回 ミミックが 出ない）。
原因は「かこまれた ところ（enclosed）が 1% いじょう」の 条件。
**えんぴつで ぬりつぶした 生きものは ほとんど 線に なる ので、かこまれた ところが ほぼ 0**に なる。
→ **奥の 線（reach から 5px より 遠い ink）が 3.5割 いじょう なら それだけで OK**に した。
（`deepN >= inkN * 0.35 || (deepN >= inkN*0.2 && enclosed >= 1%) || enclosed >= 8%`）
外がわの 見わけ（色の ついた 辺が 3つ いじょう）は そのままなので、ふつうの 絵は これまで どおり 素通り。
→ 4回 まわして 4回とも ミミックが 1番。
