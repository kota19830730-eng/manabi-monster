# v13.12 おうちの人の マシン（ごほうびマシン）（2026-09-13・sw 156）

ユーザー「カプセルマシンの 景品を 保護者が 決める システムを 作成したい。新しい ゲームを 買って あげる 口実とか、子どもが 親に 与えて ほしい ものを カプセルマシンに 入れる 構造。確率も 親が 設定できるように。壁打ちしましょう」
→ 4つの 問い（ぜんぶ おすすめ）→「オススメで 作成して ください。期限も あると 助かります」。

## 決まった こと（ユーザー）

| | 決めた こと |
|---|---|
| 場所 | カプセルマシンの 中に 4つめの 台「おうち」（金色）。いまの なかま・そうび・すがた は そのまま |
| 鍵 | 景品の 設定は **4けたの 番号**（家に 1つ・`settings.prizePin` に まぜた 形で しまう） |
| 確率 | 子どもの 画面にも **景品ごとの %** と「あと 〇回で かくてい」を 出す（うそを つかない） |
| 大物 | 景品ごとに「**〇回で かくてい**」（なし／10／20／30／50回） |
| 期限 | 景品ごとに「いつまで」（なし／今週＝日曜まで／今月／日付） |

## 私が 決めた こと

- 景品は **8こまで**。名前 20文字＋絵 8しゅるい（プレゼント・ゲーム・おかし・おでかけ・じかん・本・おもちゃ・とくべつ）。
- **出やすさ 5段階**（よく出る 40／ふつう 20／ときどき 10／めったに 4／ちょうレア 1 の 重み）→ % は 出せる 景品の 重みの 合計で わる（合計 100%）。1% みまんは 小数 1けた（0 に しない）。
- **当たる数**（1回だけ／2／3／5回／何回でも）。数に 達したら マシンから 消える。
- **ねだん**は 10／20／30／50／100 コイン（はじめは 30）。目安＝1回の たたかいで 3〜5まい（たからばこ・中ボス・ボス・★3）、ミッションで 1日 最大 5まい → 1日 3回 たたかう 子で 15〜20まい（`js/core/battle.js` `missions.js` `streak.js` を 読んで 数えた）。
- **はずれは 作らない**。出せる 景品が ない ときは「じゅんびちゅう」で 引けない。
- **かくていの 数え方**：引く たびに、出せる 景品の うち 出なかった ものは 1つ すすむ（`miss`）。つぎで かくていに なる ものが あれば それ（いくつも あれば いちばん 出にくい もの）。
- **演出**は いまの カプセルと 同じ 3だんかい。色は 出た 景品の 出にくさ そのまま（ちょうレア＝むらさき／ときどき・めったに＝金／よく出る・ふつう＝ふつう）。回数で かくていの ときは「かくてい！」。
- **ごほうび チケット**：当たると もちもの（メニュー →「もちもの」の いちばん 上）に 入る。おうちの人が 番号を 入れた 画面で「わたした」を 押すと「もらった」に なる。60まいまで のこす（わたして いない ものは 消さない）。
- 景品は **子どもごとに べつ**（`p.prize`）。
- カプセルマシンを かくして いても（`capsuleOff`）、景品が あれば なかまタブの ボタンは 出る（おうちの マシンだけ）。
- **「番号を 忘れた」**：番号と 全員の 景品を 消して 作り直す（チケットは のこす）。**子どもが 押して 自分で 番号を 作り直す ことも できる**ので、作り直した 日を `settings.prizeReset` に のこし、おうちの人ページの ホームと 設定に 赤い しるし「〇月〇日に 作り直されました」を 出す（「確認した」で 消える）。
- **「番号を 変える」**は 新しい 番号を 2回 入れる まで 前の 番号の まま（とちゅうで やめても 鍵が 外れない）。
- おうちの人ページに 入る たび・出る たびに 鍵が かかる（`MQ.ui.prize.lock`）。
- データは この 端末の セーブだけ。外には 送らない。お金は かからない。
