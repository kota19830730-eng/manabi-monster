## 2. 決めた こと（もどさない）

### ① もとの 絵の かたちを 変えない
息子さんの 絵が 分からなく なると **v2.4.1 の 苦情「自分の作った モンスターの
再現性が 低い」に もどる**。だから 足すのは **かざりだけ**（炎・つの・かんむり・
マント・ぶき・オーラ）。サメオニの **目 3つ**、スカルホースの **馬＋ガイコツの きし**、
ずかんの **羽つきの 本**、ABC の **字の かたち** は 3段階とも そのまま。

### ② ABC は 1文字ずつ べつの 系統
3つが 1体に 合体する 案は **やめた**。エーと ビーの 2体を なかまに して いる 子が
両方を 育てると、`p.pals[つぎのid]` が 上書きされて **片方の 相棒（けいけんち・つけた
なまえ）が 消える**。だから `abc-a` / `abc-b` / `abc-c` の 3系統に 分けて ある。

### ③ 2・3段階めは ふつうの たたかいに 出ない（`evoOnly: true`）
出会うのは いままで どおり 1段階めだけ。写真から 作った モンスター（v8.2）と 同じ
きまり。**`rareIdsFor()` の 息子さんぶんにも `!e.evoOnly` を 足した**
（v8.2 では customs にしか 入って いなかった）。

### ④ 進化形に `trio` を つけない
`trioFor()` は「その エリアの trio を ぜんぶ」返す。進化形にも つけると
ABC3きょうだいが 9体に なって バトルが こわれる。smoke が 3体で ある ことを 見る。

### ⑤ 名前に「キング」「まおう」を つかわない
ボス（キングスライム）・ラスボス（まおう）と かぶる。v8.2 の 王さま 44体と 同じ きまり。

### ⑥ id は `-2` / `-3`
smoke の v4.2「51体」検査は `e.line && /-[123]$/.test(e.id)` で 数えて いる ので、
**`!e.rare` を 足して** 息子さんの ぶんを よけて ある（息子さんの 4体は ぜんぶ `rare: true`）。

## 3. 作り方（手で 座標を 打たない）

道具は **`tools/son/`**。v8.2 の `tools/king/` と 同じ 3段がまえ。

```
node tools/son/build.js    # 絵を 組み立てて tools/son/sheet.html と arts.json を 書く（まだ 入れない）
node tools/son/apply.js    # monsterart.js と enemies.js に 入れる（2回 流しても こわれない）
```

| ファイル | 中身 |
|---|---|
| `tools/son/defs.js` | **どう かざるか の 決めごと**（1体ずつ）。`base`（もとの 絵）／`fitTop`（上に すきまを 作る）／`back`（うしろの 四角）／`front`（前の 四角）／`crownBox`＋`crown`／`spec`（king の 部品） |
| `tools/son/build.js` | 組み立て＋検査＋一覧ページ。**`tools/king/kit.js` の 部品（CROWNS/BACKS/HANDS/EXTRAS）を そのまま 借りる** |
| `tools/son/apply.js` | ゲームに 入れる |

### `fitTop`（v8.6 で 足した しくみ）
スカルホース・サメオニは **すでに 48マス いっぱい**で 上に すきまが ない。
- 字（A・B・C）は `fitTop` で **絵を すこし 小さく して 上を あける** → かんむりを のせる。
- スカルホース は 小さく すると 細かい ところが つぶれる ので、**かんむりを 馬の 頭の 上**に
  置いた（`crownBox: { hcx: 8, top: 13, hw: 14 }`）。
- サメオニ は **つの 2本の あいだ**に 置いた（`crownBox: { hcx: 24, top: 9, hw: 18 }`）。
  band は y6〜10、まん中の 目は y10 から なので **目 3つは かくれない**（実測ずみ）。

### 「かくれる かざり」の 検査（大事）
`build.js` の `hiddenReport()` が、**うしろに 置いた 四角が 7わり いじょう 本体に
かくれて いたら 名ざしで 出す**。1回目は マントが 97% かくれて いた（本体の うしろに
入れても 見えない）。**かざりは 本体の 外がわに 出す**のが 正解。
- スカルホースの マント → きしの **うしろ（右がわ）**に ながす
- サメオニの マント → やめて **大きな ひれ**に した
- 字の マント → やめて **光の わ（aura）／はね** に した（マントは 字を かくす）

### 白い 四角に 見えない ように
きば・トゲは **1つの 四角だと ただの 白い はこ**に 見える。**2つ かさねて 先ぼそり**に する。
