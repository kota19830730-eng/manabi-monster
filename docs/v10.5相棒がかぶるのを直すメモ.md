# v10.5 相棒が ふきだし・カットインに かぶるのを 直す（2026-09-07）

息子さん「戦闘中の 吹き出しや カットインの 時に 相棒が 前に かぶる」→ ユーザー「うまく 直せるかな？」

## まず 数えた（アリーナ 400×210〜232 の 中の 場所）

| もの | 場所 | 重なり順（z-index） |
|---|---|---|
| ふきだし `.arena__msg` | top 70・x 100〜284・1〜3行（y 70〜130） | 3（DOM では 相棒より **前**） |
| 相棒 `.pal` | left 134・bottom 20・絵 40px＋なまえ＋ゲージ ≒ 62px（y 128〜190・bob で ±6） | 3（DOM では **あと**＝同じ z なら 勝つ） |
| ためゲージ `.charge` | left 12・bottom 38（x 12〜170・y 150〜168） | 4 |
| コンボ `.combo` | left 12・bottom 8（x 12〜140） | 3 |
| アイテムボタン `.bagbtn` | 右下（x 240〜） | — |
| カットイン `.cutin` | `.fxscreen`（z 40）の 中・top 84・高さ 96・帯は rgba .92 の **半透明** | 40 |

**原因は 3つ**
1. ふきだしが 2〜3行に なると 下はし（y 116〜130）が 相棒の 頭（y 122〜）に かかり、**あとに 描かれる 相棒が ふきだしの 上に 出る**。
2. 相棒の なまえと ゲージは **ためゲージと コンボの 字に かくれて いた**（x 134〜174 は 左下の 部品の 上）。
3. カットインの 帯は 半透明なので、**下に ある ふきだしの 文字と 相棒が すけて 見えて** ごちゃごちゃ する（`#palfx` の スクショで 確認）。

## 直した こと

| # | 直し | ファイル |
|---|---|---|
| ① | 相棒を **まん中へ**：`left 134 → 190`・`bottom 20 → 12`。ふきだし（3行でも y 130 まで）・ためゲージ（x 〜170）・アイテムボタン（x 240〜）の どれとも ぶつからない | `css/style.css` `.pal` |
| ② | ふきだしを **相棒より 上**に：`.arena__msg { z-index: 3 → 4 }`（万一 かさなっても 文字が 読める） | 同 |
| ③ | **カットインの あいだ（0.62秒）は ふきだしと 相棒を 消す**：`cutIn()` が `.arena` に `is-cutin` を つけ、`.arena.is-cutin .arena__msg, .arena.is-cutin .pal { opacity: 0 }`（transition .12秒）。相棒は カットインの 中（`.cutin__pal`）に 出て いるので「とびこんだ」ように 見える | `js/ui/battle.js` `cutIn` ／ `css/style.css` |
| ④ | 追い打ちの ジャンプ `palJump` の きょりを **146 → 104px** に（右に よった ぶん。てきに めりこまない） | `css/style.css` |

**変えて いない**：`.arena__msg` の left 100 / max-width 184（v9.4 で 主人公 84px と セット）、`.arena` の 高さ、`.hero`、`.foes`、タイトルの `.tpal`（v4.9.1 で 分けた もの）。

## たしかめ方

- harness `#palbattle`（2行の ふきだし＋相棒）を **800×1280・520×940・520×780** で → 3つとも ふきだしの 下に 相棒、なまえと ゲージが 見える。
- `#palfx`（合体カットイン）→ ログ `palfx: is-cutin=ok 消える先 .arena__msg=0 .pal=0`。写真は ふきだしも 相棒も すけない。
- `#palhit`（追い打ちの 帯）→ 帯と ふきだしが 重なって 見えるのは **harness が 帯の 写しを あとから 置いて いる ため**（本物は `is-quiet` で ふきだしが 消えて いる）。
- smoke ALL OK・`#flow` エラー 0（132行）。

## わな（harness）

- **headless の virtual-time では、script が `await` して いる あいだ アニメの 時計が 進まない**（CSSTransition も CSSAnimation も `currentTime 0` の まま）。
  `getComputedStyle().opacity` で「消えた」を 見ようと すると ずっと 1 に 見える。→ **transition を いったん `none` に して「行き先の 値」を はかる**（`#palfx` の ログ）。
- カットインの 0.62秒の タイマーは 見つけた ときには 予約ずみで `freeze()` では 止まらず、`is-cutin` を 外して しまう → 写真用には inline で `opacity: 0` を 入れる（しくみの 検査は ログで）。
