# v9.2 地図と タイトルの 地面を つみきに する

ユーザー「キャラクターや モンスターの グラフィックを 向上させた スキルで **マップや
タイトル画面も 綺麗に できる？**」→ 中を 見て 答え、「お願いします」。

v9.1（モンスターの ぬり方）と **同じ 考え方を 地面に かけた**もの。

## 0. なぜ 地図が いちばん 平らだったか（実測）

| 見た もの | 実測 |
|---|---|
| 地図の 地面 | Canvas に **1マス＝1ピクセル**で 描き、CSS で 12.5倍に のばして いた |
| つまり | **画面で 12.5px の 四角が、まるごと 1色の べた塗り** |
| かざり（木・岩・家） | CSS の 四角。**右と 下だけ 暗い**（v9.1 前の モンスターと 同じ 古い ぬり方） |
| タイトルの 地面 | 緑 26px ＋ 茶色の 帯。点が 3つ だけ |

モンスターの ブロック（大きい もので 30px くらい）より **1マスが 大きい**のに 中身が 空。
＝ ゲームの 中で いちばん 平らな 場所だった。

## 1. 地図の 地面（`js/core/tiles.js` の `paint()`）

**1マスを 4×4 の 点で 描く**ように した（`SUB = 4`。絵は 4倍に なり、のばす 倍率は 12.5 → 3.125）。
マスの 中に 立体感を 入れられる ように なった。**マス目・道・島の 形は 1マスも 変えて いない。**

- **マスの ふち**：上 +0.11／下 −0.10／左 +0.08／右 −0.08。
  **よこと たての 強さを そろえる**のが だいじ。上下だけ 強いと 地面が
  マス目では なく **よこじま**に 見える（1回目が それで、直した）。
- **水ぎわは がけ**：上が 水の マスは 上を +0.22、下が 水の マスは 下を −0.20。
- **岸の かげ**：陸の 下に くる 水を 暗く する（島が うかんで 見える）。
- **波**：水は 立体に せず、ななめに ながれる 明るい すじ。
- **ざらつき**：`grain(x, y)`（同じ 場所は いつも 同じ）。陸 0.06・水 0.045。
- 描くのは `createImageData` で 1回。**`fillRect` を 3万回 呼ばない**。

## 2. 地図の かざり（`css/style.css` の `.deco`）

木・岩・家・雪山・かれ木に **上が 明るく 右と 下が 暗い 3面**＋まわりの こい ふち。

**`box-shadow` では なく `border` と `outline` で かける。**
学年ごとの 色（`.map--g1 .deco--tree i` など）が `box-shadow` を **まるごと 上書き**するので、
box-shadow で 光を 足すと 小1・小2・小4・小5 だけ 消える。border なら 色を 変えても のこる。
（花＝光る 点 と 波は のぞく）

## 3. タイトルの 地面（`css/style.css` の `.title__grass` / `.title__dirt`）

**1マス 12.5px の ブロックの ならび**に 見せる（地図の マスと 同じ 大きさ）。
四角を 何十個も 置くと 重いので、**くり返しの グラデーション 2枚**で 作る
（たて＝上 2px 明るく・下 1.5px 暗く／よこ＝右はしを 暗く）。色は 変えて いない。

## 4. さわって いない ところ

## 6. もどさない ところ

- **1マス＝1ピクセルに もどさない**（べた塗りに 逆もどりする）。
- **マスの ふちは よこと たてを 同じ 強さに**（上下だけだと よこじまに 見える）。
- **かざりの 立体感は border／outline で**（box-shadow は 学年の 色に 消される）。
- **ロゴと 勇者は さわらない。**
