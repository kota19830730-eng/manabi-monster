# v12.7 ボスを 強く（2026-09-12・sw 133）

ユーザー「ボスキャラと ラスボスが 弱すぎる。もう少し 歯ごたえが ほしい。壁打ちしましょう」
→ 実測して 6案 → おすすめ「1＋2＋4＋5 を みんなに、3 は 6 の『本気』を えらんだ ときだけ」→「オススメで」。

## 1. まず 数えた（400回ずつ 自動で 戦わせた）

| | ぜんぶ 正解 | 正答率 60% |
|---|---|---|
| ボス（HP3・最大5問） | **2問**で たおせる | 勝率 100% |
| ラスボス（HP5・最大8問） | **4問** | 勝率 100% |

弱い 理由：
- ボスの ためは **2問に 1回**だったので、2問めで かならず カウンター 2ダメージ → HP3 は 1＋2 で おわる。
- **2回めの 正解でも 1ダメージ**入る → 正答率 40% でも ほぼ 勝てる。
- ボスの 問題は さいごの ザコと 同じ lv3。
- v8.1 の ボスの わざ（たての かまえ・ぶんしん・なかまを よぶ）は 3問めから 出る 予定なので、**2問で おわる あいだは ほとんど 見られて いなかった**。

## 2. やった こと

| 案 | 中身 | 場所 |
|---|---|---|
| 1 長く | ボス **HP5・最大8問**、ラスボス **HP9・最大14問**（小1・小2の 塔は HP7・最大11問）。はじめての たたかい（v11.1）は HP3・最大5問の まま | `core/battle.js` の `BOSS_SET`（ui が わたす。**core の 初期値は むかしの まま**＝むかしの テストの ため） |
| 2 おまけを しめる | ボスの ためは **3問に 1回**（`CHARGE_BOSS` 2 → 3）。相棒の 追い打ちは **ボスには 1ダメージまで**（`PAL_BOSS_MAX`。王さま相棒の ザコへの けいけんちは そのまま） | `core/battle.js` |
| 3 本気（えらんだ ときだけ） | **1回めの 正解だけ ダメージ**。2回めの 正解は「ガードされた！」で けいけんちだけ（相棒の 追い打ちは 通る）。**ボスの けいけんち・コイン 2ばい**（`HARD_MUL`）。ボスに 1回 答えたら 変えられない | `core/battle.js` の `setBossHard` |
| 4 まとめ問題 | ボスの **2・4・6…問め**は、同じ エリアで **前に ★を とった ステージ**の ボス問題（とくい・にがての 記ろくは もとの ステージに。カードの 上に「まとめ：〇〇」）。ごちゃまぜ・塔・はじめての たたかいは なし | `core/battle.js` の `makeBossQuestion`・ui の `recap` |
| 5 見せ方 | **3だんかい**：HP が `enrageAt` いかで おこる（第2形態）→ `finalAt` いかで **さいごの 力**（第3形態・赤い オーラ・専用の ふきだし）。上の ピルは「3 / 5」→ **「にげるまで N」**。ボスの HP の 玉は **足もと**に（前は 名前の 下で、右下の アイテムボタンに かくれて 見えなかった）。ラスボスの 玉は 9こ なので 細く | `ui/battle.js`・`css/style.css` |
| 6 えらぶ | ボスが 出た ところで **「ふつうに たたかう／本気の ボスと たたかう」**のパネル（`.bosspick`・問題の 場所に かぶせる）。えらぶ まで 答えられない。はじめての たたかい・タイムアタックでは 出さない | `ui/battle.js` の `bossPick` |

ついでに 直した こと：
- `res.enrage` が おこった あと **毎回 true** に なって いた（ラスボスで「まだ 本気では なかった…！」が 2回 出た）。いまは その 1回だけ。
- 相棒の 追い打ちで ダメージが 2に なった ときに「ばくれつ こうげき！」と 出て いた。いまは ばくれつを 本当に つかった ときだけ。
- 本気モードで ガードされた ときは ばくれつ（アイテム）を つかわずに のこす。

## 3. できあがりの 数字（smoke が 毎回 はかる）

| | ぜんぶ 正解 | 正答 80% | 正答 60% | 正答 40% |
|---|---|---|---|---|
| ふつうの ボス | 約 4.6問 | 勝率 100% | 勝率 98〜100% | — |
| 本気の ボス | — | 勝率 93〜96% | 勝率 66〜67% | 勝率 20〜24% |
| ラスボス（ふつう） | 約 6.8問 | 勝率 100% | 勝率 100% | 勝率 100% |

**ふつうを えらべば 勝率は いままでと ほぼ 同じ**（負けない きまり・ばつを 与えない きまりは そのまま）。
本気は「にげられるかも」の ドキドキが ほしい 子だけが 自分で えらぶ。にげられても 何も うしなわない（いつもの にげられた と 同じ）。

## 4. もどさない

- ふつうの ボスの 勝率を 下げない（本気の ルールを みんなに かけない）。苦手な 子を くじけさせない ため。
- `BOSS_SET` は ui が わたす。core の 初期値（HP3/5・塔 5/8）を 変えると むかしの テストが こわれる。
- **金色の ばくれつ こうげきは ボスを 一発で たおせなく なった**（3ダメージ・HP5）。v2.0 で OK を もらった「ボス一発」は、ボスを 強く する ために 手ばなした（ユーザーの「オススメで」の 中）。
- 画面の 文字に「にがて」と 書かない（まとめ問題は「まとめ：ステージ名」）。
