# v12.1 りったいを 軽く する ＋ 相棒の 位置 ＋ 2D の タイトルの 勇者（2026-09-10〜11）

ユーザー「3Dやと ちょっと 重いね。もう少し 軽く サクサク 動く」→「方法ない？」
→ 同じ ターンで「相棒の 位置に 違和感あるわ。なんか いい ポジション ないかな？」
→「2Dの 主人公も 3D版と 同じにして」。

## 1. まず 数えた（PC・ソフト描画・harness `#perf3d`）

| 画面 | v12.0 | v12.1 |
|---|---|---|
| バトル（主人公＋てき＋相棒）の 面 | **393まい** | **218まい** |
| うち 主人公 | 283 | 136 |
| バトルの 1コマ（平均／悪い 5%） | 18.4ms／34ms | **16.8ms／18ms（60fps）** |
| タイトル（モンスター 11＋勇者＋たからばこ）の 面 | **767まい** | **353まい** |
| 小さな PNG（面の 模様）の 数 | 362まい | 1体 1まい（アトラス） |

**重さの 正体**＝面の 数。面は 1まいずつ GPU の 層に なる。タイトルで「前の 面だけ 出す」と 60fps に
もどり、動き（アニメ）を 止めても 変わらなかった＝**よこ・上下の 面の 数が すべて**。
（`#perf3d:title|css=...` で 5とおり ためした：noanim 22.5／nomobs 16.5／frontonly 16.8／noglow 20.4／base 23.4）

「作る 時間 430ms」は 3D の せいでは なかった（CPU プロファイルで `sfx.js` の AudioContext が 306ms。
1体 箱に するのは 2〜6ms）。

## 2. やった こと（見た目は 変えない）

`js/core/vox.js`（正本。頭の コメント ⑦〜⑪）
- ⑦ **見えない 面を 作らない**（`cull`）
  - 同じ 部品の となりの 箱に すっぽり かくれる 上・下・よこの 面（つみ重ねの あいだ）
  - カメラの 向き（rotateY ±22°）で ぜったい 見えない がわの よこの 面（`opts.hide`＝'L'／'R'。
    `js/ui/three.js` の `hideOf(ry)`：ry<0＝てき→左を はぶく／ry>0＝主人公・相棒→右を はぶく。
    **はね（rotateY で ばたばた）は はぶかない**）
  - うしろの 面は **うでと けん（170° ふり上げる・`back: true`）と ふた（108° ひらく・`keep: true`）だけ**
  - `flat`（'T'）＝上の 面も 作らない。カメラは 8° 下から なので、ゆれる だけの 画面（タイトル・カプセル＝`mo-title`）では
    見えない。**バトルは フェイント（rotateX −15°）・とびかかり・歩き で 上が 見える ので つける**
- ⑪ **同じ 平面に ならぶ 面を 1まいに つなぐ**（`mergeFaces`：右はしが 同じ x で 上下に となりあう 右の 面、など）
- ⑨ **模様は 1体 1まいの アトラス**（`Atlas`：面ごとの canvas→toDataURL を やめ、1体ぶんを 1まいに つめて 1回だけ。
  面は `background-position` で 切り出す。同じ 色の ならびは 同じ 場所を 使いまわす）
- ⑩ **同じ モンスター・主人公は cloneNode**（`three.js` の `monCache`／`heroCache`。キーに 向きと flat も 入る）
- 面の 色の まぜ算は おぼえて おく（`litRgb`）。点は `ImageData` に まとめて 書く

`js/content/chest3d.js`：ふたは `keep: true`＋`bottom: INNER`（内がわ＝明るい 木・光は「上」）。
前は できあがった あとで 面を さがして 上書きして いた → `fromGroups` の groups で わたす。

## 3. ためして やめた こと（もどさない ために 書いて おく）

- **面を ぜんぶ 外むきに して `backface-visibility: hidden`**（うらがわを GPU に すてさせる）
  → 主人公が のけぞった とき **あごの 下に 空色の 細い すきま**が 出た（12ばいの 拡大で 実測。うしろの 面を
  ぜんぶ つけても 出る・置き方を もどすと 消える）。原因は 追えなかった ので **面の 置き方は v12.0 の まま**。
- **つぎめ**：前の 面と よこ・上下の 面は 同じ へりを 共有する ので、GPU の アンチエイリアスで 1点ぶん すきまが 出る。
  v12.0 は うしろの 面が あった ので そこが 暗く 見えて「ふち」に 見えて いた。うしろを はぶくと 空が すける
  （タイトルの ドラゴンの はね・主人公の あご）。→ **前の 面を 四方に 0.5px 大きく**（`LIP`・大きく した ぶんは
  下じき＝ふちの 色）＋ **右と 下の 面を 0.6px 手まえに**（`EPS`）。1ばいの 画面では 見えない 太さ。

## 4. 相棒の 位置（`css/style.css`）

**違和感の 正体**：相棒だけ 主人公より 50px 低い「暗い ゆか」に 立ち、画面の まん中（主人公と てきの あいだ）に
ぽつんと いた。主人公の ダッシュ（`mo-dash`）が 相棒の 上を 通って いた。

3案を 実寸で 撮って くらべ（`#palbattle|css=...`）：A 主人公の うしろ（左はし）／B 主人公の 右どなり／C まん中の まま 草の 上。
→ **A**（RPG の パーティーの ならび。主人公が 先頭・相棒が うしろ）。

| 部品 | v10.5 | v12.1 |
|---|---|---|
| `.hero` | left 14 | **left 46**（32px 右へ） |
| `.arena__msg` | left 100 / max-width 184 | **left 132 / max-width 152**（右はしは 284 の まま） |
| `.pal` | left 190 / bottom 12 / z 3 | **left 6 / bottom 62 / z 1**（同じ 草の 上・主人公の うしろ） |
| `.pal__name` `.pal__gauge` | 相棒の 下に ならぶ | **足もとの 下（暗い ゆか）に absolute** |
| `.charge` `.combo` | left 12 | **left 54**（相棒の なまえの 右） |
| `palJump` | 84→104px | **120→150px**（左はしから 主人公の 前まで） |

**A のまま 主人公を 動かさない と 相棒が 主人公の かげに かくれる**（さいしょ left 0 で ためして 見えなかった）。
520×940／520×780／800×1280 で 確認（`#palbattle` `#palhit` `#palfx`）。

## 5. 2D の タイトルの 勇者（`js/ui/start.js`）

→ 2D でも **3D と 同じ 見本キャラ `TITLE_HERO`**（`MQ.hero.sprite(TITLE_HERO)` を 138px の わくに・`.title__heroimg--avatar`）。
その子の アバターでは ない（v5.0 の きまりは そのまま）。`poster()` は のこして ある（つかって いない）。

## 6. 道具

- harness **`#perf3d[:2d][:title]`**：面・箱・DOM の 数、1体 作る 時間の 内わけ（`MQ.vox.timing`）、1コマの 時間。
  **1コマは `--virtual-time-budget` なしで**（scratchpad の `cdp.js`＝Chrome を 遠隔操作して 7秒 待つ）。
- harness **`#<mode>|css=<encodeURIComponent した CSS>|js=<code>`**：好きな CSS／JS を かぶせて 撮る（位置の 案・`MQ.vox.flags`）。
- `MQ.vox.flags`：`noCull`／`noMerge`／`allBack`（検査用の スイッチ）。`box.dataset.f`＝どの 面が あるか（kLRTB＋）。
- 前後の くらべ：scratchpad の `pngdiff.js`（ちがう 点の 数）と `crop.js`（同じ はんいを 拡大して ならべる・ライブラリなし）。
  **3D の 細かい ちがいは 6〜12ばいに して 見る**（1ばいでは 見えない）。
