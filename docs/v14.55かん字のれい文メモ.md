# v14.55 かん字の れい文（2026-10-12・sw 229 に 同乗・お知らせ なし）

ユーザー「漢字の 書く 問題で かえる。だけでは どの 漢字か わかりにくい。家に かえる とか なら わかる。問題の 質が 低い。他にも あるので それも」。

## できた こと

- **全学年の かん字 900問ぶん に 短い れい文**（小1 80・小2 160・小3 39・小4 230・小5 200・小6 191）。
  - 書く：「いえに かえる」の「かえる」を かん字で かくと？／ゆびで 書く 問題も 同じ 形
  - 読む：「いえに 帰る」の「帰る」の よみかたは？
- れい文は `js/content/kanjirei.js` の DATA（`'帰る': 'がっこうから いえに ＿'`）。`＿` に よみ／かん字が 入る。
  `kanjiq.js` の `make(table, よみ, かく, 学年)` が つかう。小3（kokugo3.js に 手書き）は kanjirei.js が 読みこみ時に 書きかえる。
- 目当ての ことばに **赤い 下線**（`b.kr`・見出しの 書体は 太字が ない ので <b> だけでは 目立たない）。
- 小5の 表の「護る（まもる）」は 学校で ならわない 読みで「守る」と 区別が つかない → **救護（きゅうご）** に かえた。

## れい文の きまり（smoke が 見る）

- その 字しか 考えられない 文（帰る／返る／変える、暑い／熱い／厚い、計る／量る／測る など）。
- 目当ての 字を 文に 入れない（答えが ばれる）。
- かん字は 1つ前の 学年まで（小1・小2 は ひらがな・カタカナだけ）。
- `＿` は 1つ。

## のこり

- 数字・家族（一つ／二つ、兄／姉）は 文では しぼれない ので よみで 区別する まま。
- 実機で 字が 読めるか（長く なった ぶん 字が 小さく なる 問題が ある）。`#fit:all` に かん字の 10ステージを 足して 800×1280・520×780 とも はみ出し 0。
