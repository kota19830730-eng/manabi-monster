# v14.1 BGM を 軽く する（音は そのまま）

2026-09-13・claude-06。ユーザー「**このクオリティでもたつかないように軽くしてください。**」（v14.0 を 公開した すぐ あと）

## まず はかった（どこが 重いか）

`tools/bgmcheck/parts.js` で 部品ごとに 切れる コピーを 作り、`bench.js` で「切った とき どれだけ 軽く なるか」を 見た（ボス・コンボ MAX・おこり）。

| 部品 | 重さの うち |
|---|---|
| supersaw（のこぎり 5本＋四角・フィルター 3つ） | **約半分** |
| リバーブ・山びこ・コンプ（曲が なくても かかる） | 約 1.2%（いつも） |
| ドラム（ハイハットは 16分ごとに 4つの ノード） | 約 1% |
| ベース・パッド・アルペジオ | それぞれ 0.3〜1% |

**波（OscillatorNode）を 1音ごとに 5〜6本 その場で 作る のが 重さの 正体。**

## 直した こと（js/core/bgm.js だけ）

1. **録音して おく（サンプラー）**：supersaw の のこぎり 5本・パッド・アルペジオ・ベース・ドラムを、はじめに 1回だけ **同じ しくみ（OfflineAudioContext）で 録音**。あとは `AudioBufferSourceNode` で 再生するだけ。**フィルター・音量の 形・ビブラートは 1音ずつ かける ので 音は 同じ**。
   - 表は `BANK`（lead 0.9秒ステレオ・pad 1.3秒・pluck 0.4秒・bsaw／bbody 0.55秒）と `DRUM`（kick／kickB／snare／snareS／clap／hat／hatO／crash）。
   - 1つの OfflineAudioContext に 8つずつ ならべて 録音し、場所（`off`）で 切り出す（コピーしない）。100ms あけて じゅんに（`bankChain`）。
   - **録音が まだ・できない ときは いままでどおり その場で 作る**（`sample()` が null）。長い 音（0.84秒 こえ＝2%）も その場で。
   - さいしょの 曲の 高さを 先に、ほかの 曲は 1秒 あとから（`warmAll`）。PC で ぜんぶ 1.3〜2秒。
   - メモリ：48kHz で 約 23MB（lead が 12MB）。
2. **まとめる**（音は 数学的に 同じ）：supersaw の 左・まん中・右の フィルター 3つ → 1つ／コードの 3つの 音の フィルターと 音量 → 1つ／もりあがり 2 の 1オクターブ下の 重ねと コードの ジャーンは 1つの フィルターと 音量の 形を 分けあう（`supersaw(t, midi, dur, vol, more)`）。
3. **フィルターの 動きは k-rate**（128サンプルに 1回。`lowpass()`）。まいサンプル 係数を 計算しない。ちがい −44dB。
4. **先読み 0.3 → 0.6秒**（`LOOKAHEAD`）。たたかいの 画面を 作る あいだ（約0.4秒）画面が 止まっても 音楽が つまずかない。
5. **曲ごとの 出口 `outs`**：曲を かえる・止める ときに 予約ずみの 音を 0.06秒で 消す（`cutOuts`）。先読みを 長く した ぶん、前の 曲が のこらない ように。ファンファーレ → 勝利曲（`at` つき）は そのまま つなぐ。曲が 自然に おわった ときは `halt()`（消さない）。

## 結果

この PC・5回の いちばん 小さい 数字（v14.0 → v14.1）：マップ 6.4→3.9%／ザコ戦 5.1→3.4%／コンボ MAX 6.0→3.7%／ボス 6.4→4.9%／さいごの塔 7.8→4.1%／けっか画面 4.9→3.5%。**30〜45% へった**。画面がわの 仕事（音の 予約）は 約6わり へった。

本物の Chrome で 鳴らした たしかめ：エラー 0・バトルの 3秒へいきん −21.4 → −21.3dB・**止めた 0.15秒後 −22.6dB → −54dB**（前は 前の 曲が のこって いた）。

## 音が 変わって いないか（数字）

- その場で 作る 道（まとめる・k-rate）は 前と **帯ごとの ちがい 0.06〜0.08dB**（ほぼ 同じ）。
- 録音の 道は 帯ごとの へいきん・1音ごとの 大きさ（±0.5dB）が 同じ。波の はじまりの 位置だけ ちがう（前も 1音ごとに ばらばらだった＝下の わな）。
- 目やす：乱数だけ ちがう＝0.28dB／同じ 曲を 0.8ミリ秒 ずらす＝ベースで 3.4dB。

## わな（もどさない）

- **`frequency.setValueAtTime` を `.value =` に しない**。Chrome では 予定表だと 音の はじめ（128サンプルの のこり）が 440Hz で 鳴り、そのあと 波の 位置が 変わる。聞こえないが「公開した 音」は こっち。`.value` に すると ベースの 波の かさなり方が 変わる（帯で 2.5dB）。録音も 予定表で 作る。
- **録音した 音は `onFrame(t)` で サンプルの さかいめから 再生**。あいだから 始めると となりの 点を まぜて 読むので 8k〜13kHz が −2dB こもる。
- ビブラートは 録音した 音では `src.detune`（ない ブラウザは playbackRate）。
- ノイズは 長さごとに きまった たね（`noiseBuf`）。録音と その場で 同じ ノイズに する ため（前は Math.random）。
- `retire()`／`sweepTrash()` は そのまま（v14.0 の きまり）。
