# v9.1 グラフィックを 上げる（ぬり方の アップグレード）

ユーザー「モンスターと キャラクターの 解像度を もっと あげたい。要するに グラフィックを
もっと 綺麗に したい。でも マイクラ風は 残したい」→ 壁打ち → 5案（A ぬり方／B マス目を 2倍／
C 主人公も 合わせる／D 動きで 生きている 感／E 3Dブロック風）→ **ユーザー決定：A → D → C の 順で 入れて、
見て もらってから B'（大物だけ 96マスで 描き直す）を 決める**。

## 0. 何が「解像度が 低い」の 正体だったか（実測）

先に 数えた ところ、**マス数は 足りて いた**。足りて いなかったのは 中身。

| 見た もの | 実測 |
|---|---|
| モンスター 1体 | 48×48 の 中に **四角 5〜12個**（大きな 1色の 面が そのまま 見える） |
| 立体感 | **右と 下の 2面だけ** 暗い。上の 面（光が あたる ところ）が ない |
| 画面の 大きさ | ザコ 64px・ボス 96px・主人公 76px。タブレットで さらに 1.4〜1.8倍 |

→ **マスを 細かく するより「1つの 四角の 中身を 豪華に する」ほうが 効きが 大きい**。
しかも 絵を 1つも 描き直さずに **220体＋たからもの 136個＋写真から 作る モンスター**が
いっぺんに 変わる。

## 1. 案A：ぬり方の アップグレード（`js/core/blocks.js`）

`part()` の 中だけを 変えた。**絵の データ（`monsterart.js` の 四角の ならび）は 1文字も さわって いない。**

1. **上の 面を 明るく**（`topFace(h)`＝h≥16 は 3px・h≥10 は 2px・h≥6 は 1px、`lighter(color, .22)`）。
   右の 暗い面・下の 暗い面と 合わせて **3面**に なり、つみきに 見える。
2. **まわりの ふち**（`0 0 0 1px darker(color, .45)`）。**黒では なく 同じ 色みの こい色**。
   黒い ふちは v1.8 で「解像度が 悪く 見える」と 言われた ので 使わない。
   四角どうしの さかいめにも 出るので、ブロックの つなぎ目に 見える。
3. **ざらつき（テクスチャ）**＝`NOISE`。4px の マスで 明るさを ほんの少し ばらつかせた
   **16×16 の タイルを 1枚だけ** 作り、どの 色の 上にも かさねる
   （すきとおる 白 .085 と 黒 .075 だけなので 色ごとに 作らなくて よい＝軽い）。
   **大きな 面だけ**（w≥10 かつ h≥10）。目・歯・小さい つのには つけない。
4. **光る ところ（`g` フラグ）は 2重の グロー**（6px＋14px）。

### 軽さの ため（大事）
- **`box()` は size < 56px なら ざらつきを 省く**（`opts.plain`）。
  ずかんの タイルは 52px で **220体が いっぺんに ならぶ**。そこでは ざらつきは
  どうせ 見えないので、作らない。バトル（64・96px）と タイトルだけに つく。
- ざらつきは **タイル 1枚を 使いまわす**（色ごとに SVG を 作ると 重い）。
- CSS に **`.bx i { image-rendering: pixelated; }`**。これが ないと 拡大した ときに
  ざらつきが ぼやけて「にじみ」に 見える。

## 2. 案D：いきている 感じ（`css/style.css`）

- **`.bx__glow`**（`g` フラグの ブロック＝光る 目・コア）が **呼吸するように 明るく なる**
  （`bxGlow` 2.6秒・`filter: brightness(1 → 1.4)`）。
- **`.bx__eye`**（目らしい ところ。えらび方は 下の 9節・`blocks.js` の `pickEyes()`）が **ときどき まばたき**
  （`bxBlink` 6.5秒に 1回・`scaleY(.12)` を 130ms・`steps(1, end)` で ドット絵らしく カクッと）。
- **1体ずつ タイミングを ずらす**（`el()` が `--bxwait` に 0〜6.5秒の ばらつきを 入れる）。
  みんな 同時に まばたきすると 気もちわるい。
- **動くのは `.arena`（バトル）・`.title`・`.news__list` の 中だけ。**
  ずかんで 220体が いっせいに 動くと うるさく、タブレットも 重い。
- `prefers-reduced-motion` で 止まる。

## 3. 案C：主人公も 合わせる（`js/core/pixel.js` ＋ `js/content/hero.js`）

主人公だけは べつの しくみ（Canvas の ドット絵）なので、`polish()` に **`rim`** を 足した。
すきまの マスに **となりの 色を こく した 色**（既定 0.45）を ぬる＝モンスターと 同じ
「同じ 色みの こい ふち」。`outline`（黒の ふち）とは べつ。

- 入れた ところ：**`MQ.hero.sprite()` だけ**（`{ bevel: true, rim: 0.45 }`）。
  キャッシュの キーに `:r2` を 足して 古い 絵と 混ざらない ように した。
- **タイトルの 勇者（`poster()`）には 入れない。** モックに ふち取りが ないので v5.0 の まま。

## 4. 写真から 作る モンスター（`js/content/monstergen.js`）

`png()` にも **上の 面を 明るく**（`mix(col, 白, .22)`）を 足した。
息子さんの 絵から 作った モンスターだけ ぬり方が ちがう、と ならない ように する ため。

## 6. もどさない ところ

- **ふちは 黒に しない**（同じ 色みの こい色）。黒ふちは「解像度が 悪い」と 言われた 原因。
- **絵の データ（四角の ならび）は ぬり方の 都合で 動かさない。** かたちは そのまま。
- **ざらつきは 小さい ところ（52px の ずかん・小さい 目や 歯）に つけない。**
- **まばたき・明滅は バトル／タイトル／お知らせの 中だけ。**
- **タイトルの 勇者（poster）に ふちを つけない。**

## 7. のこり（つぎに 決める）

**B'：大物だけ 96マスで 描き直す**（ラスボス 5体・中ボス 8体・息子さんの 4体＝約20体）。
ぜんぶ（220体）を 96マスに するのは 数週間かかり、王さま形 44体・進化形 12体の
生成ツール（`tools/king/` `tools/son/`）も 作り直しに なるので すすめない。
**E（本当の 3Dブロック風）**は、いまの 絵が 正面むきで 組んで あるので 崩れる モンスターが 出る。
やるなら 試作を 1枚 見てから。

## 8. 実機で 見る こと（未確認）

- ざらつきが タブレットで ざらつきすぎて 見えないか（`NOISE` の .085／.075 を 下げる）。
- まばたきが 気に なる 子が いないか（`bxBlink` の 6.5秒を のばす）。
- ずかんを スクロールした ときに もたつかないか（もたつくなら `box()` の 56px の 線を 上げる）。

## 9. v9.1.1（同じ日）まばたきの えらび方を 直した

1つの ブロックだけを 見て「目らしいか」を 決めて いたら、**ペンギンの くちばし・ずかんの 歯・字の もよう**まで
いっしょに 消えて いた（ユーザーに 見せる 図を 作って いて 気づいた）。
→ **形ぜんたいを 見てから えらぶ**（`pickEyes(shape)` が 番号の 一覧を かえす）：

1. **顔の あたり（y ≤ 24）に 光る ブロックが ある 子は まばたきしない。**
   その 子の 目は 光る ほう なので `.bx__glow` の 明滅で じゅうぶん
   （スカル・ロボ・ゴーレム・ずかんの あくま… **息子さんの 4体と 進化形は ぜんぶ これ**）。
2. のこりの 候補は 上半分（y 2〜22）の 小さな（9×11 まで）**白か 黒**の 四角だけ。
   黄・赤・水色は 入れない（くちばし・ほっぺ・した が 消える）。
3. その 中で **いちばん 上の 行**（さいしょの y から 3px 以内）だけ。
4. **4つ より 多ければ やめる**（ならんだ もよう＝目では ない）。

**たしかめ方**：scratchpad の `blinkall.html`（165の 形を「ふだん／まばたきの しゅんかん」で よこに ならべ、
`MQ.blocks.pickEyesTest(shape)` で 何こ まばたきするかを 数える）。
**あやしい 形は 24 → 3 に へった**（のこりの 3つは 8×8 の 白目＝正しい）。sw.js v107。
