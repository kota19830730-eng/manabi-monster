## きみの 絵（ぬりえ方式）＝ `js/ui/photo.js` の `traceCells`（`/* <trace> */` の あいだ）
1. **線と 色を 分ける**：線＝紙より **こさ 40 いじょう**（`TRACE.lineMin`）暗くて 色の ない 点。
   （サメの うすい 青は こさ 20〜45・色み 15〜75、鉛筆は こさ 50〜150・色み 0〜10 ＝ `photo/stat.html` の ヒストグラム）
   色＝色み > lineS かつ 色み > 14＋こさ×0.18（鉛筆の 線の まわりの 茶色を 色に しない）。
2. **えんぴつで ぬりつぶした ところ**（15×15 の 半分が 線・大きな かたまりだけ＝`darkMin`）は こい 灰色（ドクロの 体・ずかんの かみ）。
3. **色は 色あいの 山**で 分ける（6°きざみ・山は 3% いじょう・14°いない は 1つ）。RGB の k-means だと うすい ピンクの A と オレンジが 1つに なった。
   同じ 色あいで こさが 38 いじょう はなれた 2つの 山（こい 赤の 目・うすい ピンクの ほっぺ）は 2色に（`split`）。
   色は `gameColor`（色あいは そのまま・こさと あざやかさを そろえる）。
4. **色を 近く（4px）だけ ひろげる**（線は こえない）＝色鉛筆の すじの すきまが うまる。遠くには もれない（子どもの 線は とじて いない）。
5. **線で かこまれた 場所ごと**：
   ・ほぼ ぜんぶに 色が とどく（9わり）か、うすく まばらに（色の 点 2わり いか）ぬって あって 半分 いじょうに とどく → 場所 ぜんぶ その 色（サメの 体）
   ・こく 一部だけ（ドクロの ほっぺ）→ ぬった ところだけ・色が 3% みまん → 白
6. **64マス**に 落とす。線は 1マスの 太さ（マスの 線の わりあいが よこか たての 山の ときだけ・12% いじょう）。
   色の 小さな しみ・色の 中に ぽつんと のこった すじを 消す。**線だけの 小さな かたまり（題名の 字）と かけらを 消す**（`dropLoose`）。
7. 線の 色は となりの 色の こい 色（黒に しない）。ブロックと 同じ 立体感（下・右の ふちは ×0.8、上の ふちは 白30%）。
