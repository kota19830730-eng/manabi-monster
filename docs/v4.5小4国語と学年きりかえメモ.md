### かん字 219字（★ここは 確かめて ほしい）

表は **219字**＝「4年で よく ならう かん字 199字」＋「都道府県の かん字 20字」
（茨・媛・岡・潟・岐・熊・香・佐・埼・崎・滋・鹿・縄・井・沖・栃・奈・梨・阪・阜 など）。

- **いまの 学習指導要領の 4年は 202字**。219字の うち 十数字は 5年・6年に うつって いる
  ことが あるので、**教科書の かん字一覧の 写真が もらえたら 合わせて けずる**。
  多めに 入れて あるので「習って いない 字が 出る」ことは あっても「出ない」ことは ない。
- **「殺」は 入れて いない**（子ども向けの ことばに ならない ため）。
- 1行の 書き方は kokugo2 と 同じ：`{ k: '成長', r: 'せいちょう', w: [にた形の まちがい 3つ], h: 'ヒント' }`
  - `k` は **かん字 1字**か **かん字＋送りがな**か **4年の 字＋小1〜3の 字の じゅく語**
  - `r`（読み）は 表の 中で **かぶらない**こと（書く問題の 文に なる ため）
  - smoke が「かぶりなし」「219字」「どの 行にも 4年の 字が ある」を 検査する

### ことばの 問題の 文体

**小3までの かん字 ＋ 4年の 表に ある かん字だけ**。smoke が 検査する。
5年いじょうの かん字は ひらがなで 書く（小3の kokugo3.js と 同じ）：
**じゅつ語**（述語）・**しゅうしょく語**（修飾語）・**じゅく語**（熟語）・**かんようく**（慣用句）。

### 画数の 表（`js/content/kakusu.js`）

**ゆびで 書く問題の はんてい（`handwrite.js`）は 画数の 表を 見る**。
小4の 219字が 無いと `ofWord` が 1字 2画あつかいに なり、**正しく 書いても
「なぐりがき」に されて しまう**。→ 小4 219字の 画数を 足した（440 → **659字**）。

あわせて **字ごとに「何年で ならうか」を もたせた**（`grade(1)`〜`grade(4)`）：
- `MQ.kakusu.gradeOf(字)` … 1〜4（表に ない ものは 0）
- `MQ.kakusu.upTo(字, 3)` … 小3までに ならう 字か
  → smoke の 文体チェックは **`has()` ではなく `upTo(c, 3)`** を 使う
  （`has()` は 小4を 足した ときから「小3まで」の 意味では なくなった）

## 2. 学年を いつでも 変えられる（予習・復習）

### つかい方
地図の ボタンの 下に **「小1 小2 小3 小4 小5 小6」の チップ**が 出る。押すと その場で
その 学年の ワールドに 行く。**★が ついて いるのが その子の 学校の 学年**。
じゅんびちゅうの 学年（いまは 小5・小6）は うすく 出て、押すと おしらせだけ。

トーストで 「小2の ふくしゅう！」「小4の よしゅう！」「小3に もどったよ」と 出る。

### しくみ
| もの | いみ |
|---|---|
| `p.grade` | **学校の 学年**。プレイヤーを 作る ときに 決まる。学期の せっていは これに かかる |
| `p.playGrade` | **いま あそんで いる 学年**（v4.5・新）。地図の チップで いつでも 変わる |

- `MQ.content.activeWorld()` は **playGrade** を 見る（開いて いない 学年は その子の 学年 → 小3）
- `MQ.save.setPlayGrade(g)` … 変える（じゅんびちゅうの 学年は `false` を かえす）
- **学期の しぼりこみは じぶんの 学年の ときだけ**（`MQ.terms.reviewing(p)` → `termOf` が 0）
  ふくしゅう・よしゅうでは ぜんぶの 単元を 出す（もう 習った／まだ 習って いないので しぼる 意味が ない）
- おうちの人ページの 表示は `MQ.terms.settingTerm(p)`（ほぞんされて いる 学期）を 使う。
  単元の 一覧も **その子の 学年の ワールド**から 作る（ふくしゅう中でも 中身が 変わらない）

### 学年ごとに 分けた もの
**かけら**（`p.frags`）と **にげた敵**（`p.escaped`）は キーを `'g4:sansu'` の ように 学年つきに した。
- そうしないと 小2で あつめた かけらで 小3の 塔が 開いて しまう
- とっくん・リベンジも その 学年の 敵だけ 出る
- 古い セーブは `migratePlayer` が **その子の 学年の ぶん**として つけかえる
- しょうごう「かけらの もちぬし」は **同じ 学年で 4つ**（`hero.js` の `t-frag`）
- 使う ときは `MQ.save.areaKey(areaId, player)` / `MQ.content.fragKey(areaId, player)`

### さわった ファイル
`save.js`（playGrade・areaKey・setPlayGrade・キーの つけかえ）／`world3.js`（activeWorld・fragKey）／
`terms.js`（reviewing・settingTerm）／`battle.js`（かけらの キー）／`hero.js`（しょうごう）／
`map.js`（学年チップ `gradeRow`）／`dex.js`（おうちの人ページの せつめい）／`style.css`（`.grrow` `.chip--g`）
