# v6.0 AIに 絵を 見てもらう（写真の 認識を AIに）（2026-09-04）

## きっかけ

ユーザー「**AIの写真認識する能力はあげれないの？**」→ 3つの 選たくしを 出して「**作る（おすすめ）**」。

## それまでの 問題

写真→モンスターの 認識は **AIを 1つも 使って いなかった**。ぜんぶ 手で 書いた 画像処理で、
読めるのは 色・たてよこ・目の 数（丸さがし）・つの／あしの 数（でこぼこ）・歯・四角さ だけ。
**「これは コウモリだ」という 判断は 原理的に できない** ので、候補を 出して 子どもに えらんで もらって いた。

## やった こと

### ① `MQ.ai.describe(dataUrl, kinds)`（`js/core/ai.js`）

絵を 送って **文字（JSON）だけ**を もらう。**絵は AIに かかせない**。

```
{"kinds":["bat","devil","ghost"],"eyes":2,"horns":2,"name":"コウモリン"}
```

- `kinds` … 85しゅるいの id から 3つ（合う じゅん）。id と 日本語名の 表（`MQ.monsterGen.kindList()`）を いっしょに 送る。
- `eyes` / `horns` … 絵から 読むより AIの ほうが 当たる ので **ヒントとして つかう**（`MQ.monsterGen.setHint`）。
- `name` … なまえの らんが からっぽの ときだけ 入れる。

**なぜ 絵を かかせないか**：v3.5 で「AIに かかせた 絵は ほかの モンスターと 浮く」と 3回 言われた。
**しゅるいだけ 当てて もらい、絵は いつもの `make()` で 組み立てる**ので 見た目は かならず そろう。

**AIの 名前（モデル）**：`SEE_MODELS = ['gemini-3.1-flash-lite', 'gemini-3-flash-preview', 'gemini-3.1-flash', 'gemini-2.5-flash']`。
上から ためして **404（その 名前の AIが ない）なら つぎへ**。うまく いった 名前は `conf.seeModel` に おぼえる。
（Google は モデル名を よく 変える。決めうちに しない）

**お金**：絵を 作る AI（v2.8）は 無料わくが なく 1まい 約5〜20円。**文字を かえす AIには 無料わくが ある**。
1日の 上限は v2.8 の せってい（初期 20回）を 2つで 分けあう。

### ② 候補の 先頭に もってくる（`monstergen.js` の `withFirst`）

AIの こたえた しゅるいを 候補の いちばん 前に。候補に なければ **その場で `make()` して 作る**。
かぶらない（`seen`）。第3引数に 特徴（`f`）を わたせる（テスト用。ふだんは `lastF`）。

### ③ 画面（`js/ui/photo.js`）

- できあがりの 下に **金わくの ボタン「AIに 見てもらう」**（`.photo__seerow`）。
  **かぎが ない ときは 出ない**（v2.8 の きまりを そのまま）。
- 押している あいだ「AIが 見て いるよ…」。おわると 右に **「AIは「コウモリ」だと 思ったよ」**。
- 2回目からは「もう1回 AIに 見てもらう」。
- **写真を 入れかえたら AIの こたえは 消す**（`useImage` で `aiSee = null` ＋ `setHint(null)`）。

### ④ おうちの人ページ（`dex.js`）

見出しを「AIに 絵を 見てもらう」に。**2つの ことが できる**（①見てもらう＝無料わくあり ②かっこよく する＝有料）
と、かぎを 入れない ときは どちらの ボタンも 出ない ことを 書いた。

## たしかめる 道具

`tools/harness.html#aisee`（にせの「見る AI」`fakeSee`）：

| モード | 見る ところ |
|---|---|
| `#aisee` | コウモリと 当てる → 候補の 1番めが bat・なまえが 入る・「AIは「コウモリ」だと 思ったよ」 |
| `#aisee:mimic` | たからばこの 絵 → mimic |
| `#aisee:404` | 1つめの AIが 無い → 2つめで 成功し、名前を おぼえる（seeModel） |
| `#aisee:bad` | こたえが JSONで ない → 子ども向けの まちがい文・回数は 数えない |
| `#aisee:off` | かぎ なし → ボタンが 出ない |

smoke：`kindList()` が 85いじょうで ぜんぶ 日本語名つき・`withFirst` の ならびかえ／その場づくり／かぶりなし。

## まだ 見て いない こと

- **本物の Google との 通信は 未確認**（PC に かぎが ない）。実機で おうちの人ページの「しらべる」→「AIに 見てもらう」。
- モデル名が ぜんぶ 404 の ときは 4回 むだに 通信する（かぎが ちがう ときは 1回目で 止まる）。
- AIが「85種に ない もの」を 答えたら その id は とばす（`withFirst` が BODIES に ない id を むしする）。
