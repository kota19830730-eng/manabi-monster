# v14.6 ボスの 作り直し（ナンバードラゴン・モジオニ）

2026-09-14〜15。ユーザー「ボスのデザインを変えたい。もじおにもナンバードラゴンも弱そうな感じするし、ナンバードラゴンにかんしてはドラゴンじゃない」→ 壁打ち（`docs/壁打ち_ボスの作り直し.md`）→ Claude Design の キャンバスで 3案ずつ（https://claude.ai/code/artifact/80a75047-6c78-4700-92c7-6ce52009083b ）→「**ドラゴンは C で 鬼は B でお願い。3D で 作れるなら すぐに 公開して**」＋「**タイトル画面の ドラゴンも 今の ドラゴンに 差し換えて**」。

## できた もの

| | すがた | 3D の 部品 |
|---|---|---|
| ナンバードラゴン（算数の ボス） | **竜王**：左むきの 横すがた・長い 首・大きな つばさ・4本足・長い しっぽ・金の よろい（むねあて・せなかの 板・ももの おび）・かんむりの つの・むねの 光 | 体・首と 頭・しっぽ・つばさ（手まえ／向こう）・足 4本（手まえ 2・向こう 2） |
| モジオニ（国語の ボス） | **青鬼の 大将**：青い 顔・白い たてがみ・赤い よろい・金の まえだて・つの 2本・めんぼお・なぎなた | 体・頭・たてがみ・うで 2本（肩の よろいごと）・なぎなた・足 2本 |

- **64マス**（ほかの モンスターは 48）。`enemies.js` の `base: 64`。
- バトルの 大きさは **ドットの 大きさを ほかの ボスと そろえる**（`size × base / 48`＝96 → 128・2体 ならぶ とき 80 → 107）。
- **おこった とき**（phase2）：ドラゴンは 目と むねが 赤く 燃える・体が 明るい 赤／鬼は 顔が こい 青・目が 赤。
- **タイトル**の うしろの ドラゴン（前は ザコの ドラゴニクス）も ナンバードラゴンに（136px・`.tmob--dragon` left 226 / bottom 110）。
- 3D の 向き：ドラゴンは **頭が 手まえに くる 向き（ry +18）**。鬼は ふつうの モンスターと 同じ −22。
- 動き（`css/motion3d.css` の いちばん 下）：ドラゴン＝つばさは **rotateX で はばたく**（横すがたの ため）・首を ふる・しっぽが ゆれる・こうげきで ほえる／鬼＝なぎなたを ゆらす・こうげきで ふり下ろす。

## しくみ

- 絵の 正本：**`tools/bossart/final.js`**（`geo.js` の poly／line／rect＝多角形を 2マスの 段々に）。
  → **`node tools/bossart/emit.js`** が `js/content/monsterart.js` の `<boss64>` の しるしの あいだに 書く（**手で monsterart.js を さわらない**・何回 流しても 同じ）。四角の 7つめ＝3D の 部品の 名前。
- 3D：**`js/content/boss3d.js`**（`MQ.vox.boss3d`＝has／make／ry／CFG）。部品ごとに 絵（.bx）を 作って `MQ.vox.fromGroups`（たからばこと 同じ）。向こうの つばさは 同じ 形を こく した もの。
- `vox.js`：部品の 奥ゆきの ずれ **`gr.z`**（手まえの 足・つばさは +、向こうは −）。
- `three.js` の `monster()`：`boss3d.has(shape)` なら 部品で 組む・器の 大きさは `base × unit`。
- `enemies.js`：`node()` に `base`・`paletteOf` を 外から 使える ように。
- smoke：64マスに おさまる・部品の 表と 絵が 合う・読みこみ順（`checkShape` は `e.base` を 見る）。
- harness：**`#boss64[:<ms>]`**（2体を 2D・3D・おこった で 大きく）・**`#bossof:<ステージ>`**（その ボス戦まで。例 `#bossof:kokugo3-1`）。

## もどさない

- 48マスの むかしの 絵に もどさない（「弱そう」「ドラゴンじゃない」）。
- ドラゴンの つばさを rotateY の はばたき（ふつうの モンスター）に しない（横すがたでは ドアが ひらく ように 見える）。
- 多角形の ぬり（段々）に ブロックの ふちと ハイライトを つけない（フラグ 'n'）。つけると 段 1つずつに ふちが ついて ノイズに 見えた。
- ボスの 大きさを 96 に もどさない（主人公と 同じ 大きさ＝弱そう）。
