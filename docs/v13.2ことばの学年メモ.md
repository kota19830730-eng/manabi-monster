# v13.2 ことばを 学年に 合わせる（2026-09-12・sw 139）

ユーザー「学年によって 文章や 表示の 漢字の 使用量を 改善したい。今の 表示だと 高学年には 幼稚に 見える。壁打ちしましょう」
→ 数えて 案を 出す →「任せるわ。マンガや ゲームで 読み慣れている 字は 入れてください」
→ 途中で「必殺技や 吹き出しもね」。

## 1. まず 数えた こと

| 何を | 数 |
|---|---|
| 子どもが 目にする 画面の 文字列（ボタン・ふきだし・技名・しょうごう・たからもの名・ミッション・お知らせ・しゅぎょうば） | 約 2,700 本 |
| そのうち ひらがなだけの ことば（文節）の 種類 | 1,381 種類（3回以上 出る 382 種類で 71%） |
| 画面の 文字が 学年で 変わって いた 場所 | 3か所だけ（小1・小2の 塔の 名前など） |

- **問題文は 学年ごとに 作り分けて ある**（小6の 問題は かん字 53%）のに、**まわりの 画面は 全学年 同じ「小3の 文」**だった。逆に 小1は「正解」「教科」「重さ」を 読まされて いた。
- 幼稚に 見える 正体は 3つ：①ひらがなの ことば（てき・こたえる・けいけんち）②**文節の スペース**（教科書で 使うのは 小1の 前半だけ）③語尾（〜だよ）と 技名（ほのお ギリ）。

## 2. 決めた こと（ぜんぶ おすすめの 形＋ユーザーの ひとこと）

- **文は 1つだけ 書く**（いままでどおり「小3の 書き方」）。出す ときに 学年に 合わせる。2,700本を 6通り 書く 案は 取らない。
- 学年ごとの 形：

| 学年 | かん字 | スペース | 語尾 |
|---|---|---|---|
| 小1 | ひらがなだけ（小1の 字も ひらがな） | あり | そのまま |
| 小2 | 小1の 字まで | あり | そのまま |
| 小3・小4 | その 学年までに ならう 字 | あり | そのまま |
| 小5・小6 | その 学年までの 字 ＋ **マンガ・ゲームで 読み慣れた 字**（魔王・冒険・攻撃・倒す・炎・雷・斬り・剣・盾・鎧 …） | **なし** | 文末の「よ」を 落とす（〜だよ → 〜だ） |

- **問題の 中身（問題文・えらぶ こたえ・ヒント・答えの せつめい）には 辞書を 当てない**。かん字の 読みを 答える 問題で 答えが ばれる／問題文が 変わる のを 防ぐ。小5・小6の スペース外しだけは 問題文にも する。
- おうちの人ページ（大人の 文）は さわらない。
- **見る 学年は その子の 学校の 学年**（`p.grade`）。小3が 小2を 復習しても 小3の 文。おうちの人ページ「ことばの 表示」で **自動／やさしく（小2）／高学年（小6）**に 上書き（`p.textLevel`）。
- フォントは 今回 さわらない。

## 3. しくみ

- **`js/content/kotoba.js`（`MQ.kotoba`）**＝辞書 約790行。1行 `[ひらがな, かん字, 何年生から, 送りがな, しるし, （上書きの 送りがな）]`。
  - 何年生からを 省くと **`kakusu.js` の 学年**（かん字の 形の 字を ぜんぶ ならう 学年）。学校で ならわない 字（魔・剣・炎 …）は **5** を 書く。
  - 送りがなは `'す|した|して'` の 形（長い ものが 先に 合う）。しるし `n`＝数の あとだけ（回・倍・問）／`d`＝かん字 → ひらがな だけ（目・手・下 など。ひらがなから 直すと「て」「した」が 化ける）／`s`＝送りがなは あっても なくても よい（こうげき／こうげきする）。
  - ひらがなと かん字が 同じ 行＝**さわらない ことば**（いろいろ・みたい・です・しました・まなびモンスター・かける・とる …）。ほかの ことばの 一部と まぎれない ように 止める。
  - 2だんかいの ことば：`かんじ → かん字 → 漢字`、`わりざん → わり算 → 割り算`（変換を 2回 まわす）。
- **`js/core/text.js`（`MQ.text`）**＝`fit(s, {raw, level})` / `fitHtml`。
  - **かん字 → ひらがな**（その 学年で まだ ならわない ことば）→ **ひらがな → かん字**（ならって いる ことば）→ 語尾 → スペース。
  - ひらがな → かん字は、ことばの 始まりが **文の 頭・スペースや 数字の あと・直前の ことばの 助詞（が・を・の …）の あと**だけ。**かん字の すぐ あとは 始まりに しない**（「止まった」の「まった」が「待った」に なる）。ことばの あとは **助詞の ならび／べつの ことば／おわり**で ないと 合わせない（「かくにん」の「かく」→「書く」を 防ぐ）。
  - スペース外し：かな・かん字・数字・英字の となりだけ。**数の ついた かん字（1回・2問）の あとの かん字とは くっつけない**（「1回答えよう」と 読めない）。記号（＋・！・：）の となりは のこす。
  - 入り口は 2つ：①`MQ.util.h()` が `text` / `html` / 文字列の 子 / placeholder を 作る とき（同期）②`#stage` の `MutationObserver`（`textContent = …` で 変えた 分）。h() が 作った 文字には しるし（`__mqfit`）を つけ、見はりが 2回 直さない。
  - `raw: true`（`data-raw`）＝辞書を 当てない（スペースだけ）。`#screen-parent` と `data-noconv` は さわらない。`MQ.text.pause(true)` の あいだは 何も しない（おうちの人ページを 作る とき）。
  - 小5・小6の ときは `body.is-nospace`（CSS で `word-break: normal`）。**これが ないと スペースを 外した 文が 折り返せず、問題カードから はみ出す**（`#fit:all` で 9回 出た）。
- **raw に した 場所**：バトルの `.card`（問題文・単元名）・`.choices`（えらぶ ボタン）・`.memo__q`・`.hintbox`・`feedback__note`（答えの せつめい）、しゅぎょうばの 問題カード・ヒント・答え・えらぶ ボタン。
- **セーブ**：`p.textLevel`（'auto' | 'easy' | 'high'）。`save.js` の migrate が 古い セーブに 'auto' を 入れる。
- **小6の 算数の 単元名「文しょうだい」→「文章題」**（章・題は 小3の 字。交ぜ書きが 小6に 出て いた）。

## 5. わな・きまり

- **辞書に ない ことばは 1文字も さわらない**。あいまいな ことば（かえる・とる・かける・たて・ひき・みる の 補助動詞 …）は 入れない か「さわらない ことば」に する。
- **変換の 一覧を 目で 見る**：scratchpad の `dump.js`（画面の 文字列 ぜんぶを 学年 1・3・5・6 で 出す）。まちがいは ここで 見つけた（島した・買える・光り・逃た・始丸・目森・主ひと公 …）。辞書を 足したら また 出して 見る。
- **単語の 送りがなが 落ちる 型**：`['にげ','逃',…]` は「逃た」に なる → `'逃げ'`。語幹に かならず つく 送りがなは かん字の 形に 入れる。
- **harness で ボタンを 文字で さがす ときは `MQ.text.fit('こたえる')`** を 通す（学年で 字が 変わる）。
- **同じ ツリーで 別セッションが v13.1（sw 138）を 出した**ので、こちらは v13.2・sw 139。
