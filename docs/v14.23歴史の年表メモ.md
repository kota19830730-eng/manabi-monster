## 1. なぜ 年表だけ なのか

2026-09-23 に 数えた とおり、**歴史（小6 社会 2〜4ステージ・96問）の 問い方は
87% が 人物・時代・名前の あんき**（だれ 19・いつ 26・ことば 16・その他 30・なぜ 4・どこ 1）。
絵を つけると 答えが ばれる（「縄文時代の 人々が 住んで いた 家を 何と いう？」に
たて穴住居の 絵）＝ v4.9 の きまりで つけられない。

**つけられるのは 年表だけ。** ただし 出しかたが 大事（§2）。

## 2. きまり（もどさない）

| | |
|---|---|
| **つける** | **問題文に 時代か 年が 書いて ある 問題**。その 時代に ▼と 色を つける。答え（人物・ことば・場所）は 年表に 出て いない ので ばれない |
| **つけない** | **答えが 時代・年の 問題**。れい「米づくりが 始まった 時代は？」（答え 弥生時代・えらぶ 4つは ぜんぶ 時代）／「第二次世界大戦が 終わった 年は？」。**年表には ほかの 時代の 名前が 書いて ある ので、のこり 1つに しぼれて しまう** |
| つけない（もう1つ） | 「江戸ばくふが たおれ、新しい 政府が できた 改革を 何と いう？」＝ 答えが **明治**維新。江戸を さしても 明治を さしても おかしい |
| はば | **年数では なく じゅんばん**。縄文は 1万年、大正は 15年だが 同じ はば（教科書の 年表と 同じ 考え方）。docs と 画面の どちらにも 書いて ある |

smoke が **「答えが 時代・年の 問題に 年表を つけない」**を 見る（えらぶの 1つめ＝正解が
`〇〇時代` か `1945年` の 形なら 落ちる）。
