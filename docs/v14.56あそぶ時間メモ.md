# v14.56 あそぶ時間（休憩・1日の上限・夜の時間）

2026-10-29。ユーザー「親がプレイ時間を管理できる機能。一定の時間が経つと休憩しましょうの吹き出し・強制終了のオンオフ」→ 壁打ち →「オススメで」。

## 決めたこと（ユーザー「オススメで」）
1. **強制終了はたたかいが終わるまで待つ**（途中で切ると★・けいけんちが消えて罰になる）
2. **休憩はふきだしだけ**（「やすむ」「あとで」。あとで＝10分後にもう一度）
3. **はじめは全部「なし」**。おうちの人ページ → 設定 →「遊ぶ時間」でプレイヤーごとにオン
4. 追加：**夜の時間**（20/21/22時〜朝6時は遊べない・はじめは なし）。平日／休日の分け・休憩のごほうびは入れていない

## しくみ
- ルール `js/core/playtime.js`（`MQ.playtime`）。セーブ `p.ptSet`（breakMin／limitMin／bedtime）・`p.playMs`（日ごと・14日）・`p.ptExtra`（今日だけのばした分）・`p.ptBedOk`（今夜だけ）・`p.ptSoonDay`
- 数えるのは **画面が見えていて、最後に触ってから90秒いない** の時間だけ。5分さわらないと休憩した扱い（つづけた時間は0に）。セーブへは30秒ごと・画面を隠したとき
- 画面 `js/ui/playtime.js`（`MQ.ui.playtime`）
  - `gate()`＝`MQ.ui.goMap`・`battle.start`・`startTokkun`・しゅぎょうば（`openList`・`open`）の前。止めたら「きょうは ここまで」
  - `afterResult()`＝けっか画面の2.6秒あと：止める → ひとやすみ → もう すこしで おしまい（のこり3分・1日1回）
- 時間をのばす＝カードの「おうちの人」→ **ごほうびマシンと同じ4けたの番号**（`MQ.ui.prize.pinPad` を借りる）→「今日だけ あと15分／30分」・夜は「今夜だけ遊べるようにする」
- おうちの人ページ（`parent.js` の `playtimeSection`・設定のいちばん上）＝3つの設定・7日の遊んだ時間・番号がないときの案内・スクリーンタイム／ファミリーリンクの1行
