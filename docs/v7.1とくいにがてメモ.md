# v7.1 とくい・にがて（おうちの人ページ）メモ（2026-09-05）

ユーザー「保護者が 見る ところで 自分の 子どもの 得意と 不得意の データが 見やすく わかりやすく」→ 壁打ち →
おすすめの 形（①とくい・にがて マップ ②にがて トップ3 と 落とした 問題 ③文字で コピー・子どもには 見せない）で OK。
途中で「問題の 正答率とかも 見れても いい」→ 同じ 問題文なら まとめて 回数を 数える（問題ごとの 正答率）を 入れた。

## 何が 見える か

おうちの人ページ（図かん →「おうちの人」タブ。**地図の「おうちの人」ボタンからも まっすぐ**）の いちばん 上。

1. **いま いちばん にがて**（金わく）… さいきん 5問いじょう やった 単元の 中で 70% みまんの もの、悪い 順に 3つ。
2. **教科ごとの マップ** … 教科（エリア）ごとに 単元（＝ステージ）を ならべ、色で ぬる。
   - みどり＝とくい（さいきん 85%〜）／黄＝ふつう／赤＝にがて（〜59%）／灰＝まだ すこし（5問みまん）／文字だけ 灰＝まだ やって いない
   - 数字は「さいきん n/20」を 大きく、「ぜんぶ ok/n」を 小さく。
3. 行を タップ → **こまかい 単元**（問題の `unit`・にがて 順）と **落とした 問題**（問題文・子どもの 答え・正しい 答え・日づけ・**まちがい N回・正解 M回**）と **「この 単元を れんしゅう（6問）」**。
4. **文字で コピー** … LINE や メールに はりつける 用の 文（先生に 見せる 用）。クリップボードが 使えない 端末は 文を 出して ながおし。
5. 学年の チップ … データの ある 学年（ふくしゅうで 小2を やった など）と じぶんの 学年。

**子どもには 見せない**（地図や けっか画面に「にがて」を 出さない）。赤い 単元を 見ると やる気が 下がる ため。

## しくみ

- **`js/core/battle.js`**：1問ごとに `s.results` に `{ stageId, areaId, unit, type, ok, given, answer, prompt, boss }` を ためる（`pushResult`）。
  **ok は 1回目で 合った ときだけ**（2回目で 合っても ×）。`given` は 1回目に まちがえた ときの 答え（`givenText`・時間ぎれは「じかんぎれ」）。
  `summary().results`。にげた敵・れんしゅうの 問題は `entry.stageId` で もとの ステージに ためる。
- **`js/core/stats.js`（新・`MQ.stats`）**：`record(p, sum)` が `p.stats.rows`（ステージごと と `ステージ|unit` ごとに `{ok, n, r, at}`・`r` は さいきん 20問の ○×）と
  `p.stats.wrong[ステージ]`（落とした 問題・同じ 問題文は 1つに まとめて `miss`／`ok` を 数える・多い 順・20問まで）を 更新。
  `measure`（pct・level）／`overview(p, grade)`（教科 → ステージ → こまかい 単元）／`weakest(p, grade, 3)`／`summaryText`／`gradesWithData`／`promptText`（図・表を 落として 60文字）。
  しきい値：`FEW 5`・`GOOD 85`・`WEAK 60`・`TOP_WEAK 70`。
- **`js/ui/battle.js`**：`applyRewards` で `MQ.stats.record`（とっくん・タイムアタック・塔も ためる。塔は ステージ id が `towerN` なので 一覧には 出ない）。
  **`startDrill(stageId)`**（新）＝その ステージの 問題 6問を とっくんの しくみで。`escaped` の entry に `revenge: false` → core が リベンジ あつかいに しない（リボン・EXP+15 なし）。★・記ろく・コインは つかない（tokkun）。
- **`js/ui/dex.js`**：`statsSection`（`.pstat`）を parentTab の 先頭に。古い「たんげんごとの できぐあい（さいこう記ろく）」の 一覧は 消した（マップに 置きかえ）。「いま つまずいている 問題」→「にげられた 問題 ※とっくん・リベンジで もどってくる」。
- **`js/ui/map.js`**：ボタンの 行に「おうちの人」（2×2 に なる・`.maptop__row` は flex-wrap）。
- **算数は 生成式**（毎回 数字が 変わる）なので 問題ごとの 正答率は 出にくい → こまかい 単元（`unit`）で 見る。国語の ことば・理科社会・英語・かん字は 同じ 文が くり返し 出るので 問題ごとに 数えられる。
