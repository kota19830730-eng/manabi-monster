# v7.7 てきの ため → カウンター（2026-09-06）

ユーザー「敵が なにかしらの 攻撃を して 妨害する のは どう？」→ 壁打ち →
**案A（ため → カウンター・くらっても 損は ゼロ）・ザコ 3問に 1回・ボス 2問に 1回・小1・小2にも 出す（おうちの人ページで 切れる）** で 決定。

## きまり（core/battle.js）

- 敵がわに「ため」が ある。**ザコは 3問ごと**（たからばこは 数えない：3・6・9・12体め）、**ボスは 2問ごと**（2・4・6…問め）に「こうげき」の 問題に なる（`chargeInfo()` → `{ level, need, attacking, boss }`）。
- その 問題に **1回めで 正解 → カウンター**：ザコは けいけんち **1.5ばい**（`COUNTER_MUL`・クリティカル などを 足した あとに かける）、ボスは **2ダメージ**（`COUNTER_DMG`・ばくれつと かさなる ときは 大きい ほう）。`res.counter = true`・`summary().counters`。
- **まちがえると「くらった」**：`res.hit = true`（retry / shielded）。**演出だけ**。コンボ 0は いつもの まちがいと 同じで、ライフも コインも へらない（「負けは ない」きまりは そのまま）。2回めで 正解しても カウンターには ならない。
- **とっくんでは 出ない**。タイムアタックでは 出る（時間切れは ふつうの まちがい）。
- おうちの人ページの 切りかえ：`p.attacks`（はじめは true）→ `MQ.battle.start({ attacks: true })`。**core の 初期値は「なし」**（むかしからの ボス戦の テストと ほかの 呼び出しを 変えない ため）。画面（`ui/battle.js` の start）が せっていを 見て true を わたす。
- しょうごう **「カウンターの たつじん」**（10回・`p.counters`）＝ 46種。

## 画面（ui/battle.js・css）

- 敵の 頭の 上に **ための 玉**（`.foecharge`・ザコ 3つ・ボス 2つ）。たまりきった 問題は「こうげき！」（ボスは「大わざ！」）の 赤い ラベル＋敵が 赤く 光って ゆれる（`.enemy.is-attacking`）＋うなる 音（`sfx.charge`）。ふきだしは「○○ が こうげきして きた！ 正解で カウンター！」。
- **カウンター**（`counterFx`）：金の 帯「カウンター！」（`.counterbanner`）＋主人公の 大きな ふみこみ（`.hero.is-counter`）＋白い 光＋`sfx.counter`。ダメージ表示は「カウンター +N」。
- **くらった**（`struckFx`）：敵が 主人公の ほうへ つっこみ（`.enemy.is-lunge`）→ 主人公が よろけて 赤く なる（`.hero.is-struck`）＋ゆれ＋`sfx.enemyHit`。ふきだし「くらった！ でも だいじょうぶ。もう1回 こたえよう！」。
- おうちの人ページ「きょうの フィーバー教科」の 下に「てきの こうげき（ため → カウンター）」つける／なし（`feverSection`）。

## テスト

- smoke：たからばこを 数えない ならび `12A12A12A12A`／こうげきの 問題で まちがえると hit・2回めの 正解は カウンターに ならない／6体めの けいけんち (10+5)×1.5／ボス 2問めが 大わざ・2ダメージ・burst 0／attacks:false・とっくんは なし／タイムアタックの 時間切れは wrong／しょうごう／古い セーブ。
- harness `#counter`（3体めの こうげき）`#counter2`（カウンターの 帯）`#counter3`（くらった）`#counterboss`（ボスに 2ダメージ）。`#flow` に counters の 検査。
- **同じ ファイル（ui/battle.js）を v7.5 が 直前に さわって いた** → 新しい 名前は 先に grep（`renderCharge / counterFx / struckFx / .foecharge / .counterbanner / is-lunge / is-struck / is-counter` は かぶりなし）。

## 実機で 見る こと

- 3問に 1回の 頻度が うるさく ないか（多ければ `CHARGE_MOB` を 4に）。
- 「くらった」で 小1が こわがらないか → おうちの人ページで「なし」。
