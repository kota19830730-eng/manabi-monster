## 2. できた もの

### ① 光（`pixel.js` の `LIGHTS`・`opts.lit`）
マイクラの 絵が きれいに 見えるのは グラデーションでは なく **面ごとに 明るさが きっちり ちがう**から。
だから **面の 中は 平らな まま**で、つぎの 4つを 入れた（角は 消えない）：

| | 中身 | 数字（sunset） |
|---|---|---|
| 面の 光 | ふちから `band` サブぶんを **一定の 明るさ**に（帯の 中で 変えない） | 上 +0.26／左 +0.08／下 −0.14／右 −0.10・band 2 |
| かげの 落ちこみ（AO） | 上に べつの 層が ある ところ（あごの 下の 首もと・うでの 下） | 0.20・3サブ |
| 光の 色 | 明るい ところは 白でなく **あたたかい 色**へ、くらい ところは 黒でなく **すこし 青**へ | warm [255,232,180]／cool [66,72,126]・青みは 18% |
| ふちの 光（リム） | **そとがわ**の 右と 上の ふち 1サブに 夕日の 色 | 0.55・[255,204,124] |
| にじむ 光（bloom） | `mat: glow` の まわりを くらい ふちでは なく 光に | 0.7 |

2案 作った：`day`（ひるま・リムなし）と `sunset`（ゆうやけ）。**ユーザーは B＝sunset を 選択。**
本体は `hero.js` の `HD = { hd: 2, rim: 0.45, lit: 'sunset', sat: 0.2 }`（`sprite` / `faceSprite` / `bodySprite` / `gearSprite`）。

### ② 色を はっきり（`opts.sat`）
灰色から 遠ざける（さいど +20%）。角は 変わらない。
めの色「こん」は `#1f2d5c`（黒に 見えた）→ `#2743a0`。ちゃいろ・あお・みどり・むらさきも すこし はっきり。

### ③ 目を 大きく（`face.js` の `eye96`）
4サブ（12%・v9.9）→ 6サブ（19%）→ **10×8 サブ（顔の たての 25%）**。左目 x33〜42・y22〜29。
**はなが y30 からなので、これが 上限。** 11しゅるい ぜんぶ 同じ 大きさに そろえた。
**つやが なければ 大きくても こわく ない**（v9.9 で「こわい」だったのは 大きさでは なく 光の 点と グラデーション）。

### ④ タイトルの 勇者（`tools/gen-title-art.js`・`poster()`）
- かみ … 平らな かぶり → **ツンツン**（上に とんがり 3本・明るい すじ `k` を ななめに・まえがみは 2段の ぎざぎざ）
- 目 … 3×3＋光の 点 → **4×4 の 白＋青**（白は 外がわ・平ら・光の 点なし＝アバターと 同じ）
- 口 … なし → **こい 茶色の わらった 線**（`N`。`POSTER_PALETTE` と `POSTER_MAT`（mouth＝FLAT）の 両方に 足した）
- `poster()` に `lit: 'sunset', sat: 0.2`。**`rim: false` は そのまま**（v5.0 の きまり）。キーは `'poster:v101'`。
- **その子の アバターには して いない**（v5.0 の きまり）。「この顔で」＝同じ **作り**に した。

## 3. 1回目の 失敗（もどさない ための きろく）

「全部 影が でて 不気味」の 原因は 3つ：
1. **前がみの 下の かげ（AO）が 目の すぐ 上に 落ちて、目が くぼんで 見えた**
2. **はだの かげを 青く したら 病気みたいな 顔**
3. かげが 光より 強くて、ぜんたいが v9.9 より **くらく** なった（見本は 明るい 絵）

→ **はだには AO を 落とさない・はだの かげは 青に しない・ふちの 光も はだには かけない**（`NOLIT`／`SKIN_LIT`）。
はだには **面の 光だけ**（服の 75%）を 入れて 立方体に 見せる（「べた塗り感」対策）。
はだの かげの 色（hero.js `skinDark`）は 黒ずみでなく **あたたかい 茶** `mix(skin, '#8a4a30', 0.30)`。

## 4. もどしては いけない ところ

- **目・口は FLAT**（光の 点・グラデ・リム・AO を つけない）。
- **はだに AO と 青い かげを つけない。**
- **面の 光は 帯の 中で 一定**（グラデに しない）。ざらつきは とびとび・もとの 1マスごと。
- **目の 大きさは 10×8 サブが 上限**（はなに かぶる）。
- **タイトルの 勇者に `rim` を つけない・その子の アバターに しない。**
- `POSTER_MAT` に 文字を 足し忘れると cloth あつかいに なる（claude-65 の 引きつぎメモ）。
