# v7.5 こうげきを 楽しく（2026-09-05）

息子さん（ユーザー経由）：「バトル画面の 攻防の バリエーションを ふやしたい」
→ 壁打ちで 現状を 整理 → 「攻撃の モーションとか 必殺技も もっと 楽しくしたい」
→ 9つの 案を 出して **「全部いいね！実装してください」**。

## なぜ ここを 直したか（壁打ちの 結論）

**通常こうげきは「主人公が 右に 26px すべって もどる」だけ**だった（0.32秒）。
それを **1回の たたかいで 16〜18回** 見る。ひっさつわざ（7種・v2.5）は 派手なのに、
あいだを うめる 通常こうげきが 地味で 落差が 大きかった。
主人公は けんを そうびして いるのに **振って いなかった**。

なお このアプリは **負けが ない**（ライフ制なし・HP減少なし・通常バトルに 制限時間なし）。
だから「敵の 行動は うばう ものでは なく、もらえる ものを 動かす」が 大原則。
この 版は **見た目だけ**を 直し、ルールは 1つも 変えて いない。

## さわる ときの ちゅうい

- **`sparks` という 名前を つかわない**。ひっさつわざが すでに `sparks(n, cls, r, opts)` を
  使って いる。同じ IIFE の 中で 同じ 名前の function を 作ると **上書きして しまう**
  （これで バトルが 落ちた。私の ほうを `hitSparks` に 改名して 直した）。
  → **短い 名前を 足す ときは `grep` で ぶつからないか 見る**（`.pal` の CSS 衝突と 同じ 教訓）。
- 弧・つぶは **`d.cur`（いまの 敵）の 子**。つぎの 問題で 敵ごと 作り直されるので 自然に 消える。
- カットインは **`d.fxs`（`.fxscreen`）の 子**。わざの おわりに `d.fxs.textContent = ''` で 消える。
- `playScreenFx` は `sp.tier` で 見た目が 決まる。**tier 5 は tier 4 と 同じ 扱い**に する
  CSS を 足して ある（`.fxscreen--t4, .fxscreen--t5`）。
- ためゲージは **コンボが 2いじょう の ときだけ** 出る。わざが 出た しゅんかんは かくす。
