## 2. 流れ

1. **おうちの人ページ（ホームの 下）**で 書く：
   - ひとこと **40文字まで**（からっぽは 送れない・前後の 空白は とる）
   - おまけの ミッション＝**教科を 1つ**（「なし」でも よい）。
     **いま いちばん 正答率の 低い 教科に「おすすめ」の 印**（`MQ.stats.weakest` の 1位。v7.1 と 同じ）
   - ごほうび＝**コイン 1〜3**
2. **子どもの 地図の いちばん 下に 封筒**（金色・ゆっくり ひかる）。
3. タップ → **紙の 色の カード**（ひとこと＋おねがい＋コイン）→「よんだ！」。
4. ミッションつきなら **きょうの ミッションに 1つ ふえる**（`letter: true`・金わく）。
   できたら コイン（親が 決めた 数）＋ おうちの人ページに「読んだ・ミッションできた」。
   ミッションなしなら **読んだ ときに** コイン。

## 3. きまり（くずさない）

1. **外には 送らない**（同じ タブレットの セーブの 中だけ。企画書の「データの 外部送信 なし」）。
2. **子どもの 画面に「にがて」と 書かない**（v7.2 の きまり）。ミッションの 文は
   「おうちの人から：〇〇で 1かい たたかう」＝ いつもの ミッションと 同じ 言い方。
   「おすすめ」の 印は **おうちの人ページだけ**。
3. **1通だけ**。新しく 書くと 上書き。**読んだら 封筒は 消える**（出しっぱなしに しない）。
4. てがみの ミッションは **「3つ ぜんぶ」の ボーナスに 数えない**（おまけ なので、
   親が 手紙を 出さない 日と 出す 日で むずかしさが 変わらない ように）。
5. **地図の たてを 増やさない**。封筒は てがみが ある ときだけ 出る。

## 4. テスト

- smoke「おうちの人からの てがみ」＝ からっぽ／40文字／前後の 空白／コインの 上限／
  読むと ミッションが 1つ ふえる／子どもの 文に「にがて」が ない／
  ミッションつきは 読んだ だけでは コインなし／できたら コインと done／
  「3つ ぜんぶ」は てがみを 待たない／ミッションなしは 読んだ ときに コイン／
  上書き・消す／古い セーブ／読みこみ。

  `#letter2`（封筒 → カード。画面に おさまるか）`#letter3`（読んで ミッションに 入る → できた）。
