## つづき：128マスで きれいに（2026-10-10 同じ日）

ユーザーが 見本の うさぎを 見て「どうも 汚く 見える。もっと 解像度 あげて 綺麗に」。原因＝64マス（しらべる 写真も 320px）と、体の 光と かげ（クリーム・灰色・青みの 灰色）が べつの 色に 分かれて まだらに なり、その さかいめ ぜんぶに 立体の 明暗が ついて いた こと。

- `OBJ.N` 64 → **128**。色は しらべる 写真の **2ばい**（`OBJ.hi`・mask は 320px の まま のばす）から 読む。
- 色を まとめる きょり `merge` 26 → **46**（体を 1色に）。かわりに 大きな 色（5% いじょう）に **かげの 色**（×0.86）を 1つ 足し、写真で その 色より 暗い ところを ぼかして（64マスで 2マス）10 より 暗ければ かげ＝**なめらかな 2だんの ぬり**。手本の 色は 明るい 点を 重く（明るさの 3じょう）＝ぬいぐるみの 本当の 色。
- `smoothLabels`（1マスだけ ちがう 色を ならす・2回）。立体の 明暗は **そとの ふちだけ**（中の 色の さかいめには つけない）。
- 「そのまま」「かっこよく」は 128マス、**ブロックふう 2まいは 64マス**（`coolTrace` の M。128だと まだら）。monstergen の 候補には 64マスに ちぢめて わたす（`OBJ.genN`）。
- `monstergen.evoPng`：128マスの 絵は 本体を 128 の まま、かんむり・つばさ・ほのおの 部品は 64マスで 決めて 2ばいに 描く（64・48 の 絵は 画素まで 前と 同じ＝息子さんの 4体で 確認）。3D は 前の 面が png そのものなので 128 でも そのまま くっきり（vox の グリッドは 64 の まま）。
- harness：`#mine:<sub>:<encodeURIComponent した 画像 URL>` で ほかの 絵を ためせる・`#mine:evo:<url>`（進化の すがた 6つ・ログ evo sizes）・`#mine:duel:boss:<url>`（3D の バトル）。

## つづき 2：「そのまま」は ころたまと 同じ 写真に（2026-10-10 同じ日）

ユーザー「まだ 汚い。1回 そのままは ころたまと 同じ クオリティに」。ころたまの「そのまま」は **ドット絵では なく 切りぬいた 写真**（renderRaw＝levels の 色・ふちを やわらかく・256px）。

- `MQ.subject.photo(q, m, W, H, box, r, out)`（subject.js に 足した・ころたまの renderRaw と 同じ）。まなびモンスターは 2ばいの 写真（640px）から・ふち 2px・**192px**（`OBJ.photo`）。256 だと 1まい 62KB、192 で 37KB。
- 候補の 先頭「そのまま」＝この 写真。「かっこよく」は 128マスの ドット絵、ブロックふう 2まいは 64マス。
- 影は 点ごとにも 消す（`cutShadow`・そとから つながる 床と 同じ 色みの 暗い 点・主役の 15% まで）。
- 大きな 写真（160px いじょうの data:image/png）は **なめらかに 描く**：photo.js の いちばん 上で document の load（キャプチャ）で `image-rendering: auto`／vox.js の slab の 前の 面も／monstergen.evoPng の 本体も なめらかに ちぢめる（256 まで）。ドット絵（48〜128px）は かわらない。
- **しゃしんの「そのまま」の モンスターは 12体まで**（`PHOTO_MAX`・1体 約150KB＝3段階 ぶん・セーブ（localStorage 約5MB）が いっぱいに ならない ように）。13体めは トースト「下の つくった モンスターを 1体 消すか、かっこよくを えらんでね」。
- のこり：進化の 宝石（むねの 赤い 四角）が ぬいぐるみでは 口の あたりに 来る（evoParts は 絵の 形から むねを 決める）。写真の 本体に ブロックの かんむり・つばさを のせるので 少し 絵の 感じが ちがう。

## つづき 3：ぬいぐるみは「そのまま」と「絵本ふう」の 2まい（2026-10-10 同じ日・決定版）

ユーザー「ブロック風 酷すぎる」「1回 いいと 思うように やって。子どもが 喜ぶように」→ 自分で 大きく して 見なおした：
ドット絵（かっこよく 128）は 体が 灰色で 汚れて 見え 目が 黒い かたまり、ブロックふう 2まいは 顔が ばらばらの 点に なる。
**写真には ドットの しあげは 合わない**（線で 囲んだ べた塗りの 絵 用）。→ ぬいぐるみの 候補は **2まいだけ**。

- **そのまま**＝切りぬいた 写真（`MQ.subject.photo`・192px・ふち 2px）。
- **絵本ふう**＝ころたまの `renderSoft` に 足した こと（`opt`）：`chroma`（色みを 重く した きょり＋色みの はなれた 点を 種に＝うすい ピンクの 耳・ほっぺが クリーム色に とけない）・`K: 10`・灰色っぽい 中くらいの 色は いちばん 多い 色の こい 色に（体の かげが 灰色の しみに 見えない）・`line: 3`（そとの ふち 3px を こい 茶＝ゲームらしく）・`win: 4`（2ばいの 写真なので 窓も 2ばい）・`out: 192`。`MQ.subject.soft`。
  **ころたまの 絵本ふうは opt なしの まま 同じ**（直す ときは 両方の subject.js）。
- 出さない：ドット絵（かっこよく）・ブロックふう 2まい・組み立ての 候補（デザインの あん／ほかの すがた）・「目は どこ？」・「ドットを 直す」・しあげの チップ・はいけい／線の スライダー。`paintPicks` の `hasGen`・`paintEyes`・`editRow`・`cleanRow`。一覧の「直す」も 大きな 絵（20000字 いじょう）には 出さない。
- `mon.plush = true`（photo.js の save・enemies.setCustom が 写す）→ 相棒の せりふは `PLUSH_TALK`（「かいて くれた」と 言わない）・なかまタブ「写真の 色で 決まったよ」。
- 進化の むねの 宝石は 写真（160px いじょう）では 高さ 0.68（`evoParts` の `opt.gemY`・顔が 上半分に ある ため）。
- 案内文「とりなおす」は 辞書で「鳥なおす」に なった → 「もう いちど とる」。
- たしかめ（ぜんぶ 800×1280 か 520×940 で 撮った）：写真の 画面・3D の バトル（たいけつ）・2D の バトル・相棒（64px・せりふ）・なかまタブ（進化 3つ）・タイトル（`.tmob--mine`）・地図の ふだ・けっか画面（たおした・なりたそう）・作った モンスター 一覧。harness `#mine:<sub>:<encodeURIComponent した 画像の URL>`（大きな 絵なら plush に なる）。
- うさぎ 6まい（撮り方ちがい）ぜんぶ 2まいが きれい。息子さんの 紙の 絵 4まいは 画素まで 同じ。つくえの 上の 紙は 紙の 道。
