# v7.9 細い字を 直す（本文の 書体を 入れかえ）＋オフラインでも 字が 落ちない（2026-09-06）

ユーザー：「**メニューの はじめから とかの 細い字が 気に なるけど 修正できる？**」
→「クロードデザインの スキル 使って なおして ほしい」→「**こういう 細字の ところ 全部 修正お願い**」。

## 何が 細かったのか（実測）

harness を **800×1400 で 撮って 2倍に して 見た**ら、細いのは ぜんぶ **本文の 書体 DotGothic16（ドット文字）**だった。
1本の 線が 1px の ドット書体で、太さは 1つ しか ない。使われて いた ところ：

- タイトル：「＋ はじめから」「ずかん」（`.btn--cream` `.btn--stone`）・「おと」「きょく」「おうちの人」（`.sw`）・ひとこと
- 地図：「図かん」「タイムアタック」「プレイヤー」・「こうた」「りゅうを たおす者」（HUD）・ステージ名・フィーバーの 説明
- バトル：こたえの えらび（`.choice`）・ヒント・「ひろげる／けす」・こたえの わく
- 図かん：タブ・しょうごう・そうび・すがたえらび

見出しの **Mochiy Pop One は 太い**（ロゴ・「ぼうけんの つづき」・問題文・数字）ので、
**細い ものと 太い ものが 同じ 画面に 出て、弱く 見えて いた**。

## 直したこと

**① 本文の 書体を Zen Maru Gothic に**（`--f-body`）。まるゴシックで **500 と 700 の 太さが ある**。
Mochiy Pop One（まるい ポップ体）と 相性が よく、教科書的で 小3が 読みやすい。
**ドットの 世界観は 絵（モンスター・地形・アバター）で 出して いる**ので、字は 読みやすさを とった。

**② `body { font-weight: 500 }`**（きほん）。
**③ 押す ところ・名前・ラベルは 700**（`css/style.css` の いちばん 下「文字の 太さ」）。
説明文・ヒント・注記は 500 の まま（太字だらけに しない）。

> **してはいけない**：`--f-head`（Mochiy Pop One）の ところに `font-weight` を つける。
> 400 しか ない 書体なので、ブラウザが にせの 太字を 作って **にじむ**。だから `.btn` 全体では なく
> `.btn--cream` `.btn--stone`（本文書体を つかう ボタン）だけを 700 に して いる。

**④ オフラインで 書体が 落ちる のを 直した**（ついでに 見つけた 別の 不具合）。
書体は Google（fonts.googleapis.com / fonts.gstatic.com）から 読んで いるのに、
**Service Worker が キャッシュして いなかった**。ホーム画面から オフラインで 開くと
端末の 字に 落ちて、**ロゴまで ふつうの 字**に なる（`--host-resolver-rules` で 実測）。
→ `sw.js` に **`FONT_CACHE`**（`manabi-monster-fonts-v1`）を 足し、fetch で 1回 読めたら ためる。
版を 上げても **消さない**（`activate` の filter に 足した）。書体は 変わらない ため。

**⑤ 読みこみを 軽く**：`index.html` の Google Fonts から DotGothic16 を 外し、Zen Maru Gothic 500;700 を 足した。
`js/ui/boot.js` の `document.fonts.load` も 新しい 書体に。`tools/harness.html` の link も そろえた。

**⑥ ひとことを リボンの 旗に**（ユーザー「**こたえた ぶんだけ つよくなる。も カッコ良くして ほしい**」）。
まるい 紺の 帯 → **金の ふち＋左右に 折れた しっぽの リボン**（`.title__tag`）。
・色は ロゴと 同じ 金（`--gold`）と こげ茶。あたらしい 色は 作らない
・しっぽは `::before` / `::after` を **旗の 外**に おく（かさならない ので z-index が いらない）
・字は 見出し書体（Mochiy Pop One）16px の クリーム色。**金の 字には しない**
　（ロゴが 金なので、2つ ならべると けんかする＝目立たせるのは 1か所だけ）
・**光が ゆっくり 1回 走る**（`tagShine` 4.6秒。ボタンの `shine` と 同じ 語彙。動きは これ 1つ）
・`prefers-reduced-motion` の 端末では 光を 止める
たての 収まりは **800×1280（＝ステージの 高さが いちばん 短い 700 の 場合）**で 確認ずみ
（前の 帯より 10px 高く なった ので、ロゴと 空の モンスターの あいだで 見た）。

## たしかめた こと

- スクショ：タイトル／地図／バトル／ぼうグラフ／図かん／けっか／アイテム／すがたえらび／おうちの人ページ
  （800×1400・800×1280・520×780）。**前後を ならべて 見た**。
- **`#fit:all` は 800×1280 で 286回・520×780 で 285回、はみ出し 0**（書体を 変えると 幅が 変わるので ここが 大事）。
- smoke ALL OK・`#flow` エラー 0。
- おうちの人ページは **別の 書体**（Zen Kaku Gothic New／BIZ UDPGothic）なので 見た目は 変わらない。
  先生用の 印刷（A4）も 変わらない。
- **オフラインの たしかめ方（本当に やった）**：`scratchpad/serve.js` で ローカルに サーバーを 立て、
  同じ プロファイルで 2回 ひらいて Service Worker に ためさせ、3回目を
  `--host-resolver-rules="MAP fonts.googleapis.com 127.0.0.1:1,MAP fonts.gstatic.com 127.0.0.1:1"`
  （＝Google を 完全に 止める）で ひらいた → **ロゴも ボタンも いつもの 字の まま**。
  直す 前に 同じ ことを すると、ロゴが ふつうの ゴシックに なる。

## もどさない

- 本文を DotGothic16 に もどさない（ユーザーが 細いと 言った 当人）。
- `--f-head` の ところに `font-weight` を つけない。
- `sw.js` の `activate` で `FONT_CACHE` を 消さない。
- 書体を 変えたら **かならず `#fit:all` を 2つの 大きさで 回す**（字の 幅が 変わって はみ出す）。
