# v13.11 iPad で 音楽が 流れない（2026-09-12・sw 153）

ユーザー「妻の iPad で プレイしたら 音楽が 流れないのは なぜ？」

## 原因

- 効果音（`js/core/sfx.js`）と BGM（`js/core/bgm.js`）は **べつべつの AudioContext**。
- ブラウザは「人が さわった あと」でないと 音を 出させない。ひらくのは `ctx.resume()`。
- **iPad／iPhone の Safari は pointerdown・touchstart の 中の resume() を みとめない**（touchend・click・keydown だけ）。
- BGM を ひらく のは `boot.js` の **pointerdown・1回だけ（once）** だった → iPad では ひらけない まま、2回目は ない。
- 効果音は ボタンの click の 中で `MQ.sfx.unlock()` が 毎回 呼ばれる ので ひらけて いた。
  → **「効果音は 鳴るのに 音楽だけ 流れない」**。Android・パソコンの Chrome は pointerdown で ひらける ので 気づかなかった。

## 直した こと

- `js/ui/boot.js`：**touchend・click・keydown の たびに** `MQ.sfx.unlock()` と `MQ.bgm.wake()`（capture・passive）。1回で 外さない（電話・ほかの アプリの あとも 止まる ため）。
- `js/core/bgm.js`：`wake()` を 足した。**止まって いる（suspended／interrupted）ときだけ** resume して、まだ 鳴って いなければ `play(desired)`。**ひらいて いる ときは 何も しない**（`stop()` で わざと 止めた 曲を 勝手に 鳴らし直さない）。
- `js/core/sfx.js`：`'suspended'` だけで なく `'interrupted'`（iOS で 電話・ほかの アプリ）でも ひらき直す。
- 「消音（マナーモード）」の iPad は Web Audio が ぜんぶ 鳴らない（効果音も）。これは iPad の きまり なので そのまま。

## たしかめ方

- `node tools/mapcheck/wake-audio.js [index.html の file URL]`：iPad の きまりを まねした AudioContext（resume は touchend／click／keydown／mouseup の 中だけ 効く）を 入れて、空の ところを 1回 クリック → BGM が 鳴りはじめるか。
  - 直す まえ（sw 152）：`resume を 呼んだ イベント: pointerdown,pointerdown｜NG`
  - 直した あと：`pointerdown,pointerdown,click,click｜OK`
- smoke：bgm に wake が ある・boot.js が touchend・click・keydown で 呼ぶ・sfx が interrupted でも ひらき直す。

**本物の iPad では 未確認**（奥さんの iPad で「こうしん」→ 画面を 1回 タップ）。
