## 2. 理科の 山 → **理科の 湖**

`world3.js` の 名前を「理科の 湖」に、biome を `hill` → **`lake`** に かえました。
`tiles.js` の `lake` は **ノードの 行の 下に 池を 2つ**（大きいのと 小さいの）ほり、まわりに 木を ちらします。
きしべの 砂は あとの 手じゅん（6番）が 自動で つけます。

**気を つけた ところ**：ノードの 下では 道が **左はし（16%＝5マスめ）を たてに 通る**ので、
池は **11マスめより 右**に おいて 橋に ならない ように して います。
`hill` の コードは 消しました（もう つかいません）。

## 3. 学年ごとの 地図（`js/core/tiles.js` の `THEMES`）

**4つの ワールドを べつの 島に 見せる**。方向は「**学年が 上がるほど 遠くへ 行く**」。
色は 地面（Canvas）、木や 花は CSS（`css/style.css` の `.map--g1` 〜 `.map--g4`）で そろえます。

| 学年 | テーマ | 草 | 森 | 海 | 砂 | 島の 形 |
|---|---|---|---|---|---|---|
| 小1 | **はるの しま** | 明るい 黄緑 | やわらかい 緑 | 明るい 水色 | クリーム | 小さめ・まるい・海岸なめらか |
| 小2 | **なつの しま** | こい 緑 | ふかい 緑 | こい 青 | 白っぽい | 大きい・角ばった |
| 小3 | **いまの しま** | これまでの まま（正本） | | | | これまでの まま |
| 小4 | **あきの 大陸** | 黄みどり | **紅葉（オレンジ）** | ふかい 藍 | オレンジがかった 砂 | 大きい・ごつごつ |

花の 色も 変えて います（小1＝ピンク／小2＝白／小4＝あめ色）。小3は 黄色（そのまま）。

### しくみ

- `MQ.tiles.build(spec)` に **`spec.theme`**（`'g1'`〜`'g4'`）を わたす。`map.js` の `layout()` が
  `MQ.content.activeWorld().id` を 入れます。
- テーマは `colors`（`COLOR` を 土台に 差しかえ）と `edge`（島の 形）の 2つ。
- `build` は `grid.colors` を かえし、`paint` が それを つかいます。
- 画面の いちばん外の div に **`map--g1`〜`map--g4`** の クラスが つくので、CSS で
  木・花・岩の 色を 学年ごとに 変えられます。

### ぜったいに 守る きまり

**`margin + wob` は 4 いか**。ノードは よこ 16%（5マスめ）〜82%（27マスめ）に おかれるので、
それより 外に 海が 入ると **道が 切れて ノードが 海に うく**。
`tools/smoke.js` が 4学年 × 4列 を ぜんぶ しらべます（「gN の 82% は 陸の 上」）。
はじめ 小1を margin 4、小4を wob 3 に したら この 検査で 落ちました。
