# v13.9 タイトルの 背景と 地面を 地図と 同じ 仕上げに（2026-09-12・sw 152）

ユーザー「タイトル画面の 背景や 地面も マップ画面と 同じ クオリティに して 綺麗に カッコ良く して ください」。

## まえ（数えた こと）

- 地図は v13.4 で **B案「ジオラマ」**（なめらかな 海岸線・面 3つの 木と 岩・長い かげ・砂の 道）に なった。
- タイトルは まだ **v9.2／v12.6 の ブロック**だった：
  - 地面＝緑の 帯 26px ＋ 茶色の 帯（12.5px の ます目の くり返し グラデーション）
  - 遠景＝6px の 段の 山なみ・四角の 松・四角の 城・四角の 木と しげみ・四角の 雲（`<i>` 145〜160こ）
  - ボタンの うしろ＝茶色の たての しま（22px）
- ならべると タイトルだけ 1世代 まえの 絵に 見えた。

## やった こと

**絵は Canvas に 描く**（地図と 同じ・画面の 2ばいの 点・`js/ui/scenery.js` の `paintTitle*`）。キャラ・ロゴ・ボタン・空の グラデーションは さわって いない。

| ところ | まえ | いま |
|---|---|---|
| 遠くの 山 | 6px の 段の 四角 | **面 2つ（左＝光・右＝かげ）の 山＋ぎざぎざの 雪の 山頂**（地図の 雪山と 同じ）＋かすみ |
| まおうの 城 | 四角 | **とんがり屋根の 塔 3本**・門・窓の 明かり（朝・夕・夜）・旗 |
| おか | 段の 四角 | なめらかな 曲線 2まい＋上の へりに 日の 光 |
| 木 | 四角 3段 | **地図と 同じ 3だんの とんがり（面 3つ）＋長い かげ**（色は `MQ.tiles.DECO_PAL.g3`） |
| しげみ・花 | 四角 | まるい しげみ（左上が 明るい）・地図と 同じ 5まい花びらの 花 |
| 雲 | 四角 2つ | ふっくら（まる 4つ・底は 平ら・下は すこし かげ） |
| 太陽・月 | ひし形の 段・四角の 三日月 | まるい 太陽＋やわらかい 光・まるい 三日月＋星 |
| 地面 | 緑の 帯＋茶色の ます目 | **原っぱ**（おく→手まえの グラデーション・やわらかい 明暗・草の 株）＋**地図と 同じ 砂の 道**（勇者の 足もとを 通って おかの むこうへ）＋花と 岩 |
| ボタンの うしろ | 茶色の しま | **手まえの 土の がけ**（地層・面 3つの まるい 石・小石・根っこ・草の ふちが たれる） |

- 時間帯（朝・昼・夕・夜）は いままで どおり **本当の 時計**。草・土・木は 色を まぜて 変える（`TINT`＝朝 うすい 金・夕 あたたかい 赤・夜 紺）。山・松・鳥・かすみは v12.6 の `TONE`。
- 1回 描いた 絵は とって おく（`paintCache`・時間帯ごと）。**描く 時間は 1回 2〜5ms**（PC・GPU・`tools/mapcheck/perf-title.js`）。
- **Canvas が 使えない ときは v12.6 の ブロック**（`titleBlocks` / `titleTopBlocks`・`ground()` は null → start.js が 帯の 地面）。`.title--painted` が つくのは Canvas が 使える ときだけ。

## しくみ

- `MQ.ui.scenery.title(time)` → `.bgfar.bgfar--painted` の 中に `canvas.bgfar__cv`（400×150）
- `MQ.ui.scenery.titleTop(time)` → `.bgtop.bgtop--painted` の 中に 400×96 の canvas（太陽の 光が 52px の はこで 四角く 切れない ように `overflow: visible`）
- `MQ.ui.scenery.ground(time)` → `canvas.title__groundcv`（400×450＝原っぱ 120＋土 330）。`.title__land` の いちばん うしろ（z 0）。
  土は `.title__land` の 下に はみ出して **ボタンの うしろ**まで つづく（`.title--painted .title__actions` は 背景 なし）。
  その 下は `.title__land--painted::after`（`--soil`＝土の いちばん 下の 色）で うめる。
- 遠景の いちばん 下（手まえの おか）の 色 ＝ 原っぱの おくの 色（`GREEN.meadow`）＝ つぎめが 見えない。
- 道の 形は `paintTitleGround` の `P`（[x, y, はばの 半分]）。おくは 細く（2.5）・手まえは 太く（36）。

## 気を つける こと

- **scenery.js の 中で 短い 名前を 足す ときは grep する**。1回目に `bush` と `flower` を 足したら、同じ IIFE の 中の バトルの 背景用の `bush(L, …)`／`flower(L, …)` を **上書きして バトルの 背景が 落ちた**（smoke が 見つけた）→ `roundBush`／`flower5` に 改名。v7.5 の `sparks` と 同じ 型。
- 雲を キャラの うしろに 置かない（コウモリが 雲に 乗って 見えた）。ドラゴンの うしろ（x 250〜378）は 何を 置いても 見えない。
- 暗い しみ（大きな 放射グラデーション）は うすく（.045）。濃いと 原っぱに よごれが ついて 見える。
- headless（GPU なし）では うすい グラデーションに 点々（ディザ）が 見える。実機では 見えない。
