## 1. しくみ

| ファイル | 中身 |
|---|---|
| `js/core/streak.js`（新・`MQ.streak`） | `info(player)` / `claim(player)`。**DOM を 知らない** |
| `js/ui/map.js` | 上の 帯の「れんぞく N日」（`.mapobi__stk`）と パネルの `stampPanel()` |
| `js/core/save.js` | `p.streak = { claimed: { '3': 'YYYY-MM-DD' } }` |
| `css/style.css` | `.stamp` ブロック（見た目の 正本は `docs/STYLE_GUIDE.md`） |

- **データは 新しく 作らない**。v7.4 で 入れた **`p.stats.days`**（日ごとの n / ok / 秒）を 読むだけ。
  その日 **1問でも 答えた 日**が スタンプ 1つ。
- `info()` が かえす もの：
  `days`（れんぞく 何日。きょう まだ なら きのうまでの 数）／`today`（きょう ついたか）／
  `fill`（光る マスの 数）／`here`（いま いる マス）／`cells`（7つ）／
  `next`（あしたの { n, pos, coins }）／`claimable`（きょう もらえる コイン）。
- **7マスで ひとまわり**（`posOf(n) = ((n-1) % 7) + 1`）。8日めは また 1マスめ。
- ごほうび **3日＝コイン1／5日＝コイン2／7日＝コイン3**。`claim()` は 1日 1回
  （`p.streak.claimed['3'] === きょうの 日づけ` なら もう もらえない）。

## 2. きまり（くずさない）

1. **切れても ばつは ゼロ**。へらす・とりあげる 表現を 出さない。「また 1日めから」だけ。
2. **あしたの ごほうびを 見せる**（「あした 来ると 4日め！ 5日で コイン +2」）＝ ワクワクの 本体。
3. きょう まだの ときは **これから つく マス**を オレンジの わくで 見せて
   「きょう 1問 こたえると スタンプ！」（小1・小2は ひらがな）。
4. ごほうびを もらった 日は **パネルが ひらいて** マスが はねる（`is-got`）＋トースト＋コインの 音。
5. **地図の たてを 増やさない**（v8.0 で 上を 113px に つめた）。ふだんは 上の 帯の
   小さな チップ（火＋「3日」）だけ。7マスは 帯を 押した ときの パネルの 中。

## 3. 7日めの ごほうびを 変えた わけ

企画では 7日め＝**たからもの 1つ** だったが、たからものは **ステージの ごほうび**で、
ずかんの「あつめぐあい」と ★3の 金色に つながって いる。ただで 配ると 集める 楽しみが くずれる。
→ **コイン 3まい**に した（コインは なかまの こうかんと アイテムの「もう1回」に つかえる）。
