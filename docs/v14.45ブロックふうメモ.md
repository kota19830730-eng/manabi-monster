# v14.45 ブロックふう（試作・2026-10-06・claude-cb・未コミット・未公開）

ユーザー「ブロックの種類を増やして 3Dの感じで 他のモンスターになじむようにもできる？ 自分の絵がわりとそのままか、どっちがいいか選びたい」
→ 1回め＝絵を 24マス／16マスの 四角の ならび（`blockify`）に した → **「解像度が低すぎる。なにか全然わからない。やり直し」** → ぜんぶ もどした。
→ 2回め＝**細かさは「そのまま」と 同じ 64マスの まま、ぬり方だけ ほかの モンスターと 同じ**（これ）。

## しくみ（`js/ui/photo.js` の `coolTrace` の lvl 3）
- `block = lvl >= 3`：色を `COOL.blockColors`（6）まで k-means で まとめる／色の 中の 線は 大きさに かかわらず 消す（`big = strong || block`）／
  外（空）に 面した 線は となりの 色に して **外がわの 輪かく（OUT）を 描かない**／色の 中は 平ら・**ふちの 面**＝`faceBand`（かたまりの 小さい 辺 ÷7・1〜3マス）で 上は 明るく・右と 下は 暗く（blocks.js の topFace／rightFace と 同じ 考え方）。目（eyeIn・iris）は さわらない。
- `opt.snap = 2`＝**もっと ブロック**：量子化の 直後に 2×2 ごとに 多数決で そろえる（目は あとから 64マスの g0 から のせる ので 細かい まま）。面の はばも 2マス きざみ。
- `build()` の `cool = [かっこよく, ブロックふう, もっと ブロック]`。picks の tag は `cool`／`block`／`block2`、`pickName` が「ブロックふう」「もっと ブロック」。写真画面の「きみの 絵」は 2×2 の 4枚に なる（`.photo__mine` は 2列 grid）。ほぞんは いままで どおり `trace: true`（3D は 型ぬき slab）。
- **見た 結果**：ブロックふう（64）は かっこよくと 差が 小さい。**もっと ブロック（2×2）が おすすめ**＝つぶが ゲームの モンスターと 同じ くらいで、スカルホースの 騎士・ABC の 字・ずかんの 目が 読める。サメオニの 3つの 目は 中が ぬって ある ので どの 版でも 出ない。
