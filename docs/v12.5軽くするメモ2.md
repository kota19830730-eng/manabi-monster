`|css=` で 1つずつ 外して 実測：
- バトル：面の 画像を ぜんぶ 外す → 16.7ms／よこ・上下だけ 外す → **16.7ms**／前の 面だけ 外す → 変わらず／アニメを 止める → 18.6ms／相棒を 消す → 19.8ms
- タイトル：よこ・上下の 面を 消す → **17ms**／モンスターを 5体 へらす → 24ms／アニメを 止める → 35ms（4ms ぶん）／`.tmob` の filter を 外す → 変わらず

  `background-size` で 拡大＋`pixelated` で サンプリング する ので、色だけの 層より ずっと 重い。v12.1 の「面の 数が すべて」は 半分 正しかった。

## 2. やった こと

**`js/core/vox.js`**（`buildBox` の `tex`／新しい `sideFill`・`sideCss`・`SIDE_AO`）
- よこ・上下の 面（L／R／T／B）は **アトラスの 画像を はらず、色だけ**。
  - ぜんぶ 同じ 色 → `background-color` 1つ（GPU に 画像を もたせない）
  - 行ごとに 色が ちがう（かみ＋はだ の 頭の よこ など）→ `linear-gradient` の **硬い しま**（`to bottom`／`to right`・色ごとに 区切る）
  - 明るさは 面の 光（`LIT`）× **0.92**（まえの「おくほど 暗く（AO）」の 平均に そろえる）。ざらつき（±6%）は やめた（1ばいでは 見えない）。
- `MQ.vox.flags.sideTex = true` で まえの 画像に もどせる（くらべる 用）。前の 面（`fr`）と 主人公の 絵・下じきは いままで どおり。
- 4ばいの 拡大で 見くらべ（scratchpad の `crop.js`）：よこの 面の ざらざらが 平らに なった だけ。かみ／はだの しま・3面の 明暗は そのまま。

**`js/ui/battle.js`**：3D の あいだは 2D の 主人公の `img` が hidden で、カットイン（12コンボ〜）の 瞬間に はじめて デコードされて いた
→ `setHero` で 先に `Image.decode()`（1コマの ひっかかりを へらす）。

**harness**：`#perffx:<わざ>[:pal]`＝ひっさつわざの あいだ 1.4秒の 1コマを はかる（fx の 部品の 数も）。
