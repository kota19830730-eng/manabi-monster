# 壁打ち：ボスの 作り直し（ナンバードラゴン・モジオニ）

2026-09-14・ユーザー「ボスのデザインを変えたい。もじおにもナンバードラゴンも弱そうな感じするし、ナンバードラゴンにかんしてはドラゴンじゃない。画像みたいなドラゴンのボスと鬼のボスを作成し直すのに壁打ちしましょう」（ドラゴンの 描き方の 参考画像つき：首長型の 赤い ドラゴンと ずんぐり型の 青い ドラゴン）。
とちゅうで「クロードデザインのスキル使ってね」。

## 実測（弱そうに 見える わけ）

- ナンバードラゴンは 四角 12こ・正面むきの 箱の 体に 黄色い 四角が 左右に つく だけ（首・しっぽ・4本足・つばさが ない）。モジオニは 赤い 箱＋つの 2本（13こ）。
- バトルで ボスは 96px、主人公は 84px＝ほぼ 同じ 大きさ。
- ザコの ドラゴニクス（drago-3）と 中ボスの オーガロード（mid-ogre・赤い 鬼＋こん棒）の ほうが 描きこみが 多い。
- この 2体は 算数 92ステージ・国語 26ステージの ボス＝いちばん よく 会う ボス。

## 案（キャンバス）

https://claude.ai/code/artifact/80a75047-6c78-4700-92c7-6ce52009083b （Claude Design の キャンバス・バトル画面に 置いて くらべる＋1案ずつ 大きく）

- ドラゴン A 王者の 立ち姿／B 火を はく 前がかり／C 竜王（金の よろい）
- 鬼武者 A 赤鬼の 武者（黒い よろい・金の くわがた・大太刀）／B 青鬼の 大将（白い たてがみ・赤い よろい・なぎなた）／C 旗の 鬼武者（金の よろい・せなかの 旗に「文」）
- 絵は **64マス**（ほかの モンスターは 48）。バトルの 大きさは 136px（1ドット 約2.1px＝96px の 48マスと ほぼ 同じ ドットの 大きさ）。
- **ユーザーの えらび まち**。

## 道具（tools/bossart/・git には まだ 入れて いない）

- `shapes.js`（案の 絵）・`geo.js`（poly／line／rect＝多角形を 2マスの 段々に）・`render.js`（blocks.js の part() と 同じ ぬり方を node で）
- `./shot.sh dragonA,oniA out.png` → preview.html を 撮る（自分で 見る 用）
- `node build.js` → canvas/ に .dc.html と canvas.json（キャンバスを 作り直す とき）。`arena.jpg` は harness `#boss|css=.foes,.enemy,.bossinfo,...{visibility:hidden}` を 800×1280 で 撮って `crop.ps1` で 切りぬいた もの
- **ブロックの ふち（1px の こい 色）と ハイライトを 多角形の ぬりに つけない**（フラグ 'n'）。つけると 段々 1つずつに ふちが ついて ノイズに 見えた（1回目の 失敗）。
