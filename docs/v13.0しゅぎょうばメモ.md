# v13.0 しゅぎょうば（相棒が 指導して くれる 予習・復習）

2026-09-12。ユーザー「次は 予習と 復習の システムを 作成したい」→ 壁打ち →
「予習を する 修業場みたいなのが あって そこで 問題の 解説などを おしえて くれる システムは 難しい？」→
「**指導して くれるみたいな 感じ。**」→「いいですね。お願いします。」

## 1. なにを 作ったか（ひとことで）

地図に **「しゅぎょうば」** が できた。ステージを えらぶと、**連れて 歩いて いる 相棒**（いなければ フクロン）が
となりで 声を かけながら、① せつめい → ② いっしょに とく → ③ ひとりで やってみる の 3だんで 教えて くれる。
**学期で まだ 閉じて いる「つぎの 1ステージ」も ここからは 入れる**（＝予習）。修行を おえると そのステージが
地図で 開き（「よしゅう」の リボン）、ふつうの たたかいが できる。★を とった ステージにも 入れる（＝復習）。

さいしょに 中身を 書いたのは **小3 算数 18ステージ**。ほかの 教科・学年は「じゅんびちゅう」（一覧に 出ない）。

## 2. きまり（大原則は そのまま）

- **しゅぎょうばは アプリの 中で ただ 1つ「答えを 見せて いい 場所」。** バトルでは いままで どおり 答えを 見せない。
- **ばつは ない。** まちがえても 敵は にげない・★は へらない。合格しなければ「もう いちど いっしょに」に もどる だけ（何回でも）。
- **子どもの 画面に「にがて」と 書かない。**
- **問題は 新しく 作らない。** ステージの `make()`（生成器）を そのまま 使う。指導の セリフ・手順・まちがい方の 声かけ だけ 新しく 書く。
- **予習は おうちの人が 切れる**（`p.previewOk`・はじめは ON）。OFF に すると しゅぎょうばの「よしゅう」の 行が 消え、修行ずみで 開いて いた ステージも 学期どおりに もどる。
- 効果（けいけんち）は「合格した とき」に 出る（アイテムと 同じ 考え方）。

## 3. 流れ（1ステージ 約5分）

| だん | 画面 | 相棒が する こと |
|---|---|---|
| はじめ | 相棒＋ふきだし | 「きょうは あまりの ある わり算だよ。いっしょに やろう！」 |
| ① せつめい | ふきだし＋例の カード（2〜3画面・「つぎへ」） | 単元の 考え方を 手書きの 文で（`explain`） |
| ② いっしょに とく（2問） | 問題カード → **「まず なにを する？」の 3たく**（`steps`）→ ヒント → 答えと 式 | 手順が 合えば「そう！」、ちがえば「おしい。まず 〇〇だよ」と 正しい 道へ。答えは 相棒が 見せる（子どもは 答えない） |
| ③ ひとりで やってみる（3問） | 問題カード＋ヒントが 最初から 出て いる＋テンキー／えらぶ | まちがえたら **まちがい方に 合わせた 声かけ**（`miss`）→ もう 1回。2回めも ちがえば 答えと 式を 見せて つぎへ |
| 合格 | 「しゅぎょう かんりょう！」 | 3問中 まちがい 1問まで で 合格。2問 いじょう なら ②に もどる（新しい 問題で） |

ごほうび：はじめての 合格は けいけんち **+30**、2回め いこうは **+10**。相棒が いれば 相棒にも（`MQ.pals.gain`）。
しょうごう「**しゅぎょうの たつじん**」（5ステージ 合格・`p.dojoDone`）＝ 52種め。

### 指導の 中身の 書き方（`lesson3.js`）

```js
MQ.lessons.add('sansu3-6', {
  intro: 'きょうは あまりの ある わり算だよ。',
  explain: [ { say: '相棒の ことば', ex: '<b>17 ÷ 5</b> …' }, … ],   // 2〜3画面
  steps: [ { when: /あまり/, make: function (q, n) { return { ask: 'まず なにを する？', choices: ['正しい', 'ちがう', 'ちがう'], why: '…' }; } } ],
  miss: [ function (q, v, n) { return v.r >= q.b ? 'あまりは わる数より 小さく なるよ' : null; } ]
});
```
- `steps[].when` は 問題の `unit` に 当てる 正規表現。合う ものが なければ「まず なにを する？」は とばして ヒント → 答え だけ。
- `choices` は **正しい ものを 先頭**に 書く（画面で まぜる）。
- `miss` は 上から 順に 見て、さいしょに 文字を かえした ものを 使う。ぜんぶ null なら `MQ.dojo` の 共通の 声かけ
  （10倍・1ちがい・たし算に なって いる … の 型）→ それも なければ「おしい。ヒントを もういちど 読んで ゆっくり やり直そう」。
- `n` は 問題文の 中の 数字の 配列（`nums(q)`）。筆算の 問題は `q.a`／`q.b` も ある。

### 一覧の 分け方（`MQ.dojo.candidates(player)`）

いま あそんで いる 学年の ワールドで、指導の 中身が ある ステージだけ：
- **よしゅう**＝学期で 閉じて いる ステージの うち、エリアごとに **いちばん 手前の 1つ**（`previewTarget`）。previewOk が false なら 出ない。
- **いまの ステージ**＝開いて いて ★が まだ ない もの。
- **ふくしゅう**＝★が ある もの。
修行ずみの ステージには ✓と 回数。

### 問題の えらび方（`session`）

② は `make(6, { lv: 1 })` と `make(6, { lv: 2 })` から **手順の 3たくが 書ける 問題を 先に** 1問ずつ。
③ は lv1・lv2・lv2 の 3問。かん字を 書く／ローマ字の 問題は 使わない（number／choice／divrem／frac だけ）。
図つきの 問題は そのまま 出る（カードは バトルと 同じ `.card`）。

## 6b. v13.1（sw 138）全学年・全教科に

ユーザー「修行場 どこに ある？」→「ないけど。」→「**全学年で 出るように して。**」
公開中の アプリを 本物の Chrome（800×1280・scratchpad の `live.js`＝CDP で セーブを 作って 地図の `.dojobtn` を さがす）で 調べたら、
小3で あそんで いれば バーは 出るが、**地図の 学年チップで 小2 などに して いると バーごと 消えて いた**（指導の 中身が 小3 算数だけ だった ため）。

- **バーは どの 学年でも 出す**（はじめての 子だけ 出さない＝v11.1 の まま）。
- **手書きが ない ステージは 自動の 指導**（`MQ.dojo.lesson()` → `autoLesson`・中身は `session` の 中で 作る）：
  はじめの ひとこと「きょうは「〇〇」だよ。れいを 見ながら いっしょに やろう！」／せつめい＝**れいを 2つ**（ヒント → 問題 → こたえ → 答えの せつめい。ヒントか せつめいが ある 問題を 先に）／
  いっしょに とく＝ヒント → 答え（「まず なにを する？」は なし）／ひとりで＝共通の 声かけ（10倍・1ちがい・えらぶ問題）。
- **使える 問題が 5つ ない ステージは 出さない**（`usableFor`＝make(12) を ためして number/choice/divrem/frac を 数える。かん字を 書く・ローマ字を うつ が 中心の ステージが 外れる）。
  問題が そろわない ときは `session` が null（そのまま 進むと ただで 合格に なる）。
- **予習は 問題を その場で 作る ステージ（`st.pool` が ない＝算数）だけ**。国語・理科・社会・英語の 問題リストは 学期で しぼられる ので、まだ ならって いない ステージは 0問に なる。
- **画面の 文は `MQ.dojo.TEXT` と `KID`（小1・小2＝小1の かん字だけ）に まとめた**。「合格」の「格」は 小5の 字 だった ので「クリア」に。smoke が 文の かん字を 学年ごとに 検査。
- 全学年の 実測（smoke の「しゅぎょうば 全学年」の 行）＝ 指導が ある ステージ ÷ 開いて いる ステージ が 8わり いじょう。
- harness `#dojo:g2(:map|:list|:ex)` `#dojo:g5`、`#flow` にも 小2の 1本。

## 7. つぎに やる こと

- 息子さんに 1ステージ やって もらい「指導されてる 感じが するか」「相棒の セリフが 多すぎ／少なすぎ」を 聞く。
- 自動の 指導で 足りない ところを 手書きに（小3 国語・理社・英語 → 小1・小2 → 小4〜小6）。手書きは `lessonN.js` に `MQ.lessons.add` を 足すと 自動より 先に 使われる。
- 小1・小2は ふきだしを 読み上げ（v5.3）で 声に。
- 筆算の くり上がりを 1つずつ 見せる 手順（問題の 種類ごとの 関数）は 足りない 単元だけ あとから。
