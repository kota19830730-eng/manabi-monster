# v8.1 敵がわの 攻防（2026-09-06）

ユーザー「エリート敵＝HPのあるザコ／敵のガード／なかまを呼ぶ／ボスのわざ3種／弱点の教科を
実装していきたい。壁打ちしましょう」→ 5案を 出して 決定。

**ユーザーの こたえ**
1. たたかいが 1問 長く なるのは **OK**
2. エリート敵の 呼び名は **中ボス**
3. 弱点は ごちゃまぜ バトルと さいごの塔だけ で **OK**
4. ボスの わざは **小1・小2にも 出す**

## 大原則（v7.7 から そのまま）

**敵の 行動で 何かを うしなわない。** ライフ・HP・コイン・★は へらない。
敵が する ことは ぜんぶ「**ボーナスの チャンスを つくる**」形に する。
くらった／ふせがれた ときは **演出と コンボ 0 だけ**（いままでの まちがいと 同じ）。

**1つの 問題に 出来事は 1つ。** ため（v7.7）・中ボス・弱点・なかまを よぶ・ボスの わざは
かさねない（`chargeInfo()` が 中ボス・弱点・summon・わざ・すきだらけ・呼ばれた ザコの
問題では null を かえす）。かさねると ふきだしと ラベルが けんかして 小3には 読めない。

## ② 弱点の 教科（weak）

- **ごちゃまぜ バトル**：ザコの **3体に 1体**が「まよいこんだ 敵」＝ べつの 教科の モンスターが
  この 問題を もつ（`world3.js` の `WEAK_RATE`）。その 敵は この 問題の 教科が 弱点。
- **さいごの塔**：ラスボスに 弱点の 教科が 1つ（`opts.weakArea`）。**きょうの フィーバー教科**が
  塔の 教科に あれば それ（にがて教科を 自然に 応援する）。なければ くじ。
  画面では「弱点：国語」としか 書かない（**子どもに「にがて」と 見せない** きまり）。
- その 問題に **1回めで 正解 → こうかは ばつぐん**：ザコは けいけんち **1.5ばい**（`WEAK_MUL`）、
  ボス・中ボスは **2ダメージ**（`WEAK_DMG`）。`summary().weakHits`。
- 見た目：むらさきの バッジ `.enemy__weak`（その 問題の ときは 光る `.is-now`）＋
  むらさきの 帯「こうかは ばつぐん！」＋`MQ.sfx.weak()`。
- **ふつうの たたかい（1教科）には 出ない**（教科が 1つだけ なので 弱点に 意味が ない）。
- 塔の 問題は `q.subject`（`towerQuestion` が つける）で 教科を 見る。**`areaId` は 変えない**
  （にげた敵・とくい にがての 行き先が 変わって しまう）。

## ③ ボスの わざ 3種（3問め・5問め）

`planBoss()` が **3問めから 2問おき**に 1つずつ わりあてる（`s.bossPlan`）。
ぶんしんだけ 2問 つかう。**おうちの人ページの「てきの こうげき」を なしに すると わざも 出ない**
（`opts.attacks`）。とっくんは なし。**ガードは 単独では 作らない**（正解したのに たおれないのは
子どもには ばつに 見える）ので、たての かまえ の 中に 入れた。

| わざ | 出る ところ | 正解した とき | まちがえた とき |
|---|---|---|---|
| たての かまえ（kamae） | ボスが たてを かまえる | **ガードブレイク**（けいけんち ＋10）→ **つぎの 1問は 2ダメージの チャンス**（すきだらけ） | 演出だけ。かまえは のこる |
| ぶんしん（clone） | 2問 つづけて 出る（2体 ならぶ） | 両方 1回めで 正解 → **見やぶった！ けいけんち ＋20** | ボーナスなし（ダメージは ふつうに 入る） |
| なかまを よぶ（call） | ボスの 問題の **前**に ザコが 1体 | ザコの けいけんち（ボスの 問題数には 数えない＝おまけ） | にげられる だけ。ボスとの たたかいは つづく |

- ボスが 2体 ならぶ とき（ぶんしん・呼ばれた ザコの となり）は **`.enemy--twin`**：
  80px（ラスボスは 72px）・名前と HP は 足もとに かさねず 下に ならべる
  （かさねると 2つの 名前が 重なり、右下の アイテムボタンにも かくれる）。
  **ラスボスは 名前が 頭の 上（v6.4）の まま**（`:not(.enemy--last)`）。
- わざの ラベル `.enemy__skill` は **右ぞろえ**（まん中ぞろえだと 画面の 右から はみ出て 切れる）。
- ふきだしは **2行に おさめる**（「あと N かい」を つけない。長いと ボスの 絵に かぶる）。

## ④ なかまを よぶ（ザコ・summon）

- いままでの「2体同時」を **よんだ 形**に した。1体めが 口ぶえ（`MQ.sfx.whistle`）→
  2体めが 右から とびこむ（`.is-summoned`）。
- 2体めは **同じ 系統（line）の なかま**（`MQ.enemies.mateFor`）、**10% で ゴールデンスライム**。
- ごほうびは いままでの ダブル KO ＋20 の まま。問題の 数は ふえない。

## ハマった ところ

- **ボスの HP は 3しか ない**ので、harness で わざを 見る には **わざと 2回 まちがえて ガード**
  （HP が へらない）で 3問めまで 進める。smoke は `bossHp: 12` で わざを 見る。
- **まちがえた あと 500ms は 入力を 受けつけない**（`locked`）。harness で 2回 まちがえる ときは
  700ms 待つ。**ヒントで 消された ボタンは 押せない** ので、まちがえる ときは
  「押せる まちがい」を えらぶ（`answerViaUI` を 直した）。
- 中ボス・弱点・summon の 問題に ため（v7.7）が かさなると **ふきだしが 上書きされて**
  「中ボスが あらわれた」が 見えなく なった → `chargeInfo()` で かさならない ように した。
- 新しい 名前は 先に grep（`.pal`（v4.9.1）・`sparks`（v7.5）と 同じ 事故を さける）。
  `enemy__skill / enemy__weak / enemy__kamae / elitehp / enemy--elite / enemy--twin / enemy--clone /
  enemy--kamae / enemy--open / is-summoned / is-vanish / counterbanner--*` は かぶりなしを 確認ずみ。
