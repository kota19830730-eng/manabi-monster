## 技名の 文字（ユーザー「文字の カクカク・画質が 悪い」→ 見くらべ → A）

- 原因＝ふちどりを **8方向に ずらした text-shadow** で 作って いた（ふちが 階段の ギザギザ）。
- 直し＝**SVG の 本物の 線**（`stroke-linejoin: round`・`paint-order: stroke`）＋上から下の グラデ＋わざの 色の 光（`MQ.ui.setwaza.nameEl`）。書体は Mochiy Pop One の まま（A）。
- 詠唱（カットインの せりふ）は `-webkit-text-stroke: 6px`＋`paint-order: stroke fill`（`@supports` つき。ない ブラウザは 前の 影）。
- 見くらべ（いま／A／B 太い明朝／C 太いゲーム文字）＝ https://claude.ai/code/artifact/9f6748d4-7b0c-4964-b78a-8aecd5942a23 （もと：`tools/fxcheck/setwaza_fonts.html`）。
- **ぜんぶの 技名に ひろげた（2026-09-14）**：`js/ui/fxtext.js`（新・`MQ.ui.fxtext.name(文字, 色の 名前, { size, ruby })`）が SVG を 作る。ひっさつわざ 8つ・アイテムの わざ名 4しゅるい・セットわざ 8つ。色は `MQ.ui.fxtext.STYLE`（前の text-shadow の ふちの 色と 光の 色を そのまま）。下の こい 影と まわりの 光は **1つの SVG フィルター**（影を べつの text に すると harness の 止めた 画面で 影だけ ずれて 写った）。学年の ことば（MQ.text.fit）は fxtext の 中で かける（セットわざの 漢字は raw）。
- **カットインの せりふ（.ci__tx）も ぜんぶ** `-webkit-text-stroke: 6px`＋`paint-order: stroke fill`（css/specialfx.css・`@supports`）。
- style.css の `.fxscreen--<わざ> .fxname`／`.fx--atk … .fxname` の 8方向の text-shadow は 消した（smoke が 見る）。見くらべ＝`tools/fxcheck/names.html`（`#old,z2` で 前と ならべて 2倍）。
