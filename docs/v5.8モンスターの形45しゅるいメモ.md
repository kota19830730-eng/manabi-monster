## きっかけ

> そんなん面倒くさいし、楽しくないしワクワクしないでしょ。

### ② 点数（`kindScores`）

絵から 読めるのは **色・たてよこ・目の 数・つの・あし・はね・歯・四角さ** だけ。
だから **当てられる ものだけ 点を 上げ、当てられない もの（けん・ほし・ロケット など）は 0〜1**に して、
「ほかの すがた」の 一覧から えらんで もらう。同じ 点数の ときは 絵の ゆびもんで 順番が 変わる。

### ③ 画面：候補 **12体** ＋「ほかの すがた」で **ぜんぶ**（`js/ui/photo.js`）

- 「どれに する？」の 行は **上位 12体**（前は 8体）。タイルに **日本語の 名前**が つく（`MQ.monsterGen.kindName`）。
- その 下に **「ほかの すがた」ボタン** → ひらくと **のこり ぜんぶ（49体）**が スクロールできる 枠に 出る。
  もう一度 押すと「とじる」。
- **ひらいて いる ときだけ 全部を 作る**（`want = showAll ? 99 : 12`）。ふだんは 12体しか 作らないので、
  スライダーを 動かす たびに 45体 描き直して おそく なる ことは ない。

## つぎに 形を 足す とき（手順は v4.1 から 変わらず）

1. `BODIES` に 1つ（48×48・四角 6〜14個）
2. `EYE_AT` / `SKULL_AT` / `HORN_AT` / `TEETH_AT` / `WING_AT` / `TAIL_AT` に 1行ずつ
3. `kindScores` に 点数の 式（当てられない ものは 足さなくて よい）
4. `KIND_NAMES` に 日本語の 名前
5. `tools/smoke.js` の `KINDS` に 名前・`tools/facelab.html` の `COL` に 色
6. `node tools/smoke.js .` → `facelab.html#bodies` を 撮って 目で 見る → sw.js の 番号を 上げる
