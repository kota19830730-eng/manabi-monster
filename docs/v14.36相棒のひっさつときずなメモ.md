## 1. C 相棒の ひっさつ

| | 中身 |
|---|---|
| たまる | 追い打ちを **2回** する（`MOVE_NEED`）。相棒の 札に オレンジの ほし 2つ（`.pal__star`） |
| たまった | 相棒の 足もとが 光り、頭の 上に「タッチ！」（`.pal.is-ready`・`.pal__tap`）＋きらきら音＋「ぼくを タッチ！」 |
| タッチ | **相棒そのものを タッチ**（ボタンを ふやさない）→ かまえ（オレンジの 光・`.is-armed`） |
| 出る | **つぎの 正解で**「〇〇の ひっさつ！」（金の 帯＋光の わ＋相棒の とびだし＋音） |
| 効きめ | ザコ＝けいけんち ＋30（♥1 で ＋40）／中ボス＝一発／ボス＝**＋1ダメージ（1たたかい 1回まで）**／たからばこ＝けいけんち |
| 回数 | 1たたかい 1回（♥4 で 2回）。タイムアタックでは なし |

- **大原則は そのまま**：出るのは 正解した ときだけ。まちがえても かまえは のこる。押さなくても 何も へらない。
- 本気モードで ガードされた 正解（2回め）では 出ない（かまえた まま）。
- ラスボスの 第2形態の ガードは ひっさつで やぶれる（カウンター・セットわざと 同じ）。
- ボスへの ダメージは 相棒の レベル・きずなで ふえない（v12.7 の ボスの 強さ）。

## 2. E きずな

- いっしょに たたかった 回数で たまる（1回 ＋1・ひっさつを 出した たたかいは ＋2）。`p.pals[id].bond`
- ♥の さかいめ `BOND_AT = [4, 12, 24, 40, 60]`（ひっさつを 毎回 出すと ♥5 まで 約30回）
- **進化しても のこる**（`evolveIfReady` が 引きつぐ）。相棒を かえると その子の ♥
- ♥ごとの ごほうび（`BOND_PERKS`）

| ♥ | ごほうび |
|---|---|
| 1 | ひっさつの けいけんち ＋10 |
| 2 | なまえを よんで くれる（ひとことの 半分が「{なまえ}、いっしょに いこう！」など） |
| 3 | まちがえた とき 1回 かばって くれる（コンボが きれない・1たたかい 1回・時とめが 先） |
| 4 | ひっさつが 2回 出せる（1たたかい） |
| 5 | ひっさつが 金色に＋しょうごう「さいこうの あいぼう」（しょうごう 66） |

- メニューの 相棒カードに「きずな ♥♥♡♡♡　あと N で 〇〇」（`.palnow__bond`）
- けっか画面の 相棒の 行に「きずな ♥♥♡♡♡　つぎの ♥まで あと N」／♥が ふえた ときは その ごほうび（`.rs__palbond`）
