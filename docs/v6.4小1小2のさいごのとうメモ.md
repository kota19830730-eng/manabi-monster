## 2. しくみ

- `world3.js`：`TOWER_ORDER12`＝さんすう → こくご（こうたい）。`towerStage1 / towerStage2 = makeTowerStage(1|2, TOWER_ORDER12, bossId)`。
  world1 / world2 の areas に `{ id: 'tower', name: 'さいごの とう', short: 'とう', biome: 'tower' }` を 足した。
- **小1・小2の 塔の 名前は ひらがな「さいごの とう」**（`makeTowerStage` が grade ≤ 2 で えらぶ）。
  画面の 文字は **`MQ.content.towerName()`**（新）を 見る：地図の 塔の 看板（`map.js`）・ぼうけんの きろく（`battle.js`）。
  地図の 塔の 下の 文も 小1・小2は ひらがな（「おばけキングが まって いる！」「もういちど いどむ」）。
- **かけらは 2つ**（＝教科の 数。`towerOpen` は そのまま）。さんすう 12／14ステージ・こくご 5／4ステージ の ★で とれる。
- 地図は 塔の ある ワールドと 同じ しくみで 自動（本島の 下に 海を はさんだ 小島）。**川は 出ない**（`map.js` の 川の 条件は `subjectAreas()`＝教科の 数で 見るので、塔を 足しても 2の まま）。
- 問題は いつもの ボス問題（lv3）から。小1は ひらがなだけ・小2は 小1の かん字まで（ふつうの ステージと 同じ）。「きく」（よみあげ）も 小1では 出る。
- でんせつ／やみの そうび・「ラスボスを たおした」の しょうごう「でんせつの ゆうしゃ」は まおう 限定の まま。小1・小2は 専用の しょうごう。

## 3. ついでに 直した：ラスボスの 名前と HP が アイテムボタンに かくれて いた

ラスボスは 112px で 大きく、足もとの 名前と HP（ハート）が **右下の アイテムボタンの うしろに かくれて いた**（小3・小4も 前から そうだった）。
→ `.enemy--last .enemy__name` を **頭の 上・右ぞろえ**に、HP は 足もとの すぐ 下（`margin-top: 2px`）に。520×780・520×940・800×1280 で 見て 読める。
