# v6.2 かたち判定を 作って 実測した ＋「なかまから えらぶ」（2026-09-04）

## きっかけ

v6.0 で「AIに 見てもらう」を 作ったが、**APIキーが いる**。ユーザー：

> チャッピーなキーとか言われても普通の人じゃわからんで。こっちでドット絵作るAIつくれないの？

もっとも。**キーが なくても ちゃんと 使える**ように するのが 正しい。

## ① アプリの 中だけの「かたち判定」を 作って、実測した → **使わない ことに した**

考え方は かん字の 書きとり判定（`core/handwrite.js`）と 同じ：
**85しゅるいの ドット絵を お手本に して、子どもの 絵の 形と 見くらべる**。通信も かぎも いらない。

`js/content/monstergen.js` の **`matchKinds(cells, N)`**：
1. しゅるいごとに おまけ（つの・はね）を つけない「すの 体」の 白黒（48×48）を 作る（`kindMask`）
2. 子どもの 絵も 白黒に する。**線だけで かいて あっても 中を うめる**（`fillHoles`）
3. どちらも たてよこの ひ を たもった まま **16×16 の ぬり ぐあい**に する（`shapeGrid`）
4. **りんかくの かたち**（列ごとの 上／下のはし・行ごとの 左／右のはし）を 足す（`featOf`）
5. 「ふつうの モンスター」（85の 平均）を 引いて、ちがう ところだけを コサインで くらべる
6. 左右を ひっくり返した ものも くらべて、にて いる ほうを とる

### 実測（`scratchpad/measure2.js`・お手本を ゆがめて 何番目に 当たるか）

| ためし方 | 1番 | 3番まで | 5番まで | 12番まで |
|---|---|---|---|---|
| ゆがみ なし（お手本 そのもの） | **100%（85/85）** | | | |
| 回転±8°・のび±12%・かすれ2% | 33% | 42% | 49% | 62% |
| 回転±15°・のび±25%・かすれ5% | 13% | 23% | 29% | 44% |
| 上に くわえて「線だけ」 | 33% | 49% | 54% | 68% |

**息子さんの 本物の 写真 4まいでは 良く ならなかった**（サメオニが「サメ」→「ワニ」に 入れかわるなど）。

### わかった こと

- しくみは 正しい（ゆがみ なしなら 100%）。**当たらないのは 85しゅるいの 四角い すがたが
  たがいに にすぎる から**。白黒の 形だけでは 見分けられない。
- 本物の 子どもの 絵は、この ためしの ゆがみより **もっと** ちがう。
- ちゃんと 当てるには **学習した ニューラルネット**（何MBもの ファイル・学習データ・作る 道具）が いる。
  この アプリは ビルドなし・オフライン・ファイル少なめ が きまり なので 入れない。

→ **`SIM_W = 0`（使わない）**。しくみと はかり方は のこして ある。
良く できた ときは `monstergen.js` の `SIM_W` を 上げるだけ。

## ② かわりに やった こと：「なかまから えらぶ」（これが 本命）

**かぎが なくても 2タップで 85しゅるいの どれにでも たどりつける。**

- 候補の 下に **なかまの ボタン 5つ**（いきもの／むし／おばけ・ひと／もの・のりもの／しぜん）。
- おすと その なかまだけ ならぶ（いきもの 28体・むし 8・おばけ・ひと 23・もの 19・しぜん 12）。
  もう一度 おすと とじる。
- 上の 行は「**おすすめ**」（絵から 読んだ 12体。AIに 見てもらった ときは AIの こたえが 先頭）。

前の「ほかの すがた」は **85体を 一気に ならべる**ので さがせなかった。
なかま分けは **どこを 見れば いいか 子どもに わかる**（コウモリ → いきもの）。

## いまの まとめ

| やり方 | かぎ | 当たり方 |
|---|---|---|
| おすすめ（絵から 読む） | いらない | 色・目の 数・つの・たてよこ で 12体。ぴたり とは かぎらない |
| **なかまから えらぶ** | **いらない** | **かならず 見つかる（2タップ）** |
| AIに 見てもらう | いる | 1番めが ほぼ 正しく なる（おまけ） |
