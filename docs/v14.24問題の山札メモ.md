# v14.24 問題の 山札 ＋ 学期で 足りない ときは 前の 単元から 借りる（2026-09-24）

ユーザー「同じ問題がわりと頻繫にでてくるけど、問題の種類が少ないような気がします。壁打ちしましょう」
→ 数えた → 4案（D 学期の穴／A 山札／B 生成器／C 手で 足す）→ ユーザー「D→A→B→C ぜんぶ」。
この メモは **D と A**（sw 197）。B・C は べつの メモ。

## 1. 数えた こと（直す 前）

`scratchpad/count1.js`＝smoke の 読みこみ部分を vm で 借りて、全学年 全ステージで
①`st.make(12,{boss:false})` を 60回 まわして id の 種類 ②6回 たたかって（ザコ 12＋たからばこ 1＋ボス 5＝18問）「前に 見た 問題」の わりあい。

| 教科 | 1ステージの 種類 | 3回めの たたかいで 見た 問題 |
|---|---|---|
| 算数（小1〜小6・生成器） | 130〜719 | 0〜10% |
| 国語の ことば | 44〜62 | 44〜78% |
| 理科・社会・英語（小3・小4） | 49〜55 | 44〜72% |
| 理科・社会・英語（小5・小6） | **30〜35** | **67〜100%** |

- **算数は「問題を 作る 関数」、ほかは「手で 書いた 一覧」**。それだけの ちがい。
- **学期で しぼると 半分以下に なる**（小3を 2学期まで に すると「ことばの 意味」14問・「まちの しごと」25問・「光・じしゃく・電気」28問）
  → **1回の たたかい（17問）の 中で 同じ 問題が へいきん 3.4〜5.0問**。
- **ボスの 問題（lv3）が 足りない**：小3 英語「あいさつ」は 50問中 lv3 が 10問。1回の たたかいで lv3 は 9問（ザコ 4＋ボス 5）いる
  → **同じ たたかいで ザコに 出た 問題が ボスに 出る**（5問中 3問が それ・前から）。core の `makeBossQuestion` は ボスどうしの かぶり（usedBossKeys）しか 見て いない。

## 2. できあがり

### A 山札（`js/content/world3.js` の `pickFromBag`）
- リスト教科（`listStage`／`writeMixStage`）の 問題は **ステージごとに 4つの 山**（lv1・lv2・lv3・ボス候補）を もち、
  **使い切るまで 同じ 問題を 出さない**（読解 v14.14 の トランプ方式と 同じ 考え）。
- 山の 中身は 問題の ならび（all）の 番号。セーブ **`p.qbag[ステージのキー]`**＝`{ sig, 1:[…], 2:[…], 3:[…], b:[…], r:[…] }`。
  `sig`＝問題の 数。学期の 設定が 変わって 数が 変われば 作り直す。セーブが ない とき（テスト）は `MQ.content.qbag.mem`。
- **引いた 番号は ほかの 山からも 外す**（ボス ⇔ lv3 に 同じ 問題が 入って いる）＝ザコで 出た 問題が すぐ ボスに 出ない。
- **`r`＝さいきん 出た 17問**（1たたかいぶん）。山を つみ直した ときも 先に よける。
- 引き方は 3周：①つみ直さず・さいきんを よけて（となりの むずかしさの 山も 見る）②つみ直して・さいきんを よけて ③つみ直して・よけない。
  → ボスの 問題（lv3）を 使い切ったら **くり返す 前に まだ 出て いない lv2** を 出す（出す ときの lv は 3 の まま＝smoke の「ボスは lv3」は そのまま）。
  くり返した lv3 より 新しい lv2 の ほうが むずかしい。
- 4/4/4 で となりの 山から 借りた ときも `levelOf` で ならべ直す（core の sortByLevel と 同じ・smoke の「じゅんばん」が 見る）。
- かん字を 書く（`writeMixStage`）は 書く問題の 山を `<キー>:w` で べつに。ボスの 書く問題も 山から。
- 算数・ローマ字・読解は 自分の make を もつ ので さわって いない。

### D 前の 単元から 借りる（`withBorrowed`）
- `NEED_POOL = 18`・`NEED_LV = { 1: 4, 2: 5, 3: 9 }`（ザコ 4/4/4＋たからばこ lv2 1＋ボス lv3 5）。
- ステージの 問題が 足りない とき、**同じ 教科の 前の ステージ（stage が 小さい・学期で ならった もの）**から、
  まず 足りない むずかしさを うめ、それでも 18 に 足りなければ 近い 単元から 足す。
- `MIN_POOL`（12・ステージが 開く 条件）は 変えて いない。開く 条件と、開いた あとに 足りる かは べつ。

### 結果（`count1.js`・直した あと）
- 50〜55問の ステージ：**2回めの たたかい ダブり 0%・3回め 0〜22%**・4回めで 100%（＝ぜんぶ 見た）。
- 30〜32問の ステージ：1回めは 17問 ぜんぶ べつ・2回め 6〜22%・3回めで 100%。
- 2学期まで の 小3「ことばの 意味」：1回の たたかいの ダブり 5.0問 → **0.0問**。
- **数は 1問も ふえて いない。** 3回め いこうは「ぜんぶ 見た 問題」に なる のは 変わらない → B・C で ふやす。

## 5. もどさない
- 山を ランダムの 引き直しに もどさない（ボスに さっき 答えた 問題が 出る）。
- `r`（さいきん）を 消さない（つみ直した しゅんかんに 同じ たたかいの 問題が ボスに 出る）。
- ボスの 山が からの とき lv2 を 出す のは「まだ 出て いない lv2」だけ（③の 周で はじめて くり返す）。
- 借りる のは 前の ステージだけ（先の 単元は ならって いない）。
