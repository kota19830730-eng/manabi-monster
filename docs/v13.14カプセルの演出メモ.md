| | ノーマル 70% | レア 25% | げきレア 5% |

## 期待度の はしご（うそを つかない）

レベル 0＝しろ（ふつう）・1＝金（**レア いじょう かくてい**）・2＝むらさき（**げきレア かくてい**）・3＝にじ（げきレア）

| 出る もの | ①ハンドル | ②光（1つめの わ） | ③カプセル（2つめの わ） | ④ヒビ（3つめの わ） | わりあい |
|---|---|---|---|---|---|
| ノーマル | 0 | 0 | 0（オレンジ） | 0 | いつも |
| レア | 0 | 1 | 1 | 1 | 40% |
| レア | 0 | 0 | 1 | 1 | 35% |
| レア（ぎゃくてん） | 0 | 0 | 0 | 1 | 25% |
| げきレア | 1 | 2 | 2 | 3 | 50% |
| げきレア | 0 | 1 | 2 | 3 | 25% |
| げきレア | 0 | 1 | 1 | 3 | 15% |
| げきレア（いきなり にじ） | 0 | 0 | 0 | 3 | 10% |

- ノーマルは **ぜったいに 金に ならない**／むらさきは げきレア だけ／色は 下がらない（`plan()`・smoke が 検査）。
- レアは 金に なる ところが 毎回 ちがう → さいごまで ドキドキ できる（「ドキドキしたのに はずれ」は 作らない）。

## ながさ・とばす

- 自動で 進む：ハンドル 2.6秒・タップ 2.2秒ずつ（止まった まま に しない）。タップすると すぐ 進む。
- 右上の「とばす」で いつでも ⑤ 登場へ。
- タップ あり の 実測：げきレア 約5〜7秒、ノーマル 約4〜5秒。

## しくみ（ファイル）

- `js/content/capsule3d.js` … `MQ.vox.capsuleMachine({unit})`・`MQ.vox.capsuleBall({unit, tone})`（tone＝n/r/sr）。ガラスは vox の 絵に できない（すきとおる 色は かたちに 数えない）ので 面を 5まい 組む（`buildGlass`）。
- `js/ui/capsulefx.js` … `MQ.ui.capsuleFx.play({ rarity, reveal, onReveal, onNext })`。`plan(rarity)`・`bonusOf(rarity)`・`skip()`・`close()`・テスト用 `phase() level() levels() tap()`。
- `css/capsulefx.css` … 動かすのは transform と opacity だけ（v13.10）。玉と マシンの ゆれは `translate`／`rotate`（transform とは べつ の プロパティ）。
- `js/ui/capsule.js` の `pull()` … `rolling = true` の すぐ あとで `MQ.ui.capsuleFx.play()`。出た ものの 中身は `revealOf(res)`。うらでは いつもの `showResult(res)` も 作る（テストと、演出が 使えない ときの 保険）。
- 音は いまある 音だけ（capsuleLever／capsuleRoll／capsuleHot／guardBreak／crit／capsuleOpen／capsuleSr／coin）。新しく 作って いない ので 聞きくらべは いらない。

## たしかめ方

- `node tools/3d/mkcapfx.js` → `tools/3d/capfx.html#<n|r|sr>[:<4けたの はしご>][:<sneeze|peek|double|none>][:dup][:nopal][:2d]`
- **本当の 時計で 撮る**：`node tools/3d/capfxrt.js "sr:1223" 700,1700,… <フォルダ> 520 940 1200,4500,5200,5900`（さいごは タップの 時間）。
  virtual-time では transition が 進まない ので、とちゅうの 見た目は かならず これで 見る（1回 だまされた）。
- マシンだけ：`tools/3d/capmachine.html#big`（4角度）`#side`（真横）`#look`（夜空の 上に 3つの 光り方）。

## もどさない

- 色は 上がるだけ（ノーマルに 金を 見せない・金の あとに ノーマルを 出さない）。
- 「とばす」を 消さない・自動で 進む ように しておく（毎日 引く もの・止まった まま に しない）。
- 3D の 図に filter を かけない。光は 3D の 面に つけない（面の 影が 画面の よこに のびて 帯に 見えた）→ 2D の うしろの 光。
- 実機 未確認（iPad・Android タブレットで 重く ないか）。

## カプセルマシンの 画面（メニューの 中）も 3D に（2026-09-13）

ユーザー「ここの画面も さっき 作ってくれた 3D の 画面に」（iPhone の スクショ＝2D の 赤い マシン）。

- 画面の マシンを **まわす 演出と 同じ 3D の 1台**に（`MQ.ui.capsuleFx.menuMachine(size, tone)`＝しまって ある 1台を cloneNode）。大きさ 150px（おうちは 景品の 一覧が あるので 124px）。
- `.capstage` の 高さ 132 → 150px・`.capstage--home` 100 → 124px。800×1280（ステージ 700）でも おさまる。
- ゆれは 演出と 同じ capfxSway を 7秒に（ゆっくり）。うしろの うすい 光は 2D の `.capmc3d::before`（3D の 面に 光を つけない きまり）。
- **おうちの人の マシンは 金の 台・赤い ふちと ハンドル**（`MQ.vox.capsuleMachine({ tone: 'home' })`・2D の `.capmc--home` と 同じ 色の 組み合わせ）。まわす 演出も 金の マシンに（`play({ tone })`）。
- 「りったい」を 切って いる とき・3D が 作れない ときは いままでの 2D の `.capmc`。
- たしかめ：harness `#capsule` `#prizemc` を 520×940・520×780・800×1280。
