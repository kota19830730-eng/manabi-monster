## 2. 図を つけた 問題（39問）

- **小3 社会「地図と方位」**：地図記号 17問 ＋ 方位 8問 ＝ 25問。
  問題文は そのまま、右に 図が つく。**病院だけ 問題を 書きかえ**
  （「どんな 形？」は 絵を 見せたら 答えに なる → 「この 地図記号は 何を あらわす？」＋施設名の 4たく）。
- **小3 理科（ステージ2）**：じしゃく 6問（ぼうじしゃく・2本・方位じしん）。
- **小4 理科**：回路 4問（直列・へい列・電池の 向き）＋ 月 3問（満月・三日月・形の 変化）。
- **小4 社会**：「文」の 記号 1問。

### 図を つけない と 決めた もの（答えが ばれる）
- 「地図では 上が どの 方位？」に 北ラベル入りの 円 → **ばれる。つけない**
- 「じしゃくの 両はしの 名前は？」 → **N/S の 字を かくした** 図（`magnetQ(text, true)`）
- こん虫の 体の 問題（あしは 6本 など）→ 絵で 数えられて しまう ので 見送り
- 「月の 形は 日に よって？」→ 形の 変化の 図が そのまま 答え。つけない

## 3. しくみで 気を つけた こと

- **出題 id は `stripTags(q.text)`**（world3.js の listStage）。SVG は タグなので 消えるが、
  文まで 同じに すると id が かぶって「12問 かぶりなし」が こわれる。
  → 問題文は 元の 文を のこす（書きかえた 病院だけ 一意の 文に）。
  smoke が **ステージごとに stripTags 後の 文の かぶり**を 検査する。
- smoke の 英語まざり検査（rika4/shakai4）は SVG の 属性（stroke など）に 反応する ので
  **stripTags して から** 見る ように 直した。
- じしゃく 2本の 図は 最初 N/S の 向きが 逆だった（`flip` の 条件ミス）。#zu の
  スクリーンショットで 見つけて 直した。**図を 足したら かならず #zu を 撮って 目で 見る**。
