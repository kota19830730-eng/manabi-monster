## v14.56 で 見つかった 失敗の 型（多い 順）
1. わくの 中の 手・つくえ・ゆか・ペンを 絵と して 拾う（6まい）
2. うすい えんぴつ・細い ペンの 線が 消える（c38・c15・p51）
3. 紙の 写真を ぬいぐるみ（objMode）と 誤判定 → 切りぬき写真に（p31・p67 など）
4. 自動わくが 絵でない 所（顔・手・ぼやけた 背景）を えらぶ（14/28）

## 直した こと（js/ui/photo.js）
- **sheetMask(q, w, hh)**：紙に 直した q で「明るくて 色みの ない 点」を 半径 5% で とじ、いちばん 大きい かたまりを 紙と する。
  紙の 中の あな（絵）は うめる。**ふち（2px）に かかる かたまり（手・ペン・つくえ）は 外の まま**（components の edge で 見る。
  ふちから 流す 方式だと、ふちの 点が 紙の とき 手が あなに 見えた＝p30）。へりは 1.2% けずる。
  紙らしい 点 2割 未満 → null。area 0.985 いじょう（紙が わく いっぱい・白い ゆかの ぬいぐるみ）→ null＝いままで どおり。
- **rawPaperness(p, m, w, hh)**：紙の マスクの 紙らしさを **もとの 写真の 明るさ**で 見る（subject.paperness と 同じ 見方）。
  紙に 直した q では ゆかも 白く なる ので、**うさぎ（暗い ゆか＋明るい ぬいぐるみ）が 紙に なった**（1回目の 計測で 発見）→ これで 見分ける。
- **build()**：紙が 見つかったら `fg` の 紙の 外を 0 に。自動わくが objMode でも、**手で わくを 動かし**（autoCropRect と 0.02 以上 ちがう）紙が 4割 以上・raw 0.5 以上 なら 紙の 絵の 道。
- **autoCrop()**：先に 紙を さがし、紙が 写真の 92% 以下 ＆ raw 0.5 以上 なら ぬいぐるみの 判定は とばし、候補（np）は 紙の 中だけ。
- **notPaperMask の ごみ取り**：「となりが 2つ 以下を その場で 消す」→ 1px の 線（となり ちょうど 2つ）が 線に そって 連鎖で 消えて 点線に なって いた。
  → もとの マスクを 見ながら となりが 1つ 以下だけ 消す。
- **traceCells の マス目**：fg が 4割 未満の マスは 捨てて いた → 細い 線（1〜2px）は 1マスも のこらない。線の 点が 3つ 以上 ある マスを
  「細い 線の マス」の 候補に し、**えんぴつだけの 絵（色の マスが 2割 未満）の ときだけ** 足す（色の ある 絵で 足すと、
  息子さんの スカルホースに 仕切りの 線の きれはし・ずかんの あくまに にせの 目が 出た＝⑤ で 戻した）。
- **dropLoose**：えんぴつだけの 絵は「色の ない 小片」を 消さない（線が 切れて 小片に なる ため）。
- **autoCrop の ふちに かかる かたまり**：細い 線を 消さなく なった ので、紙いっぱいの 絵（スキャン c28）は 線で ふちまで つながり
  「ふちに かかる」と して 外れ、頭が 切れた。→ 紙が 一部に 見つかって いない（!inSheet）とき、ふちに かかる かたまりでも
  写真の 4割 以上・ふちに かからない 最大の 3倍 以上・**ふちに ふれる 長さが ふち ぜんたいの 15% 以下** なら 絵と する
  （⑥ 無条件 → p48・p55 で 子どもや ゆかを 絵に した／⑦ sheet の area 0.92 超 → スキャンは sheet が null（0.985 超）で 効かず、
  p55 は かべ＋紙で 0.93 に なり 効いて しまった／⑧ ふれる 長さ で 決着）。c44・c66・c41 の 自動わくも 絵 ぜんたいを 入れる ように なった。
- smoke「v14.57 紙の 外を 捨てる」（合成画像で 手・ぬり・線・うさぎ・白い 紙 ＋ 文字列の 検査）。`MQ.ui.photo.parts` に sheetMask・rawPaperness。
