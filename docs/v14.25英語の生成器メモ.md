## 3. 見本を 読んで 直した こと（自動で 作る 文の わな）
- **形容詞に「では ない」**（「すずしいでは ない」「おこって いるでは ない」）→ その 文型を やめて `Is it 〜?`・`He is 〜.` に。
- **play できない スポーツ**（`Let's play skiing.`）→ SPORTS から swimming・skiing を 外す（ぜんぶ play 〜 と 言える もの）。
- **a が つかない もの**（`I have a scissors.`）→ scissors・glue を 外す。**数えられない 食べ物**（`I like egg.`）→ 食べ物の 文型は `{pl}`（pizza・rice などは pl を 同じに）。
- **句点の 重なり**（`I'm fine.。`・`P.E..`・`the U.S.A..`）→ `dot()` と `q()` の `..` → `.`。
- **聞き方と 答えの ずれ**（`What time do you get up?` に「おふろに 入る」）→ ask を `What do you do at 7:00?` に。道あんないの `Where is 〜?` には ask を つけない。
- **文の はじめ**（`spring is coming.`）→ `fill()` で 大文字に。
- かん字は その 学年まで（警察署 → けいさつしょ・宇宙 → うちゅう・看護師 → かんごし・温泉 → おんせん・職員室 → しょくいん室・牛乳 → ぎゅうにゅう・塔 → とう・滝 → たき・韓国 → かん国）。**「英」（英語）だけは 手書きの eigo3 と 同じく ゆるす。**

## 6. 単語・文型を 足す とき
- 単語は `[英語, 日本語, { a, pl }]`。**play できる／a が つく／数えられる** を そろえて 1つの 表に する（文型が 表ぜんたいに かかる ため）。
- 文型の ja は **単語が 名詞でも 形容詞でも 文に なる 形**（「{ja}です」「{ja}が すき」は OK・「{ja}では ない」「{ja}だよ」は 形容詞で こわれる）。
- 新しい 文型を 足したら `p11.js` で 見本を 出して 読む → smoke。
