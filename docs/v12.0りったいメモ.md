## 1. 何が 変わったか（子どもの 目で）

| 画面 | まえ | いま |
|---|---|---|
| バトル | 主人公も てきも 平らな ドット絵。こうげきは 26px すべるだけ | **箱の 立体**。主人公は **てきの 手まえまで 走って 斬って もどる**（0.42秒）。てきは 前かがみで ゆすり、ときどき フェイント。1体めと ボスは **歩いて**、2体めからは **はねて** 出て くる。たおすと **横に ばたん**、ボスは **くずれ落ちる**。くらうと のけぞる |
| たからばこ | 平らな 絵 | 3D の 箱。待って いる あいだ ふたが **ガタガタ**、正解で **ぱかっと ひらいて 金貨が とび出す** |
| 相棒 | 小さな ドット絵 | 3D（やさしく ゆれる）。追い打ちで とびかかる |
| タイトル | ドット絵の なかま 10体＋一枚絵の 勇者＋CSS の たからばこ | ぜんぶ 3D。勇者は **見本の キャラ**（青い かみ・ひかる けん・Lv30＝その子の アバターでは ない・v5.0 の きまり どおり）。オープニング（v10.4）は そのまま＋はねが ばたばた・勇者は うでを 上げて 落ちる・たからばこは 着地の あと ふたが ひらく |
| カプセルマシン | 出た モンスターは ドット絵 | 3D で 出る |
| ずかん・地図・けっか画面・HUD | 2D | **2D の まま**（275体が いっせいに 3D だと 重い） |

**絵は 1つも 描き直して いない。ルールも 変えて いない**（ぜんぶ 見た目だけ）。
せっていの **「りったい」**（タイトル 左上・メニューの せってい）で 2D に もどせる（はじめは つける）。

## 3. 動きの 対応表（battle.js）

| 出来事 | 2D（そのまま 残る） | 3D で 足した もの |
|---|---|---|
| 登場 | `.is-appear`（popin）→ 3D では 止める | 1体め・ボス＝`mo-walk`／ほか＝`mo-hop`／たからばこ＝ぽん |
| こうげき | `.hero.is-attack`（すべり）→ 止める。斬撃の 弧・つぶ・白フラッシュは そのまま | `dashTo` → 主人公 `mo-attack`＋器 `mo-dash`／てきは 200ms 後（ひっさつは 320ms）に `mo-hurt` |
| たおす | `.is-down`（downfx）→ `v3Gone`（1秒後に 名前ごと 消える） | `mo-fall`（横に ばたん） |
| ボスを たおす | `.is-bossdown` → `v3Gone` 1.3秒 | `mo-crumble`＋主人公 `mo-win` |
| ボスの おこり | 絵を 入れかえ（`foeArt(enrage)`） | ＋`mo-lunge` |
| くらう（ため → はずれ） | `.enemy.is-lunge`・`.hero.is-struck` → 止める | てき `mo-attack`（とびかかる）→ 220ms 後 主人公 `mo-hurt` |
| まちがい（ガード） | `.hero.is-hurt` | 主人公 `mo-hurt` |
| カウンター | `.hero.is-counter` → 止める（ダッシュと 二重に なる） | attack() の ダッシュが 出る |
| たからばこ | `MQ.sfx.chestOpen` | `mo-chest-open` |
| 相棒の 追い打ち | `.pal.is-hit`（とぶ） | ＋`mo-attack` |
| 2D の 影 | `.shadow--hero/--foe` | 3D では かくす（足もとの だ円が つく） |

`play(el, mo, ms)` の「ms の あと 待機に もどす」は **その あいだに 別の 動きが 入って いたら もどさない**（token）。これが ないと のけぞり（520ms）の もどしが たおれる（420ms）を 上書きして 立ち上がる。

## 5. もどさない・気を つける

- **2D の 道は 消して いない**（せっていで もどる）。3D だけの コードに しない。
- 3D の 図に **`filter` を かけない**（その 部品が 平らに なる）。光らせたい ときは `drop-shadow` を 器（`.v3scene`）の 外の 箱に。
- `.hero__img`／`.enemy__img` を さがす コードは **`.enemy__img3d` も 見る**（ボスの おこりで 1回 ふんだ）。
- 動きの 名前は `mo-*` だけ。ふやす ときは `css/motion3d.css` に 1つ＋`three.js` の `idleOf` が わかる ように。
- デモ（`tools/3d/demo3d.js`・harness `#demo3d*`）は **2D の 画面に 3D を かぶせる 道具**なので、harness の その モードだけ `v3` を 切って いる。
