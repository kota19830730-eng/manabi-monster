## 3. 問題を 作る ときの きまり（小6ならでは）

- **算数の かん字**は 小5まで ＋ `G6_EXTRA = 称拡縮値割捨展尺`。むずかしい 語には ふりがな
  （対<ruby>称</ruby>・<ruby>拡</ruby>大図・<ruby>縮</ruby>図・比の <ruby>値</ruby>・<ruby>縮尺</ruby>）。
  さいひん値・ならべ方 は ひらがな。
- **`type: 'frac'` の 答えは 分母 2いじょう**（＝整数に ならない）。分数の かけ算・わり算の 生成器は
  **整数に なる 組み合わせを 引き直す**（`if (n * k % d === 0) return ...()`）＋
  `make()` にも 保険（`q.answer.d < 2` なら 引き直す）。
- **決めうちキー（`key`）の maker を 同じ ステージの 2つの グループに 入れない**
  （12問かぶりなしが 落ちる。ステージ11 で 1回 ふんだ）。
- **国語の 表は 189字**（6年 191字 − 小4の 表に すでに ある「胃」− 数え方の 調整）。
  `kakusu.js` に **小6 189字の 画数**を 足した（837 → **1026字**）。無いと ゆびで 書く はんていが
  「なぐりがき」に 誤判定する。
- **社会（歴史）は 人名・地名で 教育漢字を 外れる**。smoke の 白リスト `OK6` に 入れる か、
  ひらがなに 言いかえる（むじゅん・だそく・すいこう・いっき・ずいひつ・しんでん造）。
  読みにくい ものは 問題文に ふりがな（弥生・鎌倉・紫式部・刀狩・浮世絵・伊能忠敬・杉田玄白・長篠・地租・藩）。
