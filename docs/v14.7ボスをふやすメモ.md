- エリアの ボスは エリア id だけで 決まって いて、id は 小1〜小6 共通。算数の ステージは 全学年で 約90 あるのに、ボスは **毎回 ナンバードラゴン**。

## しくみ

- **どの ボスが 出るか**＝`MQ.enemies.bossFor(エリア, hard)`。hard は ザコの `pickIds` と 同じ「開いて いる ステージの 中の 位置（0〜1）」。
  `tierOf(hard)`：1/3 みまん＝序盤／2/3 みまん＝中盤／それ いがい＝終盤。**hard を わたさない ときは 終盤**（いままでの ボス＝むかしの テスト・ほかの 呼び出しは そのまま）。
  - 18ステージの 算数は 6・6・6 に わかれる（smoke）。学期で しぼって 開いて いる ステージが 少なくても、さいごの ステージは かならず 終盤の ボス。
  - ごちゃまぜ バトルは `Math.random()`＝3体の どれか。
  - 小4〜の 理科（`rika`）は `AREA_ALIAS` で 理科社会の 3体を 借りる。
  - `bossesOf(エリア)`（ラスボスを のぞく）・`tierOf` も 外から 使える。
- **絵の 正本**：`tools/bossart/final.js`（竜王・青鬼）＋ **`tools/bossart/final2.js`**（13体・`tag(部品, 四角)`・PALS／COLORS／PHASE2／BOSSES）。
  → **`node tools/bossart/emit.js`** が ①`monsterart.js` の `<boss64>` ②`enemies.js` の `<areabosses>` の しるしの あいだを 書く（**手で さわらない**・何回 流しても 同じ）。
  作り直しの 3体は shape 名を かえない（mech → `knight`・`kingslime`・`titan`）＝id も しょうごう（t-umi／t-sora）も そのまま。
- **3D**：`boss3d.js` の CFG に `kind`（`'side'`＝左むきの 横すがた ry +18／`'front'`＝正面）。make() が `.v3--b64` と `.v3--b64side`／`.v3--b64front` を つける。
  部品：頭・うで・しっぽ・つばさ（wingR）・マント（cape）・かんむり（crown）・うかぶ もの（orbs＝ふだ・いなずま）・ふくろ（sack）・せびれ（fin）・水たまり（pool＝うすく 奥に 広い）・けらい（minionA／B）・足。
- **動き**：`css/motion3d.css` の いちばん 下「.v3--b64」。ふだんは 頭・うで・しっぽ・マントが ゆれ、うかぶ ものが ただよい、けらいの スライムが はねる。
  こうげきで 右うで（ぶき）を ふり下ろし、左うでは 反対に ふる・頭が ほえる。横すがたの つばさは rotateX、正面は rotateY。transform だけ（v13.10）。
- **キャンバス**：`tools/bossart/build2.js <出力>` → project/ を Artifact で 公開。`preview2.js` は 1体ずつ 大きく 見る ページ。

## もどさない

- ボスを エリアに 1体に もどさない（「毎回 同じ ボス」が 理由）。終盤は いまの ボス（いちばん 強い のは 竜王・青鬼…の まま）。
- `bossFor(エリア)`（hard なし）＝終盤 を かえない（ほかの 呼び出しと むかしの テストが たよって いる）。
- 序盤・中盤の ボスを ザコの 顔ぶれ（pickIds）に 入れない。
- 48マスの メカナイト・キングスライム・グランドタイタンに もどさない。
- 絵を 直す ときは final2.js → emit.js（monsterart.js／enemies.js の しるしの あいだを 手で 直さない）。部品の 名前を かえたら boss3d.js の CFG も（smoke が 見る）。
