## ① エラーの 保険（`js/core/guard.js`・新）

- **index.html の いちばん 先に 読む**（`MQ.util` にも たよらない）。ほかの ファイルが 読みこみ中に 落ちた とき
  （v5.0.1 の zu.js の 事故＝小4の 子だけ「つづき」が きかない）も つかまえる ため。
- `window` の `error` と `unhandledrejection` を 受けて
  1. **localStorage `manabi-monster-errors-v1` に きろく**（8件まで・同じ エラーは 回数だけ ふやす・1回の 起動で 20件まで）。
     中身は 日時・バージョン・メッセージ・`ファイル名:行:列`・出ていた 画面・段階（`load`＝読みこみ中／`boot`／ふつう）。
     **外には 送らない**（企画書の きまり どおり）。
  2. **画面の 下に バー**「こまった ことが おきたみたい／もういちど ひらくと なおる ことが 多いよ。なおらない ときは おうちの人に 見せてね」
     ＋「もういちど ひらく」（reload）「とじる」。**1回の 起動で 1回だけ**。`.guard`（`.upd` と 同じ 場所・赤オレンジの ふち・z 95）。
- `boot.js` は 起動を `try/catch` で 包み、落ちても タイトルだけは 出す → きろく → バー。さいごに `MQ.guard.markBooted()`。
- `ResizeObserver loop` は きろくしない（害の ない お知らせ）。
- API：`record / all / count / clear / text / device / bar / resetBar / markBooted / onError`。
