## A 円と 球の 問題（`js/content/sansu3.js`）

図が なかった 3つの 型に 図（`figQ3`・`scratch: false`・`key` を つけた）。

| 型 | 図 | 気を つけた こと |
|---|---|---|
| コンパス（半径／直径 → 何cm に 開く） | `compassSvg(kind, label)`：点線の 円＋コンパス（はりは 中心・えんぴつは まわり）＋開きに「？cm」 | **半径の ときは 半径を 左がわ**に 書く（コンパスと 同じ 線に「？」と 長さを 重ねると 答えを 書いた ことに なる）。直径は 下の 目もり |
| 円を n こ ならべる → はしから はしまで | `rowCirclesSvg(n, rLabel)`：1つめに 半径・下に「？cm」 | 2この とき 上の 字が 切れた → `cy = max(46, r + 18)` |
| ボールを 箱に ならべる → 何こ | `ballsSvg(n, d, L, { count: true })`：箱＋ボール 1こ＋「？こ」 | 数えられる ほど 正確では ない（5 と 6 の 見分けは つかない）ので 答えは ばれない |

**前から あった バグ**：`ballsSvg` は ボールが 2この とき 下の 長さの 字（y 130）が 120 の わくの 外に 出て いた → ボールの 大きさを 52 までに して まん中に（`x0 = 80 − bw/2`）。
「円と 球の ことば」（円の まん中の 点を 何と いう？ など）には つけない（図が 答えに なる）。

## B 修行場の 解説（`js/content/lesson3.js`・`explain[].ex`）

- 解説用の 図＝`fig(svg)`（`.dojo__fig`・問題の 図を 大きく まん中に）。よこならびは `.dojo__fig--row`。
- **あとから 読まれる ファイルの 図（sansu1 の とけい・sansu2 の 分数）は `ex` を 関数に する**（`ex: function () { return ex(…); }`）。`js/ui/dojo.js` が 開く ときに よぶ。smoke も 関数なら よんで から 検査。
- 円 3まい（`circleNamesSvg`・`radiiSvg(5)`・`ballsSvg(2,…)`）＋ ほかの 単元 14まい：
  かけ算（`dotsSvg(12, 3, {group})`）／わり算（`dotsSvg(12, 4, …)`）／時こく 1・3（とけい 2つ＋「20分 →」）／ぼうグラフ 1・2（`graphSvg(values, scale)`）／あまり（`dotsSvg(17, 5, {group, rest})`＝あまりは 赤）／大きい 数（位の 表 `.tbl`）／長さ（`roadSvg`＝道のりと きょり）／小数（`tenthsSvg(6)`）／重さ（`dialSvg(340)`）／分数 1・2（`fracSvg` を ならべて ＋ ＝）／倍（`tapeSvg`）／三角形 1・3（`triSvg` ×2・`circleTriSvg`）／そろばん（`sorobanSvg([0,7,3], 2)`）。
- 式だけで 足りる 単元（筆算 4・10・17／□の式 14）は そのまま。
- 新しい 図は ぜんぶ `MQ.sansu3.figs3` から（`compassSvg rowCirclesSvg circleNamesSvg radiiSvg dotsSvg roadSvg tenthsSvg graphSvg`）。
