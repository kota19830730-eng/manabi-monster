## 1. しくみ（`js/content/kotobagen.js` の `MQ.hyoQ`）
- **`pairs(spec, table)`**：`[A, B]` の 表から「A → B」（askA）と「B → A」（askB）の 2問ずつ。まちがいは ほかの 行から（`others`＝とびとびで 毎回 同じ）。
  - **同じ ことばが 2行に あれば その 向きは 作らない**（音読み「カ」は 花・火・家…／敬語「いらっしゃる」は 行く・来る・いる）。
  - **`minB`**：B が 短い ときは B → A を 聞かない（「変わらない」のは？ の ような 文に なる）。
  - **`kind: true`**：まちがいは 同じ しゅるい（形容詞／動詞／名詞）から（「大きい」の 反対に「北」を 出さない）。
- **`sets(spec, yes, no)`**：「なかまに 入る ものは？」（正解 yes・まちがい no）と その 逆。
- **`attach(mod, list)`**：`MQ[mod].questions` に 足す。**手書きと 同じ 文（スペースを のぞく）・同じ かぎかっこの ことばは 作らない**。`q.gen = true`。

## 4. 見本を 読んで 直した こと（自動で 作る 文の わな）
- **まちがいの しゅるい**：「大きい」の 反対に「北」「弟」→ `kind: true`（形容詞／動詞／名詞を そろえる）。
- **同じ ことばが 2つの 表に**：ANT3 の「あつい／さむい」「あつい／うすい」、「高い／ひくい」と「安い／高い」→ 答えが 2つに なる ので 1つに。`pairs` が 同じ A・B を 見つけたら その 向きを 作らない。
- **音読み「カ」の かん字は？**→ 花・火・家・歌 が ぜんぶ 正解 → 同じ B の 行は B → A を 作らない（上と 同じ しくみ）。
- **「変わらない」のは？**「上がる」のは？ → `minB: 6`（短い B は 聞かない）。B → A の 文は「〜と いう せつめいに 合うのは？」。
- **動作の 行と ことばの 行を まぜない**（「鉄しん」と どう なる？）→ 風と ゴム・電じしゃくは 表を 2つに 分けた。
- **人名が できごとに 入って いる**（「がんじん」が した ことは？ → がんじんが 仏教を…）→ その 行は 人物の 問題を 作らない。
- **二重の かぎかっこ**（「「古事記伝」を 書いた」）→ 書名は 『』。
- **学年を こえる かん字**：小3＝好・泣・笑・訓（訓は 単元名 なので ゆるす）・成虫 → せい虫・養分 → よう分・N極 → Nきょく・方位じしん → ほういじしん／小4＝職員室・警察・宇宙・県庁 → けんちょう・横浜 → よこはま・江戸切子 → えど切子／小5＝筑後川・吉野川・諸島・鉄鋼・存・覧／小6＝謙譲（けんじょう語）・千載一遇（→ 大義名分）・優柔不断（→ 有名無実）。
- **同じ 読みの 漢字の まちがいは 教育漢字だけ**（飽・篤・迅 などを 出さない。たりない ぶんは 送りがなを まちがえた 形）。
- **1学期の 単元を ふやしすぎない**：風と ゴム（1学期）を 13問 足したら 1学期に ステージ2（光・じしゃく・電気）が 開いて しまった（smoke「1学期の 理社: 1・3 だけ 開く」）→ 5問まで。**重さ**（3学期・4問）も smoke「重さだけでは 理社2は 閉じる」に つかう ので 3行まで。

## 7. 表を 足す とき
- **A と B が どちらも 1つずつ**（重なる ものは 表を 分ける）。**A は 名詞（もの・ことばの 名前）**、B は 説明。A が 動作なら askA を「〜と どう なる？」に して askB は つけない。

- 1学期の 単元は ふやしすぎない（上の ⑨）。足したら smoke ＋ 見本を 読む。
