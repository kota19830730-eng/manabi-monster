# v14.46 きろくを まもる 2（iPhone の 案内画面 ＋ ファイルに ほぞん）

2026-10-07・sw 222・お知らせ なし（子どもの 画面の あそびは 変わらない）

## きっかけ
ユーザー「Safari の タブで あそぶと きろくが 消える ことが ある。これを 解消できる？」
→ Safari の タブの まま 消えなく する 方法は ない（Apple の きまり・サイトから 止められない）。
→ 4案（①ホーム画面へ 強く みちびく ②ファイルに ほぞんしやすく ③サーバー ④App Store）
→ ユーザー「1と2 両方」。③④は 企画の きまり（外に 送らない・パスワードなし）と 費用で 採らない。

## できた もの
1. **案内画面**（`js/ui/start.js` の `keepGuide()`・`.keepguide`）
   - iPhone／iPad の Safari の タブで タイトルを ひらくと、オープニングの あとに 出る。
   - **1日 1回**（とじた 日は もう 出さない・`MQ.keep.guideDue/guideClosed`・せってい `keepGuideDay`）。
   - **プレイヤーが まだ いない ときにも 出す**（きろくが ない いまが いちばん 入れやすい）。
   - あそんだ きろくが ある ときは「記録をファイルに保存」ボタンと、Safari とアイコンで 記録が 別々な ことの 説明。
     7日 いじょう 保存して いないと ボタンが 赤（`is-due`）。
   - **あそぶのは 止めない**（「きょうはこのまま遊ぶ」で とじる）。
   - v14.42 の 小さい バー（`.keepbar`）は 使わない ことに した（案内画面と 2つ 出さない）。CSS は のこして ある。
2. **ファイルに ほぞん／もどす**（`js/ui/common.js`）
   - `MQ.ui.saveBackup()`：iPhone／iPad は 共有メニュー（`navigator.share` の files）＝「"ファイル"に保存」→ iCloud Drive。
     ほかの 端末・共有できない ときは ダウンロード。ほぞんできたら `MQ.keep.markBackup()`（せってい `backupAt`）。
   - `MQ.ui.restoreFromFile()` → `MQ.ui.restoreText(text)`：形を たしかめ・名前を 見せて 確認 → 上書き → タイトルへ。
   - 子どもの せっていの「きろくを ほぞん」も 同じ `saveBackup` を とおる（日づけが のこる）。
3. **おうちの人ページ**（`js/ui/parent.js`）
   - ホームの 赤わくの カード（iPhone の タブの とき）に 最後に 保存した 日と「記録をファイルに保存」。
   - 設定に 新しい 節「記録のバックアップ」（どの 端末でも・保存／ファイルから戻す・最後の 保存日）。
   - 「ホーム画面に入れる」の 移し方の 文を 新しい ボタンの 名前に そろえた。

## もどさない
- 案内は **大人の 文**（`data-noconv`・学年の 辞書を かけない）。
- 1日 1回より ふやさない・あそぶのを ブロックしない。
- 保存の 知らせ（`backupDue`）は あぶない 端末（iPhone の タブ）で、あそんだ きろくが ある ときだけ。
