

## りったい（3D・v12.0）

主人公・モンスター・たからばこ・相棒は **バトル・タイトル・カプセルマシン**で 箱の 立体に なる（ずかん・地図・けっか画面・HUD は 2D の まま）。
絵は 2D の ドット絵 そのまま（描き直さない）。仕様は `docs/v12.0りったいメモ.md`・作り方の きろくは `docs/3Dの試作メモ.md`。

- **器**：`.v3scene`（perspective 900px）> `.v3fig`（`rotateX(8deg) rotateY(±22deg)`＝左の 子は +22・右の 子は −22）> `.v3hold`（`scale3d`・下の まん中が じく）> `.v3`（部品 `.p--*`）。
- **光**：左上の 手まえ。上の 面＝あたたかく 明るく、右・下＝すこし 青い かげ。うしろほど 暗く（AO）。ざらつき ±6%。
- **厚み**：ぜんたい＝かたちの 短い 辺 × 0.42（上限 18マス）。主人公は 帯（頭 20／体・足 13）。けんの 刃は 4。たからばこは 24。
- **動き**（`css/motion3d.css` の `mo-*`・かんせつで 回すだけ・曲げない）：待機 `mo-idle`（主人公）`mo-menace`（てき＝前かがみで ゆすり 3.4秒に 1回 フェイント）`mo-title`（タイトル・相棒）`mo-chest`（ふたが ガタガタ）／
  登場 `mo-walk`（1体め・ボス）`mo-hop`／こうげき `mo-attack`＋器の `mo-dash`（0.42秒・てきの 手まえまで）／くらう `mo-hurt`／たおれる `mo-fall`（横に ばたん）`mo-crumble`（ボス）／かち `mo-win`／ため `mo-lunge`／たからばこ `mo-chest-open`。
- **2D の 器の 動きは `.is-3d` で 止める**（`.hero.is-attack`・`.enemy.is-appear`・`.is-lunge`・`.is-struck`・`.is-counter`・`.is-down`・`.is-bossdown`）。のこす もの：ひっさつの ふっとび・よける・ガード・にげる・ぶんしん・斬撃の 弧・つぶ・白フラッシュ。
- **3D の 図に `filter` を かけない**（平らに なる）。2D の 影（`.shadow--hero/--foe`）は かくして 足もとの だ円に。
- せってい「りったい」（はじめは つける）で 2D に もどる。**2D の 道は 消さない**。
- **v12.1 軽く**（`docs/v12.1軽くするメモ.md`）：見えない 面を 作らない（かくれる 面・向きで 見えない がわ・うしろは うで／けん／ふた だけ・
  タイトルと カプセルは 上の 面も なし）＋ 同じ 平面の 面を つなぐ ＋ 模様は 1体 1まいの アトラス ＋ cloneNode。
  **面の 置き方（内むき・両面）は v12.0 の まま**（外むき＋backface-visibility は あごの 下に すきまが 出た）。
  前の 面は 四方に 0.5px 大きく・右と 下の 面は 0.6px 手まえ（つぎめに 空が すけない）。
- **2D の タイトルの 勇者も 3D と 同じ 見本キャラ**（`TITLE_HERO`・`.title__heroimg--avatar` 138px）。v5.0 の 一枚絵は つかわない。

## バトルの 相棒の 場所（v12.1）

相棒は **主人公の うしろ（左はし）・同じ 草の 上**（`.pal` left 6 / bottom 62 / z-index 1）。なまえと ゲージは 足もとの 下の 暗い ゆかに。
そのために 主人公を 32px 右へ（`.hero` left 46）、ふきだしは left 132 / max-width 152（右はしは 284 の まま）、
ためゲージと コンボは left 54。**主人公を 動かさずに 相棒を 左はしに おくと 主人公の かげに かくれる**。
v10.5 の「まん中・暗い ゆか（left 190 / bottom 12）」には もどさない（相棒だけ 地面が ちがい、主人公の ダッシュが 相棒の 上を 通って いた）。
