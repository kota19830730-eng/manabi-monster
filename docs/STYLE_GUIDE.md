## ことばを 学年に 合わせる（v13.2）

画面の 文は いままでどおり「小3の 書き方」（ひらがな＋小3までの かん字・文節ごとに スペース）で 1つだけ 書く。出す ときに `js/core/text.js` が 辞書（`js/content/kotoba.js`）で その子の 学年に 合わせる。仕様は `docs/v13.2ことばの学年メモ.md`。

- **小1**＝ひらがなだけ／**小2**＝小1の 字まで／**小3・小4**＝その 学年までの 字／**小5・小6**＝その 学年までの 字 ＋ マンガ・ゲームで 読み慣れた 字（魔王・冒険・攻撃・倒す・炎・雷・斬り・剣・盾）＋ **文節の スペースなし** ＋ 文末の「よ」を 落とす。
- **書く ときの きまりは 変わらない**：小3の 書き方で 書く。かん字を ふやす ときは 辞書に 1行 足す（コードの 文字列は さわらない）。
- **問題の 中身には 当てない**：問題文・えらぶ ボタン・ヒント・答えの せつめいを 作る `h()` に `raw: true`（`data-raw`）。おうちの人ページ（`#screen-parent`）は 大人の 文なので さわらない（`MQ.text.pause`）。
- 小5・小6は `body.is-nospace`（`word-break: normal`）。スペースを 外した 文を 折り返す ため（ないと 問題カードから はみ出す）。
- おうちの人ページ「ことばの 表示」＝自動（学年）／やさしく（小2）／高学年（小6）。`p.textLevel`。
- harness で ボタンを 文字で さがす ときは `MQ.text.fit('こたえる')` を 通す。

## 地図の ドック（v13.3）

地図の いちばん 下は **アイコンの ならび（ドック）**。仕様は `docs/v13.3地図のドックメモ.md`。まえは 帯が つみ上がり、混む 日は 地図が 311/700 まで へって いた。

- **ならび**：メニュー（本）／しゅぎょう（まきもの・青）／**ごちゃまぜ（サイコロ・まん中・むらさき・金の わく・26px 上に 飛び出す）**／タイム（すなどけい）／小3 ▾（金）。高さ 74px、ボタン 58px（まん中 84px）。
- **アイコンは ブロックの ぬり方**（`js/ui/map.js` の `DOCK_ICONS`・40マス・`MQ.ui.map.dockIcon(name, size)`）。モンスター・たからものと 同じ 3面の 光。**ごちゃまぜに 4まいの 四角（2×2）を もどさない**（Windows の マークに にて いる）。
- ごちゃまぜの 右上に 金の ふだ「● +1」（コインは CSS の 丸 `.maptab__coinico`。たからものの コインの 絵は 14px だと 四角に 見えた）。しゅぎょうの 右上は 赤い ふだ「よしゅう」（出る ときだけ）。
- **てがみ と にげた敵は 地図の すみの ふだ**（`.mapchips`・ドックの 上 66px・左に てがみ／右に にげた敵）。**ごちゃまぜの コインの ふだ（ドックの 上 35px）より 上**に 置く（かさならない）。
- 地図の いちばん 下に あき（`.map__pad` 30px・ふだが ある 日は 72px）＝飛び出した ボタンと ふだの うしろの ステージも スクロールで 見える。
- **プレイヤーを かえる**は 学年えらび（小3 ▾）の 中（`.gradesheet__player`）。ごちゃまぜが ある ときは 学年えらびの 下を 32px あける（かくれない）。
- **はじめての 子**（v11.1）は メニューと 学年だけ。
- class 名（`.maptab` `.maptab--grade` `.mixbtn` `.dojobtn` `.tegamibtn` `.tegamibtn__t` `.revenge`）は harness が 見る ので 変えない。
- たしかめ：harness `#dock` `#dock:busy` `#dock:grade`・`#firstplay:map` `#dojomap` を **800×1280 と 520×780**。

## 地図を なめらかに（v13.4）

地図は **B案「ジオラマ」**（ユーザーが 3方向から えらんだ）。仕様は `docs/v13.4地図をなめらかにメモ.md`。

- **ブロック感を 出さない**。海岸線・道・川は なめらかな 曲線（マスの 表を ぼかして しきい値）。地面は 画面の 2ばいの 点で 描く。
- **島に 高さ**：南の へりに 2だんの がけ（草の 色を こく した 2色）。海岸に 白い 波の ふち・あさせ。光は 左上（左上 明るく・右下 すこし 暗く）。
- **色は 学年ごとの テーマから**（`MQ.tiles.smoothColors(grid.colors)`）。新しい 学年を 足す ときは `THEMES` と `DECO_PAL` の 両方。
- **木・岩＝描いた 3D**：面を 3つ（左＝光・まん中・右＝かげ）＋右下へ 長い かげ。木は 円すい 3だん。**箱に しない**（ブロックに もどる）。
- **建物＝本物の 3D**：家（赤い 屋根・白い かべ・奥ゆき 36）と さいごの塔の 城（天守 46・塔 30・塔は 手まえに 12）。カメラ 横 32°・上から 22°。**3D に filter を かけない**・とじた 城は 暗い 色。
- **ドックの アイコン＝ジオラマ仕上げの SVG**（64×64・面ごとに 平らな 3色＋足もとの かげ）。ブロックの アイコンに もどさない。
- **ステージの 数字の ブロック・名前・ふきだしは いままでの まま**。
- ふちの かげ（`.map__vig`）は スクロールの 外（`.map__view`）で 画面に 止める（v13.4.1）。
- さいごの塔の 小島は 地図の **まん中（50%）**（v13.4.2・ユーザー「もう少し 中央に」）。70% に もどすと 島が 右はしで 切れる。
- 城の 足もとは 島の まん中の 少し 下（`.tower__art--3d` margin-bottom −13・v13.4.3）＋ 右上に 9・7px（translate・v13.4.4・島の かたまりが 右下に ふくらむ ため）。−30 だと 島の 南の へりに 立って 上に はみ出す。中に 入れると 地図の まん中に よこ線が 出る。
