# v9.4 主人公を HD に（2倍の こまかさ＋素材の 質感）

息子さん「**キャラが あんまり グラフィック 上がってる 気が しない**」。
→ 正しい 感想。v9.1 で 変えたのは **ぬり方**だけで、**点の 数は 48×48 の まま**だった。
3段階（①自動で HD ②大きく 見せる ③形を 96マスで 描き直す）を 出して、
ユーザー「おすすめで」＝ **①と②を 入れて、③は 1点 試作してから 判断**。

## 1. HD の しくみ（`js/core/pixel.js` の `renderHD`）

`opts.hd = 2` で **1点を 2×2 に 分けて 96×96 で 描く**。**マス目（かたち）は 1つも 動かさない**ので、
いままでの 顔・かみがた・そうび（約1.9億とおり）が そのまま 使える。あいた こまかさに 入れる もの：

| 何 | 中身 |
|---|---|
| 素材の 質感 | かみ＝たての すじ／ぬの＝こまかい ゆらぎ／木＝たての 木目／金ぞく＝12点ごとの ななめの 光／金＝9点ごとの 強い 光／はだ・白＝ごく うすい ゆらぎ |
| 目の ハイライト | ひとみの かたまりの **左上の かどだけ** 明るく（+0.62） |
| さかいめの 立体 | 同じ 色の かたまりの ふちを **2だんかい**（となり ±0.20／2つ となり ±0.08）。上と 左が 明るく、下と 右が 暗い |
| まわりの ふち | となりの 色を こく した もの（v9.1 の rim を **1点＝半分の 太さ**で） |

**素材は 呼ぶ 側が 教える**：`layer.mat` に `'skin'`（層ぜんぶ）か `{ c: 'cloth', b: 'gold' }`（文字ごと）。
表は `js/content/hero.js` の **`MAT`**（体・ふく・顔・目・かみ・アクセ）と **`gearMat(slot, gradeNo)`**
（そうび。**グレード1＝かわ／木 だけ 金ぞくでは なく `wood`**）。

**色の 文字を 足したら `MAT` にも 足す**（書いて ない 文字は ぬの あつかいに なる）。

## 2. どこに かけたか

- `MQ.hero.sprite()`（バトル・HUD・けっか画面・お知らせ）
- `faceSprite()` / `bodySprite()`（顔だけ・体だけの 小さい絵。**切りぬきの 数字は もとの マス目の まま**。
  pixel.js が 中で 2倍に する）
- `gearSprite()`（図かんの そうび 1点。うしろの うすい かげは 質感なしの `white`）
- **`poster()`（タイトルの 勇者）には かけない。** モックに ふち取りが なく、v5.0 で 決めた 見た目。

## 3. 大きさ（案②・`css/style.css`）

点の 数が 2倍に なった ので、大きくしても ぼやけない。

| どこ | まえ | あと |
|---|---|---|
| バトルの 主人公 `.hero__img` | 76px | **84px** |
| `.hero` の 左 | 20px | **14px**（ふきだしと ぶつからない ように） |
| `.shadow--hero` | 68px | 74px |
| `.arena__msg`（ふきだし） | left 94 / max-width 190 | **left 100 / max-width 184** |
| ひっさつの カットイン `.cutin__hero` | 78px | 92px |

**てきは さわって いない**（もともと 72〜112px で 大きい）。
**ふきだしの 左はしと 主人公の 右はしは ぶつかる。** 主人公を これ以上 大きく する なら
`.arena__msg` の `left` と `max-width` も セットで 直す（88px で 試したら ふきだしが 3行に なった）。

## 5. ハマった ところ

- **node の にせ Canvas に `createImageData` が ない。** `tools/smoke.js` の スタブは
  `fillRect` と `toDataURL` だけ。→ `renderHD` の さいごで **`ctx.createImageData` が
  無ければ `fillRect` で 1点ずつ ぬる 道**に 落ちる ように した。
  （smoke.js は 別セッションが 作業中だった ので **テスト側を 直さず 描画側で 受けた**）
- **きれいな 市松の 質感は「網目」に 見える。** `(X+Y)%2` で ぬのの 織りを 入れたら
  4倍に すると 網に 見えた。→ **ハッシュの ゆらぎ**に した。
- **作業ツリーに 別セッションの 作りかけが 混ざって いた**（カプセルマシン v9.0：hero.js に
  そうびの グレード追加、style.css に オーロラの 光）。→ scratchpad の **`mine2.js`** で
  `git diff -U3` を hunk に 割り、自分の 印／相手の 印で ふり分けて **自分の hunk だけ stage** した
  （pixel.js 1／hero.js 5（相手 13）／style.css 3（相手 1）・混ざり 0）。
  検証は **作業ツリーの コピーに 自分の パッチだけ あてて** smoke と #flow と #fit を 回した。

## 6. もどさない ところ

- **`poster()` に HD と rim を つけない。**
- **`MAT` に ない 文字は ぬの あつかい**＝ 色の 文字を 足したら 表にも 足す。
- **主人公を 大きく する なら ふきだしの left と max-width も セットで。**
- **`renderHD` は `createImageData` が 無い ところでも 動く**（node の テスト）。

## 7. のこり（案③・ユーザーに 見せてから 決める）

**形そのものを 96マスで 描き直す。** 目に 白目と 光、かみに 房、よろいに 板と リベット、
けんに つばと 刃の 線。まず **目と かみ を 1点だけ** 試作して 見て もらう。
モンスターと 地図の HD は **claude-65 が 担当**（`blocks.js` / `tiles.js`）。
