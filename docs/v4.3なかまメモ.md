# v4.3 なかま（相棒）システム

2026-09-02。企画の さいしょから あった ねらい「**たおした モンスターを 連れて 歩く／息子さんの 絵を 敵から 主役に**」を かたちに した もの。
壁打ちで 決めた ルール（ユーザーが えらんだ もの）：

| 決めた こと | 中身 |
|---|---|
| 連れて 歩く 数 | **1体だけ**（「いまの 相棒」） |
| バトルの 力 | **3問 れんぞく 正解ごとに 追い打ち**（3・6・9…）。ボスには **1ダメージ**、ザコ・たからばこでは **けいけんち +10** |
| 育て方 | **一緒に レベルアップ**（主人公が もらった けいけんちの **半分**が 相棒にも 入る） |
| 進化 | **Lv10・Lv20**（`enemies.js` の `evo`）。すがたが 変わり けいけんちは 引きつぐ |
| 手に 入れ方 | ①**たおすと たまに なかまに なりたがる**（けっか画面で「なかまに する」）②**コインで こうかん**（図かんで 出会った ことが ある モンスターだけ） |
| 属性 | エリア＝教科と 同じ 4つ（見た目の 意味だけ。効果は 追い打ちに 一本化） |
| 自分の 絵の モンスター | **相棒に できる**（写真から 作った ものも 同じ しくみ） |

**大原則（v2.0）は そのまま**：効果は「**正解した とき**」だけ 出る。答えを 見せる・勝手に 敵を たおす ことは しない。

## しくみ

| ファイル | 役割 |
|---|---|
| `js/core/pals.js`（新） | ルール ぜんぶ。DOM を 知らない。`active / own / add / setActive / gain / evolveIfReady / hitOn / price / shopList / canBuy / buy / offerFrom / levelOf / expFor` |
| `js/core/save.js` | `p.pals = { id: { exp, got } }`／`p.pal`（いまの 相棒の id）。古い セーブは 空で 入る |
| `js/core/battle.js` | `start({ pal })` で 相棒を うけとる。`palHitNow()` が 3問ごとに true → ボスは ダメージ +1／ザコは けいけんち +10。`res.palHit`・`summary.palHits` |
| `js/ui/battle.js` | 主人公の 右に 相棒（`.pal`）。追い打ちで **前に とんで 光る**（`palAttack`）＋音（`MQ.sfx.palHit`）＋ふきだし「○○の こうげき！」 |
| `js/ui/result.js` | 相棒の 帯（そだった ぶん・レベルアップ・**しんか**）と 金わくの「**○○が なかまに なりたそう！**」＋ボタン |
| `js/ui/dex.js` | 「**なかま**」タブ：いまの 相棒の カード（Lv・けいけんちの バー・つぎの しんか）／もっている なかま（タップで 交代）／**コインで なかまに する**（ねだんは つよさで 3・6・10、自分の 絵の モンスターは 3） |
| `js/ui/common.js` | HUD（地図・図かんの 上）の 顔の 横に 相棒を 小さく |

### レベルの 上がり方
`expFor(lv) = 15(lv-1)² + 25(lv-1)`。1回の たたかいで 入るのは 100〜200 くらい なので、
**Lv10（しんか）は 10回ぶん・Lv20 は 40回ぶん**が 目やす。さいだい Lv30。

### なかまに なる 見こみ
たおした ザコの うち 1体だけ（`offerFrom`）。つよさ1＝16%／2＝10%／3＝6%、レアと 自分の 絵の モンスターは 20%。
**もう なかまの もの・ボス・たからばこは 出ない**。

## 気を つけた ところ
- **けっか画面は 1画面**が 決まり。相棒の 帯＋なかま候補で 2行 ふえる ので、`fit()` を 入れた：
  入りきらない ときだけ ①余白を つめる（`.rs--tight`）②「手に入れた もの」を かくす ③ボーナスチップを かくす の じゅん。
  **画面が 出る 前は 高さが 0** なので、`requestAnimationFrame` と 320ms 後に はかる。
- バトル画面の 相棒は **コンボの 文字（左下）と かさならない** 位置（`left: 134px`）に した。
- `String.replace` の 置きかえ文字列で **`$$` は `$` に なる**（harness の `$$(...)` が `$(...)` に 化けた）。パッチを 書く ときの 落とし穴。

## つぎ（やって いない こと）
- 相棒の 属性ボーナス（教科と 合うと 強い）は **入れて いない**（ユーザーが 追い打ちだけを えらんだ）。
- しょうごう（なかまを N体 あつめた など）は まだ。
- 相棒の 名前を 子どもが つける 機能は まだ。
