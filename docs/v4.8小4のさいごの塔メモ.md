## 1. あたらしい ラスボス「ダークロード」

小3の まおうを もう一度 たおすのでは 気もちが 上がらないので、**小4は 新しい ラスボス**に しました。

| | まおう（小3） | **ダークロード（小4）** |
|---|---|---|
| id | `boss-maou` | **`boss-dark`** |
| すがた | 金の つの・赤く 光る 目・マント・むねの 宝石 | **3つとがりの 王かん**・かぶとの スリットに 光る 目・**右手に 大きな けん**・下で 広がる マント |
| 色 | 赤 → 第2形態で もっと 赤い | むらさき → 第2形態で あかるい むらさき |
| HP | 5（最大 8問・HP3で 第2形態） | 同じ |

絵は `js/content/monsterart.js` の `dark`（48×48・四角 15こ）。
データは `js/content/enemies.js`（`area: 'tower4'`・`last: true`・`phase2` つき）。
図かんは **152 → 153体**に なりました。

**画面の 文字は ぜんぶ `MQ.content.lastBoss()` を 見ます**（「まおう」を 直に 書かない）。
バトルの ふきだし・FINAL BATTLE の 文・けっか画面・ぼうけんの きろく・地図の 塔の 文字、ぜんぶ。

## 2. しくみ（塔を 学年ごとに した）

`js/content/world3.js` を こう 直しました。

```js
const TOWER_ORDER3 = [算数, 国語, ローマ字, 理科社会, 英語];
const TOWER_ORDER4 = [算数, 国語, 理科, 社会, 英語];

function makeTowerStage(grade, order, bossId) { ... }   // 学年ごとに 1つ 作る
const towerStage  = makeTowerStage(3, TOWER_ORDER3, 'boss-maou');
const towerStage4 = makeTowerStage(4, TOWER_ORDER4, 'boss-dark');
```

- slot に `area` を 書かない ときは `kind` を そのまま エリア id に します
  （小4の `rika` / `shakai` は そのまま、小3の 理社は `area: 'rikashakai'`）。
- ローマ字は ステージでは なく `MQ.romaji3` から 直に 出します。国語の ローマ字ステージには
  **`noTower: true`** を つけて、国語の わくから 外して あります（前は id で 決めうちに して いました）。
- ステージ id は `tower3` / `tower4`。`terms.js` の 表には 入れないので いつでも 開いて います
  （開くか どうかは **かけら**が 決める）。

### かけらの 数は 教科の 数

`towerOpen(player)` は `fragCount(player) >= subjectAreas().length`。
小3は 4教科 → **かけら 4つ**、小4は 5教科 → **かけら 5つ**。
地図の 塔の 文字も `かけら n / 4` を やめて **`n / 教科の 数`** に しました。

## 3. たしかめ方

```bash
cd manabi-quest
node tools/smoke.js .          # ALL OK（3回）
```

smoke が 見て いる こと

- `lastBoss()` が 学年で 変わる（小3＝まおう／小4＝ダークロード）
- 小4の 塔の たからものが ある／ダークロードの 絵が ある
