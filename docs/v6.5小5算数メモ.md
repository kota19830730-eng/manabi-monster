## 2. あたらしい しくみ：分数の 入力（type `frac`）

- 問題：`{ type: 'frac', answer: { n: 分子, d: 分母 } }`（`fracQ()` が gcd で **約分ずみ**に して 入れる。smoke が 約分ずみ・d ≥ 2 を 検査）。
- 画面（`js/ui/battle.js`）：わり算の あまり（divrem）と **同じ 2つの わく**を「分子（上）」「分母（下）」の ラベルで 使う。分子 → こたえる → 分母 → こたえる。
- 判定（`js/core/battle.js` の `isCorrect`）：`value.q === n && value.r === d`（**約分して いない 6/8 は ×**。問題文に「（約分した 形で）」と 書いて ある）。`answerText` は「4分の3」。
- harness の 自動回答（`playBattle`）にも frac を 足した。smoke の `TYPES` に 'frac'。
- 問題文の 分数は `fr(n, d)`（`.frac`：上に 分子・下線・下に 分母）、帯分数は `mixed(w, n, d)`。**choices（ボタン）は 文字だけ**なので `ft(n, d)`＝「4分の3」を 使う（smoke が choices に HTML が ないか 検査）。

## 3. ことばの きまり（小5）

小4までの かん字 ＋ **5年で ならう 字**（`G5_EXTRA = '比率均応仮容増減厚個割偶奇捨条展'`）。
- 6年・中学の 字は 問題文で ふりがな：`WARI`（割合）`WARIBIKI`（割引）`GUU`（偶数）`KI`（奇数）`SHASHA`（四捨五入）`TENKAI`（展開図）。ヒント・note は HTML が 使えない ので そのまま（白リストで 通す）。
- ひらがなに した もの：すいちょく・ちょう点・てん開図（TENKAI で ruby）・がい数・「個」→ こ数。
- 「値」「条件」「頂面」は 使わない（答え／きまり／上の面）。
