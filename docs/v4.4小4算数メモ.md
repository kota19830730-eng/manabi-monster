## ことばの きまり（小4）

**小3までの かん字（`js/content/kakusu.js` の 表）＋ 4年の 単元で つかう かん字だけ。**
smoke.js の `G4_EXTRA = '位億兆単辺以捨積量帯置展'` が 白リスト。ここに ない かん字が
問題文・ヒント・答え合わせの 文に 出たら テストが 落ちる。

- 中学の かん字は ひらがな：**すいちょく**（垂直）・**がい数**（概数）・**ちょう点**（頂点）
- 教科書の ことば なので 通した もの：**四捨五入**（捨＝小6）・**展開図**（展＝小6）
  → 問題文だけ ふりがな（`SHASHA` / `TENKAI` の ruby）。ヒント・答えの 文は そのままの 字
    （ヒントと note は HTML が 使えず、そのまま 文字に なる ため）

## 図（inline SVG）

`js/content/sansu4.js` の 中。見る 道具は `tools/harness.html#figs4(:-1)`。

| 図 | 関数 | 出し方 |
|---|---|---|
| おれ線グラフ | `lineGraphSvg(set, values)` | カードの はば いっぱい（`class="graph"`） |
| 分どき（分度器） | `protractorSvg(deg)` | カードの はば いっぱい（`class="figwide"`） |
| 角 | `angleSvg(deg, outer)` | 文字の 右（`.figbox`） |
| 一直線の 上の 角 | `straightSvg(deg)` | 文字の 右 |
| すいちょく・平行 | `linesSvg('perp'/'para'/'cross')` | 文字の 右 |
| 四角形 | `quadSvg(kind, {diag, angle})` | 文字の 右 |
| 長方形の 面積 | `rectSvg(w, h, wLabel, hLabel)` | 文字の 右 |
| L字の 図形 | `lShapeSvg(a, b, c, d)` | 文字の 右（外の 4つの へんに 長さ） |
| 直方体・立方体 | `boxSvg(cube, labels)` | 文字の 右 |
| 展開図 | `netSvg('cross'/'tee'/'step'/'bad')` | 文字の 右（bad だけ 組み立てられない） |
| 表 | `tableHtml(head, rows)` / `tableRows(rows)` | 問題文の 中（CSS `.tbl`） |

**角の 大きさは かならず 読める ように する**：
角の 絵だけ 出しても 目分量に なって 答えられない。
「はかる」問題は **分度器を 描いた 図**（`protractorSvg`）、
「180度より 大きい 角」は **小さい ほうの 角の 大きさを 問題文に 書く**。

## 画面に おさめる きまり（ここが いちばん ハマった）

たて700の 端末では **問題カードに 使える 高さは 約170px**（メモ欄なしの とき）。

1. **図の ある 問題に メモ欄を つけない**（`scratch: false`）。
   メモ欄（96px）と 図（112px）は 両方 入らない。smoke.js が 検査する。
   そのぶん 数を 小さくして 頭の 中で 計算できる ように した（面積は 3〜12cm など）。
   大きい 数の 計算は **図の ない 問題**（`bigAreaQ` など）で メモ欄つきに する。
2. **図の ある 問題は 問題文を 小さく**（`js/ui/battle.js` の `fitPrompt` が
   `class="graph" / "tbl" / "figwide"` を 見て `card__q--s`）。
3. **グラフの 高さは `--stage-h` の 17%**（css `.graph, .figwide`）。
   22% だと たて700で 下の 問題文が 切れた（**小3の ぼうグラフも 切れて いた**。ここで 直った）。
4. **表の 前に `<br>` を 入れない**（表は それだけで 行が かわる。空行 27px の むだ）。
5. **表の しらべの 名前は unit の 行**（上の 小さい 字）に 出す。問題文に 入れると 1行 むだ。
6. 問題文は **1行で おさまる 長さ**に する（21px で 15〜16字）。
   「かわり方が いちばん 大きいのは どこ？」→「いちばん 大きく かわったのは？」
7. 「5分の □」の ように 切れると 読めない ところは `<span class="nw">`（`white-space: nowrap`）。
