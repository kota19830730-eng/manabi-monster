## できた もの
- **地面**（`js/core/tiles.js` の `paintSmooth`）：マスの 表（cells）は そのまま、見た目だけ。
  マスの 表を 小さな 絵に して ぼかし → しきい値＝なめらかな 海岸線・道・川。島の 南の へりに 2だんの がけ（高さ）・海岸の 白い 波・あさせ・草の やわらかい 明暗・森・岩場の まるい 石・道の じゃり・板の 橋。
  色は **学年ごとの テーマ（grid.colors）から 作る**（`smoothColors`）＝ 小1 春・小2 夏・小3・小4 秋・小5 冬・小6 闇 が そのまま。
- **かざり**（`tiles.js` の `paintDecos`）：木＝円すい 3だん・面を 3つ（光・まん中・かげ）＋右下へ 長い かげ／岩＝3つの 面／花＝5まいの 花びら（小6は 光る）／雪山・枯れ木・クリスタル。学年ごとの 色は `DECO_PAL`（小5の 木は てっぺんが 雪）。
- **建物＝本物の 3D**（`js/ui/map.js` の `house3d` / `castle3d`）：家 3けん と さいごの塔の 城。
  奥ゆき 家 36・天守 46・塔 30（v12.0 の 自動の 厚みは 上限 18 で「薄っぺらい」）。カメラは 横 32°・上から 22° 見おろす。城は 部品ごと（天守・左右の 塔・ぎざぎざ 手まえ／奥・旗）に 組み、塔を 天守より 12 手まえに 出す。
- **ドックの アイコン**（`map.js` の `DOCK_ICONS` / `dockSvg`）：64×64 の SVG・面ごとに 平らな 3色＋足もとの かげ。本・まきもの・サイコロ・すなどけい・コイン。

## 重さ（本物の 時計・GPU あり の PC）
| | 地図を 作る 時間 |
|---|---|
| まえ（ブロック・SUB 12） | 約 60ms |
| なめらか（はじめ・画素を 読み出す しきい値） | 約 260ms |
| **なめらか（しきい値を SVG の フィルターで GPU に）** | **約 110ms**（学年を 切りかえた とき） |
| 同じ 学年に もどる（とって おいた 絵を 写す） | **約 30ms** |

- 重かった のは マスクの 画素の 読み出し（12枚×12ms）。`ctx.filter = 'url(#mqth-…)'`（feGaussianBlur → feFuncA linear）で 読み出しを なくした。**ためして 使えない 端末は 読み出しの 道**（`gpuThreshold`）。
- 描いた 地面は **3枚まで とって おく**（`smoothCache`）。**タイトル画面の オープニングの あと**（2.6秒）に ひまな ときに 先に 描く（`MQ.ui.map.warm`）。
- マスクは 画面と 同じ はば（400）で 作り、2ばいの canvas に 引きのばす。きっちり 0/255 で 切ると 階段に なる ので **しきい値の まわり 1px を なだらかに**。

## もどさない
- **木と 岩を 本物の 3D（箱）に しない**＝ブロックの 木に もどる（ユーザー「ブロック感 なくして」）。箱に するのは もともと 四角い 建物だけ。
- **3D の 図に filter を かけない**（平らに なる）。まだ 開いて いない 城は 暗い 色の 絵の具（`CASTLE_LOCK`）で 作る（前は `.tower--lock .tower__art` の grayscale）。
- **下から 見上げる 角度に しない**（rotateX が プラスだと 建物の うらが 見えた）。
- **ステージの 数字の ブロック・名前・ふきだしは さわらない**（ユーザー「ステージの 数字の とこは 今の 表示で いいよ」）。
- マスの 表（島の 形・道・ノードの 場所）は 変えない。smoke の 島の 形の 検査は そのまま 通る。
- `ctx.filter` が ない ブラウザ（古い Safari）は いままでの ブロックの 地図（`paintBlocks`）と div の かざり。「りったい」を 切ると 家は 地面に 描いた 絵・城は いままでの TOWER_B。

## v13.4.1 地図の まん中の よこ線（2026-09-13・sw 142）
- ユーザーの iPhone の スクショで 地図の まん中に よこ線（線より 上が すこし 明るい）。
- 原因＝ふちの かげ（`.map__vig`・inset の box-shadow）が **スクロールの 中**に あり、画面 1枚ぶんの 高さで いっしょに 動いて いた。「いま ここ」まで スクロールすると 下の はしが 地図の まん中に 出る（0 や 画面 1枚 いじょう スクロールした 撮り方では 見えない ＝ harness では 見のがして いた）。
- 直し＝`.map__view`（position relative・flex 1）で スクロールを つつみ、かげは その 上に 止める。**`.map__vig` を `.map__scroll` の 中に もどさない。**
- たしかめ方：たて長（520×1120）で スクロール 330 に して 撮る。
