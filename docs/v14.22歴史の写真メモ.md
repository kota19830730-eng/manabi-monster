# v14.22 歴史の 写真（偉人と 道具・たてもの）

2026-09-23。ユーザー「社会も 偉人の 写真ぐらいなら いいんじゃないの？」→ 数えて 方向を 決め →
「Bで。画像使わない方針なんて言った覚えないよ」→ 本物の 写真を 入れる →
「道具とか 物も できるなら お願い」→ たてもの・道具も 足した。

## 1. まず「画像ファイルは 使わない」を やめた

CLAUDE.md と STYLE_GUIDE に 「画像ファイルは 使わない」と 書いて あったが、
**企画書の「やらない」リストには 入って いない**（あちらは ライフ制・制限時間・ランキング・
広告課金・パスワード・外部送信・実在キャラクター）。
CSS と SVG で ぜんぶ 描く 作りに した 流れで **Claude が 足した 技術メモ**だった。
ユーザーの 指摘どおりなので、この 版から **写真を つかう**。

## 2. いちばん 大事な きまり：**問題には つけない。答えた あとに 出す。**

数えた 結果（歴史 96問）：

| | 問題数 |
|---|---|
| 人名が **答え**（顔を 問題に 出すと ばれる） | 17 |
| 人名が **問題文の 中**（顔を 出しても ばれない） | 4 |
| 人名が 出て こない | 75 |

**問題カードに 顔を 出せるのは 4問だけ**。だから 問題には つけず、
**「正解！」や「こたえは ○○」の ふきだしの 中**に 出す。
これなら 17問 ぜんぶで つかえて、答えは 1つも ばれない（v4.9 の きまりを まもれる）。

`js/ui/battle.js` の `feedback()` に 置いて ある。
**`feedback()` を よぶのは `ok()`（正解）と `sayAnswer()`（答えを 見せる）の 2つだけ**なので、
ここに 書けば「解いて いる あいだは 出ない」が しくみとして 保証される。
**問題を 解いて いる 画面に 写真を 出す 変更を しない こと**（smoke が 見て いる）。

## 4. 写真の 出どころ（ここを くずさない）

ぜんぶ **Wikimedia Commons**。**パブリックドメイン・CC0・CC BY・CC BY-SA・Attribution だけ**
（NC／ND は つかわない＝smoke が 見て いる）。

**CC の 写真は 作者名を 書くのが つかう 条件**なので、
おうちの人ページの 設定に **「歴史の写真の出どころ」**（`js/ui/parent.js` の `creditsSection`）を
置いて 47件 ぜんぶの ライセンスと 作者を 出して いる。**この 一覧を 消さない こと。**

あつめ方は **`tools/rekishi/`**（README つき）の `fetch_jinbutsu.js` / `fetch_mono.js` / `fetch_cc.js`
（ja.wikipedia の 記事の 代表画像 → Commons で ライセンスを 見て → 360px の thumb を 取る）。
**ja.wikipedia の 代表画像は 人物でも「花押（サイン）」の ことが ある**
（信長・秀吉・家康が そうだった）。**かならず 目で 見る。**

## 7. たしかめ方

```
node tools/smoke.js .        # 「v14.22 歴史の 写真」の 節
                             #  ・ファイルが ある ・ライセンスが ある ・NC/ND が ない
                             #  ・pic の id が ぜんぶ ある ・つかって いない 写真が ない
                             #  ・**問題文に 写真が 出て いない**
tools/harness.html#rekiall                 # 47まいを ならべて 見る
tools/harness.html#reki                    # 本物の バトルで 答えて ふきだしを 見る
tools/harness.html#reki:shakai6-3:kaitai   # ステージと 写真を さして 見る（2まいの ときの 形）
tools/harness.html#dojo:reki               # しゅぎょうばの 答えの わくの 下
```

**ふきだしは すぐ 消える**（予約ずみの タイマーは `freeze()` で 止まらない）ので、
harness は 見つけた すぐ あとに **写しを とって `#screen-battle` に つける**。
