## しくみ

- **絵の 正本 `tools/bossart/final3.js`**（geo.js の `setBase(96)`＋K=1.5：座標は 64マスの つもりで 書いて 1.5ばい。細かい かざりは `RQ`／`RP`＝96マスの 座標 そのまま）→ `node tools/bossart/emit.js` が
  ①`monsterart.js` の `<boss64>`（エリアボスの あとに 6体）②`enemies.js` の **`<lastbosses>`**（base: 96・last: true）を 書く（**手で さわらない**）。
- **3D**＝`js/content/boss3d.js` の `LASTB`（部品の 表・座標と 厚みは 64マスの つもりで 書き `scale: 1.5`）。まおうの つばさは **左右 べつの 部品**（wingL／wingR）。
  クラス `.v3--b64last`（`css/motion3d.css` の いちばん 下）＝wingL は 反対むきに はばたく・ハデスの ほのおの かみ（mane）が ゆれる。ほかの 動きは v14.7 の `.v3--b64front` と 共通。
- **見る 道具**：harness **`#lastall[:<ms>][:enrage|:2d]`**（6体を 3D で ならべる）・`tools/bossart/preview3.js` → preview3.html（2D）。

## ボス・ラスボスも まちがえたら こうげき（ユーザー決定）

- `js/ui/battle.js` の `counterStrike` が **ボスの 問題でも** はんげきを 出す ように なった（`bossStrike`）：
  ボスの しゅるいの 色の オーラ（AMB_STYLE の わざの 色）を まとって つっこみ、大きな 光の たてが くだける（中ボスと 同じ 強さの 演出）。
  **演出だけ**＝何も うしなわない（v7.7 の 大原則）。てきの こうげき なし・とっくん・タイムアタックでは 出ない（いままで どおり）。
  ふきだし「〇〇の ブリザード！ でも だいじょうぶ。もう1回 こたえよう！」。
- **ガードくだき（gbe）の 問題では はんげきを 出さない**（submit の retry：gbe が あれば counterStrike を よばない）。光の たてが 2重に なる うえ、mobStrike が ambushTok を ふやして 大わざの のこりの 演出を 止める ため（claude-69 の 指摘・#gbreak:broke／:crack で 確認ずみ）。

- **6体の 名前の ならび**＝おばけキング／かいぞくキャプテン／デビルカイザー／ダークロード／ブリザードキング／メイオウハデス。キングが 2体（小1・小5）いるが 学年も 世界も 遠い ので OK。

## ハマった ところ（もどさない）

- **'g'（光る）で 箱に すっぽり 入る 目は、かたむけた 3D で 黒く 消える ことが ある**（切りぬかない 層と 前の 面の z-fighting。ハデス・まおうで 実測。むねの 宝石・ほのおは 出る）。
  → **目だけ 'g' を やめて**、こい 色の 目＋明るい 点（グリント）を ふつうの 層で 描く。vox.js の 切りぬかない 層には `translateZ(.5px)` を 足した（保険）。
- **AMB_STYLE の 口の 場所**（ほのお・かみなり などの はなつ ところ）は 新しい 絵に 合わせて 直した（まおう 0.4,0.33／かいぞく 0.42,0.44／ブリザード 0.44,0.36／ハデス 0.42,0.34／おばけ 0.4,0.56）。絵を 動かしたら ここも。
- ラスボスの バトルの 大きさは 112px（アリーナの 上の あきが 112px しか ない）。大きく したければ アリーナごと 直す こと。
