## 2. ふくしゅう（`js/core/review.js`・`MQ.review`）

### きまり（このアプリの 大原則を くずさない）
- **ばつを 与えない。** もどって きた 問題は **けいけんち ボーナス（+10）の チャンス**。
- **子どもの 画面に「にがて」と 書かない。** リボンは **「もういちど」**。
- **答えは 見せない。** むずかしさも 変えない（同じ 問題が そのまま 出る だけ）。

### セーブ
```
player.review = { 'g3:sansu': [ { key, q, enemyId, stageId, areaId, at, miss }, … ] }
```
キーは にげた敵（`player.escaped`）と 同じ 形（**学年ごと**・`MQ.save.areaKey`）。
`q` は 問題まるごと なので **算数の 生成問題も 同じ 数字で もどる**。
`miss` が 多い ものから 先に 出す。エリアごと **20問**まで。

### ためる → 出す → 消す
| いつ | どうなる |
|---|---|
| 1回めで まちがえて 2回めで 合った | `s.reviewNow` → `summary().review` → `MQ.review.add` |
| 2回 まちがえて にげられた | **リベンジに ひっこす**ので `MQ.review.done` で 消す（二重に しない） |
| つぎの たたかい（ふつうの たたかいだけ） | ザコの わくに **2問まで** まざる。リベンジと あわせて **3問まで** |
| 1回めで 正解 | `s.reviewDone` → **消える（おぼえた）**＋けいけんち **+10** |
| また まちがえた | のこる（`miss` +1） |

- **ザコの 数は ふえない**（`core/battle.js` が 新しい 問題を 1つ 減らして 入れかえる）。
  smoke が「mobs 4 → 4 の まま」を 検査。
- 出るのは **ふつうの たたかいだけ**。とっくん・塔・ごちゃまぜ・タイムアタック・
  **はじめての たたかい**では 出ない。
- ためるのは normal（ごちゃまぜを ふくむ）だけ。**とっくんと 塔では ためない**
  （とっくんは そもそも ふくしゅう。塔は 問題の エリアが 決まらない ことが ある）。

### 画面
- 敵に **水色の オーラ**（`.enemy--review`）＋**みどりの リボン「もういちど」**（`.enemy__ribbon--review`）。
  **リボンは みどり**＝青い モンスター（クリスタルンなど）と 同じ 色みに すると 読めない（1回 ふんだ）。
  **字は 5文字**（「もういちど！」の 6文字だと 絵から はみ出す）。`z-index: 4`（絵より 上）。
- ふきだし「**まえの もんだいが もどってきた！ こんどは いけるぞ！**」
- たおすと「**おぼえたね！ … ボーナス ＋10**」
- けっか画面に「**ふくしゅう N もん おぼえた ＋N EXP**」

### さわった ところ
| ファイル | 中身 |
|---|---|
| `js/core/review.js`（新） | `add / pick / done / listIn / count / countAll`。DOM を 知らない |
| `js/core/battle.js` | `XP.review = 10`／`s.reviewNow / reviewDone / reviewHits`／`noteReview(q, wasRetry)`／`opts.review` を ザコに まぜる／`summary().review / reviewDone / reviewHits / reviewBonus`／`plain()` から `review` を 落とす |
| `js/ui/battle.js` | `MQ.review.pick` を わたす／`applyRewards` で 出し入れ／リボンと ふきだし |
| `js/ui/result.js` | 「ふくしゅう N もん おぼえた」の カード |
| `js/core/save.js` | `p.review` の 初期化 |

## 3. はじめての 子（`p.battles === 0` の あいだ だけ）

### ① さいしょの たたかいは 短く
`js/ui/battle.js`：`FIRST_MOBS = 6`・**中ボスなし**（`elite: false`）・**なかまを よぶ なし**（`summon: false`）・
**てきの こうげき なし**（`attacks: false`）・**ふくしゅう なし**。
→ **16〜18問 → 10〜12問**（実測 10問）。たからばこと ボスは そのまま 出る（うれしい ところは 残す）。

### ② 地図は だんだん ひらく
`js/ui/map.js` の `isFirstTime(player)`。1回も たたかって いない あいだは 出さない：
フィーバーの 帯（`.mapobi`）・その パネル・ごちゃまぜ・てがみ・とっくん・**タイムアタック**。
残るのは **地図と メニュー・プレイヤー・学年** だけ。
→ 上の 高さ **113px → 72px**（地図が さらに 41px 広い）。

### ③ 案内の ふきだし
- 地図：`「ここを おしてね！」`（`.mapguide`）を **いま ここ ノードの 下**に。
  **上や よこは だめ**（実測：ゾーン見出し y43〜75／ノード y76〜170／つぎの 行 y212 →
  **あいて いるのは y170〜212 の 42px だけ**。harness `#firstplay:measure` で 測れる）。
- バトル：1問めだけ こたえ方を 1行（`.qguide`・`GUIDE` の 表）。2問めから 消える。
  はじめての 子は サポート（ヒント先出し）も 出る＝**いちばん つまる ケース**だが
  520×780 でも 800×1280 でも はみ出し 0（`#firstplay:q1`）。

### ④ 1回 たたかったら「できる ことが ふえた！」
`unlockPop`（`.unlockpop`・わくは **`.bagcard`**。**`.newscard` は 借りない**＝
harness の お知らせ検査と ぶつかる。v9.3 で 1回 ふんだ）。
フィーバー／ミッション／あそび方 の 3行。**アイコンは 地図の 部品を そのまま 借りる**
（金の 星 `.mapobi__star`・`MQ.ui.coinNode`・`.mixbtn__ico`）＝ただの 四角に すると 浮く。
`p.seenUnlock` で 1回だけ。**古い セーブ（もう たたかって いる 子）には 出さない**
（`save.js` の `p.seenUnlock = (p.battles || 0) > 0`）。

## 5. もどさない ところ
- **ふくしゅうの ごほうびは「けいけんち +10」だけ。** 答えを 見せる・むずかしさを 下げる 方向に しない。
- **リボンは みどりの「もういちど」5文字。** 青（モンスターと かぶる）・6文字（はみ出す）に もどさない。
- **ザコの 数を ふやさない**（入れかえ）。1回の たたかいの 長さは 変えない。
- **はじめての 子の 地図から 部品を 出さない。** ふえるのは 1回 たたかった あと。
- **さいしょの たたかいだけ 6体。** 2回目から 12体（ここを ずっと 6体に しない）。
- **`p.seenUnlock` を 古い セーブに false で 入れない**（息子さんに 案内が 出て しまう）。
