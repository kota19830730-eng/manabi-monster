## ① レベルの ごほうび（`js/core/levelup.js`・`MQ.levelup`）

レベルが 1つ 上がる たびに：

| レベル | ごほうび |

| Lv2〜9 | コイン 2 |
| Lv10〜19 | コイン 3 |
| Lv20〜29 | コイン 4 |
| Lv30〜 | コイン 5 |

- **もう あそんで いる 子**（古い セーブ）：`init(p)` が いまの レベルまで はらった ことに して、
  **これまでの ぶんの むりょうけん**を 5の ばいすう × 1まい（さいだい 5まい）わたす。はじめての 子は 何も なし。
- しょうごう：Lv30 にじいろの けんし／Lv40 たいようの けんし／Lv50 えいゆう（しょうごう 57）。

## ② そうびを きたえる（`js/core/forge.js`・`MQ.forge`）

- **きたえるのは そうびの 場所**（けん・たて・かぶと・よろい・マント）。べつの そうびに かえても +3 は のこる（うけつぐ）。
  → 弱い そうびを きたえて ムダに なる ことが ない（小3が まよわない）。その 場所に そうびを つけて いる ときだけ 効く・きたえられる。
- ねだん：+1 5まい／+2 10／+3 20／+4 30／+5 40（1か所 105・5か所で 525まい＝約1か月ぶんの コイン）。
- ふえ方（**正解した ときだけ 効く**＝アイテム・そうびと 同じ 大原則）：

| 場所 | ふえ方 | +5 の とき |
|---|---|---|
| けん | +1 ごとに 正解 1もんの けいけんち ＋1 | ＋5 |
| たて | +2 と +4 で「まちがえても にげない」＋1回 | ＋2回 |
| よろい | +2 と +4 で「コンボが 切れない」＋1回 | ＋2回 |
| マント | +2 と +4 で「おわりに コイン」＋1 | ＋2 |
| かぶと | +5 で「ひっさつわざが 1コンボ 早く」 | ＋1（**かぶとの 合計は 3まで**＝`SPECIAL_CAP`） |

- かぶとを 3で 止める わけ：4に すると 1コンボめから わざが 出て、毎問 長い 演出に なる。
- +5 は アイコンが 金に 光り、「+5」の ふだが にじ色。きたえた 瞬間は アイコンが はねる（`forgeHit`・transform だけ）。
- 音は 新しく 作って いない（`MQ.sfx.crit`・+5 は `levelup`）。
- **コインが 足りない ボタンも 押せる**（暗い だけ）。押すと「コインが あと 27まい たりない」。
- しょうごう：かじやの でし（はじめて きたえる）／きたえの たつじん（5か所 ぜんぶ +5）。
- 中身は `hero.js` の `gearPower`（場所ごとに `forgeBonus` を 足す）と `slotPower`（画面用）。core/battle.js は さわって いない。
