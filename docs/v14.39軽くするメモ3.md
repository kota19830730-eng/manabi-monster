## 直した こと（見た目は 前と 同じ・画面を ならべて 撮って 確認）
- **A** `.hero.is-gearaura .hero__img, img.sprite.is-gearaura`＝filter は 止めた まま（呼吸の まん中の 強さ）。
  呼吸は バトルでは .gaura__glow、ほかは 足もとの 光の わ（::before）＝どちらも transform／opacity。
- **B** `.title__tag` の 光の すじ＝子の 板 `.title__tagshine`（はば 260%）を transform で すべらせる。
  しっぽが 外に ある ので 切るのは `.title__tagclip` だけ。字は `.title__tagtx`（js/ui/start.js）。
- **C** `.bx__glow::after`（白い 板）の opacity 0 → .3 を 動かす。まわりだけの ブロック（'o'）は
  blocks.js が `bx__glow--o` を つけて 板を 出さない。`.bx__glow--still` は 板も 止める。
