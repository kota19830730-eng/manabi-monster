## 2. あたらしい 図（ぜんぶ inline SVG・`sansu3.js` の `figs3` から 見られる）

| 角 2つ（あ・い） | `anglesSvg(degA, lenA, degB, lenB)` | 16 角の 大小（辺の 長さで だまされない ように 長さも 変えられる） |

harness **`#figs3b`** で 12こ ならべて 見られる（`#figs3` は 2学期の 図の まま）。

**答えが ばれる 図は つけない**（v4.9 の きまり）：
- 角の 大小は「開きぐあい」を 見るのが ねらい なので 図が 答え そのもの。かわりに hard では 小さい 角に 長い 辺を つけて「辺の 長さでは ない」を 学べる ように した。
- テープ図は 目もりを 数えれば 答えが 出るが、教科書も 同じ（図で 考える 単元）。長さの 文字も 入れて 計算でも 出せる。

## 3. きまり・注意

- **図の ある 問題に メモ欄は つけない**（`num()` の `HAS_FIG` で 自動・`scratch: false`）。筆算（17）と 文章題は メモ欄あり。
- **場面 → 式を えらぶ**（14）：「□ + 12 = 40」と「12 + □ = 40」は 中身が 同じ なので、**まちがいの 候補に 入れない**（`BOX_MIRROR`）。
- 「辺」は 4年の かん字 なので、問題文では **「辺（へん）」**と ふりがなを つける（小4の 四捨五入と 同じ やり方）。「二等辺三角形」「正三角形」は 教科書の ことば なので そのまま。
- 倍の 見方の 数は 長さ・こ数だけ（体重を 入れると「18kg の お父さん」の ような 文に なるので やめた）。
- **学期**は `terms.js` の `STAGE_TERM['sansu3']` が もう 14〜18＝3学期 に なって いた ので 変えて いない。**「ぜんぶ」の 子には すぐ 出る**。「2学期まで」に して いる 子には 1月に なったら おうちの人ページで「3学期まで」を 押して もらう（自動提案の 金わくが 1〜3月に 出る）。
- たからもの（`sansu3-14`〜`18`）は v1.2 から 用意ずみ（しきの 書・ばいの ほし・三角の かんむり・ひっ算の 金かぎ・そろばんの まきもの）。
