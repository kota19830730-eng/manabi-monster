# v9.3 さいごの塔を「まおうの 城」に ＋ ひらいた ときの お知らせ

ユーザー「ラスボスの 塔も もっと カッコ良くして」→ 3案を 作って 見て もらい **B案「まおうの 城」**に 決定。
つづけて「ラスボスと 戦えるように なったら **告知の ポップ**も 出るように しておいて」。

## 0. まえの 塔（なぜ 作り直したか）

`64 × 74` の むらさきの 四角 1つに、赤い 目 2つ と 黒い とびら。上に ぎざぎざが 5こ。
ラスボスの すみかとしては さびしく、**地図の 中で いちばん 手が かかって いない ところ**だった。

## 1. 3案 → B に 決定

| 案 | どんな もの | ひきかえ |
|---|---|---|
| A とがった塔 | 細く 高い 尖塔・屋根の 先に 赤い 玉・まど 3つ | 引いて 見た ときの 存在感は B に 一歩 ゆずる |
| **B まおうの 城**（採用） | 天守＋左右の 小塔・城かべ・大きな もん・赤い 目・はた | よこに 広く、島の 面積を いちばん つかう |
| C うかぶ岩の塔 | 岩ごと うかび かけらが ただよう・紫の クリスタル | 細長く、遠目には 柱に 見える ことが ある |

見せ方は **じっさいの 島の 上に 置いて、ゲームと 同じ 看板を つけ、2倍に 拡大した 画像**。
くらべる ための「いまの 塔」も 同じ 条件で 出した。ページは
https://claude.ai/code/artifact/1308f854-b1d3-4e4e-ac30-1e063e587fd8

## 2. 城の 作り（`js/ui/map.js` の `TOWER_B` ＋ `css/style.css` の `.twb--*`）

`100 × 108` の 中に 四角を 25個（`[左, 下から, よこ, たて, たね]`）。monsterart.js と 同じ 書き方。
色と 光は CSS が もつ ので、**かけらが そろって いない ときは まとめて 暗く できる**
（`.tower--lock .tower__art { filter: grayscale(.42) brightness(.72); }`）。

- 石は モンスターと 同じ **3面の 光**（上が 明るく 右と 下が 暗い）＋まわりに こい ふち。
  かざりと そろえて **border と outline** で かける。
- 光る ところ（門の 上の 赤い 目・小塔の まど）は **ふちを つけずに にじませる**。
- **`.tower` は 下が 地図の 位置に そろう**（`transform: translate(-50%, -100%)`）。
  城は 前より 24px 高いので、そのままだと **看板が 24px 上がって 上の ステージ名と かさなる**。
  → `.tower__art { height: 108px; margin-bottom: -24px; }` で **場所を とる 高さを 前と 同じ**に した
  （城は 下に はみ出して 島に 深く 立つ）。

## 3. ひらいた ときの お知らせ（`js/ui/common.js` の `MQ.ui.towerPop`）

かけらが ぜんぶ そろった **つぎに 地図へ 行った とき 1回だけ** 出る モーダル。
`MQ.ui.goMap()` の さいご（お知らせ画面「あたらしい こと！」の あと）で 呼ぶ。

- 中身：ラスボスの 絵（104px・ゆれる）＋「〇〇が 待って いる！」＋
  「ぜんぶの 教科の 問題が じゅんばんに 出るよ。」＋ **「いく！」と「あとで」**。
  「いく！」は その場で 塔の バトルへ。音は `MQ.sfx.towerIntro()`。
- **出さない とき**：かけらが そろって いない／**もう ラスボスを たおして いる**／その 学年で 1回 見た。
- おぼえ方は **学年ごと**（`p.seenTower = { g3: true }`）。かけらも 塔も 学年ごと（v4.5）だから。
  たおしずみの 子には 出さずに、その場で「見た」ことに して 二度と 出さない。
- 文は 学年で 変える（小1・小2は ひらがな。`MQ.content.towerName()` と `lastBoss().name` を つかう）。
- **教科の 数を 書かない**（小3は 4・小4と 小5は 5・小1と 小2は 2）。

## 4. ハマった ところ

**`.newscard` を 借りたら `#flow` が 落ちた。**
お知らせ画面の カードの わくを つかい回そうと して `.newscard` を つけた ところ、
harness の「お知らせを とじたら もう 出ない」検査が **こちらの ポップを お知らせ画面と まちがえて**
「また 出る（MISSING）」に なった。→ わくは **`.bagcard`**（アイテム画面と 同じ）に して、
`.towerpop__card` / `.towerpop__title` を 自前で もつ ように した。
**画面を またいで 短い クラス名を 借りない**（v4.9.1 の `.pal`、v7.5 の `sparks` と 同じ 型の 事故）。

harness の 地図モード（`#last1map` `#last2map` `#last4map` `#last5map`）は かけらを ぜんぶ
そろえる ので **ポップが 地図を かくす** → `dismissTowerPop()` を 入れて とじてから 撮る。

- **ポップは 学年ごとに 1回だけ・たおしずみには 出さない。**
- **`.newscard` を ほかの 画面で 使わない。**
