# v14.52 しゅぎょうばの 改善（2026-10-12）

## きっかけ
ユーザー「ひっ算書く修行なのに ひっ算書くとこがなく、暗算させてる」「修業場の 全体的な 改善、予習と 復習が しやすい 仕組みと 環境を」。

## 見つけた こと（数えた）
1. **ひっさんの メモ欄が ない**：修行場の カードは 問題文（「345 + 278 = ?」）だけ。バトルの メモ欄・方眼は 修行場に なかった。
2. **えらぶ 問題の 正解が いつも いちばん 上**（400問 中 400問）。`stage.make()` は「正解が 先頭」の 形で、バトルは
   core/battle.js の prepare で まぜて いるが、修行場は まぜて いなかった。
3. 一覧が 長い（ふくしゅう 10いじょう）だけで、どれから やれば よいか わからない。まちがえた 問題を ときなおす 場所が ない。

## 直した こと
- **えらぶ 問題を まぜる**（`MQ.dojo.prep`）。
- **計算の 問題に メモ欄**（`MQ.dojo.wantsMemo`）。バトルと 同じ しくみ（`MQ.ui.battle.makeMemo`・`hissanHtml`）。
  ひっさんは 方眼の マスに 数字・上の カードは 単元の 見出しだけ（タブレットでも キーまで 1画面）。
  「ひろげる」で 画面いっぱい。まちがえて もう 1回の とき 書いた 線は のこる。
  **いっしょに とく の 答えでは 方眼の 3だんめに 答えを 緑で 書いて 見せる**。
- **きょうの おすすめ**（一覧の いちばん 上・3つまで・`MQ.dojo.recommend`）：
  ① まちがえた 問題を とき直す（あれば）② もう いちど れんしゅう（★の ある ステージで さいきんの 正解が いちばん 少ない／いちばん 前に やった）③ よしゅう（なければ つぎに たたかう ところ）。
- **教科の タブ**（ぜんぶ／算数／国語…）。行に「N日まえに しゅぎょう」。
- **まちがえた 問題の とき直し**（`MQ.dojo.fixSession` / `fixComplete`）：バトルで まちがえた 問題（p.review と にげた敵 p.escaped）を 5問まで。
  1回めで 正解 → p.review から 消える（おぼえた・けいけんち +10）。にげた敵の リベンジは のこす。
- **しゅぎょうずみの ステージは「すぐ ひとりで やる」**（せつめいを とばして ふくしゅう）。

## もどさない
- えらぶ 問題は かならず `prep` を 通す。
- 子どもの 画面に「にがて」と 書かない（「もう いちど れんしゅう」）。
- ばつは ない（とき直しで まちがえても のこる だけ）。
