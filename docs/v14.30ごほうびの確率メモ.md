# v14.30 ごほうびマシンの 出やすさを「%」で 決める（2026-09-25）

ユーザー（おうちの人の マシンの 設定画面の 写真つき）
**「このおうちカプセルやけど ちゃんと 確率で 調整できるようにして。」**

## 1. 何が だめだったか

いままでは 出やすさが **5段階の ボタン**（よく出る／ふつう／ときどき／めったに／ちょうレア）だけで、
中身は **重み 40 / 20 / 10 / 4 / 1**。ほんとうに 出る % は **ほかの 景品しだい**だった。

| 入って いる 景品 | 「ちょうレア（1）」の 実際の % |
|---|---|
| ちょうレア 1つだけ | 100% |
| ＋よく出る 1つ | 2.4% |
| ＋よく出る 2つ | 1.2% |

つまり おうちの人は「これを 3% に したい」と 思っても **その 数字を 入れる ところが なかった**。
画面には「→ いまの 景品と 合わせて 8%」と 出て いたが、**えらべるのは 5段階だけ**だった。

## 2. どう したか

**% を 直に 決める。** `it.pct`＝いま ほんとうに 出る %（出せる 景品ぜんぶで 合計 100）。

### 画面（おうちの人ページ → ごほうびマシン → 景品を 入れる／直す）
```
出やすさ（この景品が当たる確率）
[ − ] [====○========] [ ＋ ]   20%
[よく出る 40%][ふつう 20%][ときどき 10%][めったに 4%][ちょうレア 1%]
ほかの景品は比をたもって自動でならします（合計100%）。0%にはできません。
┌────────────────────────────┐
│ この ごほうび    ▇▇▇▇        20% │  ← いま さわって いる 景品（太字）
│ あたらしい ゲーム ▏           1% │
│ すきな おかし 1つ ▇▇▇▇▇▇▇▇   45% │
│ こうえんで あそぶ ▇▇         11% │
│ ゲーム 30分 のばし ▇▇▇▇      23% │
└────────────────────────────┘
```
- **つまみ（スライダー）＋「−」「＋」で 1% ずつ**。大きな 数字で いまの % を 出す。
- 5段階の ボタンは **% つきの おすすめ ボタン**として のこした（よく出る 40% など）。
- **下見の 表**＝この % に したら ほかの 景品が どう なるかを **ほぞんする 前に** 見せる。
  ここに 出た 数字が そのまま ほんとうの 数字に なる（smoke が 検査）。

### ルール（js/core/prize.js）
- `it.want` … **おうちの人が つまみで えらんだ 数字**（1〜99）。**ほかの 景品を 足しても 消えない**。
- `it.pct` … **いま ほんとうに 出る %**（出せる 景品だけで 合計 100・1〜100）。
- いま さわって いる 景品は **えらんだ % きっかり**。ほかは **want の 比**で のこりを 分ける（`renorm`）。
- **0% は 作らない**（`MIN_PCT = 1`）。どの 景品も かならず 当たりうる
  ＝「はずれを 作らない」の きまりと 同じ 考え方。
- 上限は **ほかの 景品に 1% ずつ のこした のこり**（`pctCap`。8こ 入って いれば 93%）。
- 景品を **消した・数に 達した・期限が きれた** あとも、`ensure()` が のこりを ならして 合計 100% に する。

### 「先に 入れた 景品が かってに 大きく なる」を 防ぐ（大事）
`want` を のこして いないと こう なる：
1. ゲーム（ちょうレア）を 入れる → 1つだけ なので 100%
2. おかし（よく出る 40%）を 足す → ゲームが 60%
3. こうえん（10%）を 足す → **ゲーム 54%**（ちょうレアの はずが いちばん 出やすい）

`want` の 比で ならすと **ゲーム 2% / おかし 88% / こうえん 10%** に なる。
**ここを もどさない**（`renorm` と `preview` は `x.want` を 見る。`x.pct` を 見ると 上の バグに もどる）。

## 4. 引きつぎ（古い セーブ）

`clean()` が **5段階の 重み（40/20/10/4/1）を そのまま % に する**。重みの 比は 前と 同じ なので、
**子どもの 画面に 出る % は 1つも 変わらない**（40/20/10 → 57/29/14＝前と 同じ）。
`it.level` は のこして ある が **カプセルの わくの 色と 演出の はで さ の ためだけ**（`levelFromPct` で % から 決まる）。

## 5. たしかめ方

- `node tools/smoke.js .`（「おうちの人の マシン」と「prize%」の 節）
- harness **`#prize:form`**（景品を 入れる フォーム）**`#prize:edit`**（一覧）を **820×1400** で 撮る
- 数字の たしかめ＝scratchpad の `pztest.js`（景品を じゅんに 足して % を 出す）

## 6. もどさない こと

- **5段階の ボタンだけに もどさない**（ユーザーが 直に 言った 要望）。
- **`renorm` / `preview` の 比は `want`**（`pct` に すると 先に 入れた 景品が ふくらむ）。
- **0% を 作らない**（`MIN_PCT = 1`）。
- **下見の 表に 出た 数字と ほぞんの 結果を ずらさない**（smoke が 見る）。
- 子どもの 画面の % は `MQ.prize.rates()`（合計 かならず 1）＝**うそを つかない**。
