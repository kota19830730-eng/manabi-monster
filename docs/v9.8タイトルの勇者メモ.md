# v9.8 タイトルの 勇者を 直す（2026-09-07）

ユーザー：**「タイトル画面も HD化してる？」→「勇者ダサいから修正お願い」**

---

## 1. まず 数えた（当てずっぽうで 直さない）

タイトルの 部品は バラバラ なので、1つずつ 中身を 見た：

| 部品 | 中身 | HD？ |
|---|---|---|
| モンスター・ドラゴン | `MQ.enemies.node` → `blocks.js` | **v9.6 で 材質つき ✅** |
| ロゴ・かんばん・たからばこ・地面 | CSS の div | ぼやけない |
| **勇者** | `MQ.hero.poster()` | **❌ hd も rim も なし・1ドット 3.82px**（モンスターは 2.67px） |

→ **タイトルは 半分だけ HD**で、**勇者だけ 取りのこされて いた**。

さらに `posterRows` を 数えて、**ダサい 理由が 3つ**あると 分かった：

1. **かみ（`K`）が 108マスで いちばん 多い。** 頭の 上 **6行**が こげ茶の べた塗り
   ＝「茶色の かたまり」に 見える。
2. **よろいが `#3a3a48` と 暗い。** 明るい 空に 沈んで、体ぜんたいが 黒い かたまり。
3. **顔が よこ 10マスしか なく**、左右の かみ 2列に はさまれて 小さい。

---

## 2. 直した こと

### ① 頭を マイクラの 形に（`tools/gen-title-art.js`）
マイクラの 頭は「**顔が ほとんど・かみは 上の うすい かぶり**」。

| | まえ | あと |
|---|---|---|
| かみ（上） | 6行 | **4行** |
| 顔 | よこ10 × たて8 | **よこ12 × たて10** |
| よこの かみ | 2列 | **1列** |
| かみの すじ | なし（べた塗り） | 明るい `k` を 5マス |

**かみ（K）108マス → 60マス。** 目の 位置も 1つ 上へ（行12 → 行11）。

**マス目は 手で 打たず `node tools/gen-title-art.js` で 作り直す**（v1.8 からの きまり）。

### ② 色（`POSTER_PALETTE`）
3案（銀の きし／青の 勇者／くろがねの 勇者）を 作って 見くらべ、
**タイトルと 同じ 130px で いちばん よく 読める「青の 勇者」**に した。

| キー | まえ | あと |
|---|---|---|
| `A`/`L`/`D` よろい | `#3a3a48` / `#4e4e5e` / `#26262f` | **`#4a76dd` / `#7098f2` / `#2b4a97`（青）** |
| `p`/`q` あし・くつ | `#2b2b36` / `#1d1d26` | `#2c3d6b` / `#1d2a4c` |
| `V`/`v` マント | `#3f66c9` / `#294a9e`（青） | **`#e8443a` / `#a82424`（赤）** |

**マントを 赤に した わけ**：よろいを 青に すると 空・たてと 同じ 色みに なって
体の りんかくが 消える。赤い マントが うしろに あると 形が 立つ。

### ③ **HD（`hd: 2`）は つけて いない**
claude-36 から「ユーザーに **『目が怖いわ。マイクラ風でお願いします』**と 言われて、
いま `pixel.js` の HD を つやつやから マイクラ寄りに 直して いる」と 連絡が あった。
**先に 勇者へ `hd: 2` を つけると 勇者だけ つやつやに なる**ので、
`pixel.js` の 直しが 終わってから 別で 入れる。

## 3. もどさない こと

- **タイトルの 勇者は その子の アバターでは ない**（専用の 一枚絵・v5.0 の きまり）。
- **かぶとは かぶらない・黒い ふち取りは つけない**（v5.0 の 見本の まま）。
- **かみは 4行・顔は たて10行。** 6行に もどすと また「茶色の かたまり」に なる。
- **マス目を 手で 打たない**（`tools/gen-title-art.js` を 通す）。
- けん・たて・金の かた当て／ベルト・青い 目 は v5.0 の まま さわって いない。
