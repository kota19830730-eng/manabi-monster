## 入れた もの

### A 光る ブロックの 粒（`js/ui/fxcanvas.js`・`MQ.ui.fxc`）
- バトル画面の 上に Canvas を 1まい（`.fxc`・z 38・技名の 帯 z 40 の 下）。わざが ない ときは 何も 描かない（rAF も 止まる）。
- 粒は **四角**（マイクラの 火の粉・雷と 同じ）。光る 粒は `'lighter'`＝重なった ところほど 明るい。にじみは 色ごとに 64px の ぼかしを 1まい 作って 使いまわす（`glowOf`）。
- 岩・氷の かけら・いん石は **Canvas に 3面を 描く 回る 箱**（`cube`）＝CSS 3D より ずっと 軽い。
- 大きな もの：三日月の 一閃（`slash`）・枝分かれの 雷（`bolt`・45ms ごとに 道を 作り直す・2px の ます目に そろえる）・しょうげきの わ（`ring`）・光の すじ（`rays`）・光の たま（`orb`）・光の 柱（`pillar`）・4とがりの きらめき（`glint`）・オーロラ（`aurora`）・氷の 柱（`spike`・くだけると 箱が とぶ）・いん石（`meteor`・火の 尾）・走った あとの 光（`trail`）。
- 台本は `SCRIPTS[わざ]`。**当たる 時間は battle.js の `SP_MOTION.hit` と そろえて ある**（ほのお 490ms・はっぱ 330/520・こおり 360・かぜ 380・いなずま 600・メテオ 620・ビッグバン 550・スターバースト 500〜860 と 1300）。
- **時間は 1/60秒 きざみ**（seed つき 乱数）→ `seek(ms)` で 同じ 絵が 出る＝harness `#fx:<わざ>:<秒>` で 止めて 撮れる。
- おそい 端末は 1コマ 30ms こえが 8回 つづくと 粒を 25% ずつ へらす（`quality`・50% まで）。粒の 上限 900。
- わざの あいだは **背景（空・山・ゆか）だけ 暗く**（`.arena__spsky`＝`.arena__bg` の いちばん うしろ・わざごとの 色）。キャラは その 上なので 明るい まま。光る 粒は 暗い 空で 映える。
- Canvas が つかえない 端末だけ いままでの CSS の エフェクト（`buildFx`）。

### B 8コンボ いじょうで バトル画面を 広げる（`grow`）
- アリーナの 高さを ステージの 56% に（`BIG_RATIO`）。**ふやした ぶん `margin-bottom` を マイナスに する**＝下の 問題の 大きさは 1px も 変わらない（上に かぶさる だけ・`fitPrompt` に さわらない）。
- 広げる ときは 0.28秒の transition。**もどすのは つぎの 問題が 出る しゅんかん**（`render` → `endSpecial(true)`）。
  わざの おわりに ゆっくり もどすと 3D の 画面を 毎コマ 描きなおして 0.1秒 ひっかかった（実測）。
- ボス／ラスボスの WARNING の 前・たたかいの はじめ（start 3つ）でも `endSpecial(true)`。

### C カットイン（`.ci`）
- **下の 問題の ところ（アリーナの 下）に 出す**＝わざの 動きを かくさない。だから **5コンボの わざにも 出す**（v12.2 の「12コンボ〜だけ」は やめた）。
  問題の ところは 暗い 幕（`.fxveil`）。
- 5つの 形：`band`（ななめの 帯・点線の すじ）／`slash`（ななめに 切った コマ・集中線）／`face`（顔の アップ）／`duo`（相棒と 2コマ・金の しきり）／`full`（16コンボ〜・下の ところ ぜんぶ）。
  1〜3段めは band／slash／face を 前と ちがう ものから。相棒と いっしょ＝duo。
- 主人公は **3D で ポーズつき**（`css/specialfx.css` の `ci-pose-*`＝raise／thrust／guard／sweep／sky／point／spread／charge）。
  **うでを 手まえ（rotateX 90° ちかく）に 向けない**＝大きな 四角に 見えて 顔を かくす（スターバーストで 1回 ふんだ）。よこ・上に ひらく。
- **3D は 見せる 大きさで 作る**（`ciUnit`＝48マス × unit・4まで）。小さく 作って のばすと ぼやける（v12.0 と 同じ）。unit 5〜6 は はじめの 1コマが 重く なったので 4まで。
  たたかいの はじめ 0.9秒後に unit 4 を 1回 うすく 描いて おく（`ciWarm`・0.25秒で 消す）。
- 主人公と 相棒は `.ci__win`（clip-path）の 中＝**帯の 下の へりで 切る・上は 飛び出して よい**（マンガの コマやぶり）。
- せりふは わざごとに 3つ（`SP_LINES`）・相棒と いっしょは 3つ（`PAL_LINES`）。前と 同じ せりふは つづけない。
  **せりふは 学年の 変換（v13.2）を 通る**。「あつい」→「暑い」・「まえ」→「前」の ように 意味が 変わる ことばは 使わない（`scratchpad/textt.js` で 小1〜小6 を 出して 見た）。

## v13.6.1 こおりの やいばを 本物の 3D に（sw 148）

ユーザー（公開の あと）「氷の刃だけ あんまり 変わってない。これこそ 3D に したら カッコ良く なるはず」。

- `fxcanvas.js` に **小さな 3D の 描き方 `mesh(g, M, o)`**：多面体（`CRYSTAL`＝六角の 柱＋とがった 先・`BOX`）を Z→Y→X の じゅんに 回し、`5/(5+z)` の 遠近で 画面に。
  凸の 形なので 面の 向きは「まん中 → 面の まん中」で 外に そろえ、手まえ（z＜0）を 向く 面だけ 奥から ぬる。光は 左上の 手まえ（`L3`）＋つよい ところは 白く（6乗）＋ふちに 白線＝結晶の カット面。
- 台本：① 3D の 氷の 刃が 3本（`iceBlade`・主人公の 肩の 高さで 生まれ、刃先を てきに 向けて 回りながら とぶ）
  ② 360ms（当たる）で てきを **すける 3D の 氷の 箱**に とじこめる（`iceCage`・すけ 42%）＋地面から **3D の 結晶が 花のように ひらく**（`iceBloom`・8本・右は 画面の はしに 近いので 左に 多め・まん中から じゅんに 0.12秒で のびる）
  ③ 790ms（てきが たおれる 820ms の 直前）に くだけて **3D の 結晶の かけら 34こ**（粒の `m: 'x'`）が 回りながら とぶ＋白い 光。
- 結晶は 太め（`sx`/`sz` 1.05）。細いと 針に 見えて 迫力が なかった（1回め）。
- 見る：`#fx:ice:0.24`（刃）`#fx:ice:0.62`（箱と 結晶）`#fx:ice:0.84`（くだける）を 800×1280 で 撮って **てきの まわりを 2ばいに 切りぬいて** 見る（scratchpad の `crop.sh`）。
- `#flow` は 塔が ふえて 長く なった ので `--virtual-time-budget=3000000`（1500000 だと 小2の 塔で 切れる）。
