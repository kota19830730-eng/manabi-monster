# v5.4 そうびと アイテムの しゅるいを ふやす（2026-09-04）

ユーザーの ひとこと：「装備品や アイテムの 種類を もう少し 増やせる？」→ 数えて 現状を 出し、
3つの 案（①そうびに 効果 ②そうびの 見た目を ふやす ③アイテムの わざを ふやす）→ **「とりあえず 全部」**。

## 直す 前の 状態（実測）

| | 数 | 中身 |
|---|---|---|
| そうび | **20点** | 5部位 × 4グレード。**かたちは 部位ごとに 1つだけ**で 色ちがい。**戦いの 効果は ゼロ**（見た目だけ） |
| アイテム | **99個 / わざ 8しゅるい** | 形 16種 → わざ 8種。みちしるべ 25個・パワーアップ 15 など かたよっていた |

## ① そうびに 効果（`js/content/hero.js` の `GEAR_POWER` ＋ `js/core/battle.js`）

**大原則は アイテムと 同じ：効果は「正解した とき」に 出る。** 答えを 見せる・問題を とばす そうびは 作らない。

| 部位 | 効果 | かわ / てつ / りゅう / でんせつ / ほし / やみ |
|---|---|---|
| けん | 正解 1もんごとに けいけんち ＋N | 1 / 2 / 3 / 5 / 7 / 10 |
| たて | まちがえても てきが にげない（セーフ N回） | 1 / 1 / 2 / 2 / 3 / 3 |
| かぶと | **ひっさつわざが N コンボ 早く 出る** | 1 / 1 / 1 / 2 / 2 / 2 |
| よろい | まちがえても コンボが 切れない（N回） | 1 / 1 / 2 / 2 / 3 / 3 |
| マント | たたかいの おわりに コイン ＋N | 1 / 1 / 1 / 2 / 2 / 3 |

- **セットボーナス**：同じ グレードを 5点 そろえて つけると **けいけんち ×(1 + 0.1 × グレード番号)**
  （かわ ×1.1 … やみ ×1.6）。`MQ.hero.setMulFor(no)`。
- しくみ：`MQ.hero.gearPower(player)` → `MQ.battle.start({ gear })`。
  たて・よろいは **はじめから `s.buff.shield` / `s.buff.freeze` に 入れる**ので、
  アイテムの てっぺき・時とめと 同じ 道を 通る（コードが 2本に ならない）。
  かぶとは `MQ.battle.specialBoost()` → `ui/battle.js` の `specialOf(combo)` が 中で 足す。
  マントは `summary()` の `gearCoins`。**とっくんでは コインは なし**、
  **タイムアタックでは たて・よろいは 効かない**（きろくの 公平さ）。

## ② そうびの 見た目：4 → **6グレード・30点**、かたちも グレードごと

- グレードは `かわ / てつ / りゅう / でんせつ / **ほし** / **やみ**`。
- **かたちの 作り方**：「てつ」の 一式（デザインモックの 騎士）を **元の かたち（BASE）**に して、
  ほかの グレードは その 48×48 マス目を **けずる／かざり（`e`）を 足す** だけで 作る（`SHAPER`）。
  手で 座標を 打たない。こうすると 6つとも 同じ 世界の 絵に なる。
  - かわ … かざりを 消して 小さく（木のけん・小さい たて・ぼうし・えりなし・みじかい マント）
  - りゅう … 刃の ギザギザ・つばの 宝石・たての とげ・つの・大きな かた当て・ふちどり
  - でんせつ … 長い 刃＋はねの つば・十字の たて・よこの はね・むねの 宝石・えり
  - ほし … かがやく 刃＋星の にぎり・星の たて・かんむりの とがり 3つ・むねの 星・きらめき
  - やみ … はば広の 大けん・とげの たて・大きな つの・かたの とげ・すそが ボロボロ
- **手に入れ方**
  - かわ〜りゅう（15点）… いままでどおり ★2いじょうで 1つずつ
  - でんせつ（5点）… まなびの かけら ＋ ラスボス
  - **ほし（5点）… ★3の ステージが 3・6・9・12・15 に なるたび 1点**
  - **やみ（5点）… さいごの塔を クリアするたび 1点**（でんせつが そろった あと）
- しょうごう **38 → 42**（そろいの きし／ほしの ゆうしゃ／やみを まとう者／そうび マスター）。

## ③ アイテムの わざ：8 → **13しゅるい**

形と わざを **1対1**に した（前は 3つの 形が「みちしるべ」を 分けあって いた）。
**たからもの 99個は そのまま**。形の わりあてが 変わっただけ。

| わざ | 形 | 数 | 効果（ふつう → 金色） |
|---|---|---|---|
| ばくれつ こうげき | gem | 12 | つぎの 正解 ×2 → ×3 |
| てっぺき まもり | crown | 7 | セーフ 1 → 2回 |
| 時とめ | hourglass | 5 | コンボを まもる 1 → 2回 |
| みちしるべ | book | 8 | 先に ヒント 1 → 2回 |
| ゴールデンコール | star | 7 | ゴールデン 1 → 2体 |
| たからばこ よび | key | 7 | はこ ＋1・コイン 1 → 2 |
| パワーアップ | orb | 9 | けいけんち ×1.5 → ×2 |
| ひっさつ チャージ | bell | 8 | コンボ ＋3 → ＋5 |
| **きずなの わ** | ring | 6 | 正解 1回で なかまゲージ 2 → 3つ（**相棒が いる ときだけ**） |
| **コンボの まきもの** | scroll | 9 | 正解するたび コンボ ＋1 → ＋2 多く |
| **たからの コンパス** | compass | 8 | コイン 2 → 3まい（その場で） |
| **はやての はね** | feather | 7 | はやとき ボーナス ＋30 → ＋60 が かならず |
| **なかまの くすり** | potion | 6 | 相棒の けいけんち ×2 → ×3（**相棒が いる ときだけ**） |

- `palOnly` を treasure.js の わざに つけると、相棒が いない ときは グレー（「なかまが いない」）。
- 中身は `js/core/battle.js` の `useItem`（`bond / rush / find / swift / elixir`）。
  `s.buff` に `palPlus / comboPlus / fastSure / palXp` が 増えた。
  `elixir` は `summary().palXpMul` → `ui/battle.js` の `MQ.pals.gain(p, xp × mul)`。
