# v8.3〜v8.5 ワクワクを つくる 3つ（2026-09-06 決定・未実装）

ユーザー「息子に 聞くのも 大事やけど、**次は どんな 機能が ついているんだろう。って ワクワクさせるのも
大事じゃない？**」→ 5案（A お知らせ画面／B 予告カード／C スタンプカレンダー／D おうちの人からの てがみ／
E きねん日イベント）を 出して → **「効果大は 全て 取り入れたい」**＝ **A・C・D の 3つを 作る**。

**作る 順**：**v8.3 ＝ A（お知らせ画面）→ v8.4 ＝ C（スタンプカレンダー）→ v8.5 ＝ D（てがみ）**。
A を 先に する わけ：**すでに 作った のに 息子さんが 知らない 機能が 10いじょう ある**
（v7.2 フィーバー教科・サポート／v7.3 ごちゃまぜ／v7.5 こうげきの 演出／v7.7 カウンター／
v8.0 地図／v8.1 中ボス・弱点・ボスの わざ …）。A は それを ぜんぶ「新機能」として 見せられる ので、
**新しく 作らずに いちばん 大きな ワクワクが 出る**。

**やらない と 決めた こと**：B（予告カード）は 今回 入れない。入れる なら
**「予告した ものは かならず 出す」**（子どもは おぼえていて、来ないと がっかりする）。
E（きねん日）は そのあと。

## A（v8.3）あたらしい こと！＝ お知らせ画面

### なにが うれしいか
こうしんしても いまは 画面下に「あたらしい バージョンが あるよ［こうしん］」と 出るだけで、
**何が ふえたか 子どもには 分からない**。ここを「**あたらしい こと 3つ**」の 画面に すると、
これからの こうしんが 毎回 イベントに なる。

### しくみ
- **`js/content/news.js`（新・`MQ.news`）**に 版ごとの お知らせ。
  ```js
  { v: 'v8.1', date: '2026-09-06', items: [
      { kind: 'mons', id: 'mid-golem', title: '中ボスが 出るように なった！',
        text: 'さいごの てきは HP2。つよい 一げきで 一発だ！' },
      { kind: 'icon', icon: 'weak', title: 'よわい 教科が 見つかる', text: '…' } ] }
  ```
  - `kind: 'mons'`＝`MQ.enemies.node(id, {size:48})` で **本物の モンスターの 絵**を 見せる
    （タイトル画面の 教訓：専用の 絵を 別に 作ると 安っぽく 見える）。
  - `kind: 'item' / 'gear' / 'icon'` も 同じ 考え方で 既存の 部品を つかう。
  - **1つの 版に 3つまで**（多いと 読まない）。文は その 学年の かん字＋文節スペース。
- セーブに **`p.seenNews`**（さいごに 見た 版の 文字）。`MQ.news.unseen(p)` が 新しい ものを かえす。
- 出す ところ：**タイトル →「ぼうけんの つづき」→ 地図に 行く 前**に 1回だけ。
  画面は アイテムの モーダル（`.bag`）と 同じ 作り（紺の カード＋金わく＋金グラデの バナー文字）。
  ボタンは「あそぶ！」。**とじたら もう 出ない**（`p.seenNews` を 今の 版に）。
- **はじめて 見る 子（`p.seenNews` が ない）**＝ v7.2〜v8.1 の たまった ぶんを
  「**ひさしぶりの 大アップデート**」として **3つずつ ページ送り**（「つぎ ▶」）。
  ここが 今回の 本番。**息子さんが つぎに 開いた とき、まとめて 見せる**。
- **あそびを 止めない**：×で いつでも とじられる。1回の 起動で 1回だけ。

### 気を つける こと
- `sw.js` の 版を 上げたら **news.js にも 1行 足す**（smoke が 検査：さいごの 版が
  sw の 版と 合っているか・items は 5つ いか・`kind: 'mons'` の id が 図かんに いるか）。
- 文は **子どもの ことば**で（「`chargeInfo` が…」では なく「てきが こうげきして くるように なった！」）。

### テスト
- smoke：news の 形・版の ならび・id が ある・`unseen` の 出し分け（`seenNews` なし／古い／同じ）。
- harness `#news`（はじめての 子＝ぜんぶ）`#news2`（1つだけ）`#news3`（もう 見た → 出ない）。

## C（v8.4）スタンプカレンダー＝ つづけた 日

### なにが うれしいか
「**あしたも 開く 理由**」。いまは その日 やる 気に なるものが ない。

### しくみ
- **データは 新しく 作らない**。v7.4 で 入れた **`p.stats.days`**（日ごとの n / ok / 秒）を 読むだけ。
  その日 1問でも 答えた 日＝スタンプ。`MQ.stats` に `streak(p)` / `last7(p)` を 足す。
- 地図の 下の 段（`.maptabs` の あたり）か HUD の 下に **7マスの 帯**（きょうが 右はし）。
  ついた 日は 金の スタンプ、きょうは オレンジで pulse、これからの 日は うすい わく。
  上に「**れんぞく N日**」。
- **ごほうび**：3日＝コイン 1／5日＝コイン 2／7日＝アイテム（たからもの 1つ）。
  7日 こえたら また 1日めから（毎週 まわる）。セーブは `p.streak = { claimed: {'3':'2026-09-06'} }`。
- **切れても ばつは ゼロ**（このアプリの きまり）。「また 1日めから！」だけ。
  へらす・とりあげる 表現は 使わない。
- **あしたの ごほうびを 見せる**（「あした 来ると ★ コイン 2」）＝ ここが ワクワクの 本体。

### テスト
- smoke：れんぞくの 数え方（きょう やって いない 日を またぐ／日づけを またぐ・`MQ.stats.setNow` 相当）、
  ごほうびは 1日 1回・7日で 1周・切れても マイナスなし。
- harness `#streak`（3日め）`#streak:7`（7日め＝アイテム）`#streak:0`（切れた あと）。

## D（v8.5）おうちの人からの てがみ

### なにが うれしいか
**親も うれしい**（製品として 配る ときの 強み）。子どもは「見て もらえている」と 分かる。

### しくみ
- **おうちの人ページ（`js/ui/parent.js`）**に「**子どもに てがみを おくる**」：
  - 文（**40文字まで**）＋ おまけの ミッション（教科を 1つ えらぶ・**にがて教科が おすすめ**として
    上に 出る＝v7.1 の `MQ.stats.weakest` を つかう）＋ ごほうび（コイン 1〜3）。
  - **外には 送らない**（同じ タブレットの localStorage。企画書の「データの 外部送信 なし」を くずさない）。
- **子どもの 画面**：地図に **封筒**（`.letter`・金の わく・pulse）。タップ → 手紙の カード
  （紙色・手書きふうでは なく いつもの 書体・文は そのまま 出す）→「よんだ！」で とじる。
  ミッションつきなら **きょうの ミッションに 1つ ふえる**（`missions.js` に `custom` わくを 1つ）。
- おわったら おうちの人ページに「**〇月〇日の てがみ：読んだ ／ ミッション できた**」が 出る。
- セーブ `p.letter = { text, areaId, reward, at, read, done }`（**1通だけ**。新しく 書くと 上書き）。

### 気を つける こと
- **子どもの 画面に「にがて」と 書かない**（v7.2 の きまり）。ミッションの 文は
  「国語の 森で 1かい たたかう」など いつもの ミッションと 同じ 言い方。
- 手紙が 出しっぱなしに ならない ように、**読んだら 封筒は 消える**。

### テスト
- smoke：40文字・からっぽは 送れない・ミッションが 1つ ふえる・読んだら 消える・古い セーブ。
- harness `#letter`（親が 書く）`#letter2`（地図の 封筒）`#letter3`（読んで ミッションに 入る）。

## この 3つに 共通の きまり（くずさない）

1. **ばつを 与えない**（切れた・見なかった で へらす ものを 作らない）。
2. **あそびを 止めない**（お知らせも 手紙も ×で とじられる。1回の 起動で 1回だけ）。
3. **外に 送らない**（手紙も お知らせも 端末の 中だけ）。
4. **絵は 既存の 部品**（`MQ.enemies.node` / `MQ.treasure.node` / `MQ.hero.gearSprite`）。
   お知らせの ために 新しい 絵を 別に 作らない。
5. **文は 子どもの ことば**・その 学年の かん字・文節スペース。
