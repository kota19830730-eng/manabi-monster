# v5.3 よみあげ（英語の 音・小1の 問題文）

2026-09-04。ユーザー「（読み上げも）実装してください」。

## 何が できるように なったか

- **英語の 問題に「きく」ボタン**（カードの 右下）。おすと `"Good morning."` を
  **英語の 声**で 読む。小3・小4 とも（エリア id は どちらも `eigo`）。
- **正解の あとの ふきだしにも「きく」**。`note` の 中の 英語（`"Good afternoon."`／
  `happy ＝ うれしい` の `happy` など）を 読む。
- **小1は 問題文を 日本語で 読む**（まだ 字が すらすら 読めない ため）。
- おうちの人ページ（せってい）の **「おと／きょく／よみあげ」** の 3つめで 切れる。

## 大事な きまり

### ① 音声ファイルも 通信も 使わない
タブレットに さいしょから 入って いる 声（**Web Speech API**）を 使う。
だから **企画書の「データの 外部送信 なし」は そのまま**（AI の ときと ちがい、
外に 何も 送らない）。あたらしい ファイルも ふえない。

### ② 声が 入って いない 端末では **ボタンを 出さない**
`MQ.ui.canSpeak(lang)` が `false` の ときは `MQ.ui.listenButton()` が `null` を かえす。
「おしても 何も 起きない ボタン」を 子どもに 見せない。
（Android で Google の 音声エンジンが 入って いない、ブラウザが 古い、など）

### ③ **読み上げで 答えが ばれる 問題には つけない**（v4.9 の 図の きまりと 同じ）
読むのは **画面に 出て いる 問題文 そのもの**。だから 読み上げで あたらしく ばれるのは
「字を 見ても わからないが 声に すると わかる」もの ＝ **かん字の 読み** だけ。

→ **小1で かん字の 入った 問題文は 読まない**（`hasKanji`）。
   「『山』の よみかたは？」を 読むと 声が「やま」と 言って しまう。
   小1の 問題文は ひらがなが きまり（CLAUDE.md）なので、かん字が 出て くるのは
   かん字を 答える 問題だけ。この 1つの ルールで ぜんぶ ふせげる。
   実測：小1 こくご 307問 の うち **147問に「きく」・かん字の 160問は 読まない**。

→ **小2〜小4の 国語・算数・理科・社会は 読まない**（`forQuestion` が null）。
   読み上げても わかりやすく ならず、答えが ばれる ものが 多い。

## しくみ

| どこ | 何を する |
|---|---|
| `js/core/speech.js`（新） | `MQ.speech`。DOM を 知らない。声さがし・読む・止める・**何を 読むか を 決める** |
| `js/ui/common.js` | `MQ.ui.canSpeak(lang)`（声＋せってい）と `MQ.ui.listenButton(say)`（金の「きく」ボタン）。せっていの スイッチも ここ |
| `js/ui/battle.js` | `renderListen(q)`（カードの 下に ボタン）＋ ふきだしにも ボタン。問題が かわる ときと バトルを 出る ときに `MQ.speech.stop()` |
| `css/style.css` | `.card__listen` `.listen`（金の ボタン・CSS で 描いた スピーカー・読んで いる あいだ 光る） |

**わけかたの きまり**：`MQ.speech.forQuestion()` は **「何を 読むか」だけ**を 決める。
**「読める か どうか」（声が あるか・せっていが 入って いるか）は 画面がわ**が 見る。
（さいしょ core の 中で 両方 見て いたら、テストで 声の ありなしを 差しかえられなかった。）

### `MQ.speech` の おもな もの
- `ready(lang)` … その ことばの 声が ある か（`en` / `ja`）
- `speak(text, lang, {onend})` … 読む。**前の を 止めてから** 読む（かさならない）
- `stop()`
- `forQuestion(q, {areaId, grade})` … `{ text, lang, label }` か `null`
- `forNote(note, {areaId})` … ふきだし用（英語ステージだけ）
- `englishIn(text)` … `"…"` の 中の 英語を とり出す。カタカナの ふりがな
  （`"Nǐ hǎo（ニーハオ）"`）は 読まない。かぎかっこが ない ときは 英語の
  かたまりを ひろう（`happy ＝ うれしい` → `happy`）
- `hasKanji(s)` … 小1の 見はり

### 読む はやさ
子ども向けに おそめ。**英語 0.8・日本語 0.9**（`RATE`）。声は `en-US` / `ja-JP` を 優先。

`speechSynthesis` と **`SpeechSynthesisUtterance` の 両方**を にせに する。

## 実機で たしかめる こと（次に 会ったら）

- iPad … 英語・日本語の 声は 標準で 入って いる。**はじめの 1回は 画面を さわった あと**
  でないと 鳴らない ことが ある（アプリは タップで 出す ので だいじょうぶな はず）。
- Android … Google の「テキスト読み上げ」が 入って いれば 鳴る（ふつうは 入って いる）。
  入って いなければ **ボタンが 出ない**（それで 正しい）。
- 声が 速い／おそい と 言われたら `speech.js` の `RATE`。
