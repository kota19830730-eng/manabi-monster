## 2. カプセルマシン

### 場所と 見た目

図かん →「なかま」タブ → **金の 3Dボタン「カプセルマシン」** → **全画面の モーダル**。
見た目は アイテムの モーダル（`.bag`）と 同じ 紺カード＋金わく＋金グラデの バナー＋✦。
新しい 見た目を 発明しない（STYLE_GUIDE の「アイテム（v2.0）」に そろえる）。

画面の 中に **カプセルが 2しゅるい**。どちらも 10まい。

| カプセル | 中身 |
|---|---|
| **モンスターの カプセル** | なかまに できる モンスター |
| **すがたの カプセル** | 主人公の すがたの パーツ |

**子どもが えらべる**のが 大事。1つに まぜると
「モンスターが ほしいのに ぼうしが 出た」に なる。

### ねだん・かくりつ・天井

| きまり | 中身 |
|---|---|
| 1回 | **コイン 10まい** |
| ノーマル | **70%** |
| レア（金） | **25%** |
| げきレア（むらさき） | **5%** |
| 天井 | **10回 引いたら かならず げきレア** |
| かぶり | **コイン 5まい もどる** |

**画面に 出す ことば（v10.2・2026-09-07 ユーザー指定）：いちばん 下の わくは「ふつう」では なく「ノーマル」。**
内部の id は `n` の まま（`js/core/capsule.js` の `RARITY` と `js/ui/capsule.js` の `RARE_NAME`）。
この 文書の ほかの ところで「ふつう」と 書いて ある わくは この「ノーマル」の こと。

- 金＝レア・むらさき＝げきレア。**色は いまの アバターの バッジ**
  （`face.js` の `rare: 'r' / 'sr'`）と 同じ。コードは `sr` の まま、画面の 文字だけ「げきレア」。
- **天井の カウンターを 画面に 出す**：「あと 3かいで げきレア かくてい」。
  これが いちばん 効く ワクワク。引く 前から 見えて いる こと。
- 天井の カウンターは **カプセルの しゅるいごと**に 数える。

### いちばん 上の わくの 呼び名（2026-09-06・ユーザー指摘）

最初は「**キラキラ**」に して いたが、ユーザー：「**キラキラの表現が幼稚やなぁ。他の表現ないの？**」。
マーケットは 全国の 小学生の 男の子なので、女の子むけ・幼児むけに 見える ことばは 使わない。
モックの 5枚めに 4つの 案を 実物の 大きさで ならべた。

| 案 | ことば | 良い ところ | 気に なる ところ |
|---|---|---|---|
| ① | **でんせつ** | そうびの グレード（かわ／てつ／りゅう／**でんせつ**／ほし／やみ）と 同じ ことば。アプリの 中で もう 使って いる | 意味が ②と かぶる |
| ② | レジェンド | カタカナで 強そう。小1でも 読める | ①と 同じ 意味。どちらか 一方に する |
| ③ | げきレア | 「レア」の 上だと ひと目で わかる | 金の ままだと レアとの 差が つきにくい |
| ④ | UR（ULTRA RARE） | カードゲームふう で いちばん 大人っぽい | 小1には 読めない |

**2026-09-06 ユーザーが ③「げきレア」に 決めた**（「③で行こう。」）。
私の おすすめは ①だったが、ユーザーの えらんだ ③で 進める。

**色は むらさきの まま**（表では ③を 金で 出して いたが、金だと レアと 見分けが つかない）。
アバターの パーツが すでに むらさき＝SR なので、**むらさき＝いちばん すごい**の 意味を 2つに しない。
コードの 中の 呼び名は `sr`（face.js と そろえる）、**画面に 出す 文字だけ「げきレア」**。

### はずれを 作らない

企画書の「**ばつを 与えない**」の きまりを ガチャにも 通す。

- **からっぽの カプセルは 出さない。** かならず 何かが 出る。
- **かぶっても 損を させない**（コイン 5まい もどる＝半分）。
  画面の 文も「かぶっちゃった」では なく「**コインが 5まい もどって きた！**」。
- コインが 足りない ときは ボタンを おせない ように して、
  「あと N まい」と 出す（おして から 断らない）。

### 3しゅるい・ぜんぶ カプセル限定

画面の 上の チップで **なかま／そうび／すがた**を えらぶ（下に 大きい マシンが 1台）。
**どれも カプセルでしか 手に 入らない**。お店にも バトルにも 出ない。

| チップ | 中身 | 数 |
|---|---|---|
| **なかま** | カプセル専用モンスター | **18系統**（きし 9／ほし 6／しんじゅう 3）＝引けるのは 18体 |
| **そうび** | カプセル専用そうび | **10点**（5部位 × 2グレード） |
| **すがた** | カプセル専用の すがたパーツ | **20個** |

カプセルから 出るのは ぜんぶで **48個**（18＋10＋20）。
天井の カウンターと「あつめた n / m」は **チップごと**に 数える。
（モンスターは 進化ぶんを 入れると 図かんでは 54体に なるが、**引ける のは 18体**）

### なかま（カプセル専用モンスター 18系統・54体）

**新しく 描く。いまの 220体は 1体も つかわない。**

**進化する。**（claude-65 の 指摘：いま 図かん 220体の うち **134体が 進化する**ので、
カプセルの 目玉が「育てても 姿が 変わらない 子」だと、王さま形を 持って いる 子には ものたりない）

| | 数 | どうやって 手に 入る |
|---|---|---|
| **1段階め** | **18体** | **カプセルから 出る**（これが 景品） |
| 2段階め | 18体 | 相棒に して **Lv.10** |
| 3段階め | 18体 | 相棒に して **Lv.20** |

図かんは **220 → 274体**。**引ける のは 1段階めの 18体だけ**（2・3段階めは 育てた ごほうび）。
これは v8.2 の 決めごと（王さま形は 育てて なる もの）と 同じ 考え方。

**絵の 作り方**（手で 座標を 打たない）：
- **1段階め 18体は 手で 描く**（`monsterart.js`・48×48）。ここが 本番。
- **2・3段階めは 部品を かさねて 作る**。v8.2 の `tools/king/`（かんむり・背中・手・おまけ）と
  v8.6 の `tools/son/` と 同じ やり方。**`tools/capsule/` を 新しく 作る**。

**フラグ**：
- 1段階め … `capsuleOnly: true`（カプセルからだけ）
- 2・3段階め … `evoOnly: true`（育てて なる もの。カプセルにも お店にも 出さない）
- **どちらも `pickIds` から 外す**（ふつうの たたかいには 出ない）。
- `line` / `stage` / `evo` は **ふつうに つける**（つけないと smoke の
  「系統に 入って いない モンスターが ない」が 落ちる。下の テストの 節を 見る）。

**レアさ**（1段階めの 18体の わけ方）：ふつう 9系統／レア 6系統／げきレア 3系統。
**レアさと 家族は 1対1**（ふつう＝ちいさな きし／レア＝ほしの モンスター／げきレア＝しんじゅう）。
下の「18系統の わけ方」を 見る。

**見わけの しるし**：18系統 ぜんぶが **カプセルの 形の 宝石**（上 明るい／下 こい の 2段）を
どこかに 1つ 持つ。「カプセルの 子だ」と ひと目で わかる。

### 18系統の わけ方（2026-09-06 決定）＝ **家族が そのまま レアさ**

モックの 3案から 1つ えらぶ つもりだったが、ユーザー「**ABC全部ほしいね。**」
つづけて「**しんじゅうは激レアで。**」→ **3つの 家族を レアさに 割りあてた。**

| レアさ | 家族 | すがた | 系統 | かくりつ |
|---|---|---|---|---|
| **ノーマル** | **B ちいさな きし** | ミニ勇者。よろい・けん・たて・ぼうし | **9系統** | 70% |
| **レア**（金） | **A ほしの モンスター** | 宇宙。暗い 体＋光る コア | **6系統** | 25% |
| **げきレア**（むらさき） | **C しんじゅう** | 神話の けもの。金の かざり・ほのお | **3系統** | 5% |

**この 分け方が いい ところ**：
- **出た 瞬間に すごさが わかる。** 数字や バッジを 読まなくても、
  金の かざりの けものが 出たら「当たりだ」と 体で わかる。小1でも わかる。
- **引く たびに 顔ぶれが 変わる**ので あきない（1つの 家族だけだと どれも 似て 見える）。
- 図かんで 3つの かたまりに 分けて 見せられる。
- ふつうの わくが いちばん 数が 多い（9系統）＝ **いちばん よく 見る 子が いちばん 種類が 多い**。

**気を つける ところ**：
- 3家族が ばらばらに 見えないよう、**カプセルの 形の 宝石**は 18系統 ぜんぶに 入れる
  （これが「カプセルの 子」の しるし）。
- **A（ほしの モンスター）は 体が 暗い**ので、地図や 図かんの 紺の 上で しずまない よう
  光る ところを 大きめに する。
- **C（しんじゅう）は 3系統だけ**なので、1体 1体を いちばん 気合を 入れて 描く。
  ここが カプセルマシンの 目玉に なる。

### そうび（カプセル専用そうび 10点）

5部位（けん・たて・かぶと・よろい・マント）× 2グレード（**カプセル**／**げきレア**）。

> **2026-09-07 に つよさを 変えた**（下の「げきレアを 欲しくなる ものに する」の 節）。
> はじめは 下の とおり「てつ〜りゅう」に とどめて いたが、
> ユーザーに 「**激レアが しょぼいから もっと 欲しくなるようなのにして。装備とかの話です**」と
> 言われた。**下の 表の 数字は もう 古い。**

（はじめの 考え）効果の 強さは v5.4 の「てつ〜りゅう」くらいに とどめる。理由：
**ほし**（★3 の ステージ 3・6・9…）と **やみ**（さいごの塔クリア）は
**がんばった ごほうび**なので、運で 手に 入る そうびが それを こえると 意味が なくなる。

**そのかわり セット効果を べつの ものに する**：

| そろえた もの | 効果 |
|---|---|
| v5.4 の 同じ グレード 5点 | けいけんち ×(1 + 0.1 × グレード番号) |
| **カプセルそうび 5点** | **おわりに コイン ＋3** |
| **げきレアそうび 5点** | おわりに コイン ＋6（→ **＋ けいけんち ×1.6**） |

コインが ふえる → もう1回 引ける。ユーザーの 言う 流れ
（コイン集める → 勉強量ふえる → 引きたくなる）に そのまま つながる。
**大原則（効果は 正解した ときに 出る）は そのまま。**

（さいごの塔を クリアした ごほうびと 同じ ところで 止める）。

**②セットは コイン ＋6 と けいけんち ×1.6 の 両方**（`setCoins` と `setMulNo`）。

**③1点ずつ「オーロラだけの 力」を もつ**（`hero.js` の `AURORA_POWER`）。
ここが「欲しくなる」の 本体。ほかの どの そうびにも ない。

| 部位 | やみと 同じ 数字 | ＋ オーロラだけの 力 | 中身 |
|---|---|---|---|
| けん | けいけんち ＋10 | クリティカルが **2コンボ**から（ふつうは 3） | `critEasy` |
| たて | セーフ 3回 | **中ボスを 一発**で たおせる（ふつうは 2問） | `pierce` |
| かぶと | ひっさつ 2コンボ 早い | **ひっさつわざが 1つ 上に なる**（5コンボで いなずま） | `tierUp` |
| よろい | コンボ 3回 まもる | **なかまゲージが 2ばい** | `palPlus` |
| マント | コイン ＋3 | **ボスを たおすと コイン もう ＋2** | `bossCoin` |

**④5点 そろえて つけると 主人公が 光る**（`.is-gearaura`）。
バトル・地図の HUD・けっか画面・ずかん、**アバターを 出す ところ ぜんぶ**で 光る。
自まん できるのが いちばん 効く（見た目の ごほうび）。
※ **タイトルの 勇者は 専用の 一枚絵**なので 光らない（さわらない きまり）。
※ わざの 名前は v9.5 で「スターバースト ストライク」に 変えた（ユーザー指示）。class も `--starburst`。そうびの オーロラとは 別物。

**⑤大原則は そのまま**：効果は **正解した ときに 出る**。
答えを 見せる・問題を とばす・敵の HP を 勝手に へらす 力は 作らない。
5つとも「正解した ときの もらいが ふえる」だけ。

### マシンでの レアさ（`cap`）

## 3. 相棒の お店（4の 答え）

**お店は そのまま のこす。** 中身が かぶらなく なった ので、役わりが はっきり 分かれた。

| | お店（なかまタブ） | カプセルマシン |
|---|---|---|
| 何が 出る | **バトルで 会った** モンスター | **カプセル専用の 18体** |
| えらべる | ねらって 買う | 運（天井つき） |
| ねだん | 3 / 6 / 10まい | 10まい |

### お店の 直し（1つだけ）

`shopList` は **図かんに のって いれば 何でも 売る**ので、しぼりを 2つ 足す。

```js
if (e.evoOnly || e.capsuleOnly) return;   // 育てて／カプセルでしか 手に 入らない
```

**① `evoOnly`（12体）**… 息子さんの 4体の 2・3段階め。**育てないと 手に 入らない** ものなので 外す。

**② `capsuleOnly`（カプセル専用の 1段階め 18体）**… これを 忘れると **抜け道が できる**
（claude-65 が 見つけた。`js/core/pals.js:144` を 読んで 確認した）：

1. カプセルで 1段階めを 引く → 図かんに のる
2. 相棒に して Lv.10 → 2段階めに 進化。`evolveIfReady` が
   `delete p.pals[cur.id]` で **1段階めを 相棒から 消すが、図かんには のこす**
3. `shopList` は「図かんに ある ＆ いま 相棒で ない」で 出す ので、
   **その 1段階めが お店に コイン 3まいで 復活する**

**10まいの カプセルで 出した ものが 3まいで 買える**＝「ぜんぶ カプセル限定」という
ユーザーの 指示（2026-09-06）が くずれる。だから `capsuleOnly` も 外す。

**外すのは この 2つだけ。**

**それ以外は 外さない。** さいしょ「王さま形（stage3）と 2段階めも 外す」と 書いたが、
実測して 取り消した（claude-65 の 指摘）。`pickIds` を 全エリア × むずかしさで 回した ところ：

| | 図かん ぜんぶ | ふつうの たたかいに 出る |
|---|---|---|
| 2段階め | 63体 | **57体** |
| 3段階め（王さま形） | 67体 | **61体** |
| `evoOnly` | 12体 | **0体** |
| 中ボス（`mid`） | 8体 | **0体** |

v8.2 で 色ちがいを 44系統に まとめた とき、こい 色の ほうを 2段階めに しただけ なので、
マグマゴーレムの ような 57体は **前から ふつうに 出会う ザコ**。外すと
**会った ことが ある のに 買えない 子が 118体**でき、お店が すかすかに なる。

**中ボス 8体は お店に のこす。** 野生（`pickIds`）には 出ないが **バトルで かならず 会う**ので
図かんに のり、「会った 子を ねらって 買う」の きまりに 合う。ねだんは `PRICE_SOLO` の 10まい。
相棒に した ときの 強さは `stage` が ない ので `POWER[1]`（いちばん よわい）＝つよさの 問題も ない。

### ねだんの 件は v8.9 で 決着ずみ（この 機能では さわらない）

`pals.js` の `power()` は いまの 相棒の `enemy.stage` を 見るので、
**王さま形（stage3）を 10まいで 買うと Lv1 の まま いちばん 強い 追い打ちが 手に 入る**
という 話が あった。これは 別セッション（claude-65）が ユーザーに 相談し、
**「ねだんを 段階で 上げる」**に 決まって **v8.9（sw v104・commit ba029c0）で 入った**。

| | いま |
|---|---|
| 系統に 入って いる もの | `PRICE = { 1: 3, 2: 20, 3: 40 }`（段階べつ） |
| 系統に 入って いない もの（ゴールデンスライム・中ボス・じぶんの モンスター） | `PRICE_SOLO = { 1: 3, 2: 6, 3: 10 }`（前の まま） |

**v9.0 では `price()` に さわらない。** `shopList` だけ 直す。
ねだんを 動かす ときは smoke の パルショップの 検査
（1/2/3段階＝3/20/40・3段階めは ぜんぶ 40いじょう・3まいで 買える 子が 50体いじょう）も いっしょに 見る。

## 11. 絵を 描いた ときの 教訓（2026-09-07・1段階め 18体）

6. **v9.1 の ぬり方**（claude-36）に 合わせる：たて 6px いじょうの 四角に 上の 光と ふちが つく／

   `MQ.blocks.pickEyesTest(shape)` で 意図しない まばたきを 数える（18体 ぜんぶ 0 を 確認ずみ）。
7. **既存と 名前・id が かぶらない**ことを `dexList()`＋`bosses` で 照合する（かぶりなし 確認ずみ）。

## 11b. 進化形 36体（2・3段階め）の 教訓（2026-09-07）

## 15. 引く 演出（v9.10・2026-09-07）

### まず バグ：**演出が 1つも 出て いなかった**
ユーザー「①2秒の 演出が 長すぎないか … **こんな演出なかったけど。**」

原因は 1行。かぶせた 1枚（`.capsule`）の `onclick` が「演出ちゅうなら タップで とばす」で、
**「まわす」ボタンの クリックが そこまで バブリングして、押した その 瞬間に 自分で とばして いた。**
→ ボタンの `onclick` で **`e.stopPropagation()`**。ここを 外さない こと。

**なぜ テストで 見つからなかったか**：harness が いつも
`MQ.ui.capsule.pull()` → `MQ.ui.capsule.skip()` と **関数を 直に 呼んで いた**ので、
クリックの バブリングが 一度も おきなかった。
→ **`#capsule:roll` と `#flow` は `$('.capgo').click()` で ほんものの クリックを する**ように 直した
（300ms 後に「ゆれて いる／結果は まだ 出て いない」を 見る）。
**画面の 検査は、関数を 呼ぶのでは なく ボタンを click() する。**

### 期待度で 演出を 変える
ユーザー「**期待度で演出ちょっと変えて下さい。**」

| レアさ | 時間 | 中身 |
|---|---|---|
| ふつう | **1.5秒** | マシンが ゆれる → **オレンジ**の カプセルが ころん |
| レア | **2.1秒** | ゆれが 速く なり **マシンが 金色に 光る＋金の 光の すじ**（0.9秒〜）→ **金**の カプセル |
| げきレア | **2.9秒** | **むらさきの 光の すじ＋カードの わくが むらさきに 光る＋まわりが 暗く なる** → **むらさき**の カプセル |

- **ウソは つかない。** カプセルの 色＝出る ものの レアさ。
  「金が 出たのに ふつうだった」は 作らない（小3を がっかりさせない）。
- 音も 3だんかい（`MQ.sfx.capsuleHot(big)` を 足した。レアは 1.4kHz まで・げきレアは 2.6kHz まで 上がる）。
- **どの だんかいでも タップで すぐ 結果へ**（毎日 引く ものなので）。

**CSS の わな 2つ**（見つけ方＝**演出の とちゅうで 止めて スクショを 撮る**）
1. `.capstage` に `position: relative` が ないと、カプセル（`position: absolute`）が
   カードぜんたいを 基準に して **落ちる 場所が ずれる**。
2. `.capstage` に `z-index: 0` が ないと、光の すじ（`z-index: -1`）が
   **カードの 背景の うしろに 回って 見えなく なる**。
   1回目は これで「ログでは あるのに 画面に 映らない」に なった。

**止めて 撮る 道具**：`MQ.ui.capsule.hold()`（`finish` を 止める）＋ harness `#capsule:roll:<n|r|sr>:shot`。
`freeze()` だけでは **予約ずみの setTimeout は 止まらない**（v7.5 と 同じ 教訓）。
