# v14.17 感想フォーム（2026-09-22）

ユーザー「いろいろな人に まなモンを 渡して いるので、感想を 受け取れる フォームを 作りたい。壁打ち」
→ 3案（A Google フォーム／B アプリから 直接 送る／C メール）→「まかせる・オススメで」＝**A**。

## 決めた こと

- **Google フォーム**（無料・答えは スプレッドシートに 1行ずつ たまる・届いたら メールで 知らせる）。
- アプリは **何も 送らない**。親が おうちの人ページの ボタンで フォームを 開き、「送信」を 押した ときだけ 届く
  （企画書の「データの 外部送信 なし」は そのまま）。
- **学年と アプリの 情報（版・端末・たたかい数・正答率・さいきんの エラー 3件）を 最初から 入れて 開く**（事前入力 URL）。
  **子どもの 名前は 入れない**。情報は 700字まで（URL が 長く なりすぎない ため）。
- 書く 人＝親（子どもの 一言は 親に 聞き書きして もらう 欄を 作る）。名前は **任意**（連絡先も 任意＝返事が ほしい 人だけ）。
- 場所＝おうちの人ページの ホーム（手紙の 下の カード「感想を聞かせてください」）＋設定の「こまったとき・感想を送る」。
  LINE で 送る 文の コピーは のこす。
- 子どもの 画面には 出さない。

## しくみ

- `js/ui/parent.js` の `FEEDBACK_FORM = { url, grade, info }`。**url が からの あいだは ボタンを 出さない**
  （フォームが できる 前に 公開しても 何も 変わらない）。
- `feedbackUrl(p)` → `…/viewform?usp=pp_url&entry.学年=小3&entry.情報=…`。`<a target="_blank">` で 開く
  （ホーム画面の アプリからでも ブラウザで 開く）。
- harness `#fbform`（ホームの カード）`#fbform:set`（設定）`#fbform:none`（url なし＝何も 出ない）。

## フォームの 質問（おすすめ）

タイトル：まなびモンスター 感想フォーム
説明：使ってくださって ありがとうございます。1〜2分で 答えられます。名前は 書かなくても かまいません。

| # | 質問 | 形式 | 必須 |
|---|---|---|---|
| 1 | お子さんの学年 | プルダウン：**小1／小2／小3／小4／小5／小6**／その他（字は この とおりに。アプリが 自動で 選ぶ） | ○ |
| 2 | どのくらい遊んでいますか | ラジオ：ほぼ毎日／週に2〜3回／週に1回くらい／最初だけ・今はあまり | ○ |
| 3 | お子さんが夢中になったところ（いくつでも） | チェック：モンスター集め・図かん／バトル・ひっさつわざ／カプセルマシン／自分の絵がモンスターになる／なかま（相棒）／そうび・アイテム／しゅぎょうば／その他 | |
| 4 | 全体の満足度 | 均等目盛 1〜5（1 いまいち ／ 5 とても満足） | ○ |
| 5 | お友だちや知り合いにすすめたいですか | ラジオ：ぜひすすめたい／たぶん／まだ何とも言えない／すすめない | |
| 6 | お子さんの一言（聞いてみてください） | 段落 | |
| 7 | 気になったところ・むずかしかったところ | 段落 | |
| 8 | 不具合（どの画面で・何をしたら・どうなった） | 段落 | |
| 9 | アプリの情報（自動で入ります・さわらなくてOK） | 段落 | |
| 10 | お名前（ニックネーム可）と連絡先（返事がほしい方だけ） | 記述 | |

設定：
- 「メールアドレスを収集する」＝**収集しない**
- 「回答を 1 回に制限する」＝**オフ**（オンだと Google の ログインが いる）
- 回答タブ →「スプレッドシートにリンク」
- 回答タブ の ⋮ →「新しい回答についてのメール通知を受け取る」

## 事前入力の リンクの とり方（作った あと 1回だけ）

1. フォームの 編集画面の 右上 ⋮ →「事前入力したリンクを取得」
2. 質問1 に「小3」、質問9 に「テスト」と 入れる（ほかは 空で よい）
3. 下の「リンクを取得」→「リンクをコピー」→ Claude に 送る
4. Claude が `entry.〇〇` を 読みとって `FEEDBACK_FORM` に 入れ、`#fbform` で 学年と 情報が 入るのを 確かめて 公開（sw を 上げる）

## のこり

- フォームの URL を もらって 入れる → 公開（お知らせは なし で よい＝子どもの 画面は 変わらない）。
- 配る QR コードの ページ（作業場の `まなびモンスターのQRコード.html`）にも フォームの QR を のせるか（おすすめ）。
