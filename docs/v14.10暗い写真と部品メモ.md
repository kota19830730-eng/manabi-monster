## 実測（息子さんの 4まいを 暗く した 写真で）
| | 紙の ざらつき（thresholds の d） | 線の しん（こい 灰色の 上から 2%） |
|---|---|---|
| 明るい 写真 | 11〜19 | 121〜136 |
| 暗い 写真 1（k .42・ざらつき 7） | 33〜37 | 67〜72 |

→ 線の 決めうち 40 と ざらつきで 線が 消える。色えんぴつの あざやかさも 同じ わりあいで 半分に なる。

## 直した こと（js/ui/photo.js）
1. **prepare()**：ざらつき（auto.d）が `NOISY = 21` を こえる 写真だけ 1-2-1 の ぼかしを かけて しらべ直す（明るい 写真は 何も しない）。build／autoCrop／debugImages が つかう。
2. **線の しきい値**：`LD = max(lineD, min(40, 40 × 線の しん ÷ 120) × inkMul)`。明るい 写真は 40 の まま（**公開中の 版と 画素まで 同じ**を 4体で 確認）。
3. **「線を こく」スライダーが 効く**：`inkMul = 1.4 − inkLv × 0.008`（50＝1倍・100＝0.6倍・0＝1.4倍）。前は 下限 40 に 負けて いた。
4. **色も もどす**：`cf = 線の しん ÷ 120`（0.35〜1）。色みを 1/cf 倍に した qs で 色を 見て、絵の 色も qs から とる。
5. **暗い 写真の 注意**：できあがりの 下に「くらい しゃしんだよ…」＋「もう いちど とる」（`lastDark` ＝ ぼかした か cf < 0.7）。とる ボタンの 下にも ひとこと。
6. **目は どこ？**：きみの 絵の 下の ボタン → できあがりの 絵を タップ → 線の 丸＋白目＋黒目を 描く（もう一度 タップで 消す・4つまで）。「かっこよく」は タップした 丸だけを 目に する（`opt.taps`）。わくを 動かす・写真を かえると 消える。
7. **にせの 大きな 目を 出さない**：coolTrace の 目の 大きさの 上限 5% → `COOL.eyeMax = 0.035`（本物で いちばん 大きい 目は ずかんの あくまの 2.8%）。

### やめた こと（もどさない）
- ぽつんと した 色の 点を 消す → 本の 絵に 白い 穴。
- 灰色の 線の 見分け `s < 14 + d × 0.08` の 14 を cf 倍 → 本の 目・ガイコツの 体が 消えた。

## ゲーム版の 部品（js/content/monstergen.js）
- 絵から 目の 色・もよう を 自動で 読むのは 当たらない（実測：ガイコツの 赤い 目が 灰色・どの 絵も しま 5〜8本）→ **子どもが えらぶ**。
- `PART_LIST`：め 8（おまかせ・1つ・2つ・3つ・大きな 1つ・ねこの め・ひかる め・おこり め）／つの 8（おまかせ・なし・1本・2本・3本・おにの つの・かんむり・みみ）／くち 5（おまかせ・なし・きば・大きな くち・にっこり）／せなか 5（おまかせ・なし・はね・こうもりの はね・トゲ）／しっぽ 3／もよう 4（なし・たてじま・ぶち・おなか）／もちもの 4（なし・けん・たて・つえ）＝**37**。
- 場所は 体の 四角を 48マスに ぬった 形（上の へり・はんい）と EYE_AT／TEETH_AT から 決めるので **85しゅるい どれにも つく**（smoke が 85 × ぜんぶの 部品で はみ出し 0・すがたが かわる を 検査）。
- `setParts / parts / partList`。えらんで いない（おまかせ）ときは いままでと 同じ すがた。
- 画面：組み立ての すがたを えらぶと「パーツを えらぶ」（しゅるいの チップ 1行 ＋ えらびの チップ 1行）。えらんだ パーツは 上の すがた ぜんぶに つく。写真を かえると もどる。
- **ことばの わな**：「しま」は 小3〜で「島」に なる → 「たてじま」。

## デザイン案（designSets）
- 絵から 読める もの（丸の 数＝目・上の でっぱり＝つの・ギザギザ＝きば・よこの 出っぱり＝はね・えんぴつの 黒ぬり＝こうもり）で「絵に ちかい」、そこから「つよそう」（おこり目・おにの つの・きば・けん）「かわいい」（大きな目・みみ・にっこり・おなか）。
- でっぱり 3つ いじょうは つのでは なく せなかの トゲ（ひれ と かさなって ごちゃごちゃ だった）。
- variants() の 先頭に **いちばん 合う 体 2しゅるい × 3案＝6体**（`design`・`label`）。画面は「きみの 絵」の 下に「デザインの あん」。子どもが えらんだ パーツが あれば そちらが かつ。
