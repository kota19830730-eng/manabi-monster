# v12.4 教科書（出版社）えらび（2026-09-11・sw 129）

ユーザー「初期設定とか 転校した 時に 教科書の 出版社の 設定が できると 嬉しい。出版社ごとの 問題も 作成できる？」
→ 「出版社ごとに 別の 問題」では なく **「出版社ごとに 単元の じゅんばんと 時期の 表を 持つ」** を 提案 →「任せる」。

## 1. なぜ「問題」では なく「表」なのか

- ならう 中身（学年ごとの かん字・算数の 単元・理科の 単元）は **国の 学習指導要領で 決まる**ので、どの 出版社も 同じ。
- ちがうのは **じゅんばんと 時期**（東京書籍は 3年の「表とグラフ」が 3学期、日文は 6月 など）。
- この アプリで「学校で ならった ところだけ 出す」を 決めて いるのは v2.6 の 学期の 表（`terms.js`）。
  → 出版社を えらぶ ＝ **その 出版社の 学期の 表に 切りかえる**。問題も ステージ id も 変えない ので ★・記ろく・にげた敵は そのまま。
- 国語の 読みもの（お話・説明文）は 出版社で まったく ちがうが、この アプリは 読みものを 使わない ので 影響なし。

## 2. しくみ

| もの | 場所 |
|---|---|
| 出版社の 一覧と 表 | **`js/content/textbooks.js`（新・`MQ.textbooks`）**。`terms.js` より **前**に 読む（index / sw / harness・smoke が 検査） |
| 表の 見かた | `terms.js` の `stageTerm(stageId, player)`・`unitTerm(player, entry)` が 先に `MQ.textbooks` を 見て、ちがい が なければ 自分の 表（きほん）を 使う |
| セーブ | `p.books = { sansu: 'tokyo', kokugo: 'mitsumura', ... }`（ない 教科は きほん）。`save.js` の migrate が `{}` を 入れる。**学年を 変えても 転校しても のこる**（`setGrade` は さわらない） |
| 画面 | おうちの人ページ →「学校で ならった ところ」の いちばん 上「教科書（出版社）」（`dex.js` の `booksBlock`）。教科ごとに チップ。押すと `MQ.textbooks.setBook` → **その 教科の 単元の ✓（上書き）だけ 消す**（ほかの 教科の ✓は のこす）。感想コピー（`parent.js`）に「教科書 算数 東京書籍」の 1行 |

### 表の 書き方（`textbooks.js`）
- `PUBLISHERS[教科]`＝出版社の 一覧。**いちばん 上が きほん**（＝いままでの `terms.js` の 表 そのもの。算数 日本文教出版・国語 東京書籍・理科 東京書籍・社会 東京書籍・英語 東京書籍）。きほんは 表を 持たない（smoke が 検査）。
- `STAGE[教科][出版社][prefix] = { ステージ番号: 学期 }`＝**きほんと ちがう ところだけ**。書いて ない ステージは きほん。きほんと 同じ 学期を 書くと smoke が 落とす（表が ふくらむ のを 防ぐ）。
- `UNIT[教科][出版社] = { UNITS3 の units[0]: 学期 }`＝小3 リスト教科（国語・理科／・社会／）の 単元。小3 理科社会は 1つの エリア `rikashakai` だが、単元の 文字の 頭「理科／」「社会／」で 出版社を 分ける。
- ローマ字は ステージ（`kokugo3-5`）と 単元（`ローマ字`）の 両方で 決まる ので、**両方に 書く**（光村＝1学期）。
- 英語の 小3・小4は 文部科学省の Let's Try!（どの 学校も 同じ）→ `fromGrade: 5`。小5・小6の 7社も 単元の じゅんばんは ほぼ 同じ ので、いまは 出版社を おぼえる だけ（表は 空）。

## 4. 表の 中身は「目安」（大事）

- 表は 私（Claude）の 記おくに ある 各社の 単元の ならびから 書いた **下書き**。**各社の 年間指導計画（各社の サイトに 公開）や 教科書の 目次と つき合わせては いない。**
- 画面にも「目安です。学校と ちがう ところは 下の 単元を 押して 直してください」と 書いて ある。
- **たしかめ方**：息子さんの 教科書（日文 算数・東書 国語）の 目次の 写真 → きほんの 表を 合わせる。ほかの 社は 各社サイトの「年間指導計画」PDF を 見て `STAGE`／`UNIT` を 直す。
- 教科書は 4年に 1回 変わる（つぎは 2028年ごろ）。そのときは 一覧と 表を 見直す。
- ちがいを 書いて ある ところ：算数（6社 × 小2〜小6）・国語（光村＝ローマ字・修飾語・こそあどが 1学期／教出＝ことわざ 2学期）・理科 小3（風とゴム・電気・重さ）・社会 小3（教出＝消防 2学期）。小1の 算数・国語は どの 社も ほぼ 同じ ので 表なし。

## 5. たしかめ方

- `node tools/smoke.js .`（教科書の 節：読みこみ順・出版社 id の かぶり・きほんは 表なし・ステージ番号が ある・学期 1〜4・きほんと 同じ 学期を 書いて いない・UNITS3 に ある 単元・東書で ぼうグラフが 3学期／長さが 1学期・光村で ローマ字が 開く・大日本で 風とゴムが 閉じる・setBook が その 教科の ✓だけ 消す・学年ごとの 教科・古い セーブ）
- harness **`#books`**（おうちの人ページ：算数＝東書・国語＝光村・1学期。ログ `books chips on:`・**啓林館を click() して 変わるか**）**`#books:map`**（その 地図＝ぼうグラフが「3学期から」・長さが 開く）
- スクショ 520×940・800×1280 で おさまって いる。`#flow` エラー 0。

## 6. やって いない こと

- **地図の ならびは 変えない**（日文の じゅんの まま。閉じた ステージは とばして 番号を つめる＝v2.6 の しくみ）。出版社ごとに 地図を ならべ直すのは 大ごと で、★の 場所も ずれる ので やらない。
- 子どもの 画面には 何も 出ない（おうちの人ページ だけ）。だから news.js には 書いて いない。
- プレイヤーを 作る 画面（子どもが さわる）には 出版社を 置かない。学期と 同じく おうちの人ページで。
