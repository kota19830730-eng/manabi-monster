# v14.19 全学年の「わかりにくい 問題」に 図（2026-09-22〜23）

ユーザー「他にも 全学年で わかりにくい 問題とか あったら 同じように 改善して」（v14.18 の つづき）。

## まず 数えた（全学年 全ステージ）

道具＝scratchpad の survey.js（`MQ.content.worldForGrade(g)` を 1〜6 で まわし、各ステージの 問題を
50回ぶん 作って **問題の 種類**と **図の ついて いる わりあい**、**図が 0の 単元**を 出す）。

分かった こと：

- 図が 0% の ステージは 多いが、その ほとんどは **筆算・九九・小数の 計算**＝**図では 助けに ならない**（メモ欄の ほうが 大事）。
- **図が いるのに 文字だけ**だったのは 次の 4つ。ここだけ 直した。
  | 学年 | 単元 | 前 | 入れた 図 |
  |---|---|---|---|
  | 小2 | とけいと じかん（なんじかん・なんぷん 96種） | 文字だけ | **とけい 2つ**（はじめ → おわり） |
  | 小3 | 時こくと 時間（302種） | 文字だけ | 時こくを もとめる＝**はじめの とけい**／時間を もとめる＝**とけい 2つ** |
  | 小2 | ながさ（cm と mm）・かさ（L と dL） | 文字だけ | **ものさし**（0〜10cm・1mm 目もり）／**1L ます（10dL）** |
  | 小3 | 長さ（道のりと きょり） | 文字だけ | **道の 絵**（道のり＝赤い 点線／きょり＝青い 直線・v14.18 の `roadSvg`） |
  | 小5 | 割合（くらべる量・もとにする量・百分率・割引 170種） | 文字だけ | **二重数直線**（上＝量・下＝割合・わからない ところが「？」） |

## しくみ

- とけい 2つ＝`js/content/sansu1.js` の **`clockPair(text, [h,m], [h,m])`**（`clockHtml` を 2つ＋矢印）。
  小2 は `S1.clockPair`、**小3 は 読みこみ順が 先なので `MQ.sansu1.clockPair` を 関数の 中で よぶ**。
  CSS は `css/style.css` の `.clockq--pair` `.clockpair` `.clockbox--pair`（`--cs` を 0.34〜0.46 に 小さく）。
- ものさし・ます＝`js/content/sansu2.js` の `rulerSvg(mm)`（よこ長・`figwide`）／`cupSvg(dl)`＋`rulerQ`／`cupQ`。
- 二重数直線＝`js/content/sansu5.js` の `rateLineSvg({ base, part, rate, rateText, unit, q })`＋`rateQ`。
  `q` が `part`／`base`／`rate` の どれかで **そこだけ「？」**。
- 図を つけた 問題は **`scratch: false`**（メモ欄を 出さない＝カードが 高く なりすぎない）。

## もどさない・気を つける こと

- **答えの 数字を 図に 書かない。** 時こくを もとめる 問題は **はじめの とけいだけ**（答えの 時こくは 出さない）。
  二重数直線も 聞かれて いる ところは かならず「？」。
- 目もりを 数えれば 出る 図（ものさし・とけい 2つ）は そのままで よい＝**それが この 単元の 学び**。
- **SVG の 文字には `style="font-family: var(--f-body)"`**。つけないと 見出しの 書体（Mochiy Pop One）に なり、
  **「量」の ような 字が □（豆腐）で 出る**（実測）。
- 二重数直線の まん中の 数字は 割合が 0.72 より 右／0.16 より 左だと はしの 数字と かさなる → **1段 上に 書く**。
- ます は いつも「1L ます ＝ 10dL」の ものさし代わり（水の 量では ない）。

## たしかめ方

- harness **`#qfig:<ステージ>[:<単元の 一部>]`**（新）＝その 単元の 問題を 6つ カードで ならべて 見る。
  れい `#qfig:sansu2-7:なんぷん` `#qfig:sansu3-3:時こく` `#qfig:sansu2-4:cm と mm` `#qfig:sansu5-15:割引`
  （単元は `encodeURIComponent` して わたす）。ログに 「図あり N」 が 出る。
- `#fit:all` を 800×1280 と 520×780・`#flow`・smoke ALL OK ×3。

## のこり（やらなかった もの と その わけ）

- **小2 ひょうと グラフ**（598種・図 0%）＝ ○を ならべた 絵グラフが すでに 出て いる（教科書の 絵グラフと 同じ）。
  本物の 棒グラフに するかは 息子さんの 様子を 見てから。
- **小6 ならべ方・組み合わせ**＝樹形図を 出すと **図が 答えそのもの**に なる ので つけない。
- **小4 がい数（四捨五入）**＝数直線を 出すと どちらに 近いかが 見えて しまう（答えが ばれる）。
- 筆算・九九・小数の 計算＝図では なく メモ欄が 助けに なる ので そのまま。
