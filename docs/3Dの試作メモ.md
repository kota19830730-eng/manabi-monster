## 3. しくみ（2つとも 同じ 作り方）

1. **かたち（ぬって ある ところ）を 48マスの 表に する**
   モンスターは `.bx` の 中の 四角から、主人公は 96マスの 絵（Canvas）から。
2. **1行ずつ「つながって いる ところ」を 四角に して、たてに つづく ぶんは まとめる。**
3. その 四角を **箱**に する。**まん中ぞろえ**（手まえと おくに 半分ずつ）。
4. **前の 面には いまの 絵を 切り出して 貼る**（`background-position` でずらす）。
   横・上・うしろの 面は その ところの 絵の 色を こく／明るく した もの。

**厚みの 決め方（大事）**
- 絵ぜんたいの 厚み ＝ かたちの たてよこの **小さい ほう × 0.42**（上限 18）
- 1つの 段の 厚み ＝ **min(はば, 高さ×2.5) × 0.75**（上限＝ぜんたいの 厚み）
- **上下の 行より 大きく はみ出して いる 段（はね・うで・ひれ）は うすく する**
- 主人公は 帯ごと（かみと頭 20／体・うで 13／足 10）＋その 四角より 厚く しない

## 4. 5回 やり直した。**同じ しくじりを くり返さない ための きろく**

| 回 | 何が 起きたか | ほんとうの 原因 | 直し |
|---|---|---|---|
| 1 | 部品が 手まえに 浮いて 見える | **かさなりを 前後の ずれで 表して いた**（1つ 0.5pxずつ 手まえへ）。四角 50この 絵では さいごが **25pxも 前**に 出る | やめた。目・口・かざりは **下に ある 大きな 四角の 表面に 貼る** |
| 2 | ぜんたいが ペラペラ | ①厚みを **小さい ほうの 辺**から 決めて いた（体の 段は よこ長なので うすく なる）②**確認ページの バグ**：CSSの `scale()` は **たてよこだけ 拡大して 奥ゆきを 拡大しない** → 見せて いた 絵が 実物より 2〜3倍 平べったかった | 厚みは **はば**から。表示は **`scale3d()`** |
| 3 | 主人公が「横に 切った 板」の かさなりに 見える | かたちを 1行ずつ 箱に して、**はばが 変わる ところに はば いっぱいの ふた**が ついて いた | ふたは **ほんとうに はみ出して いる ところだけ** |
| 3b | 主人公の かみが「くまで」 | **はば10・高さ2の とんがり**に 頭と 同じ 厚み 40が ついて いた | 四角ごとに **自分より 厚く しない** |
| 4 | モンスターだけ 直らない | **モンスターだけ 作り方が ちがった**（四角 1つ＝箱 1つ）。厚みの 式を いくら 直しても、この 作り方では 部品が 前に 出る | **主人公と 同じ 作り方に そろえた**（かたち ぜんたいを かたまりに する） |
| 5 | 横に のびる **長い 板**（息子さんの スクショ） | 輪かくの **1〜2マスの 段差**に **奥ゆき18の ふた**が ついて いた＝はば2×奥18の 刃 | ふたは **ふちの 4マスだけ・3マス未満の 段には つけない・裏（下）の 面は 作らない**。はね／うでは 体より うすく |

**やり方の 教訓（これが いちばん 大事）**
- **ななめから 見た 絵だけで 判断しない。** 飛び出しは **真横（`rotateY(-90deg)`・`side.html`）**でしか 見えない。
- **1体を 大きく（280px＋）して 4つの 角度**で 見る。小さい 一覧では 見のがす。
- 原因を 当てに いく 前に **数字を 出す**（`dbg` で 箱ごとの はば・高さ・厚み・前後の z）。
  「はば10・高さ2 → 厚み40」の 1行で 原因が 確定した。
- **止めて みる**（ふたの 面だけ 切って 描き直す）と 原因が 1回で 分かる。
- ユーザーは **スクショを 送って くる**。同じ 絵を こちらでも 再現してから 直す。

## 5. のこって いる 弱点（正直に）

- 3Dの ほうは **表面の ざらつき・材質・目の 光**が 消えて 色が 平ら（本物の 面が ついた ぶん、CSSの にせの 陰影を 外した ため）。**あとから 面に 模様を 貼れば もどせる。**
- **細い もの（けん・つの）は 板の まま**。もとの 絵が 2マスなので、立体に しても うすい。
- **うしろ姿は ない**（正面の 絵を のばして いるだけ）。**回すのは ±35度まで**が きれい。
- ずかんの 275体を いっぺんに 3Dに すると 重い → **バトル・タイトル・カプセルだけ 3D、ずかんは 2Dの まま**が 現実的。

## 6. ゲームに 入れる とき（まだ やって いない）

1. `js/core/blocks.js` に `MQ.blocks.box3d(shape, colors, opts)` を 足す（`vox.js` を 移す）。
   **`box()` は そのまま のこす**（ずかん・お知らせ・地図は 2Dの まま）。
2. まず **バトル画面だけ**（`js/ui/battle.js` の てき と `.hero__img`）。
3. CSS：`.arena` に `perspective: 1100px`、絵に `transform-style: preserve-3d`。
   **`scale()` では なく `scale3d()`**（奥ゆきも 拡大する）。
4. 大きさは いま どおり（てき 96〜112px・主人公 84px）。実測で **1体 90この 箱・78ms**。
5. たしかめ：`tools/3d/one.html` で 4角度 → `side.html` で 飛び出し 0 → `#flow` エラー 0 → sw を 上げる。

### 7b. 主人公の 頭の 線（ユーザー「キャラは 頭が 線で 切れてる感じ 修正お願い」・モンスターは「完璧」）

**正体は 2つ**（`better.html#hero` の 箱の 一覧で 数字を 出して 確定）：
1. かみ（z17）／ひたいの 行（z15）／顔（z17）で **箱の 厚みが ちがい、前の 面が 前後に 段**に なって いた
   （うすい 行は 厚み 3 → となりの 0.9倍 → 15）。段の ところが 暗い 線に 見える。
2. かみ・ひたい・顔の はばが **1マスずつ ちがう**（52／50／48）ので 行ごとに 別の 箱に なり、
   1マスの 段差に 暗い ふた（下の 面）が つく＝もう 1本の 線。

**直し（`vox2.js`・主人公＝`uniform` だけ。モンスターの 作り方は さわって いない）**
- 帯の 中は **ぜんぶ 同じ 厚み**（頭 20／体と 足 13。足を 10 に して いた 帯の さかいめの 線も 消えた）。
  はばが ぜんたいの 3割 みまん の もの（かみの とんがり）だけ 自分の はばで（頭と 同じに すると「くまで」）。
- **1マスの ちがいまで 同じ 箱に まとめる**（union）。まとめて できる 1マスの すきまは
  **前の 面の 下じき**（左半分＝左の ふちの 色・右半分＝右の ふちの 色・行ごとの 2×h の Canvas）で うめる。
  → 頭が 本当の 立方体に なった（箱 14 → **7**）。
- **1マスの 段差に ふたを つけない**（明るい／暗い 線に 見える）。これは モンスターにも 効くが 見た目は 変わらない。

### 7c. モンスターの 顔の 線（ユーザー「モンスターの 顔にも 変な 線」）

数字を 出したら **正体は「はみ出す 段は うすく」の ルール**だった：サメオニの ひれの 行（はば 48）は 上下の 行（36）より
大きいので 行ごと うすく なり（z9 → z7）、**顔の ある まん中まで 2px 引っこんで 目の 高さに 線**が 出て いた。

サメオニ＝6／36／6 に 分かれ、顔は z9 で そろった。モンスターも 主人公と 同じ uniform（同じ 厚み・1マスの ちがいは 同じ 箱・すきまは ふちの 色の 下じき）に した。

### 8d. たおれる ときの「首に 顔」（ユーザー「変な 残像。首に 顔が あるような」）
正体＝**箱の 上下の 面を「はみ出した ところだけ」に して いた**ので 頭の 底が あいて いて、
かんせつで 頭を うしろに かたむけると **箱の 中（前の 面の うら＝顔の 裏がわ）が 見えた**。
→ **上下の 面は はば いっぱいに つけて 箱を 閉じる**（`buildBox`。となりに かくれる ぶんは 見えない ので むだは ない。

## 10. たからばこを 3D に ＝ 2026-09-10・`tools/3d/chest3d.js`・harness `#demo3dbattle:chest[:open[:秒]]`・検査 `tools/3d/chest.html#big` / `#mid[:秒]`

ユーザー「**宝箱だけ 2D で 浮いてる から 次は ここから**」。
タイトル（`start.js` の `chest()`＝CSS の div の 絵・はば 74）と バトル（`enemies` の `chest`＝48マスの 平らな 絵）で
作りが ちがって いた ので、3D は **1つの 作り**に そろえた。絵は ゲームの 部品（`MQ.blocks.el`）で 描く。

**しくみ（vox2.js に 足した もの）**
- `fromGroups(groups, opts)`：**部品ごとに 別の .bx** から 箱を 作って 組む。
  たからばこは 同じ 行に ふたと 金貨が ある ので、1つの 絵からは 切り分けられない（`solidBoxes` は 行の 白黒だけ 見る）。
  `fromBx` の 中身を `builder()` に 分けて、両方が 同じ 箱の 作り方（前の 面に 本物の `<i>`・面の 模様・光）を 使う。
- かんせつに **奥ゆき `jz`**（`transform-origin` の 3つめ）。ふたの ちょうつがいは **土台の うしろの 上の へり**（y 20・z −12）。
  `rotateX(+)` で 前が 上に あがる（うでと 同じ 向き。§8 の きまり）。
- `assemble` が 部品ごとの `make`（箱を 作る 関数）を もてる。

**かたち**（48マス・はば 38・奥ゆき 24＝箱らしい ふかさ）：ふた＝2段の 山形（上の 段は 4マス せまい）＋金の ふち＋金の おび 2本＋赤い 宝石（グロー）／

**直した こと（1回で 見つけた）**

## 11. v12 の 動きが 決まった（③④⑤＝おすすめ）＋ オープニング ＋ ダッシュ こうげき ＝ 2026-09-10

ユーザー「**全部オススメでOK。オープニングのアクションを前回みたいな飛び出してくる感じにしたいのと、攻撃の時にモンスターの近くまで早く移動して攻撃するモーションをいれたいけど可能？**」

**決まった こと**
- ③登場＝**1体めと ボスだけ 歩く**（`mo-walk`）。**2体めからは はねて 出る**（`mo-hop`・0.6秒・右から 2回 はねて 着地・あしを ちぢめ はねは ばたばた）。
- ④こうげき＝**0.42秒**。主人公は **てきの 手まえまで 走って（22%）斬って（55%）もどる**（`mo-dash`＝器の `.v3scene` に。`--dash`＝きょり）。
  部品の 動き（ふりかぶり・体・頭・けん）も 0.42秒に そろえ、あしは 走る（`moDashLegA/B`）。
  **きょりは 画面から 測る**：主人公の 器の 右はし → てきの 左はし −8px（けんの ぶん）。ステージの 拡大（`MQ.stage.size().scale`）で 割りもどす。
  実測 218px（520×940・てき 72px）。ゲームでは `renderFoes` の あとに 同じ 式で 入れる。
- ⑤ボスは **くずれ落ちる**（`mo-crumble`・1.1秒＝ぐらっと ゆれ → 前に ひざを つき（体 −48°・あしは 左右に）→ しずんで 消える）。
  ザコは いままでの 横に ばたん（`mo-fall`）。ボスは 大きい ので 横だと 画面から はみ出す。
- **オープニング**（v10.4）は **外の 箱（`.tmob`・`.title__hero`・`.title__chest`）を 動かす ので 中が 3D でも そのまま 効く**。
  足した 3D の 動き：とびこむ あいだ はねを ばたばた・あしを ちぢめる／勇者は 両うでを 上げて 落ちて くる／たからばこは 着地（0.95秒）の あと ふたが ひらく（1.0〜1.7秒）。
  `.title.is-opening` の 下に 書く（motion.css の さいご）。

**harness**：`#demo3d:open[:秒]`（3D に した タイトルの オープニングを 止めて 撮る）／`#demo3dbattle:attack|hop|crumble:<秒>`。
**わな（2つ ふんだ）**：①`freeze()` の あとに `await wait()` を 書くと もどって こない（setTimeout が 死ぬ）→ 同じ tick で 止める。
②`render()` が 予約した「1.75秒後に is-opening を 外す」タイマーは freeze() では 止まらない（予約ずみ）→ **番号で ぜんぶ clearTimeout** してから freeze()。
（`#open` モードは render の 前に freeze() する ので この 問題が ない。3D は render の あとに 作る ので 順が 逆に なる）
