# v13.10 同じ 見た目の まま なめらかに（2026-09-13・claude-f7）

ユーザー「同じクオリティで軽くできるならなめらかになるように軽くしてください」。
**見た目は 1画素も 変えない**（前と あとを 同じ 乱数で 撮って 画素を くらべた）。

## まず 数えた

この PC は Chrome が 30こ いじょう 動いて いて、1コマの 時間は 同じ ものを はかっても 1.6ばい ぶれた。
→ **時間ではなく「描き直し（Paint）の 回数」**を 数えた（PC の 混みぐあいに よらない）。道具は `tools/fxcheck/paintwho.js`。

| たたかいの 画面・何も して いない とき | **100回/秒** | **6回/秒** |
| ほのお ギリ | 217回/秒 | 146回/秒 |

## 犯人と 直し方（ぜんぶ「transform で 動かす」に した）

1. **アイテムボタンの 光沢スイープ（`.btn__shine`）**＝たたかいの あいだ ずっと 1秒に 約95回 描き直し。
   `background-position` を 動かして いた → すじを `::before` に 描いて `transform` で すべらせる。
   前は はば 220% の 絵を くり返して −140%→240%。同じ 見た目に する ため `::before` を 絵 4まいぶん（880%・`background-size: 25%`）に して、
   くり返しの つぎ目まで 同じ 位置に なる ように −30.9091%→−82.7273%（計算は `css/style.css` の コメント）。ほかの ボタン（タイトル・カプセル など）も 同じ しくみ。
2. **カットインの 光の すじ（`.ci__shine`）**＝`background-position`＋`mix-blend-mode: screen`。すじを `::before` にして transform（−80%→18.4615%）。
   **白い 光は screen でも ふつうの かさねでも 同じ 色**に なる ので screen を 外した（screen は うしろを まとめて 描き直す）。
3. **カットイン band の 速さの すじ（`.ci--band .ci__speed`）**＝`background-position`。`::before` を 1くり返し（180px）長く して transform で ずらす。
4. **地図の フィーバーの 光（`.fever::before`）**＝`left` を 動かして いた（毎コマ レイアウトの やり直し）→ transform（自分の はばの 0→400%）。
5. **Canvas（`js/ui/fxcanvas.js`）**：わざの たびに 同じ 大きさの Canvas を 作り直して いた（GPU の 入れものを 取り直す）→ 大きさが 同じ なら そのまま。
   `mesh()` の 作業用の 配列を 使いまわす（ごみ集めの ひっかかりを へらす）。描く 絵は 前と 画素まで 同じ（0画素 ちがい）。CPU の 差は 小さい（いちばん 重い コマが すこし へる）。

## のこした もの（直すと 見た目が 変わる）

- **わざの はじめの ひっかかり**＝カットインの 3D の 主人公（面 約300まい）を はじめて 描く ぶん。面を へらすと 見た目が 変わる ので そのまま。
- 8コンボ〜で バトル画面を 広げる とき（`.arena.is-big`）は 高さを 動かす（0.28秒 レイアウト）。transform に すると 下の 動き方が 変わる ので そのまま。
- タイトルの ひとこと（`tagShine`）は 4.6秒に 1回 すこし 描き直す（1回/秒）。タイトルは claude-4c の 担当なので さわって いない。

## きまり（これから）

- **動かす アニメは `transform` と `opacity` だけ**。`background-position`・`left/top/width/height`・`filter`・`box-shadow`・`clip-path` を keyframes で 動かすと、そこが 毎コマ 描き直しに なる。
  光の すじ・すじの 列は **`::before` に 描いて transform で すべらせる**。
- 足したら `node tools/fxcheck/paintwho.js battle 4 3`（何も して いない たたかい）で **描き直しが 1秒に 10回 いか**か 見る。

## 道具（`tools/fxcheck/`）

- `paintwho.js <モード> [はじめる秒] [はかる秒]`：何が 描き直されて いるか（要素ごとの 回数）。いちばん 役に 立った。
- `ab.js <わざ> <回数> 名前=<ハッシュ>…`：部品を 1つずつ 外して メイン／GPU の いそがしさ・描き直しの 回数を くらべる（dpr 2・800×1280）。
- `trace.js`／`prof.js`：Chrome の トレース・JS の 重い 関数。
- `diff.html?a=&b=`：2まいの 画像の ちがう 画素を 数える。**乱数を 固定して 撮る**（harness に `|js=` で `Math.random` を 種つきに する）と 前と あとを くらべられる。
  前の 版は `git worktree add -f <一時フォルダ> HEAD --detach` で 別に 出して 同じ 道具で 撮る。
