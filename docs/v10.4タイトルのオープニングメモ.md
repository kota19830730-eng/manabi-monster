# v10.4 タイトルの オープニング（みんなが とびこんで くる）（2026-09-07）

ユーザー「タイトル画面に もっと ワクワクする アクションというか 動きとか モーション、派手さが あるのは どう？ 壁打ちしましょう」
→ 5案（A オープニング／B ときどき 事件／C さわると 反応／D 生きた 空／E 勇者と ドラゴンの にらみ合い）
→ おすすめは C＋B＋D の 3点セットと 伝えたが、ユーザー「**とりあえず A だけ お願いします**」。

## できた もの

アプリを ひらいた とき、**1.75秒**で みんなが とびこんで くる。

| 秒 | 何が 起きる | どこ |
|---|---|---|

| .5 | リボンが ポンと 出る（`tOpenPop`） | `.title__tagrow` |
| .35〜1.2 | モンスターが **左から 5体・右から 5体** じゅんばんに ジャンプして 着地（`tOpenJumpL/R`・弧を 描いて 着地で ぺちゃ） | `.tmob--*`（bat robo slime lizard ninja ／ dragon ghost golem magma gold） |
| .55 | 「A」ブロックが 回りながら 落ちる（`tOpenFall`） | `.title__cube` |

| .85〜1.35 | 勇者が 上から 落ちて **着地で ぺちゃっと つぶれて もどる**（`tOpenHero`・linear で 加速は keyframes に 焼きこみ） | `.title__hero` |
| 1.15 | **着地の しゅんかん**：地面が ゆれる（`quake1fx` を 借りる）・足もとに 土ぼこり 6つ（`.title__dust`）・たからばこから コイン 5まい（`.title__fly`）・かみふぶきが 降って くる（`tOpenBits`・margin-top） | `.title__land` ほか |

## しくみ

- **CSS だけで 動く**。JS（`js/ui/start.js` の `attachOpening`）は `.title` に `is-opening` を つけて 1.75秒後に 外すだけ。
  `.title.is-opening .tmob--bat { animation: tOpenJumpL … both }` のように、**opening の あいだだけ bob を 上書き**する。
  `bob` は `translateY(0)` から 始まるので、外れた ときに つぎ目は 出ない。
- **1回の 起動で 1回だけ**（`openedAt`）。地図から「プレイヤー」で もどった ときは 出ない。
- **フォントが 読めて 描き直す とき**（`boot.js` は 起動の すぐ あとに もう一度 `render()` する）は、
  さいしょから やり直さず **つづきから**：`--tshift: -0.3s` を `.title` に つけ、ぜんぶの delay が `calc(.35s + var(--tshift))` に なって いる。
- **タップで とばせる**：`.title` の `pointerdown` で `is-opening` を 外す。ボタンの タップも バブリングして 来るので、ボタンは そのまま 効く。
- **「動きを へらす」の 端末**：`prefers-reduced-motion` は JS で 見て つけない＋CSS の いちばん 上の `* { animation: none }` でも 止まる。
  だから **土ぼこり・コインは ふだん `opacity: 0`** で 置いて ある（アニメが なければ 見えない）。
- **動かすのは transform と opacity だけ**。`filter` に さわると v10.3 の 夕日の ふち（`.title .tmob .bx`）や `.tmob` の 影が 消える（claude-65 の 注意）。
- 音は ない。さいしょの 起動は タップの 前なので WebAudio が 鳴らせない（鳴らす なら 2回め いこうだけに なり、ちぐはぐ）。

## わな（1回 ふんだ）

- **`animation-fill-mode: both` は delay の あいだ 0% の 形で 待つ**。土ぼこりの 0% を `opacity: .95` に して いたら、
  着地の 1秒 前から 足もとに 土の 四角が 出て いた（`#open:0.3` の スクショで 発見）。→ 0% は `opacity: 0`、8% で .95。
  **とびこむ ものは 0% を 画面の 外＋opacity 0 に して おく**（だから 着地前は 何も 見えない）。

## たしかめ方

- harness **`#open[:<秒>]`**（`freeze()` で おわりの setTimeout を 止め、`document.getAnimations()` を <秒> で 止めて 撮る。0.3／0.7／1.0／1.2／1.5 で 5枚）
- **`#open:skip`**（ボタンの `pointerdown` を dispatch → `is-opening` が 外れる）／**`#open:again`**（2秒 あと・2回めの render は 出ない）／**`#open:mid`**（0.3秒で 描き直し → `is-opening` true・`--tshift` -0.3s）
- smoke ALL OK／`#flow` エラー 0（133行）／`#start` の さいごの 形は v10.3 と 同じ／520×780 でも 着地の ゆれが 画面の 中。
- スクショは scratchpad の `open_0.3.png`〜`open_1.5.png`（shoot_open.sh）。
