# v14.20 理科・社会の 図（2026-09-23）

ユーザー「算数以外は 大丈夫？ 社会とか 理科とか」（v14.19 を 公開した あと）。

## まず 数えた

理科・社会・国語・英語の 全ステージを 数えた（scratchpad の survey2.js）。

- **図が あるのは v4.9 で 入れた 39問だけ**（地図記号・八方位・方位じしん・じしゃく・回路・月）。
  それ いがいは **ほぼ 0%**（小3 理社 12〜50%・小4〜小6 の 理科／社会は 0〜8%）。
- ただし **理科・社会の 問題は「ことばを 知って いるか」を 聞く ものが 多い**
  （「110番は どこに つながる？」「リサイクルの いみは？」）。こういう 問題に 絵を つけても かざりに なるだけ。
- **図が 効くのは「ようすを 思いうかべる」問題**＝ 道具・実験・場所の かんけい を 聞く もの。そこだけ 直した。

| **ながれ図**（`flowQ(text, steps)`） | 小4 社会 水・ごみ 2問 | 箱と 矢印。**聞かれて いる ところが 赤い「？」** |

## もどさない・気を つける こと

- **川の 曲がりは S字に しない。** さいしょ S字で 描いたら 外がわ・内がわ が どちらか 読めなかった（実測）。
  1つの 曲がり＋流れの 矢じるしに する。
- 図を 足す ときは **v4.9 の きまり**（答えが 図で ばれる 問題には つけない）を まもる。
- `flowPic` の SVG にも `style="font-family: var(--f-body)"`（見出し書体だと 字が □ に なる）。
- 理科・社会の 問題は リスト（`text:` の 行）なので、図は **`text: MQ.zu.〇〇Q('…')`** の 形で つける。
  問題文は そのまま のこす（id が 変わると 12問かぶりなしが こわれる）。

## のこり

- 社会の「都道府県」は 日本地図が いる（作るのが 重い）ので 見送り。やるなら 地方ごとの かんたんな 形から。
