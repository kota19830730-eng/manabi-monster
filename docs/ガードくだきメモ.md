# ガードくだき（ボスが 子どもの まもりを ねらう）メモ

2026-09-14・claude-f7。ユーザー「ボス系の モンスターは 攻撃して きて ガードや 守りを 壊して くる 要素を 追加したい。壁打ちしましょう」

見せ方は **「主人公の 頭の 上に まもりの アイコン」**（おすすめ どおり）。

## きまり（もどさない）

- ボスの 大わざ（ため 3問に 1回＝`chargeInfo` の attacking・v7.7 / v12.7）が **「ガードくだき」** に なった。ラベルも「大わざ！」→「ガードくだき！」。
- ねらうのは 子どもの まもり：**たて**（`buff.shield`＝2回めに まちがえても にげられない）と **よろい**（`buff.freeze`＝コンボが きれない。時とめ・サポートの コンボ ガードも ここ）。
- **1回めで 正解** … はね返した！ カウンター 2ダメージ（いままでどおり）＋ **たてが 1つ ふえる**（1たたかい 2つまで＝`GB_GAIN_MAX`）。
- **ふつうで まちがえた** … まもりに ヒビが 入る 演出だけ。**へらない**。
- **本気モード（v12.7・子どもが ボスの 前に えらんだ ときだけ）で まちがえた** … まもりが 1つ **ほんとうに こわれる**（たてが 先・なければ よろい）。この たたかいの あいだだけ。
- こわれた まもりは **ボスの 問題に 1回めで 2問 れんぞく 正解すると なおる**（`GB_REPAIR`・けいけんち ＋10＝`GB_REPAIR_XP`・本気は 2ばい）。1回めで まちがえると れんぞくは きれる。
- ふきだしは **先に 本当の ことを 言う**：本気で まもりが ある ときだけ「まちがえると まもりが こわれる」。ふつうは「正解で はね返して カウンター」。
- てきの こうげき なし（おうちの人ページ）・タイムアタック・とっくん・ザコでは おきない。

### 「てきの 行動で 何も うしなわない」（v7.7・v8.1）との かんけい
**ふつうの 子は いままでどおり 何も うしなわない。** こわれるのは 本気モード（えらんだ 子だけ・ごほうび 2ばい）の ときだけで、
この たたかいの あいだ だけ・なおせる。ユーザーが えらんだ 形（2026-09-14）。**ふつうでも こわれる 形に しない。**
