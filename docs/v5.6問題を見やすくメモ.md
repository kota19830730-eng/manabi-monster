# v5.6 問題を 見やすく（2026-09-04）

ユーザーが **実機（Android タブレット）の 写真 2まい**を 出して
「かなり 問題が 見にくくて やる気に ならないから 修正お願い。問題を みやすく 解きやすいように」。

## 写真で 分かった こと

| 写真 | 見えた こと |
|---|---|
| ラスボスの ぼうグラフ | **問題文も グラフも 見えない**。カードに 単元名「かいたい動物（人）」だけ |
| かん字を 書く（ひつじ） | **黒い ふきだしが「きみの 字／おてほん」の 上に かぶさって いる**。下も つまって いる |

## いちばんの 原因：**タブレットは いちばん せまい**

`stage.js` は `scale = min(よこ/400, たて/700)`。タブレットは よこが 広いので
**高さで scale が 決まり、ステージの 高さは 700（＝いちばん 短い）に なる**。
スマホ（たてに 長い）では 866 くらい あるので 気づけなかった。

その 700 の 中で
- `.card`（問題）は `flex: 0 1 auto; min-height: 0; overflow-y: auto`
- `.memo`（メモ欄）は `min-height: 96px` で まもられて いた

→ 場所が 足りないと **まもられて いない カードだけが つぶれ、問題文が 切れた**。
`overflow-y: auto` なので 中で スクロールして いただけで、子どもには 見えない。
プレーンな 「17 ÷ 5 の あまりは？」でも 下半分が 切れて いた。

## 直した こと

### ① むだな 28px を 消した（いちばん 効いた）
`.card__unit` は `<p>` で、**ブラウザ標準の margin（上下 14px ずつ）**が ついて いた。
どの 問題でも 28px を すてて いた。`margin: 0 0 2px` に。

### ② 場所の ゆずりあいの じゅんばんを 決めた
**問題 ＞ キー ＞ ヒント ＞ メモ欄**。
- `.card` … `flex: 0 1 auto; min-height: 62px; max-height: 58%; overflow: hidden`
- `.memo` … `min-height: 96 → 64px`、**ヒントが 出て いる あいだは 34px**（`.has-hint`）
- メモ欄が ない 問題では `.card` が のこりを もらう（`:not(.has-memo)`）
- `.battle__body` の すきま・キーの 高さ・えらぶボタン・ヒント枠を 少しずつ つめた

### ③ 入るまで 自動で 合わせる（`fitPrompt`）
前は **字の 数だけ**で 大きさを 決めて いた（実さいに 入るか 見て いなかった）。
いまは **`card.scrollHeight > card.clientHeight` を はかって、入るまで 段を 下げる**。
- 字：`xl 46 / l 39 / 34 / m 26 / s 21 / xs 17`
- 図：`--figk`（1 → .85 → .7 → .55 → .45）で **ぜんぶの 図が そろって 小さくなる**
  （グラフ・とけい・かたち・見くらべ・数直線）
- それでも 入らない ときだけ `.battle.is-cram` … バトル画面（上）を 30% → 24%、キーを 少し ひくく
- **逆に 場所が あまる ときは 字を 大きくする**（メモ欄の ない 短い 問題は 46px）

### ④ 図の 大きさは「端末の 高さ」ではなく「ステージの 高さ」で
`@media (min-height: 820px)` で とけい・かたちを 大きくして いたが、
**タブレットは 端末 1280px でも ステージは 700px** なので、そこで あふれて いた。
`calc(var(--stage-hn) / 900 …)` に（`--stage-hn` ＝ 単位の ない 高さ。stage.js が 出す）。

### ⑤ 図の ある 問題に メモ欄を つけない を 小3にも
v4.4 で 小4に 決めた きまりが 小4しか 検査されて おらず、
**小3の ぼうグラフ（ボスの「ぜんぶで 何人？」）と 球の 問題が すりぬけて いた**（＝写真1）。
`sansu3.js` の `num()` が **問題文に 図が あれば 自動で `scratch: false`** に する。
smoke は 小1〜小4 ぜんぶを 検査する。

### ⑥ かん字の 見くらべの ふきだしを やめた
「おてほんと くらべてみよう」の 黒い ふきだしが **くらべる 2つの 字の 上に かぶさって いた**（＝写真2）。
言うことは **カードの 中（絵の すぐ 上）**へ。ふきだしは 出さない。

## テスト（tools/harness.html）

- **`#fit` / `#fit:all`** … 小1〜小4の 16ステージを 実さいに 遊んで、
  **1問ごとに「カードから はみ出して いないか」「キーや ヒントが 下で 切れて いないか」**を はかる。
  まちがえて **ヒントを 出した ところ**も 見る（いちばん せまい）。
  → 800×1280（タブレット）・520×780・520×900 の どれでも **190回 しらべて はみ出し 0**。
- `#fitdbg:<ステージ>:<学年>` … カードの 中身の 高さを ぜんぶ 出す（犯人さがし用）。
  ↑ これで `.card__unit` の 28px の margin が 見つかった。

## 気を つける ところ

- **`fitPrompt` は「はかってから 決める」。字の 数だけで 決める 方式に もどさない。**
- **まん中よせ（`justify-content: center`）を カードに つけない。**
  はみ出しが **上**に 出て `scrollHeight` で 気づけなく なる（一度 やって 単元名が 切れた）。
- 図を 足す ときは **`--figk` を かけ算に 入れる**（`calc(… * var(--figk, 1))`）。
  入れ忘れると その 図だけ 小さく ならず、問題文が 切れる。
- 図の 大きさに **`@media (min-height: …)` を つかわない**。`--stage-h` / `--stage-hn` で 決める。
- 直したら **`#fit:all` を 800×1280 と 520×780 の 両方**で 回す。
