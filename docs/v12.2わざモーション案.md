## ① わざごとの 主人公の 動き（3D・部品を 回すだけ・絵は さわらない）

| コンボ | わざ | 主人公の 動き | てきの やられ方 |
|---|---|---|---|
| 5 | ほのお ギリ（算数 fire） | とび上がって 落ちながら たてに 一閃（ジャンプ斬り） | のけぞって 地面に しりもち |
| 5 | はっぱ カッター（国語 leaf） | 体を ひねって 左右に 2連斬り | 左右に 2回 ゆれる |
| 5 | こおりの やいば（理社 ice） | けんを 前に かまえて 突き ぬける | 固まって（動きが 止まる） かたむく |
| 5 | かぜの たつまき（英語 wind） | 空中で けんを ぐるぐる 回す（手首の 回転） | くるっと 回されて ふらつく |
| 8 | いなずま おとし（bolt） | 高く ジャンプ → てきの 真上から 落下斬り。着地で 地面が ゆれる | ビリビリ ふるえる |
| 12 | ひかりの メテオ（star） | しゃがんで ためる → けんを 天に かかげる。落ちて くる 間は 見上げた まま | いん石に おされて ぺしゃんと つぶれる |
| 16 | ぎんがの ビッグバン（nova） | 空中に うかんで 両うでを 広げる → 光が すいこまれる → 落下と 同時に 爆発 | すいこまれて → 大きく ふっとぶ |
| 20 | スターバースト ストライク（starburst） | 高速の 連続 突き ×6（0.1秒ごと）→ さいごに 大きく 一閃 | 突かれる たびに はねる → さいごに ばたん |

**きまり**
- **3D の 体・頭・あしには 背中の 面が ない**（v12.1 で 軽く した ぶん）。体ごと 1回転（rotateY 360）は 作れない。
  回すのは **けん（`p--sword`・背中あり）と 手首だけ**。うでは 170° まで OK（背中あり）。
- 作り方：`css/motion3d.css` に `mo-sp-<id>`（主人公）と `mo-hit-<id>`（てき）を 足し、`battle.js` の こうげきの ところで
  `sp ? 'mo-sp-' + sp.id : 'mo-attack'`、てきは `sp ? 'mo-hit-' + sp.id : 'mo-hurt'`。長さは `sp.ms` に そろえる
  （`play(el, mo, ms)` の 待機もどしは token）。ダッシュ（`mo-dash`＝器を 走らせる）は わざごとに 使う／使わない を 決める
  （メテオ・ビッグバンは その場、いなずまは ジャンプ、スターバーストは ダッシュ）。
- 主人公の 器 `.v3scene` は 84px。ジャンプは `translateY` で 器の 外に 出て よい（`overflow` なし）。
- 音（`MQ.sfx.special`）と 2D の 絵（`buildFx`）は そのまま。**ゆれ・ふっとび・技名・音は へらさない**（息子さん「もっと 派手に」）。

## ② 演出を「主人公と てきが 見える 場所」に よける

- 技名の 帯 `.fxband` を **アリーナの いちばん 下**（問題カードの すぐ 上）へ。主人公と てきに かぶらない。
- 画面ぜんたいの 色の 光（`.fxscreen` の tint）は **アリーナの 中だけ**（問題・テンキーは 光らせない・読める まま）。
- 集中線と 大きな わの 中心を **てきの 位置**に（いまは 画面の まん中・`top 112`）。てきの 中心は `d.cur.getBoundingClientRect()` を stage の scale で 割って 出す。
- カットイン（`cutIn`）は **12コンボ 以上（tier ≥ 3）だけ**。5〜8コンボは 動きで 見せる。合体（相棒と いっしょ）は いままで どおり。
- 演出の 長さ（`sp.ms`）・ゆれ・音は いまの まま。
