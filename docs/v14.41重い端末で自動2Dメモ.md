## しくみ

- **さいしょの 3D の たたかい**（ふつうの ステージ・塔・ごちゃまぜ＝`js/ui/battle.js` の `start`）で
  `MQ.ui.v3.probe()`（`js/ui/three.js`）が 画面の 描きかわる 回数（rAF）を 数える。
- はじめの **6秒は 数えない** → つぎの **3秒** を 数える → **1秒に 25回 みまん**なら
  せってい `v3` を false（つぎの 画面から 2D）＋ お知らせ「うごきを かるく したよ（せっていの「りったい」で もどせるよ）」4.5秒。
- 結果は せってい `v3auto`（`'ok'`／`'2d'`／`'manual'`）と `v3fps`。**1回 決めたら もう はからない**。
- せっていの「りったい」を 手で 押したら `v3auto = 'manual'`（2D を 3D に もどした 子を また 2D に しない）。
- とちゅうで 画面を かくした・たたかいを 出た ときは **決めない**（つぎの たたかいで もう一度）。
- 端末の スペック（コア数・メモリ）では 決めない（iPad は 本当の 値を 出さない）。
- せっていは 端末ごと（プレイヤーごとでは ない）＝重さは 端末の こと なので これで よい。

## なぜ 6秒 まつか（実測）

CDP で CPU を おそく して、本物の 時計で はかった（scratchpad の probecpu.js 方式・800×1280・GPU あり）。

| CPU | 1.2秒後から はかる | 6秒後から はかる |
|---|---|---|
| ×1 | 55 | — |
| ×4（タブレットの まね） | **10〜12 → 2D に なって しまう** | **43〜60 → 3D の まま** |
| ×6 | 2 | 46 |
| ×8 | — | 7.5 → 2D |

たたかいの はじめ 数秒は カットインの 絵づくり（cisnap の pump・約3秒）と 字の よみこみ（fxWarm）で 重い。
**skip を 短く もどさない**（ふつうの タブレットまで 2D に なる）。
