# v14.42 きろくを まもる（2026-10-01）

ユーザー「あと なにか した方が いい こと ある？ 壁打ち」→ コードを 見て 気づいた 穴 →「1 お願いします」。
配った 先で「記録が 消えた」が 起きると いちばん がっかり される、の 予防。

## なにが あぶなかったか

子どもの きろくは ブラウザの 中（localStorage）。ブラウザに「消さないで」と たのんで いなかった。

- **iPhone・iPad**：ホーム画面に 入れずに Safari の タブで あそぶと、しばらく（目安 7日）ひらかない サイトの きろくは 自動で 消される。ホーム画面の アイコンから ひらけば 消えない。
- **Android など**：端末の 空きが へると 消される ことが ある。`navigator.storage.persist()` で たのむと 守られる。

## もどさない こと

- バーを 出すのは **iPhone・iPad の タブだけ**。Android・PC には 出さない（persist で 守る・うるさく しない）。
- バーは 大人の 文（`data-noconv`＋`MQ.text.pause`）。子どもに「消える」と おどさない＝3回 とじたら もう 出さない（おうちの人ページの カードは のこる）。
- はじめての 画面の 1行は **カードの 上**（下だと タブレットで かくれた）。
- ホーム画面に 入れると きろくは べつに なる（Safari の タブ ⇔ アイコン）。うつし方は 設定の 同じ 節に 書いて ある（きろくの ほぞん → きろくを もどす）。
