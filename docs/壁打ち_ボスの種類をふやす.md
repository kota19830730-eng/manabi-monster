# 壁打ち：ボスキャラの 種類を ふやす（2026-09-17・claude 新セッション）

ユーザー「ボスキャラの種類をもう少し増やしたいので壁打ちしましょう」。
**v14.7 で 実装ずみ（sw 171）。** この doc は 壁打ちの きろく。仕様の 正本は `docs/v14.7ボスをふやすメモ.md`。

## 1. まず 実測（いま ボスは 何体・どこで 何回 出るか）

### いまの ボスの 顔ぶれ（enemies.js）

| 役わり | 数 | 中身 |
|---|---|---|
| エリアボス | **5体** | ナンバードラゴン＝竜王（算数）／モジオニ＝青鬼の大将（国語）／メカナイト（理科社会＋理科）／グランドタイタン（社会）／キングスライム（英語） |
| ラスボス（塔） | **6体** | おばけキング（小1）／かいぞくキャプテン（小2）／まおう（小3）／ダークロード（小4）／ブリザードキング（小5）／メイオウハデス（小6） |
| 中ボス（HP2の ザコ） | 8体 | エリアごと 2体（v8.1・ボスでは ない） |

### 問題の 本体：**エリアボスは「エリア id」で 決まり、id は 全学年 共通**

`bossFor(areaId)` は エリアに 1体め の ボスを 返すだけ。エリア id は 小1〜小6 ぜんぶ
`sansu`／`kokugo`／`rika`／`shakai`／`eigo`（world3.js で 確認）。つまり：

- **算数の ステージは 全学年 合計 約90**（小1 11〜12・小2 14・小3 18・小4 15・小5 18・小6 15）。
  ふつうの たたかいは **毎回 さいごに ボスが 出る** ので、算数を あそぶ かぎり
  **ボスは 100% ナンバードラゴン**。小1の 1ステージめも 小6の さいごも 同じ。
- 国語 約26ステージ → ぜんぶ モジオニ。英語 16 → ぜんぶ キングスライム。
  理科（＋小3理社）16 → ぜんぶ メカナイト。社会 12 → ぜんぶ グランドタイタン。
- ★あつめで 同じ ステージを 2〜3回 あそぶ ので、小3の 子が 算数を 1年 あそぶと
  **同じ 竜王を 40〜60回** たおす 計算。
- ごちゃまぜバトルの ボスも フィーバー教科の ボス（= 上の 5体の どれか）。

### 絵の 状態（v14.6 の あと）

- 竜王・青鬼の大将＝**64マス・3D 部品つき**（v14.6 で 作り直し・いちばん 新しい 水準）。
- **メカナイト・キングスライム・グランドタイタンは 48マスの 古い 水準の まま**
  （v14.6 の きっかけは「もじおにも ナンバードラゴンも 弱そう」＝同じ 指摘が いつ 来ても おかしくない）。
- ラスボス 6体も 48マス（ただし 塔は 学年に 1回 なので 出番は 少ない）。

### まとめ：たりないのは「数」より「**同じ 子が 見る 種類**」

ボスは 合計 11体 いるが、**1人の 子（たとえば 小3）が ふだん 見るのは 5体だけ**で、
しかも 教科を 決めたら 毎回 同じ 1体。ザコは rank1→3 で 顔ぶれが 変わるのに、ボスだけ 変わらない。

## 2. 案（6つ）

### 案A（本命）：エリアボスを「序盤・中盤・終盤」で 3体に

ザコの rank1→3 と 同じ しくみ（エリア内の ステージの 位置 0〜1）で ボスも 交代。
- 例（算数）：序盤＝竜王の 子ども「コドラ王子」→ 中盤＝べつの キャラ → 終盤＝**竜王（いまの まま）**。
- 終盤に いまの ボスを のこす ので「いちばん 強いのが 竜王」は くずれない。
- しくみ：`bossFor(areaId, hard)` に むずかしさを わたす（ザコの `pickIds` と 同じ 考え方）。
  図かん・きろく・にげた敵は id ごと なので 自動で ふえる。
- 新しい 絵：**エリアごと 2体 × 5エリア ＝ 10体**（64マス・3D 部品＝v14.6 の 水準）。
  いっぺんには 多い ので **算数・国語から**（ステージ数と あそぶ 回数が いちばん 多い）。
- ついでに：英語・理科・社会を さわる 回で、古い メカナイト・キングスライム・タイタンも
  64マスに 作り直せば 一石二鳥。

### 案B：学年の 色に 合わせて ボスを 変える（低学年／中学年／高学年）

- 小1・小2＝かわいい 系、小5・小6＝やみの 大陸に 合う こわい 系。
- ただし **実測した 痛みは「同じ 子が 同じ ボスを 40〜60回 見る」**で、
  学年で 変えても その 子の 中では 毎回 同じ ボスの まま ＝ 効きが うすい。
- 案A に「学年の 色」を まぜる ことは できる（小5・小6だけ 見た目を やみ寄りに など）。

### 案C：息子さんの モンスターが ボスに なる（お絵かき強化の B案・決定ずみの 道）

- 壁打ち「お絵かきモンスター強化」で **A → D → B ぜんぶ OK** と 決まって いる（B＝これ）。
- じぶんの 絵の モンスターが たまに「ライバル」として ボスの 場所に 出る。
  **絵を 描く コストが ゼロ**（子どもの 絵＋v14.4 の 3D 型ぬき）で、種類は 子どもの 数だけ ふえる。
- 案A と かちあわない（じゅんばんの 問題だけ。いま D＝QR交換 が 先の 予定）。

### 案D：中ボス 8体を ボスに 昇格して ローテーション

- 絵は あるので いちばん 安い。が、中ボスは 同じ たたかいの 中に「HP2の ザコ」として もう 出て いる
  ＝ 同じ 顔が 2回 出て へん。絵も 48マスの 古い 水準。**おすすめしない**。

### 案E：しゅうまつ・イベントの 特別ボス

- v13.16 の しゅうまつ イベントに「まつりの 特別ボス」を 1〜2体（土日だけ 出る）。
- 出番が 少ないぶん スペシャル感は 出るが、ふだんの「毎回 同じ」は 直らない。**あとの おかず**。

### 案F：ボスの 色ちがい・そうびちがい（安い かさまし）

- 王さま形の ような 色がえ＋かんむり・ぶきの さしかえで 1体 → 2〜3体に。
- 安いが、ユーザーは「弱そう」に きびしい（v14.6 の きっかけ）。**単独では おすすめしない**
  （案A の 序盤ボスを「終盤ボスの 子分」に する ときの 手として なら あり）。

## 3. おすすめ

**案A を 本命に、算数・国語から**（新ボス 2体×2エリア＝4体を 先に）。
1. 算数：序盤・中盤の 新ボス 2体（終盤＝竜王）
2. 国語：序盤・中盤の 新ボス 2体（終盤＝青鬼の大将）
3. つぎの 回で 英語・理科・社会（＋古い 3体の 64マス 作り直し）
4. 案C は 予定どおり D（QR交換）の あとの B で（案A と 両立）

やり方は v14.6 と 同じ：Claude Design の キャンバスで 見た目の 案を 出す →
えらんで もらう → `tools/bossart/` に 足して 64マス＋3D 部品 → harness `#boss64` 系で 確認。

## 4. ユーザーの 決定（2026-09-17・AskUserQuestion で 回答）

1. **方向＝案A**（エリアの ボスを 序盤・中盤・終盤の 3体に。終盤＝いまの ボス）
2. **5エリア いっきに**（教科で 分けず、新ボス 10体を まとめて）
3. **古い 3体（メカナイト・キングスライム・グランドタイタン）も 64マスに 作り直す**
