## ④ ごちゃまぜ バトル（`world3.js` の `makeMixStage` ＋ `ui/battle.js`）

- **ねらい**：「国語を やるか どうか」を さいしょに 決めさせない 入口。にがてな 教科が 自然に まざる。
- **入口**：地図の いちばん 下の **むらさきの バー**（`.mixbtn`・4色の ブロック＋「ごちゃまぜ バトル」＋「ぜんぶの 教科が まざる・コイン +1」）。
  あそべる 教科が 2つ いじょう ある ときだけ 出る（`MQ.content.mixOpen(player)`）。ステージ id は **`mix3`** の ように 学年ごと（`findStage` が 返す・`MQ.content.mixStage()`）。
- **中身**（`stage.make`）：
  - ザコ 12体を **あそべる 教科から 同じ 数ずつ**（4教科 → 3体ずつ・5教科 → 3,3,2,2,2・小1・小2 → 6体ずつ）。教科ごとに `make(k)` で やさしい〜むずかしいを もらい、core の `sortByLevel` が 全体を ならべ直す（4/4/4）。
  - 問題には `areaId`・`stageId`（もとの ステージ）・`unit` に 教科名（「算数 ・ 暗算」）・**その 教科の モンスター `enemyId`**（core は `enemyId` が 入って いれば そのまま 使う ように 変えた）。
  - ステージは 教科ごとに「開いて いて ★で とどいて いる」ものから くじ（`mixGroups`）。
  - **ボスは フィーバー教科の ボス**（フィーバーが なければ くじ。`opts.bossArea` → `MQ.battle.start({ mix: true, bossArea })` → `makeBossQuestion` が わたす）。背景も その 教科。
  - たからばこ あり。レアは ゴールデンスライムだけ。にげた敵の リベンジは まざらない（`escaped: []`）。
- **ごほうび**：**★・さいこう記ろく・そうび（★2）・ほしの 一式は つかない**。おわりに **コイン +1**（`summary().mixCoins`）。けいけんち・なかま・ミッション（バトル回数 など）は ふつうどおり。
- **にげた敵は その 問題の 教科に 入る**（`q.areaId` → `addEscaped`）→ その 教科の リベンジ・とっくんに 出る。**とくい・にがては もとの ステージに ためる**（`q.stageId`）。
- **フィーバーの「たたかった 回数」には 数えない**（ごちゃまぜで 国語を さわっても、国語の 森が フィーバーから 外れない）。フィーバーの けいけんち 2ばいも つかない。
- 画面：1問めの 帯「ごちゃまぜ バトル！ ぜんぶの 教科が まざる・ボスは 英語の空・コイン +1」（`.modebanner`）／けっか画面の 見出しは「ごちゃまぜ クリア！」（パーフェクトは そのまま）、`.rs__fever` の 行に「ごちゃまぜ バトル！ ぜんぶの 教科で たたかった コイン +1」／「つぎの ステージへ」は 出ず「マップへ」「もういちど」。

## ⑤ ミッションの 寄せ（`core/missions.js`）

- 「○○で 1かい たたかう」の 教科を **7割の 見こみで フィーバー教科**に（`FEVER_RATE`）。その ときは 文に「（フィーバー）」、**コイン 2まい**（`REWARD_FEVER`・ミッションごとの `m.reward`）。
- ほかの 2枠（かず・わざ）は そのまま。3つ ぜんぶが 苦手教科がらみに なると やらされ感が 出る ので 1枠だけ。
- 地図の ミッションの 行に「コイン +2」が 先に 見える。

## 地図の たての 長さ（タブレット対策）

- フィーバーの 帯を **3行に つめた**（1行め＝星・「フィーバー教科」・教科名・「いく ▶」／2行め＝効果 1行／3行め＝相棒の ふきだし。なかまゲージ 2ばいは ふきだしの 中）。
- **ステージの 高さが 760 みまん（タブレット＝700）では ミッションを たたんで おく**（`missionsPanel`）。ひらけば 見える。スマホ（866〜）は いままでどおり ひらいて いる。
