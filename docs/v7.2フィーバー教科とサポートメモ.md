# v7.2 きょうの フィーバー教科 ＋ 相棒の おねがい ＋ サポート（2026-09-05）

## なぜ 作ったか

ユーザー：「息子が 得意科目（算数）ばかりして 苦手科目（国語・英語）を 積極的に してくれない。
苦手科目も 楽しく 頑張って ほしい」。避ける 理由は「むずかしくて まちがえる」から。
息子さんが いちばん 喜んで いるのは「自分で キャラクターを 作れる ところ」。
**製品として リリースする ので 息子さん専用に せず、どの 子でも 自動で 回る 形に する**（ユーザー指示）。

壁打ちで 出した 6案の うち、ユーザーが えらんだ **①②③** を 実装した。

**やらない こと**：得意科目を ロックする・苦手を やるまで 進めない。
このアプリの 根っこは「ばつを 与えない」なので、**にがてな 教科の ほうが おトクで こわくない** 方向だけ。

## ① きょうの フィーバー教科（`js/core/fever.js`）

- 毎日 1つの 教科が「フィーバー」。**いちばん たたかった 回数が 少ない 教科**（同じ 回数なら **さいきんの 正解率が 低い** 教科、それも 同じなら 日づけの くじ）。
- たたかった 回数は `p.areaPlays['g3:kokugo']`（学年ごと・`applyRewards` で +1。とっくん・塔は 数えない）。
- 正解率は v7.1 の `p.stats.rows`（ステージごとの さいきん 20問）を 教科で 足す。
- 効果（ふつうの たたかいだけ。とっくん・塔・タイムアタックは なし）
  - けいけんち **2ばい**（`core/battle.js` の `gain()` で 1回ごとに ばい → 画面の「+20」も ばいで 出る。ふえた ぶんは `s.feverXp` → `summary().feverBonus`）
  - おわりに **コイン +1**（`summary().feverCoins`）
  - **レアが 出やすい**（`ui/battle.js` `RARE_CHANCE` 0.4 → `RARE_CHANCE_FEVER` 0.8。じぶんの 絵の モンスターも レア枠 なので 出やすく なる＝息子さんの 好きな ところ）
  - **なかまゲージ 2ばい**（`buff.palPlus` を はじめから 1。相棒が いる とき）
- おうちの人ページ「きょうの フィーバー教科」：**おまかせ／教科を えらぶ／なし**（`p.feverPick`＝null／エリア id／'off'）。教科ごとの たたかった 回数・正解率・サポートの 有無も 出す。
- 決めた ものは `p.fever = { day, g, areaId, pick }` に おぼえる。日づけ・学年・えらびが 変わったら 決め直す（`ensure`）。

## ② 相棒の おねがい

- 相棒が いて フィーバーが ある とき、地図の オレンジの 帯に **相棒の 顔＋ふきだし「きょうは 国語の森に 行きたいな！」**（`MQ.fever.palLine`）。
- バトルの 1問めの 帯にも「○○も はりきって いる！ なかまゲージ 2ばい」。

## ③ サポート（にがて・はじめての 教科）

- 教科の さいきんの 正解率が **70% みまん（weak）**、または **まだ 5問 みまん（new）** なら ON（`MQ.fever.level`）。
- 効果（`core/battle.js` の `support`）
  - **やさしい 問題 多め**：ザコを 3体 多く 作って むずかしさ順に ならべ、うしろの 3体を 落とす（12体：4/4/4 → **5/5/2**）。ボスは そのまま lv3。
  - **ヒントが 先に 出る**（`MQ.battle.preHint()`。みちしるべと 同じ 中身：ヒントの 文／えらぶ問題は まちがいを 1つ 消す／ローマ字は さいしょの 2字。ザコだけ・たからばこ と ボスは なし・1問 1回）。
  - **コンボ ガード ×2**（`buff.freeze` に はじめから 2。よろい・時とめと 同じ 道）。
- **大原則は そのまま**：効果は 正解した ときに 出る。答えは 見せない。問題は とばさない。
- 画面の 文言に「にがて」は 出さない（子どもに 貼らない）。帯は「サポート！ やさしく スタート・ヒントつき・コンボ ガード」／はじめての 教科は「はじめての 教科は やさしく スタート！」。おうちの人ページだけ「にがて（サポート中）」。
