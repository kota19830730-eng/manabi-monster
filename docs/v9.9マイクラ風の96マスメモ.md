# v9.9 主人公を 96マスで 描き直す（マイクラ風）

- 日づけ：2026-09-07
- sw：**115**／お知らせ：**v9.9**
- さわった ファイル：`js/core/pixel.js`・`js/content/face.js`・`js/content/hero.js`・`js/content/news.js`・`sw.js`

## 1. ユーザーの ことば（正本）

> **96マスの 描き直しを やって。**
> **目が怖いわ。マイクラ風でお願いします。**

v9.4 で 「96マスで 描き直す（案③）」を 出して 返事まちに なって いた ところへ、
「やって」＋「**でも 目が こわい。マイクラ風で**」が 来た。

**この 2つは 同じ ことを 言って いる。**
返事まちの 試作（scratchpad の `face96.html`）は 96マスの こまかさを
**白目・虹さい・ひとみ・光の 点・まぶた・まつげ・まゆ**に つかって いた。
これは **マイクラでは ない**（アニメ調の 目）。だから こわく 見えた。

→ **96マスに する。ただし ふえた こまかさは「目の 作りこみ」では なく
「マイクラの テクスチャ（平らな 面＋とびとびの ざらつき）」に つかう。**

## 2. なぜ 前の 顔は こわかったか（実測）

いまの 版（v9.4）を 8ばいに して 見て、原因は 3つと わかった。

| # | 原因 | 数字 |
|---|---|---|
| ① | **ひとみに 光の 点**（`mat: 'iris'` → かたまりの 左上に `k += 0.62`） | 白目 100% に 近い 明るさの ガラス玉に 見える |
| ② | **色の さかいめの なめらかな 立体**（±0.20 → ±0.08 の 2だんかい） | 目も 顔も つやつやの プラスチックに 見える |
| ③ | **目が 大きすぎる** | 白目の たかさ 3マス ÷ 顔 16マス ＝ **顔の 19%**。<br>マイクラの Steve は **12%**。じっと 見つめる 顔に なる |

おまけに 口が **赤 `#a5473a` の 4×2 の かたまり**で、大きく 見ると
「口を 開けて 叫んで いる」ように 見えた。

## 3. 直した こと

### ① `js/core/pixel.js` … しあげを マイクラの ことばに 直した

```
FLAT    … 目（白目 white・ひとみ iris）と 口 mouth は **何も しない**
step3   … ゆらぎは -1 / 0 / +1 の **とびとび**。しかも **もとの 1マス（2サブ）ごと**の かたまり
glint   … 金ぞく・金は **ぽつんと 明るい マス**（ななめの すじは やめた）
region  … 同じ ものの 明るい面・くらい面（c と C、h と k）は **1つの かたまり**
立体    … ±0.20/±0.08 の 2だんかい → **ふちの 1サブだけ**（中は 平ら）
```

- **1サブごとの ゆらぎは だめ**。84px では 1サブ＝0.875px なので「網目」に 見える。
  かならず **もとの 1マスごと**（`grain(X >> 1, Y >> 1)`）。
- **`region()` が いる わけ**：ざらつきの かたまり（`k`）に ふちの 明暗が つくと、
  ぬのが 平らでは なく「ぼこぼこ」に 見える。大文字を 小文字に そろえて 同じ かたまりに する。
- rows2 の 層で `palette` が 関数（レインボーの かみ）の ときは **48マスの 座標**を わたす
  （96マスの y を そのまま わたすと 色の 帯が 2ばい 速く 変わる）。

### ② `js/content/face.js` … 96マスの 絵（`rows2`）

いちばん 下（`function pick` の 直前）に 節を 足した。**もとの 48マスの 絵は 1つも 消して いない。**

| 道具 | すること |
|---|---|
| `grid2 / px2 / rect2 / block2 / rows2of / M2` | 96マスに 四角を 置く（48マスの 道具と 同じ 書き方） |
| `up2(rows)` | 48マスの 絵を 2ばいに のばす（かたちは そのまま） |
| `h2(x,y,salt)` | いつも 同じ ばらまき |
| `speckle(g, from, to, rate, salt)` | **もとの 1マスごと**に すこし こい かたまりを ばらまく |
| `jag(g, ch, salt)` | 下がわの ふちを 1サブ 出したり 引っこめたり（毛先の ぎざぎざ） |

作った もの：

- **`headRows2`** … はな は 平らな こい はだ（x46〜49・y30〜32）、
  口は **こい 茶色の ほそい 線**（x45〜50・y36〜37）＋ **はしを 1サブ 上げて わらう**。
- **`bodyRows2`** … ぬのに かたまりの ざらつき（`c`→`k` 14%／`p`→`K` 14%）。
- **め 11しゅるい ぜんぶ**（`eye96` ＋ `EYE96`）…
  白目の たかさ **4サブ＝もとの 2マス＝顔の 12%**（マイクラの わりあい）。
  ふつう／まるめ／たれめ／つりめ／きらきら／にっこり／ねむい／ウインク
  ＋ カプセル限定の ほしのめ／ハートのめ／ねこのめ。
- **かみがた ぜんぶ**（カプセル限定も）… `speckle('h','k',20%)` ＋ `jag('h')`。

### ③ `js/content/hero.js`

- `palettes()` に **`k`（ふく・かみの すこし こい 色）**と **`K`（ズボン）**を 足した。
  こさは **10%**（かみだけ 13%）。**これ いじょう こく すると「よごれ」に 見える。**
- 口の 色 `m` を **`#a5473a`（赤）→ `#6f4234`（こい 茶）**に した。
- `MAT.body` / `MAT.hair` に `k` / `K` を 足した（**色の 文字を 足したら かならず ここにも**）。
- `layersFor()` が `rows2` を わたす（からだ・顔・め・かみ の 4つ）。

## 4. もどしては いけない ところ

- **目に 光の 点・グラデーション・まつげ・虹さいを つけない。**
  試作を 見せて「**目が怖い**」と 言われた 方向。1つでも 入れると もどる。
- **白目の たかさは 4サブ（顔の 12%）まで。** 6サブに すると また 見つめる 顔に なる。
- **口は こい 茶色の ほそい 線。** 赤い かたまりに もどさない。
- **ざらつきは とびとび（3段階）で、もとの 1マスごとの かたまり。**
  なめらかな グラデーション・1サブごとの こまかい ゆらぎ・ななめの すじ に もどさない。
- **`region()`（大文字と 小文字を 同じ かたまりに する）を 消さない。**
  消すと ざらつき 1つ 1つに ふちが ついて ぼこぼこに 見える。
- **48マスの 絵（`rows`）は のこす。** rows2 が ない パーツ（かざり・めがね・そうび）は
  いままで どおり 2ばいに のばして 出る。**1つずつ 置きかえて いける。**

## 5. まだ やって いない こと

- **そうび 30点は 96マスの 絵に して いない**（`rows` を 2ばいに のばして いる）。
  ただし **金ぞく・金の 質感は 新しい しあげ（とびとびの ざらつき＋ぽつんと きらり）で 変わって いる**ので、
  ぱっと 見て 古い ままには 見えない。
  もし 描き直す なら `SHAPER` の もと（BASE＝「てつ」の 一式）を 96マスで 描き直す ことに なる。
- **かざり（アクセ）・めがね**も 48マスの まま（小さい ので 見た目の 差が ほとんど ない）。
- **実機 未確認。**
