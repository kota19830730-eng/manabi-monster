# v9.6 地図と モンスターを HD に（2026-09-07）

ユーザーの ことば：**「マップも モンスターも HD化して ほしいです。できる？」**

v9.4 で 主人公アバターは HD に なった（別セッション）。のこりの 2つを ここで やる。
**分担**：claude-36＝アバター（`pixel.js` / `hero.js`）／こちら＝**モンスター（`blocks.js`）と 地図（`tiles.js`）**。

---

## 1. まず 実測した（ここが 出発点）

「HD化」は 場所ごとに 意味が ちがう。感覚で 直す 前に 測った：

| どこ | 描いて いる もの | いまの こまかさ | ぼやける？ |
|---|---|---|---|
| モンスター 176形 | `blocks.js`（CSS の div） | **1体 へいきん 16.8この 四角** | **ぼやけない**（div は どの 大きさでも くっきり） |
| 地図 | `tiles.js` → canvas | COLS 32 × **SUB 4 ＝ よこ 128点** を 400px に のばす | **1点が 3.1px の 四角**＝いちばん 粗い |

→ **モンスターに 足りないのは「点の 数」では なく「四角 1つの 中の 情報」**。
→ **地図は 素直に 点を ふやせば よい。**

**220体を 描き直す 案は 取らない**（1体 16.8この 四角 × 176形。息子さんの 絵も 崩れる）。

## 2. 地図（`tiles.js`）

### SUB 4 → 12
canvas は **よこ 384点**に なり、画面（400px）と **ほぼ 1:1**。
実測：1点＝**5.1px → 1.70px**（`#hd` が 出す。2px いかが 合格）。

- **`EDGE = SUB/4`**：つみきの ふち（上が 明るく 下が 暗い）の あつさを SUB に 合わせる。
  ここを 1点の まま にすると **v9.2 の 立体感が 消えて 平らに 見える**。
- **`WAVE = SUB*2+3`**：波の すじの 間かくも SUB に 合わせる。
- 描く 時間：**19.5ms（96行）／38.4ms（192行）**。前は 数ms。
  1つの 画面で 1回しか 描かない ので これで よい。

### `texture(v, gx, gy)`＝材質の きめ
ふえた こまかさを **「その 場所が 何で できて いるか」**に つかう。

| 地形 | きめ |
|---|---|
| 草・こい草 | **たてに 8点 のびる 葉すじ**（まばら） |
| 森 | もっと こい 葉すじ（6点） |
| 岩・むらさきの砂 | 2×2 の かくばった まだら ＋ ななめの ひび |
| 砂 | こまかい つぶ |
| 道 | じゃりの つぶ ＋ ときどき 小石 |
| 橋 | よこの 板の 線 |
| 水 | よこに ながれる 波の すじ（2点の 厚み） |

**葉すじは「長く・まばら」。** 1回目は 4点で 多く したら **ざらざらの ノイズ**に 見えた。
`grain()` を つかうので 描き直しても 同じ もよう（ちらつかない）。

**マス目・道・島の 形は 1マスも 変えて いない。**

## 3. モンスター（`blocks.js`）

### 色の キーごとに「材質」を のせる
CSS の グラデーションなので、`.bx` を `transform: scale()` しても **かどが ぼやけない**
＝ **どの 大きさでも HD**（48→96px でも くっきり）。

| キー | 使われて いる 数 | 材質 |
|---|---|---|
| `y`（金）・`s`（鉄） | 391＋13 | **ななめの 光の すじ**（みがいた 金ぞく） |
| `r`（赤）・`e`（水色） | 224＋157 | **左上の まるい ハイライト**（宝石） |
| `w`（白・ほね・歯） | 377 | うすい ななめの つや |
| `m`（マント）・`W`（羽） | 27＋40 | こまかい ななめの おりめ（ぬの） |
| `A/B/C/D`（体） | 1314 | **うすい 面の 光**（上が 明るく 下が 暗い） |

**絵の データ（四角の ならび）は 1つも さわって いない。**

### ずかん（52px）にも のせる
`box()` は `size < 56` で `plain` に なり、いままで ざらつき（NOISE）を 省いて いた。
**材質も 省くと ずかんだけ のっぺり**する ので、実測して 決めた：

```
210体 ならべる … 質感なし 18.4ms → 質感あり 22.4ms（＋4ms）
```

→ **材質は plain でも のせる**。ざらつき（NOISE）は いままで どおり 大きい ときだけ。

### 数字を 強く しすぎない
体（`body`）は 白 .13／黒 .10 まで。強くすると **まるく なって マイクラらしさが 消える**。

---

## 4. もどさない こと

- **地図の SUB を 4 に もどさない**（1点が 3px の 四角に なる）。
  変える ときは **`EDGE` と `WAVE` も SUB から 決まって いる**ことを 見る。
- **草の 葉すじは 長く・まばら**（短く 多いと ノイズに 見える）。
- **モンスターの 材質は CSS の グラデーション**で 描く。
  ビットマップの タイルに すると 大きく した ときに ぼやける。
- **絵の 四角の ならびは さわらない。** 息子さんの 4体と 進化形 12体の 形が
  崩れない ことが 合格ライン（v2.4.1 の「再現性が 低い」に もどさない）。
