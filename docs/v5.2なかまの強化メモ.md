## ① なかまゲージ

**前**：コンボ（れんぞく 正解）が 3の ばいすうの ときに 追い打ち（`hitOn(combo)`）。
まちがえると コンボが 0に もどるので、追い打ちも 遠のいて いた。

**いま**：`s.palGauge` が **正解する たびに 1つ たまる**。3つ たまったら 追い打ちを
出して 0に もどす。**まちがえても へらない**。

なぜ 変えたか：このアプリの 大原則は「ばつを 与えない」（負けは ない・通常バトルに
制限時間は ない）。ゲージが まちがいで 0に もどるのは その きまりから はずれて いた。
がんばった ぶんは かならず 追い打ちに つながる。

- 何問で たまるか … `MQ.pals.gaugeNeed()`（いまは 3）
- いまの ゲージ … `MQ.battle.palGauge()`
- 画面 … 相棒の 名前の 下に **玉 3つ**（`.pal__gauge` / `.pal__dot`）。たまると 金色に 光る。
- `hitOn(combo)` は **のこして ある**（ふるい やりかた。まだ 使う ところが ある）。

## ② なまえを つける

図かん →「なかま」タブ → 相棒の カードの 下の **「なまえを つける」** ボタン。

- **8文字まで**（`MQ.pals.NAME_MAX`）。前後の 空白は とる。
- **からっぽに すると もとの 名前に もどる**。
- **進化しても なまえは のこる**（ドラコ → 進化 → ずっと「ドラちゃん」）。
- つけた なまえは バトルの 相棒の ラベル・追い打ちの 帯・けっか画面・図かんの ならび、
  ぜんぶに 出る（`MQ.pals.info()` の `name` が つけた なまえを かえす。
  もとの 名前は `baseName`、つけたか どうかは `named`）。

息子さんは アプリの 名前（まなびモンスター）を つけた 人 なので、なまえを つけられる
ことが いちばん うれしい ところに なる はず。

## ③ 3回 たおしたら かならず なかまに なりたがる

**前**：たおした とき、つよさで 6〜16%（レア・自分の 絵は 20%）の ぐうぜんだけ。
**いま**：それに くわえて **その モンスターを 3回 たおして いれば かならず 出る**
（`SURE_KILLS = 3`）。「この 子が ほしい」と 思ったら 3回 たおせば 手に 入る。

図かんの「たおした回数」（`p.dex[id]`）を 見る。**この たたかいの ぶんも 数える**ため、
`ui/battle.js` の `applyRewards` で **図かんを ふやす 処理を なかまの 処理より 先**に
うつして ある。

## 追い打ちの 見た目

追い打ちの ときに **金わくの 帯「〇〇の こうげき！」**（`.palbanner`）が 出る。
出て いる あいだ（0.9秒）は 上の ふきだしを 消す（`is-quiet`）ので かさならない。
帯は `.fx` の 中に 置く ので、**つぎの 問題が 出る ときに 消える**（`d.fx.textContent = ''`）。
ふつうは 敵を たおす 演出が 1.5秒 ほど ある ので 最後まで 見える。

## テスト

- `node tools/smoke.js .` … ゲージの 数・なまえ（8文字・からっぽ・進化で のこる）・
  3回で かならず・2回では まだ・もう なかまの ものは 出さない・しょうごう 38。
- harness
  - `#palgauge` … 2問 正解 → まちがえる。ゲージが **へらない** ことを 見る。
  - `#palhit` … 3問め（ゲージが たまった ところ）の **帯**を 撮る。
  - `#palname` … なまえを つけて カード・ならびに 出る ことを 見る。
  - `#pals` `#palbattle` `#palresult` `#palresult2` … v4.3 から ある もの。
- `#flow` エラー 0。

**帯を 撮る ときの コツ**：帯は 0.9秒で 消える タイマーが ついて いて、さらに
つぎの 問題で `.fx` が 空に される。harness は **写しを `.arena` に おいてから
`animation-play-state: paused` で 止めて** 撮って いる。

## さわる ときの ちゅうい

- **ゲージは まちがえても へらさない**。ここを コンボに もどさない（この 版の いちばんの ねらい）。
- **なまえは 進化で 消さない**（`evolveIfReady` が 引きつぐ）。
- **図かんを ふやすのは なかまの 処理より 先**（③が 効かなく なる）。
- 大原則は そのまま：**効果は「正解した とき」だけ**。相棒が 勝手に 敵を たおしたり
  答えを 見せたり しない。

sw.js は **v67**。
