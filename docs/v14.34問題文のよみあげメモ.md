# v14.34 問題文の よみあげ（小2〜小3にも）

## きっかけ
ユーザーとの 壁打ちで「読み上げを 小2〜小3にも」を えらんだ（2026-09-26）。
息子さんは 長い 文を 読みたがらない（[[manabi-son-learning-profile]]）。
これまで 問題文を 声で 読むのは **小1（ひらがなの 問題）と 英語**だけだった。

## しくみ
- `js/core/speech.js` の `forQuestion(q, { readJa, text })`：`readJa` が true で、
  エリアが 算数・理科・社会（`sansu|rika|shakai|rikashakai`）なら 日本語で 読む。
- **読まない もの**
  - 国語（かん字の 読みが そのまま 答えに なる）。読解は 前から ある 🔊 の まま。
  - ローマ字・書き取り（`roma`／`write`）。
  - 漢数字の 読みが 答えに なる 問題（`NO_JA_TEXT`：「読み方」「数字で」「漢数字」・「三万五千」の ような かぎかっこ）。
  - 分数（`.frac`）が 入った 問題（数が ぬけて 意味が かわる）＝ 画面がわが 空を わたす。
  - 短い 問題文（図の ある カードは 20字・ない カードは 14字 みまん）。ねらいは 長い 文章題。
    図の 2択（小2「せいほうけいは どっち？」）に ボタンを 足すと タブレットで 15px はみ出した。
- **読む 文**は 画面がわ（`js/ui/battle.js` の `cardSpeech()`）が カードから とる。
  図・表・とけい・グラフ・そろばん・ひっさん（`svg, table, .clock, .figbox, .graph, .tbl, .soroban, .hissan` など）の 中の 字は 読まない
  （とけいの「1 2 3 … 12」を 読んで しまう ため）。
- **この 子で 読むか**＝`MQ.speech.readJaOn(p)`：`p.readJa` が `auto`（はじめ）なら **学校の 学年が 小3まで**、`on`／`off`。
  おうちの人ページ → 設定 →「問題文の よみあげ」（`dex.js` の `readSection`・「ことばの 表示」の つぎ）。
- 子どもの せっていの「よみあげ」（声 ぜんぶの オン／オフ）が 切って あれば 出ない。声の ない 端末でも 出ない（v5.3 の まま）。
- 「きく」の 光る 時間は 文の 長さに 合わせた（6秒 → 最大 30秒）。

## たしかめ方
- smoke「よみあげ」の 節（読む／国語は 読まない／漢数字／分数（空）／せって いなし／自動は 小3まで）。
- harness **`#readja:<ステージ>:<学年>[:off]`**（にせの 声で ボタンを 押して、読んだ 文を ログに 出す）。
  例：`#readja:sansu3-5:3`（グラフの 問題→ 図の 字は 読まず「いちばん 多いのは どれ？」だけ）、
  `#readja:kokugo3-1:3`（国語＝ボタン なし）、`#readja:sansu3-7:3`（漢数字＝なし）、`#readja:sansu3-2:5`（小5 自動＝なし）。

## のこり
- 実機（Android タブレット・iPad）で 日本語の 声が 入って いるか、読む はやさ（0.9）が ちょうど よいか。
- ÷・× を 声が どう 読むかは 端末しだい（Chrome の 日本語の 声は「わる」「かける」）。
