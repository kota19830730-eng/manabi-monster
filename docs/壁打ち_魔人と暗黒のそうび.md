## 3. ほかの 案（今回 入れなくて よい もの）

1. **のこりの「もらえない 場所」2つは つぎの シリーズの 種**：レベル 30・35・40・45・50 で 1点ずつ（例「おう（王）」シリーズ）／タイムアタックの 記ろく（例「しっぷう」シリーズ）。今回 4つ いっぺんに 作ると 絵が 20点で 2〜3日 かかる ので、まず 2つ。

4. **魔人と 暗黒を「対（つい）」に する**：10点 ぜんぶ そろえると しょうごう「魔と 闇を したがえし 者」。合体わざまでは 作らない（わざが 1たたかい 2回の きまりと ぶつかる）。
5. きたえる（＋5）で 見た目が 変わる案は やらない（v13.15 の 金の 光で 足りて いる）。
