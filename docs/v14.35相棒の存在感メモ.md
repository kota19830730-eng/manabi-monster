# v14.35 相棒の 存在感（大きく・レベルで 強く・しゃべる）

ユーザー「相棒のモンスターの存在意義と存在感があまりないかも。バトル画面でも小さいし、もっと育てたくなり存在感があるようにしたい。壁打ち」
＋「バトル画面も大きくしたし もっと活かしたい」
→ 実測 → 5案（A 大きく／B レベルで 強く／C 押して わざ／D しゃべる／E きずな）→ **ユーザー決定「A＋B＋D」・立ち位置は「主人公の となり」**。

## 1. 数えた こと（出発点）

| | 前 |
|---|---|
| 大きさ | 主人公 84px・てき 72〜96px・ボス 112〜128px に 対して **相棒 40px**・左はし（x6〜46）で 主人公に 半分 かくれる |
| 効きめ（小3 さんすう1・200回） | けいけんち 相棒あり 412 vs なし 376（**+10%**）。追い打ちは 3問 正解ごとに 勝手に 出る＝子どもが 関わる 場面が ない |
| 育ち | Lv10＝8回・Lv20＝31回・Lv30＝71回の たたかい。**レベルは 進化（Lv10・Lv20）にしか 効かない**（Lv5 と Lv9 は 同じ） |
| しゃべる | バトル中は 一言も しゃべらない |

道具（scratchpad）：`palmeas.js`（1回の たたかいで 相棒が した こと）／`palbal.js`（レベルべつの けいけんちと ボスの 勝率）。

## 2. できた もの

### A 大きく・主人公の となり（`js/ui/battle.js` の `PAL_SIZE = 64`・`css/style.css` の いちばん 下「v14.35」）
- 40 → **64px**（主人公の 8わり）。**主人公の 右どなり**（left 132・bottom 62＝同じ 草の 上・z 1）
- 名札（なまえ＋ゲージ）は 足もと（`.pal .pal__tag { left: 6px }`）。セットゲージは 主人公の 足もとに もどした（`.arena.has-pal .setgauge { left: 46px }`）
- 追い打ちの とびだし `palJump` の きょりを 120 → 92px

### B レベルで 目に見えて 強くなる（`js/core/pals.js` の `power(p)`・`PERKS`）
| レベル | ごほうび |
|---|---|
| 5ごと | 追い打ちの けいけんち ＋2（Lv30 で ＋12） |
| **Lv15** | **ゲージが 2つで 追い打ち**（3問 → 2問） |
| **Lv25** | **追い打ちで コンボ ＋1** |

- `power()` が `{ xp, dmg, need, combo }` を かえす。core（`js/core/battle.js`）の `palNeed()` が need を 見る・`palHitNow()` が combo を 足す（コンボは その 前に 数えて ある ので 画面に そのまま 出る）
- **ボスへの ダメージは 変えない**（`PAL_BOSS_MAX = 1`・v12.7 の ボスの 強さ）
- メニューの 相棒カードに **つぎの ごほうび**（`.palnow__perk`「Lv.5：追い打ちの けいけんち ＋2」）＝育てる 目当て
- けっか画面の 相棒の 行に **「強く なった！ 〇〇」**（`.rs__palperk`・`perksBetween(lvBefore, lv)`）

### D しゃべる（`js/ui/battle.js` の `palSay`・`PAL_TALK`）
- 出る とき＝たたかいの はじめ（0.9秒後）・ボス（先制こうげきの あと）・まちがえた とき（**15秒に 1回まで・2回め いこうは 半分**）・ボスを たおした とき
- 口調は 段階で かわる（1＝こども「いっしょに がんばろう！」／2＝げんき「よし、いくぞ！」／3＝たのもしい「まかせておけ！」）
- ふきだしは **相棒の 頭の 上**（`.pal__say`）。右（草の 上）に 出すと てき（とくに ボス 128px）に かかった＝v12.9 で 言われた 形。頭の 上は コンボの 帯と かさなる ので **しゃべる 2秒だけ コンボ・ためゲージを うすく**（`.arena.is-paltalk`）
- 相棒は しゃべる とき ぴょんと はねる（`.pal.is-talk`）。カットイン中は 出さない
- **ルールは 1つも 変えない**（演出だけ）

## 3. 効きめ（実測・`palbal.js`・各400回）

| 相棒 | ふつう 60% 勝率 | 本気 60% 勝率 | けいけんち（ふつう 90%） |
|---|---|---|---|
| なし | 80% | 78% | 381 |
| 1段階 Lv5 | 93% | 93% | 427（+12%） |
| 3段階 Lv20 | 94% | 95% | 550（+44%） |
| 3段階 Lv30 | 95% | 95% | 578（+52%） |

- **ボスの 勝率は ほぼ 変わらない**（Lv5 → Lv30 で 93 → 95%）＝ボスへの ダメージを 変えて いない ため
- けいけんちは 育てるほど ふえる＝**育てる 意味**。Lv30 まで 約71回の たたかい（1日 3回で 約24日）

## 4. もどさない こと
- `PAL_TALK` という 名前（`PAL_LINES` は カットインの せりふで もう ある＝1回 ぶつかって 落ちた）

- ふきだしを 右（てきの ほう）に 出さない
- まちがいの ひとことを 毎回 出さない（うるさい・ばつに 聞こえる）
- 効果は 正解した ときだけ（大原則）
