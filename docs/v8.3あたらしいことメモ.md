## 3. きまり（くずさない）

1. **1つの 版に 3つまで**（多いと 読まない）。1ページ 3つ・「つぎ ▶」で ページ送り。
2. **文は ひらがな ＋ 小1の かん字だけ**（小1の 子も 読む）＋文節スペース。
   みだし 18字・文 62字まで（smoke が 検査）。
3. **絵は ゲームに ある 部品**（モンスター・たからもの・コイン・主人公）。
4. **あそびを 止めない**：× で いつでも とじられる。**1回の 起動で 1回だけ**
   （`shownThisLaunch`）。とじたら `p.seenNews` が いまの 版に なって もう 出ない。
5. **外に 送らない**（端末の 中だけ）。
6. **はじめての 子には 出さない**（`newPlayer` で `seenNews = latest()`。ぜんぶ はじめて なので）。
   古い セーブは `seenNews === null` ＝ **たまった ぶんを まとめて**。

   バグ直しだけの ときは 足さなくて よい（smoke は「こえない」ことだけ 見る）。
3. `node tools/smoke.js .` → `#news` を 撮って 目で 見る。
