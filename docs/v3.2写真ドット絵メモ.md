# v3.2 写真から ドット絵（2026-08-31）

息子さんの 本物の 絵（夜の 室内で とった 4コマの 紙・えんぴつ＋色えんぴつ）を、ゲームの
「じぶんの モンスターを つくる」に そのまま 通したら **ほぼ 何も 出なかった**（点が ぱらぱら。
自動わくは キーボードを えらぶ）。ユーザー「子どもの 意図を 線が 細かろうが 再現しないと いけない」
→ `js/ui/photo.js` の「しらべる 道具」を 作り直した。写真は `写真ドット絵テスト/`（作業場・git の 外）。

## なぜ 出なかったか
1. 「はいけいを 消す」の しきい値が **固定**（明るさの 差 90）→ 暗い 写真の えんぴつ線は 紙と 見なされる
2. 自動わくは「紙でない いちばん 大きな かたまり」→ キーボード
3. 紙の 明るさは 見ていたが **色**は 見ていない → 黄色い 電灯で 紙が 黄色く、色えんぴつが くすむ
4. 1まいの 紙に 4体 → 正方形の わくに 題名・仕切りの 線が 入る

## 作り直した しくみ（photo.js）
| 段階 | 前 | いま |
|---|---|---|
| 紙の 色 | 8×8 の ますごとに 明るさ 1本 | 8×8 の ますごとに **R・G・B**（`paperMap`）。候補は **色みの ない 点**だけ（色えんぴつの 塗りで うまった ますは まわりに 合わせる） |
| 正規化 | なし | **写真を 紙の 色で わって「白い 紙に かいた 色」に**（`normalize`）。暗い 写真・黄色い 電灯・かげ でも 同じ 結果 |
| しきい値 | 固定（スライダー） | **写真ごとに 自動**（`thresholds`：紙らしい 点の 中央値＋ゆらぎ×3。2段階で しぼる）。スライダー「はいけいを 消す」は その 倍率（55＝自動の まま） |
| 紙でない 点 | 明るさ＋色み | 「紙より 暗い」or「色が ある」（`notPaperMask`）＋ ごみ消し ＋ **端から 端まで とどく まっすぐな 線を 消す**（`removeLines`：途切れない・細い・えんぴつ色 の 3条件。仕切り線・罫線。本の へり など 端まで とどかない 直線は 消えない） |
| 絵の 中 | 外から つながる 紙を 背景に | 同じ。ただし **線の すきまを 半径 2 で うめて 見る**（`dilate`）ので、線で 囲まれた 白（ガイコツの 顔）は 絵の 中 |
| 本体だけ | なし | **いちばん 大きな かたまり＋近く（5%）**だけ（`keepMain`）。ふちに かかる 細長い もの・小さな 切れ端・10px 未満の ごみは 外す |
| マスの 色 | 暗ければ 線 | 1マス 36点を **えんぴつ（暗くて ほんとうに 灰色）／色／白っぽい**に 分ける。えんぴつ 3点 いじょう → 黒い 線（うすい 線ほど 少し 明るい 灰色）。ただし 平均に 色が あれば（黄色い 電灯の 下の 水色えんぴつ）その 色の 線。色 3点 いじょう → その 色（`dense`＝白からの 距離 1.7倍 で 色えんぴつの うすさを こく、`vivid`）。細い 色の 線は 少し こく |
| わく | 正方形だけ | **長方形で OK**（右下の つまみで たて・よこ べつべつ）。できあがりは 絵の はんいで 正方形に する。`workCanvas` は 比を たもつ |
| 自動わく | 大きな かたまり | 写真ぜんたいを 正規化 → 紙でない かたまり → **ふちに かかる もの・長くて 細い もの を 外して いちばん 大きな 絵**＋近くの 小さな もの（3%）。となりの 絵は まぜない |
| バトル | 72px | **じぶんの 絵の モンスターは 96px**（`battle.js`・64マスが つぶれない）。写真画面の「バトルでは」も 96px |

ドラッグ中の 作り直しは 1フレーム 1回（`scheduleRefresh`）、指を はなした ときは かならず 作り直す。

## 結果（息子さんの 4体・スライダー初期値の まま）
| | 前 | いま |
|---|---|---|
| スカルホース | 点 51マス | 白い ガイコツ＋赤い 目・黒い 体・オレンジの 馬・青い 水 |
| サメオニ | 点 60マス | 形・目 3つ・歯。水色は 青灰色（黄色い 電灯で 灰色に 写るため） |

自動わく：1体だけの 写真 → その 絵。写真ぜんたい（4コマ）→ スカル＋ABC が 1つに なる（絵が 仕切り線に 触れている ため。わくを 指で 合わせれば OK）。

## のこる 課題
- **自動わく**は 1体だけの 写真なら その 絵を えらぶが、この 4コマの 紙のように 絵と 題名が くっついている・絵が 仕切りの 線に 触れている ときは 題名や となりの 絵まで 入る ことが ある（写真ぜんたい → スカル＋ABC）。**わくを 指で 合わせる（長方形 OK）のが 確実**。本体の 上／下に まるごと ある 小さな かたまりは 題名と 見なして 外す ルールは 入れてある（`cluster` の vtol）
- 4コマの 紙で 題名が 絵に くっついている とき（ずかん）は 題名が 入る → 長方形の わくで 外す か「ドットを 直す」の 消しゴム
- 黄色い 電灯の 下の 水色えんぴつは 青灰色に なる（紙の 色で 割っても 色みが 少ない）
- 色えんぴつの 塗りが うすい ところは 白が まざる（子どもの 塗りの まま）
- 実機（タブレット）の 速さは 未確認（320px で 線さがし 17角度×2 ＋ 正規化。PC では 一瞬）

## v3.5 ゲームふうを「ほかの モンスターと 同じ」に（2026-09-01）
ユーザー「まだ 尊重し過ぎ。**ほかの モンスターと 比べて 違和感の ない ように**」→ ゲームの てき（`monsterart.js`・48×48・

1. **48マス 固定**（バトルの 96px 表示で 1ドット＝2px＝もとの てきと まったく 同じ 大きさ）。こまかさの チップは かくす
2. `unoutline`：**絵の ふちの 黒い 線を 体の 色に**（ゲームに 黒ふちは ない。STYLE_GUIDE）。中の 線（目・口）は のこす
3. `hatchToShade`：**中の 細い えんぴつ線（かげぬり）を 体の 色の こい 面に**（5×5 の 半分 いじょうが 線＝ぬりつぶし は そのまま）

**たしかめ方**：`scratchpad/photo/side.html`（ゲームの てき 3体＋自作 4体を 96px で ならべる。enemies.js を 直に 読む）。

## v3.9 目の 数を「丸さがし」で 読む＋候補に ドクロ頭・はこ（2026-09-01）
ユーザー「スカルホースに ドクロが 乗って ない。サメのは 三つ目。ずかんの あくまは 一つ目で 本の 形。認識できないの？」
→ **子どもは 目を「線で かこんだ 丸」で かく**。そこを 見れば 目の 数は 取れる。

- `loops()`：こい 線（ink）を **半径 1** ふとらせて 切れ目を ふさぎ、外がわから ぬりつぶす。
  たどりつけなかった ところ＝**子どもが かいた 丸**。かたまりに 分けて 大きい じゅんに かえす。
  → 息子さんの 4まいで **目の 数 2／3／1／1**（ぜんぶ 合って いる）。
  **半径を 2 に すると 小さな 丸が つぶれて サメの 3つ目が 1つに なる**（実験ずみ）。1 の まま に する。
- `eyeLoops()`：まるっこい（たてよこ比 0.45〜2.2）・大きすぎない（絵の 0.2〜16%）・すきまが 少ない（0.42以上）・上の ほう（72%より 上）。
- 色の かたまり（`colorSpots`）でも 目を 拾おうと したが、**となりの 色と つながって 数を まちがえる** ので 使わない。
- **ドクロ頭・本（はこ）は 自動では 見わけられなかった**（線が 切れて いて 輪郭が 閉じない）。
  むりに 判定せず、**候補の 中に 入れて 子どもに えらんで もらう**：
  `variants()` は ①いちばん 合う すがた ②**目が 2つなら ドクロ頭**の すがた ③**はこ（本）**の すがた ④つぎに 合う すがた。
  → スカルホースは 2番目に 白い ドクロ顔、ずかんの あくまは はこ が 出る。
- **学び**：自動で 当てられる もの（目の 数・色・たてよこ・つの）と、当てられない もの（何の 生きものか）を 分ける。
  当てられない ものは 候補に して えらばせる。しきい値の 追いこみは 1回 実測 → 1回 直す まで。sw v52。

|---|---|
| `drawParts(cells,N)` | 絵を **色あい（hue）の 山**で かたまりに 分ける（15°の ます 24こ → 山を さがす → 近い 山は 1つに）。かたまりごとに いちばん 大きな つながりを とり、線や 色の ない マスは **いちばん 近い かたまりに くばる**（多点BFS）。かえり値は 左から 右。`core`＝ぬった 色だけ／`mask`＝くばった ぶんも 入れた ぜんぶ |
| `letterOf(part)` | かたまりを 12×16 の マスに して 36文字の おてほんと 見くらべる。**子どもは 字の 中を ぬる ので「ぬった 色の 形＝字の 線」**。だから `core` が あれば 線（`raw`）と、なければ 外の 形（`fill`）と くらべる。点数＝形 0.5＋えんぴつの 線が おてほんの 上に あるか 0.22＋**あなの 数**（A=1・B=2・C=0）0.28 |
| `letterGuess` | 上の 判定を かたまりごとに。**`row`**＝ぬった 色の わくが かさならずに 左から 右へ ならび、たてに 長い（平均 38%・いちばん 高い もの 48% いじょう）→「字が ならんだ 絵」 |
| `riderGuess` | 列ごとの いちばん 上を とり、**まん中あたりより 高い 山**が 1つ（はば 10〜62%・高さ 20%いじょう）で、その **左右に 体が つづく**（12%ずつ）→ 何かが 乗って いる |
| `corners()` → `isBox` | 四すみが 3つ いじょう うまって いれば 本・はこ |

## 候補の じゅんばん（`variants`・8体に ふやした）

1. 字が よこに ならんで いる（`row` かつ 点数 0.5以上） → **字**
2. たて長で 1文字 だけ 強く 出た（0.78以上） → 大きな 1文字
3. 乗って いる（0.62以上） → **馬に のった きし**
4. いちばん 合う すがた → ドクロ頭ちがい → 2ばんめ → のりもの → 3ばんめ → 字 → はこ → のこり

**字と のりものは いつも 候補に 入る**（読みまちがえても 子どもが えらび直せる）。

## もじは 子どもが えらぶ（大事）

写真から **どの 字か を 当てるのは むずかしい**（実測：息子さんの ABC は S・N・N と 出た。
えんぴつの 線が 太くて 中まで こく 写り、字の あなが うまって しまう）。
サメや 本を 字だと 見て しまう ことも あった（→ ならびの 条件で はじいた）。
