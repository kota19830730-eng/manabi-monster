# まなびモンスター

小学生のための「モンスターを集めて進む」学習ゲーム。
問題に正解するとモンスターを倒せて、けいけんち・そうび・たからもの・図鑑が増えていきます。

- 決めたことの中身 … `../docs/v1.2企画書.md`（最新）／`../docs/企画書.md`（最初の版）
- 中の仕組み … `../CLAUDE.md`

## 動かす

`index.html` をダブルクリックすると、パソコンのブラウザで動きます。

タブレットに入れる・ネットなしで動かす（ホーム画面にアイコンを置く）には、
インターネット上に置く必要があります。その手順は、そのときに一緒にやります。

## あそびかた（かんたんに）

1. 名前と 見た目（かみの色・かみがた・はだの色）を えらぶ
2. 地図から ステージを えらぶ。ボスを たおすと たからものが 1つ
3. **★3でクリアすると たからものが 金色に なる**
4. 教科ごとに ★を 8こ あつめると「まなびの かけら」
5. かけら4つで **さいごの塔**が ひらく → ラスボス「まおう」（5教科から5問）

## 問題を ふやす

`js/content/` の 教科ファイルに、同じ形で 足すだけです。

```js
{ stage: 1, unit: 'かん字の読み', text: '「学校」の 読みかたは？',
  choices: ['がっこう', 'がくこう', 'かっこう', 'がくしゃ'],
  note: '学校（がっこう）。', hint: '「がっ」と つまる音。' }
```

- **正解を いちばん 先に** 書きます（画面では 毎回 順番が かわります）
- `choices` は 4つ、ぜんぶ ちがう文字に します
- `note` は 答え合わせのときに 出る 説明（かならず 書く）
- `hint` は まちがえたときに 出ます（なければ 選たくしが 2つ 消えます）
- 各ステージ 10問以上に します（`node tools/smoke.js .` が 検査します）

かん字を書くステージ（国語2）は、上の形で 足すと
「えらぶ問題」と「ゆびで 書く問題」が **自動で 両方 作られます**。

## じぶんの モンスターを ふやす

図かん →「じぶんの モンスターを つくる」→ 紙の絵を 写真に とる →
わくを あわせる → なまえと エリアを えらぶ。
つぎの バトルから ほんとうに 出てきます。写真は 外に 送りません。

## 直したあとに かならず やること

```
node tools/smoke.js .          # 中身のテスト（数回 まわす）
```
`sw.js` の `CACHE_NAME` を 1つ 上げる（そうしないと 古い画面が 出ます）。
